조용한 디자인은 대담한 디자인보다 더 어렵습니다. 절제에는 정밀함이 필요합니다. 지나치게 시끄럽거나 공격적이거나 자극적인 디자인의 개성을 유지하면서 시각적 강도를 낮춥니다. 결과를 일반적인 디자인으로 만들지 않습니다.

---

## 방문자 모드

Persuade + Experience: “quieter”는 더 절제된 팔레트, 여유 있는 여백, 타이포그래피의 공간감을 뜻합니다. 극적인 표현은 줄이되 없애지 않습니다. 관점은 유지합니다.

Operate + Read: “quieter”는 시각적 잡음을 줄이는 것입니다. 배경 포인트를 줄이고 카드의 입체감을 낮추며 색과 모션을 절제합니다. 도구는 과업 속으로 더 완전히 사라져야 합니다.

---

## 현재 상태 평가

무엇이 디자인을 지나치게 강하게 느끼게 하는지 분석합니다.

1. **강도 원인 확인**:
   - **색상 채도**: 지나치게 밝거나 채도가 높음
   - **극단적인 대비**: 고대비 조합이 지나치게 많음
   - **시각적 무게**: 굵고 무거운 요소가 너무 많아 서로 경쟁
   - **애니메이션 과다**: 모션이 너무 많거나 연출이 과장됨
   - **복잡성**: 시각 요소, 패턴, 장식이 너무 많음
   - **크기**: 모든 요소가 크고 강하며 위계가 없음

2. **맥락 이해**:
   - 목적은 무엇인가요?(마케팅, 도구, 읽기 경험)
   - 대상은 누구인가요?(일부 맥락에는 에너지가 필요함)
   - 무엇이 잘 작동하나요?(좋은 아이디어를 버리지 않음)
   - 핵심 메시지는 무엇인가요?(중요한 내용 유지)

코드베이스만으로 이 중 어느 하나라도 분명하지 않으면 추측하지 않습니다. 사용할 수 있다면 Codex의 구조화된 사용자 입력 / 질문 도구로 묻고, 없으면 채팅에서 답을 받은 뒤 계속합니다.

“Quieter”는 세련되고 눈이 편하다는 뜻이지 일반적으로 보이라는 뜻이 아닙니다. 일반적인 조용함은 흰 바탕의 회색 텍스트, 균일한 굵기의 sans 하나, 똑같은 카드 grid처럼 보입니다. 절제에도 관점이 필요합니다.

## 개선 계획

영향을 유지하면서 강도를 낮출 전략을 세웁니다.

- **색상 접근**: 채도를 낮출지 더 절제된 색조로 옮길지
- **위계 접근**: 어떤 요소를 굵게 유지하고(아주 적게), 어떤 요소를 뒤로 물릴지
- **단순화 접근**: 무엇을 완전히 제거할 수 있는지
- **세련도 접근**: 절제로 품질을 어떻게 드러낼지

Subtlety는 정밀함이 필요합니다. 의도 없는 조용함은 일반적인 디자인으로 무너집니다.

## 디자인 절제

다음 영역에서 강도를 체계적으로 줄입니다.

### 색상 절제
- **채도 낮추기**: 완전 채도에서 70~85% 정도로 조정
- **팔레트 부드럽게 만들기**: 밝은 색 대신 채도를 낮춘 색조 사용
- **색 종류 줄이기**: 더 적은 색을 더 신중하게 사용
- **중성색 비중 확대**: 중성색이 더 많은 역할을 하고 색상은 포인트로 사용(10% 규칙)
- **대비 부드럽게**: 중요한 부분에만 고대비 사용
- **색조가 있는 회색**: 순수 회색 대신 따뜻하거나 차가운 색조를 넣어 강하지 않으면서 깊이 추가
- **회색 글자와 색 배경을 함께 쓰지 않음**: 색 바탕의 회색 텍스트는 그 색의 더 어두운 색조나 투명도로 변경

### 시각적 무게 줄이기
- **타이포그래피**: 글꼴 굵기 낮추기(900 → 600, 700 → 500), 필요하면 크기도 줄이기
- **섬세한 위계**: 색상과 굵기 대신 굵기, 크기, 공간으로 위계 구성
- **여백**: 숨 쉴 공간을 늘리고 정보 밀도 낮추기
- **테두리와 선**: 두께와 불투명도를 줄이거나 완전히 제거

### 단순화
- **장식 요소 제거**: 목적에 맞지 않는 gradient, shadow, 패턴, 질감 삭제
- **형태 단순화**: 극단적인 모서리 반경을 줄이고 사용자 지정 모양 단순화
- **레이어 축소**: 가능한 경우 시각 위계를 평탄화
- **효과 정리**: blur, glow, 여러 그림자를 줄이거나 제거

### 모션 감소
- **애니메이션 강도 낮추기**: 이동 거리를 줄임(40px 대신 10~20px), easing을 부드럽게 함
- **장식 애니메이션 제거**: 기능적 모션은 남기고 장식은 제거
- **미묘한 micro-interaction**: 과장된 효과 대신 부드러운 피드백 사용
- **정제된 easing**: 자연스럽고 절제된 모션에 ease-out-quart 사용. bounce / elastic은 금지.
- 명확한 목적이 없는 애니메이션은 완전히 제거할 수 있습니다.

### 구성 절제
- **크기 차이 축소**: 크기 대비를 줄이면 더 차분해짐
- **Grid 정렬**: 벗어난 요소를 체계적인 정렬에 맞춤
- **간격 균형 조정**: 극단적인 간격 차이를 일관된 리듬으로 바꿈

**피할 것**:
- 모든 요소를 같은 크기 / 굵기로 만듦(위계는 여전히 필요)
- 색을 모두 없앰(조용함은 흑백이 아님)
- 개성을 전부 지움(정교한 조정으로 특성 유지)
- 미감을 위해 사용성 희생(기능 요소에는 여전히 분명한 affordance가 필요)
- 모든 요소를 작고 가볍게 만듦(기준점이 일부 필요)

## 품질 검증

절제 후에도 품질을 유지하는지 확인합니다.

- **기능 유지**: 사용자가 과업을 쉽게 완료할 수 있나요?
- **차별성 유지**: 고유한 성격이 남아 있나요, 일반적인 디자인이 됐나요?
- **읽기 개선**: 오래 봐도 글을 편하게 읽을 수 있나요?
- **절제하되 사라지지 않음**: 덜어 낸 뒤에도 관점이 남아 있나요?

결과가 적절하면 최종 점검을 위해 `$impeccable polish`로 넘깁니다.
