# Craft (더 이상 사용하지 않는 별칭)

`craft`는 새로운 시각 작업을 시작하는 일반 요청의 폐기된 별칭입니다. 별도의 설정, 인터뷰, 체크포인트, 도구, 품질 동작을 추가하지 않습니다. SKILL.md의 일반 라우팅을 적용합니다. PRODUCT.md가 없으면 [init.md](init.md)로 만들고, 시각적 권위, 세계관, 화면 결정, 구현, 마무리는 [new-work.md](new-work.md)를 따릅니다.

사용자에게 `craft`를 호출해야 한다고 말하지 마세요. “이 기능을 만들어 줘”, “랜딩 페이지를 만들어 줘”, “이 화면을 재설계해 줘” 같은 자연스러운 요청도 같은 절차를 사용합니다.
