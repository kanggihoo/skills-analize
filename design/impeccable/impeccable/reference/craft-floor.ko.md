# Craft 품질 하한선

방향을 확정한 뒤 이 내용을 읽고, 점검표를 알리지 않은 채 구현합니다. 고정된 브리프나 이미 합의된 시각 세계는 여기의 지침보다 우선합니다. 단, 금지라고 표시한 항목은 예외입니다. 자신의 습관을 기준으로 판단하지 않습니다. 디자인 hook이 활성화되어 있으면 수정 중 기계적인 검사를 이미 수행하므로 각 규칙을 다시 감사하지 말고 탐지 결과에 대응합니다.

## 확인

각 항목은 의도가 아니라 실제 구현 결과를 확인합니다. 스크린샷을 별도로 여러 번 찍지 말고 렌더링을 함께 검토하는 묶음에서 모든 검사를 합니다. 검사는 같은 렌더링 결과를 공유합니다.

- **대비**: 본문과 placeholder 텍스트는 4.5:1 이상, 큰 텍스트는 3:1 이상이어야 합니다. 색이 있는 surface의 보조 텍스트는 그 색조나 전경색에서 파생합니다. 회색을 쓰지 않습니다.
- **깊이**: 그림자에는 offset과 부드러운 blur가 있어야 합니다. offset이 0인 컬러 후광은 장식입니다.
- **간격**: 가까운 요소는 모으고 그룹 사이에는 넉넉한 간격을 둡니다. 제목 위 공간을 아래보다 넓게 둡니다. 계산된 값을 읽어 확인합니다.
- **타이포그래피**: 본문 줄 길이는 65~75ch, 디스플레이 크기는 최대 6rem, 자간의 하한은 -0.04em, 제목은 균형 있게 구성하고 크기와 굵기의 단계는 분명해야 합니다. 모든 중단점에서 실제 문구를 실행해 넘치는 부분을 고칩니다.
- **모션**: 흩어진 효과나 모든 섹션에 똑같이 적용한 등장 효과가 아니라, 연출된 순간 하나를 만듭니다. 기본 상태에서 이미 보이던 요소를 exponential ease-out으로 움직입니다. 움직임 표현은 transform과 opacity에 한정하지 않습니다. blur, backdrop-filter, clip-path, mask, shadow도 매끄럽게 실행된다면 선택할 수 있습니다.
- **상태**: hover, disabled, loading, error, empty를 확인합니다. 실제 콘텐츠, 작동하는 컨트롤, 반응형 구성, 키보드 초점도 확인합니다.
- **브라우저 표면**: 직접 그리지 않은 부분도 디자인에 영향을 줍니다. 텍스트 선택, caret, 사용자 지정 scrollbar, focus ring, 밑줄 offset, 표의 숫자는 브라우저 기본값으로 제공되며 디자인 시스템과 무관합니다. 팔레트에 맞게 스타일링합니다. 페이지를 조립한 것이 아니라 만들었다는 가장 손쉬운 증거이며, 모델이 가장 자주 빠뜨리는 부분입니다.
- **문구**: 제품 고유의 언어를 사용합니다. 컨트롤 이름은 동작을 설명하고 오류는 문제와 복구 방법을 알려야 합니다.
- **요구사항 적용 범위**: 브리프의 모든 요구사항을 포함하고 사용자가 몇 초 안에 찾을 수 있어야 합니다.

## 거부할 기본값

아래 항목은 범주에서 흔히 쓰는 기본값이지 절대 금지사항은 아닙니다. 브리프에 명시된 내용은 어떤 항목이든 사용할 근거가 될 수 있습니다. 선택할 수 있는 요소에서 이런 것을 무심코 사용하면 디자인 결정을 내리지 않은 것입니다. 이를 알아차렸다면 요소를 약하게 만드는 대신 다시 작성합니다.

페이지 골격:

- 페이지 구조 전체를 같은 크기의 아이콘 + 제목 + 텍스트 카드로 채우기. 카드는 손쉬운 컨테이너이며 카드 안에 카드를 겹쳐 넣는 것은 항상 잘못입니다.
- hero 숫자 템플릿: 큰 숫자, 작은 레이블, 보조 수치, 포인트 색상.
- 제목 위 kicker나 eyebrow. 이 항목은 기본값이 아니라 금지입니다. 어떤 브리프도 이를 되살릴 수 없습니다. 제목 자체에 무게가 있으므로 레이블을 지우고 제목이 말하게 합니다.
- 독자에게 필요한 정보가 없는 한 섹션 번호(01 / 02 / 03).
- 중단이나 보호된 초점이 필요 없는 작업에 modal 사용.

표면 표현 습관:

- 그라데이션 텍스트. 굵기나 크기로 강조합니다.
- 구체적인 효과가 아니라 장식 목적으로 쓰는 glass와 blur.
- 카드, 목록 항목, callout, 경고 상자에 1px를 넘는 색상 `border-left` 또는 `border-right` 추가.
- 실제 neobrutalist 시각 세계가 아닌데 단단한 offset 그림자(`box-shadow: 4px 4px 0`) 사용. blur 없는 블록 그림자는 깊이 시스템이 아니라 의상입니다. 해당 세계가 선택하지 않았다면 기본값으로 쓰면 안 됩니다.
- 콘텐츠를 대신하는 sparkline, 진행 ring, 부드러운 그림자와 둥근 사각형.
- 코드, 데이터, 측정이 아닌데 “기술적”으로 보이려고 monospace 사용.
- 자체 시각 세계를 가진 페이지의 디스플레이 목소리로 시스템 기본 글꼴(Impact, Arial Black, 플랫폼 sans) 사용. 승인된 글자 형태에 맞는 글꼴을 구해 직접 호스팅합니다. 설치된 글꼴 중 가장 가까운 것을 대체 글꼴로 쓰는 것도 실패입니다.
- 아이콘 시스템 대신 Unicode glyph나 emoji 사용. 아이콘은 실제 라이브러리나 직접 작성한 SVG를 사용하고 일관된 선과 굵기를 유지합니다.
- 유기적인 윤곽 대신 기하학적 mask 사용. 원, 다각형, radial-gradient cutout으로 사진 대상의 가장자리를 흉내 내면 효과의 값싼 버전처럼 보여서 생략하는 것보다 못합니다. 실제 이미지에서 alpha matte를 만들거나 cut-out 에셋을 준비합니다.
- 용도와 상관없이 범주만 보고 밝거나 어두운 테마 선택. 사용 장소, 사람, 주변 조명에 맞춰 정합니다.

- 자간은 -0.04em까지만 줄입니다. -0.02~-0.03em이 대체로 더 자연스럽습니다.
- 높이 표현은 border 또는 shadow 중 하나만 선언합니다. 폭넓고 부드러운 그림자 아래의 1px 테두리는 유령 카드처럼 보입니다. 카드의 모서리 반경은 12~16px로 유지합니다. pill은 작은 컨트롤에만 사용합니다.
- 실제 일러스트를 사용하거나 사용하지 않습니다. 스케치 스타일 SVG 장면, `loose-sketch` / `doodle` 클래스 이름, `feTurbulence` grain은 아마추어처럼 보입니다. 이 금지는 그림을 흉내 내는 SVG에만 적용되며 기하학 표현은 해당되지 않습니다. 선명한 벡터 도형, 다이어그램, 애니메이션 선, shader 기반 효과는 여전히 주요 매체입니다. 음영, 원근, 인물이 들어간 일러스트는 선화라도 그림입니다. 기하학이란 한 세션에서 정확히 지정할 수 있는 도형을 말합니다.
- 배경은 surface입니다. 질감을 넣는다면 대상 세계에 근거해야 합니다. `repeating-linear-gradient` 줄무늬나 가로·세로 grid overlay는 실제 캔버스, 지도, 설계도, 측정 도구가 바탕에 있어야 합니다.
- 주장과 설정값은 제공된 사실에서 가져오고 예시 값은 예시라고 분명히 표시합니다. 개념을 이름 붙인 다음 비꼬는 것은 사실 주장과 다릅니다.

이 기준은 구현의 기본 조건을 지키지만 디자인 방향을 대신 정하지 않습니다. 모든 검사에 문제가 없다면 합의된 시각 세계에 페이지를 맡기고, 다듬기와 확신 있는 표현 사이에서 망설일 때는 확신 있는 쪽을 선택합니다.
