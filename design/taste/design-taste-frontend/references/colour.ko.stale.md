# 색상

방향성 시트는 역할 이름이 붙은 팔레트를 다룹니다. 이 문서는 색을 얹은 듯한 페이지가 아니라 확고한 방향을 가진 페이지로 보이도록 팔레트를 적용하는 방법을 설명합니다.

## 1. 조사에서 확인한 내용

- 조사한 페이지의 41%는 어둡고 59%는 밝습니다. 4분의 1은 순백색, 12%는 순수한 검정 바탕입니다.
- 패널에서 분류한 색상 구성은 단색 + 강조색 하나 23%, 밝은 중립색 22%, 어두운 중립색 14%, 여러 단색 사용 13%, 엄격한 투톤 12%, 사진이 색을 담당 9%, 채도 높은 색상 면 하나 6%였습니다.
- 사이트의 52%에서 버튼은 중립색(검정, 흰색, 회색)입니다. 버튼에 색을 입히는 것은 선택이지 필수가 아닙니다.
- 상위 점수 사이트의 22%와 낮은 점수 사이트의 52%에서 그라데이션 채우기를 사용했습니다. 그라데이션 텍스트는 각각 2%와 13%였습니다.
- 246개 사이트 중 기본 버튼이 테라코타색인 곳은 하나이고 보라색인 곳은 없습니다. 그런 색상은 갤러리의 페이지가 아니라 생성된 페이지의 전형입니다. 따뜻한 미색 바탕은 실제로 나타났지만(32개 사이트), 거의 항상 오렌지 강조색 대신 어두운 잉크색이나 녹색과 함께 사용됐습니다.
- 상위 점수 사이트는 섹션 사이에서 페이지 바탕색을 더 자주 바꿨습니다(섹션별 바탕색 중앙값은 2개, 다른 사이트는 1개).

## 2. 역할

```css
:root {
  --bg: …;          /* the ground: most of the surface */
  --surface: …;     /* one tone step from the ground: filled panels, form fields, tiles */
  --ink: …;         /* main text and the strongest marks */
  --muted: …;       /* secondary text; still passes contrast on --bg */
  --accent: …;      /* the one accent */
  --accent-ink: …;  /* text on the accent */
  /* --field-1 … --field-n and their inks, when the palette has section fields */
}
```

구현에서는 모든 색상에 토큰을 사용합니다. 컴포넌트에 원시 hex 값을 쓰면 두 번째 팔레트를 시작하는 셈입니다. 역할 사이에 회색을 추가하지 않습니다. 텍스트를 더 차분하게 만들고 싶으면 `--muted`를, 표면을 낮추고 싶으면 `--surface`를 사용합니다.

## 3. 비율

색을 지정하기 전에 비율을 정하고 스크린샷에서 확인합니다.

- **바탕:** 페이지의 70–90%.
- **잉크:** 텍스트와 경우에 따라 반전된 섹션 하나(잉크를 바탕으로, 바탕색을 글자로 사용).
- **강조색:** 화면 전체에서 5% 미만. 행동을 표시하고 많아도 반복 요소 하나에만 사용합니다. 다섯 곳에 등장하는 순간 강조 의미가 사라집니다.

색상 면을 사용하는 팔레트(단색이 강한 구성, 파스텔)는 다르게 다룹니다. 섹션마다 색상 면 하나를 전체 농도로 사용하고 비율 규칙은 각 섹션 안에서 적용합니다(색상 면, 그 안의 잉크, 다른 요소 없음).

방향성 시트에서 지정하지 않았다면 강조색을 제목, 아이콘, 글머리 기호, 테두리, 밑줄에 쓰지 않습니다. 제목은 잉크색으로 표시합니다.

## 4. 선이나 그림자 없이 표면 구분하기

선과 그림자를 금지한 경우 표면은 명도 차이만으로 바탕과 구분합니다.

```css
.panel { background: var(--surface); }          /* 2–6 lightness points from --bg */
.field { background: var(--surface); border: 0; } /* inputs: filled, with a clear focus state */
.field:focus-visible { outline: 2px solid var(--accent); outline-offset: 2px; }
```


- 한 단계 차이로 충분합니다. 패널이 구분되지 않으면 두 번째 색을 추가하기 전에 padding을 늘리거나 공간으로 분리합니다.
- 패널 안에 패널을 중첩하지 않습니다.
- 이미지에는 프레임이 필요하지 않습니다. 밝은 사진이 밝은 바탕에 섞이면 윤곽을 두르지 말고 자르기를 바꾸거나 `--surface`에 배치합니다.
- 잉크색이나 강조색으로 그은 두꺼운 막대(4px 이상)는 그래픽 요소이므로 방향에서 허용하는 경우 사용할 수 있습니다. 1px 선은 허용되지 않습니다.

## 5. 색상 면

섹션 전체의 바탕색을 바꾸는 것은 가장 강한 색상 표현이며 구분선, 카드, 배경 장식을 한꺼번에 대체합니다.

- 면과 면은 페이드 없이 경계가 맞닿습니다.
- 모든 면에는 팔레트에 지정된 잉크색이 있습니다. 색상 면 위에는 `--muted`를 사용하지 않습니다. 해당 면의 잉크를 전체 농도로 사용하거나, 보조 텍스트에 70% 불투명도를 적용하되 대비를 통과하는지 확인합니다.
- 인접한 색상 면은 색조뿐 아니라 명도도 달라야 합니다. 그래야 화면이 진동하듯 보이지 않습니다.
- 장처럼 순서를 잡습니다. 강하게 시작하고, 쉬어 가고, 변화를 주고, 어둡거나 아주 밝게 마무리합니다.
- 페이지의 메타 테마 색상과 내비게이션은 첫 번째 면의 색상을 따릅니다.

## 6. 어두운 페이지

- 루트에 `color-scheme: dark`를 설정해 폼 컨트롤과 스크롤바도 어두운 테마를 따르게 합니다.
- 바탕은 팔레트 색조가 살짝 감도는 짙은 색, 잉크는 부드러운 밝은 색으로 합니다. 대비가 강한 투톤 방향이 정확히 `#fff`와 `#000`을 요구하는 경우가 아니라면 흰색과 검정을 그대로 맞대지 않습니다.
- 어두운 페이지에서 문제는 보조 텍스트에서 자주 생깁니다. `--muted`와 바탕의 대비를 확인합니다(4.5:1).
- 어두운 테마의 깊이감은 빛 번짐이 아니라 더 밝은 표면 단계로 표현합니다.
- 밝은 페이지에서 쓸 글꼴보다 더 가는 굵기를 사용합니다.

## 7. 색상과 사진

- 사진이 색을 담당한다면 UI는 중립적으로 유지하고 이미지에서 가장 어두운 색조를 잉크색으로 사용합니다.
- 사진을 브랜드 색상으로 씻어내듯 덮지 않습니다. 사진은 그대로 두거나 페이지의 모든 이미지에 동일한 처리를 적용합니다(전부 흑백 또는 전부 원본).
- 사진 위에 텍스트를 놓으려면 안정적으로 읽힐 영역이 있어야 합니다. 그런 영역이 없다면 텍스트를 이미지 밖으로 옮깁니다. 검사기에서 허용하는 유일한 그라데이션은 중립색 스크림(검정 또는 잉크색, 불투명도 30–55%, 단색 또는 텍스트가 있는 영역만 페이드)입니다.
- 사진에서 추출한 평평한 색상 면(하늘이나 그림자 색 등)은 섹션을 사진과 어울리게 만듭니다.

## 8. 대비

- 본문 텍스트는 4.5:1 이상, 디스플레이 글꼴과 큰 숫자는 3:1 이상이어야 합니다. 이 팔레트는 잉크와 바탕의 대비를 7:1로 맞춥니다.
- `inspect.mjs`는 단색 바탕 위의 텍스트 대비를 계산하고 2.6:1 미만이면 실패 처리합니다. 사진 위 텍스트는 검사할 수 없으므로 스크린샷에서 직접 확인합니다.
- 결과 대비를 확인하지 않은 채 텍스트 opacity를 낮춰 “부드럽게” 만들지 않습니다.
- 포커스와 호버 상태는 대비를 높여야 하며 낮춰서는 안 됩니다.

## 9. 금지된 색상군과 여기서 말하는 “따뜻함”

검사기는 다음을 실패로 처리합니다.

- **크림색과 테라코타색 조합.** 노란 기가 도는 크림색 바탕(대략 색조 22–62, 밝고 채도가 눈에 띄게 높음)에 녹슨색, 클레이 또는 번트 오렌지 강조색을 함께 씁니다. AI 도우미와 그들이 생성하는 페이지의 전형적인 스타일입니다. 어느 한쪽만 사용해도 의심스러우며 함께 쓰면 확연하게 드러납니다.
- **보라색과 인디고색.** 초기 생성 페이지가 보라색 위주였고, 지금도 그렇게 읽힙니다.

브리프에서 따뜻한 분위기를 원하면 채도 낮은 돌 / 뼈 / 퍼티색 바탕(채도 약 15% 미만), 짙은 녹색·갈색·옥스블러드 잉크색, 사진, 또는 넓고 자신 있게 단색으로 사용한 따뜻한 색상 면(머스터드, 토마토 레드, 분홍색)으로 표현합니다. 따뜻함은 베이지색이 아닙니다.

브랜드 자체 색상이 금지된 색상에 해당하면 해당 브랜드의 색으로 유지합니다. `--keep palette`를 사용하고 검사기에 `--allow palette-purple`(또는 해당 규칙)을 전달한 뒤 보고서에 기록합니다.
