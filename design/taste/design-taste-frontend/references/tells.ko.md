# 징후 목록 — 시의성 있는 등록부

징후(tell)는 페이지가 생성형으로 보이게 하는 장치입니다. 그 자체가 나쁜 디자인은 아닙니다. 대부분 좋은 사이트에 쓰인 좋은 아이디어로 시작했습니다. 이유 없이 어디서나 기본값으로 만들어져 징후가 된 것입니다. 이 목록은 시의성이 있고 대체 글꼴, 색상, 컴포넌트를 지정하지 않습니다. 공개된 “대신 이것을 쓰세요” 목록은 몇 달 안에 다음 징후가 되었기 때문입니다. 여기서 제안하는 대체 방법은 제품이 아니라 절차입니다(라이브러리에서 추첨, 대상에서 유래).

`scripts/inspect.mjs`와 `scripts/lint.mjs`가 대부분의 항목을 감지합니다. 상태가 **banned**이면 inspector가 페이지 검사에 실패하고, **warned**이면 경고하므로 사용 이유가 필요합니다.

## 1. 첫 번째 유행(2023~2024)

| 징후 | 상태 | 대신 할 것 |
|---|---|---|
| hero, 버튼, 빛남에 보라 / 인디고 그라데이션 사용 | 금지 | 추첨된 팔레트, 단색 |

| 빛나거나 그라데이션이 있는 “Get started” 버튼 | 금지 | 동작 이름을 단순하고 분명하게 쓴 버튼 |
| 모든 카드 아래에 부드러운 회색 drop shadow | 금지 | 색조 단계 사용 또는 카드 제거 |
| 둥근 사각형 안에 아이콘이 있는 동일한 기능 카드 세 개 | 금지 | 추첨된 섹션 청사진 |

## 3. 세 번째 유행(2025~2026): “수정”이 새로운 디자인이 된 시점

첫 두 유행을 해결하기 위해 공개된 처방은 “따뜻하게 만들고 편집 디자인처럼 만들기”였습니다. 모델들이 이를 통째로 받아들여 이제 생성형 디자인에서 가장 쉽게 알아볼 수 있는 스타일이 되었습니다.

| 징후 | 상태 | 대신 할 것 |
|---|---|---|
| 노란 크림 바탕 + 테라코타 / 녹슨 색 / 점토 포인트 | 함께 쓰면 금지, 테라코타 단독도 금지, 크림은 경고 | 추첨된 팔레트. 채도가 낮은 돌 색, 짙은 잉크, 사진, 전체를 채우는 따뜻한 색으로 온도 표현 |
| “고급”을 표현하는 지름길로 높은 대비의 세리프나 부드러운 세리프 display 사용 | 규칙 없음 | 분류와 상관없이 추첨된 타이포그래피 시스템 |
| 지나치게 큰 이탤릭 세리프 제목 | 규칙 없음 | 추첨된 대로 사용 |
| 신문을 흉내 내듯 곳곳에 머리카락처럼 가는 선, radius 0, 빽빽한 열 | hairline으로 금지 | 공간과 색조로 구조 표현 |
| “Field notes”, “Quietly trusted by”, “On our desks” 같은 연출형 레이블 | lint: copy | 단순한 섹션 이름 |

## 4. 갤러리 유행, 하우스 스타일로 금지

현재 어워드 사이트에서 흔히 볼 수 있습니다. 조사에서는 낮은 점수 사이트보다 **높은 점수 사이트**에서 더 많이 관찰됐습니다(패널 관찰: monospace 레이블 44% 대 24%, index 번호 38% 대 21%, 측정된 얇은 선 61% 대 52%). 그래도 소유자의 결정에 따라 여기서는 금지합니다. 생성기가 갤러리에서 가장 먼저 복사하는 요소이며 정보가 없고, 이를 쓰지 않고도 페이지를 만들려면 실제 구조를 찾아야 하기 때문입니다.

| 징후 | 상태 | 대신 할 것 |
|---|---|---|
| monospace 작은 레이블, “기술적” 목소리로서 monospace, monospace 캡션 | 금지 | 본문 서체 사용, 데이터에는 tabular figure 적용 |
| index 번호: 01 / 02 / 03, (001), “Step 02”, 번호가 붙은 섹션 마커 | 금지 | 위치, 크기, 문구로 순서 표현. 실제 목록에는 `<ol>` 사용 |
| 얇은 선: hairline 구분선, 줄 쳐진 grid, 1px 윤곽 상자와 타일 | 금지(상자 3개 이상) | 공간, 색조 단계, 단색 도형. 막대가 개념일 때만 굵은 막대 사용 |
| 장식으로 쓰는 디자인 도구 chrome: 십자선, crop mark, 선택 handle, 점선 안내선, 자 | hairline, dashed로 금지 | 제거 |
| 에이전시식 작은 meta: 현지 시각, 좌표, 날씨, 버전 표시, “©2026 — Scroll”, 가운데점 연결 문구 | lint: copy; micro-label | 제거 |
| viewport 곳곳에 흩어진 작고 자간이 넓은 대문자 캡션 | 금지(3개 이상) | 읽을 수 있는 크기의 문장형 대소문자를 설명 대상 콘텐츠와 함께 배치 |

이 그룹에서 글자 간격이 넓은 작은 대문자는 데이터에서도 좋지 않은 것으로 확인됐습니다. 상위 사이트의 16%에 쓰인 반면 낮은 점수 사이트는 57%였습니다.

## 5. 구조적 징후

| 징후 | 상태 | 대신 할 것 |
|---|---|---|
| 제목 전체를 display 크기로 사용해 세네 줄 차지 | 금지(두 줄 초과) | 다섯 단어 정도의 제목. 나머지는 아래로 보냄 |
| 표준 섹션 순서: hero, 로고, 기능, 추천사, 가격, CTA | 규칙 없음. copy.md §1 참조 | 논증에 맞는 순서 |
| 모든 섹션이 같은 레이아웃 유형 | critique.md 9단계 | 시트에 따라 섹션마다 다른 구성 |
| 모든 요소를 가운데 정렬 | 72% 초과 시 경고 | 왼쪽 기준 정렬과 가운데 정렬을 한 순간만 |
| 모든 요소에 동일한 중간 크기 radius(12~16px) | 없음 | 정사각형 또는 완전히 둥근 형태 중 한 번 선택 |
| 크기가 거의 비슷한 글꼴 아홉 단계 | 9개 초과 경고 | 서로 차이가 큰 크기 다섯 개 |
| 지어낸 사회적 증거: 로고, 인용문, 별점 행, “10,000+ teams” | copy.md §5 | 실제 증거 또는 표시하지 않음 |
| 사진이 들어갈 자리에 텍스트나 CSS 상자 | critique.md cap | 실제 사진 또는 사진이 필요 없는 디자인 |

## 6. 문구 징후

`lint.mjs`가 표시하는 항목: 해당 장르에서 자주 쓰는 동사와 형용사(unlock, supercharge, seamless, elevate, effortless, cutting-edge, all-in-one 등), “X가 아니라 Y다”라는 정정형 문구, 세 단어 병렬 제목, 레이블에 쓰는 “Get started”와 “Learn more”, em dash를 지나치게 많이 사용, lorem ipsum. `copy.md` §6을 참고하세요.

## 7. 모션 징후

모든 블록에 똑같은 fade-up 적용, hero에서 stagger 등장 열두 개 사용, 모든 카드에 hover lift 사용, bounce easing, 의미 없이 무한 반복, 빈 띠만 남기고 실패하는 reveal. `motion.md` §9를 참고하세요.

## 8. 없애는 것만으로 부족한 이유

모든 징후를 제거하고 아무것도 대신 넣지 않은 페이지는 예의 바른 빈 화면이며 그것도 징후입니다(“회피 미감”: 범주와 피해야 할 항목만 알면 누구든 예상할 수 있는 화면). 징후가 채운 자리는 원래 아이디어가 들어가야 했습니다. `SKILL.md`의 작업 순서는 먼저 그 빈자리를 채우기 위해 존재합니다. 주제에서 나온 아이디어, 추첨한 구성, 실제 사진 또는 확정한 글꼴을 정하고 마지막에 검사를 합니다.
