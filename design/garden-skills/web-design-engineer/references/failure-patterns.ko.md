# 상황별 실패 패턴

반복되는 AI 생성 설계 실패를 파악하려면 이 카탈로그를 사용하세요. 아티팩트와 관련된 섹션만 읽으십시오. 이는 보편적인 취향 법칙이 아닌 명시적인 예외가 있는 강력한 기본값입니다.

## 내용

- 마케팅 및 다중 섹션 페이지
- 레이아웃 및 구성 요소
- 타이포그래피 및 콘텐츠
- 이미지 및 브랜드
- 모션 및 상호작용
- 대시보드 및 제품 UI
- 최종 사용

## 마케팅 및 다중 섹션 페이지

### 반복되는 섹션 헤더 공식

- **기본값**: 모든 제목 위에 작은 대문자 눈썹을 넣지 않습니다.
- **이유**: 기계적으로 템플릿화된 리듬을 만듭니다.
- **탐지**: 동일한 라벨 + 헤드라인 + 단락 스택이 대부분의 섹션에 나타납니다.
- **예외**: 매뉴얼, 의도적으로 색인이 생성된 편집 시스템 또는 확립된 브랜드 패턴.
- **수리**: 정보가 부족한 라벨을 제거합니다. 리드 문장, 이미지, 숫자, 인용문 또는 직접적인 헤드라인을 사용하여 계층 구조를 변경합니다.

### 지그재그의 단조로움- **기본값**: 3회 이상 연속된 왼쪽/오른쪽 이미지-텍스트 분할을 방지합니다.
- **이유**: 교대만으로는 구성이 아닙니다.
- **감지**: 인접한 섹션 간의 유일한 차이점은 미러링입니다.
- **수정**: 전체 너비 증명 지점, 세로 설명, 비교, 갤러리, 다이어그램 또는 집중된 텍스트 나누기를 도입합니다.

### 기본 중앙 영웅

- **기본값**: 간단한 지원 없이 중앙 헤드라인 + 그라데이션 + 두 개의 CTA를 선택하지 않습니다.
- **이유**: 이는 설계 결정이 아니라 통계적 기본값입니다.
- **예외**: 선언문, 출시 설명, 검색 우선 유틸리티 및 의도적인 기념 페이지.
- **수정**: 콘텐츠 계층 구조, 자산 역할, 대상 및 뷰포트를 재평가합니다. 이러한 제약 조건을 가장 명확하게 만드는 구성을 선택하세요.

### 장식적 신탁 극장- **기본값**: 조작된 지표, 사용후기, 로고, 보안 배지 또는 "사용" 주장이 없습니다.
- **이유**: 잘못된 신뢰는 정직한 격차보다 더 나쁩니다.
- **수리**: 라벨이 붙은 자리 표시자를 사용하거나 실제 증거를 요청하세요.

### CTA 중복

- **기본값**: 동일한 의도에 대한 라벨을 일관되게 유지합니다.
- **탐지**: '시작하기', '무료로 사용해 보기', '계정 만들기'는 모두 의미 있는 구분 없이 동일한 작업으로 전달됩니다.
- **예외**: 테스트된 퍼널 문구 또는 다양한 약속 수준.
- **수정**: 라벨을 정규화하거나 뚜렷한 결과를 명확히 합니다.

## 레이아웃 및 구성 요소

### 카드화

- **기본값**: 그룹화, 선택 또는 고도화가 의미가 있는 경우에만 컨테이너를 사용합니다.
- **탐지**: 모든 단락, 측정항목, 아이콘이 둥근 카드에 표시됩니다.
- **수정**: 공백, 정렬, 구분선, 타이포그래피 또는 하나의 공유 표면을 사용합니다.

### 리듬이 없는 도시락- **기본값**: 모든 셀에는 콘텐츠와 구성 역할이 필요합니다.
- **감지**: 빈 필러 셀, 균일한 텍스트 전용 타일 또는 임의 범위.
- **복구**: 셀 ​​수를 내용과 일치시킵니다. 빈 지오메트리가 아닌 크기, 미디어, 데이터 또는 상호 작용을 통해 계층 구조를 만듭니다.

### 모양 드리프트

- **기본값**: 반경 문법을 정의하고 따릅니다.
- **탐지**: 알약, 날카로운 카드, 소프트 카드 및 원형 컨트롤이 의미 규칙 없이 나타납니다.
- **수리**: 구성 요소 역할별로 반경을 할당하고 토큰을 통합합니다.

### 분할 헤더 필러

- **기본값**: 분할이 아무 것도 전달하지 않는 경우 작은 부동 오른쪽 단락과 쌍을 이루는 큰 왼쪽 헤드라인을 피합니다.
- **수정**: 콘텐츠를 쌓거나 두 번째 열에 실제 시각적, 액션 또는 증거 역할을 부여합니다.

## 타이포그래피 및 콘텐츠

### 일반 디스플레이 타이포그래피- **기본값**: ID 표시 디스플레이 선택으로 Inter, Roboto, Arial, system-ui, Fraunces 또는 Instrument Serif에 자동으로 접근하지 않습니다.
- **예외**: 기존 브랜드/시스템 요구 사항, 접근성 컨텍스트 또는 의도적인 플랫폼 중립성.
- **수리**: 선택한 레시피, 제공된 브랜드 글꼴 또는 정당한 페어링을 사용합니다.

### 마이크로 라벨 노이즈

- **탐지**: 사용자에게 도움이 되지 않는 장식적인 버전 번호, 가짜 좌표, 날씨, 상태 점, 섹션 번호 또는 메타데이터.
- **수정**: 삭제하거나 실제 상태/컨텐츠에 연결합니다.

### 복사 모양 장식

- **탐지**: 모호한 주장, 허위 정확성, 대행사 슬로건 또는 공간을 채우기 위해 작성된 캡션.
- **수정**: 사용자가 제공한 사실, 명확한 자리 표시자 또는 더 적은 단어로 대체합니다.

### 읽을 수 없는 영웅- **탐지**: CTA가 의도한 초기 뷰포트 아래로 떨어지거나, 텍스트 클립을 표시하거나, 복사/이미지 경쟁으로 인해 계층 구조가 파괴됩니다.
- **복구**: 재구성; 아티팩트에 다른 읽기 환경이 필요한 경우 범용 단어 또는 줄 대문자를 적용하지 마세요.

## 이미지 및 브랜드

### CSS를 위조 자산으로 간주

- **기본값**: 인식 가능한 제품, 로고 또는 인터페이스를 장식적인 CSS 모양으로 바꾸지 않습니다.
- **수정**: 공식 자료를 소스로 제공하고, 신원이 중요하지 않은 확장 프로그램을 생성하거나 정직한 자산 슬롯을 노출합니다.

### 이미지 라벨이 복잡해짐

- **기본값**: 이미지를 식별, 제어 또는 설명하지 않는 한 이미지에 알약과 캡션을 오버레이하지 않습니다.
- **수정**: 필요한 메타데이터를 안정적인 캡션으로 이동하거나 제거합니다.

### 생성 세계 드리프트- **감지**: 다중 이미지 출력은 팔레트, 재료, 조명, 타이포그래피 문자, 장치 처리 또는 브랜드 기호를 변경합니다.
- **수리**: 시각적 성경을 재사용하고 관련 없는 장식으로 패치하는 대신 다양한 프레임을 재생성합니다.

## 모션 및 상호작용

### 스펙타클 전용 모션

- **기본값**: 모든 애니메이션에는 계층 구조, 피드백, 인과 관계 또는 내러티브 목적이 필요합니다.
- **감지**: 애니메이션을 제거하면 이해나 피드백이 변경되지 않습니다.
- **수리**: 제거하거나 모션 다이얼을 낮추거나 의미있는 상태로 묶습니다.

### 스크롤 상태 렌더링

- **기본값**: 모든 스크롤 또는 포인터 프레임에서 광범위한 React 상태를 업데이트하지 않습니다.
- **수정**: CSS, 모션 값, IntersectionObserver 또는 스택에 적합한 애니메이션 라이브러리를 사용합니다.

### 반복되는 광경

- **기본값**: 한 표면에 여러 개의 선택 윤곽, 고정된 챕터, 자기 컨트롤 또는 경쟁하는 주변 루프를 피합니다.
- **수정**: 하나의 시그니처 순간을 선택하고 다른 전환을 더 조용하게 만듭니다.### 움직임 감소 경로 누락

- **기본값**: 단순 상태 피드백 이상의 모션은 감소된 모션에서 깔끔하게 축소되어야 합니다.
- **수정**: 애니메이션에 의존하지 않고 콘텐츠 순서와 상호작용 완료를 유지합니다.

## 대시보드 및 제품 UI

### 운영UI 마케팅 스타일링

- **탐지**: 거대한 헤드라인, 과도한 공백, 영화 같은 카드, 저밀도 제스처로 인해 스캔이 방해됩니다.
- **수리**: 밀도를 높이고, 그리드를 안정화하고, 상태를 명확하게 하고, 작업 완료의 우선순위를 지정합니다.

### 장식적인 데이터 시각화

- **감지**: 그라데이션, 3D, 그림자 또는 애니메이션으로 인해 비교 및 규모가 불분명해집니다.
- **수정**: 데이터 잉크 비율, 레이블, 의미 색상 및 접근 가능한 대안을 개선합니다.

### Happy-path 전용 구성요소

- **감지**: 채워진 성공 상태만 존재합니다.
- **복구**: 관련 로드, 비어 있음, 오류, 권한, 비활성화 및 오버플로 상태를 추가합니다.
