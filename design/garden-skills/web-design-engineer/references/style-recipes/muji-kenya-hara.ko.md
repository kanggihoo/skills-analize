# muji-kenya-hara — 무인양품 / 하라 켄야

- **분류**: 에디토리얼 / 미니멀
- **분위기**: 비어 있음이 곧 충만함, 미색을 가치로 삼고, 거의 침묵에 가까움
- **적합한 용도**: 조용한 프리미엄 포지셔닝, 생활용품, “일상의 공예” 아이덴티티
- **참고 대상**: muji.com (모든 지역 사이트), 하라 켄야의 책 *백(白)*, MUJI 료칸 안내 표지

**팔레트**
- 바탕: `#F4F2EC` (따뜻한 종이색 미색 — `#FFFFFF`는 사용하지 않음)
- 잉크: `#2A2A28` (따뜻한 잉크색 — `#000000`은 사용하지 않음)
- 보조 텍스트: `#7C7B76`
- 가는 선: `#D9D6CD`
- 강조색: 없음. 꼭 추가해야 한다면 작은 모서리 표시나 선에만 브랜드 빨강 `#C8161D` 하나 사용.

**타이포그래피**
- 디스플레이: Söhne, Inter Tight, Klim's Calibre 같은 휴머니스트 산세리프 — 굵기 400, 500보다 굵게 쓰지 않음. 자간은 약간 넓게 (0.01em–0.02em).
- 본문: 같은 글꼴 패밀리의 15–16px, 행간 약 1.8
- 일본어·영어 병기 환경에서는 굵기를 맞춘 Noto Sans CJK JP를 함께 사용

**간격**: 8 / 16 / 32 / 48 / 96 / 160 / 240. 큰 간격이 중요 — 섹션 사이 240px도 일반적임.

**모서리 반경**: 0. 단단하고 솔직한 모서리. 입력란에만 2px 정도 허용.

**그림자**: 없음.

**모션**: 거의 알아차릴 수 없게. 600–900ms 페이드. 어떤 요소도 몇 px 이상 이동하지 않음. 튀는 움직임은 절대 금지.

**시그니처 요소**
- 페이지의 60–80%를 빈 공간으로 둠 — 콘텐츠는 가장자리에서 멀리 떨어진 좁은 열에 배치
- 한 “화면”에 제품 이미지 하나만 넣고 페이지에 비해 작게 표시하며 평범한 캡션을 붙임
- 각 섹션이 무엇인지 설명하는 작은 라벨 (10–11px, 자간을 넓게) — “01 — 면”처럼 쓰고 소리치는 헤드라인은 사용하지 않음
- 대괄호처럼 보이는 삽입 문구를 중립적으로 표현
- 장식은 가는 1px 선만 사용

**피할 것**
- 모서리의 MUJI 빨강 이외에 채도 높은 색상
- 모든 종류의 그림자, 발광, 그라데이션
- 탭, 아코디언, 메가 메뉴, 고정 배너
- “스크롤하지 않아도 보이는 영역”에 대한 집착 — MUJI는 시선이 페이지 중간에서 시작해도 괜찮음

**AI 프롬프트 시드**
> 따뜻한 미색 `#F4F2EC` 종이 바탕 위에 놓인 생활용품 하나, 왼쪽 위에서 비스듬히 들어오는 자연광, 사물 주위의 길고 고요한 여백, 3:2, 필름 사진, 과장된 그림자 없음, 중립적인 톤.

**사용하지 말아야 할 경우**
- 제품의 많은 기능을 전달해야 할 때 (사양, 요금제, 비교 표) — MUJI의 고요함이 메시지를 숨김
- 사용자층이 빠르게 스크롤하고 정보 밀도를 원할 때 (뉴스 / SaaS / 대시보드) — 이탈할 수 있음
- 경쟁이 치열한 시장에서 브랜드가 크게 외쳐야 할 때 — 고요함도 고급스러움이지만 언제나 필요한 것은 아님
