# vignelli-swiss-helvetica — Vignelli / 스위스 인터내셔널

- **학교**: 정보 아키텍처
- **Vibe**: 엄격한 그리드, 전체적으로 Helvetica, "6개의 서체로 충분합니다."
- **최적의 용도**: 길 찾기/교통 시스템, 기관 정체성, 심층적으로 정리된 정보
- **시금석**: 1972년 NYC 지하철 지도(Vignelli), Knoll 카탈로그, *The Vignelli Canon*

**팔레트**
- 블랙 `#000000` 및 화이트 `#FFFFFF`
- 다음 중 하나 추가: 빨간색 `#E2231A` / 노란색 `#F5C518` / 파란색 `#0033A0` / 주황색 `#FF6F00`(하나만 — 두 개의 악센트는 없음)
- 보조 콘텐츠용 쿨 그레이 `#8A8A8A`

**타이포그래피**
- 디스플레이 및 본체: Helvetica 또는 Helvetica 현재 독점. 무게: 400 / 500 / 700, 이탤릭체 없음.
- 무게나 색상이 아닌 크기별 계층 구조
- 공통 규모: 72 / 48 / 32 / 24 / 16 / 12, 모두 동일한 기준 그리드에 있음

**간격**: 8픽셀 기준선 그리드, 12열 레이아웃, 문자 크기와 같거나 그 이상의 넉넉한 기준선과 기준선 간격.

**반경**: 0, 항상.

**그림자**: 없음.**모션**: 없음 또는 즉시. 스위스 디자인은 본질적으로 정적입니다. 어떤 것이 움직이면 간판이 제자리로 회전하는 것처럼 움직입니다.

**시그니처 무브**
- 굵은 가로 또는 세로 색상 막대는 흰색 Helvetica의 섹션 헤더를 전달합니다.
- 그리드는 도움이 될 때 **표시**됩니다. 기둥 홈통은 때때로 희미한 선으로 그려집니다.
- 정보 세트(데이터, 일정, 목록)는 엄격한 기준선 정렬을 통해 표 형식 레이아웃을 얻습니다.
- 본문 문구는 읽을 수 있는 단일 단위로 왼쪽 정렬됩니다(최대 60~70자). 결코 중심에 있지 않다
- 각 블록의 왼쪽 상단에 하나의 큰 숫자(챕터/섹션)가 표시됩니다.

**피하세요**
- 전체적으로 세리프체
- 잉크+그라운드+원액센트 이외의 색상 조합
- 기울임꼴, 그림자, 그라데이션, 모든 부드러움
- "친절한" 카피라이팅 톤 — 스위스어는 사실입니다.**AI 프롬프트 시드**
> 대중교통 표지판 스타일 구성, 단일 강조 색상의 평면 필드에 검은색으로 설정된 대형 방향 화살표, 응축된 Helvetica 목적지 라벨, 장식 없음, 16:9 평면 벡터 미학.

**다음과 같은 경우에는 사용하지 마세요**
- 브랜드에는 따뜻함이 필요합니다. - Helvetica + 그리드는 제도적/차갑게 읽힙니다.
- 콘텐츠는 감정적/스토리텔링입니다. 스위스에서는 감정을 제거합니다.
- 현대성/신선함이 목표입니다. 이제 스위스 디자인은 클래식/아카이브로 읽혀집니다.
