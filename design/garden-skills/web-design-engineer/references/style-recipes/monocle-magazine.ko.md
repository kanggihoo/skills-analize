# monocle-magazine — Monocle 매거진

- **분류**: 에디토리얼 / 미니멀
- **분위기**: 국제적이고 세심한 구성, 잡지 수준의 상단 라벨 / 헤드라인 / 부제 위계
- **적합한 용도**: 에디토리얼, 여행·호스피탈리티, 저널, 세심하게 큐레이션한 라이프스타일 출판물
- **참고 대상**: monocle.com, Monocle 계간지, Cereal 매거진

**팔레트**
- 바탕: `#F2EFE7` (크림색 종이)
- 잉크: `#1A1A1A`
- 에디토리얼 강조색: `#C7322E` (Monocle 시그니처)
- 올리브색: `#5E6347`
- 가는 구분선: `#C8C2B0`

**타이포그래피**
- 디스플레이: 정제된 슬랩 세리프 또는 트랜지셔널 세리프 — Plantin, Mercury, Tiempos Headline. 이탤릭을 폭넓게 사용.
- 본문: Plantin 또는 Tiempos Text 16–17px, 행간 약 1.6
- 상단 라벨 / 태그는 Söhne 같은 정밀한 그로테스크체 10–11px, 자간 0.08em로 설정하며 에디토리얼 빨강을 자주 사용
- 긴 특집 기사에는 드롭캡 사용 가능

**간격**: 4 / 8 / 16 / 24 / 32 / 48 / 96. 여러 열의 작업에서는 열 사이 간격을 좁게 (16–24px) 설정.

**모서리 반경**: 0. 잡지는 모서리를 둥글게 하지 않음.

**그림자**: 없음.

**모션**: 최소한으로. 페이지 넘김 같은 페이드. 대표 사진에는 느린 켄 번스 효과.

**시그니처 요소**
- 3단 위계: 아주 작은 빨강 상단 라벨 → 굵은 세리프 헤드라인 → 이탤릭 세리프 부제
- 가는 열 구분선이 있는 다단 본문 (2–3열)
- 번호가 붙은 특집 기사 (`Feature 04 — Lisbon`)와 여백의 작은 숫자
- 한쪽 가장자리에 바짝 붙여 자른 대표 사진, 빈 여백 안에 헤드라인을 배치
- 본문보다 훨씬 크게 한 열에 배치한 이탤릭 인용문

**피할 것**
- 산세리프 헤드라인 — Monocle의 시그니처는 세리프의 어조
- 스톡 사진 — 따뜻하고 사람과 장소가 풍부한, 의뢰 제작한 듯한 사진이 필요
- 카드 그리드 — SaaS 방식이 아니라 잡지 지면 구성
- 강조색을 하나보다 많이 사용 (에디토리얼 빨강 하나면 충분)

**AI 프롬프트 시드**
> 장소의 특색이 드러나는 장면 (예: 해 질 무렵 도쿄 뒷골목)을 담은 에디토리얼 매거진 사진, 따뜻한 색보정, 약한 필름 그레인, 중경에 사람 한 명, 3:2, 따뜻한 흙색 계열에 빨간 물체 하나만 포함한 팔레트.

**사용하지 말아야 할 경우**
- SaaS 제품 페이지를 만들 때 — 잡지의 공예적 표현이 어울리지 않음
- 이끌 만한 에디토리얼·인물·장소 콘텐츠가 없을 때 — 사진이 없으면 구성이 속 빈 느낌
- 사용자가 빠르게 훑어보길 원할 때 — Monocle은 훑어보기보다 읽기를 보상함
