# tufte-dataink — Edward Tufte / 최대 데이터 잉크

- **학교**: 정보 아키텍처
- **Vibe**: 모든 픽셀이 제 위치를 차지합니다. 차트는 페이지이다
- **최적의 용도**: 분석 보고서, 과학 출판물, 데이터 기반 스토리텔링
- **기준**: *정량적 정보의 시각적 표시*, *아름다운 증거*, edwardtufte.com

**팔레트**
- 접지 : `#FBFAF6` (따뜻한 종이)
- 잉크: `#1B1B1A`
- 데이터 색상은 두 가지입니다. 일반적으로 따뜻한 빨간색 `#A6300E`와 차가운 슬레이트 `#3E4A5C`입니다. 3차원에 정말로 필요한 경우에만 3차원을 추가하세요.
- 희미한 참조 규칙: `#D8D2C2`

**타이포그래피**
- 디스플레이 및 본문: 구식 또는 과도기적 세리프 — ET Book(Tufte의 계열), Equity 또는 Lyon Text. 본문의 무게는 400이고 강조는 이탤릭체입니다.
- 본문 12~14px(Tufte는 의도적으로 작은 본문 텍스트를 사용합니다. 독자가 몸을 기울입니다.)
- 축 레이블에 대해서만 Sans — 10~11px의 Humanist Sans, 색상 `#5C5550`**간격**: 빡빡합니다. 4 / 8 / 12 / 16 / 24 / 48. 여백은 공백이 아닌 보조 메모로 채워집니다.

**반경**: 0.

**그림자**: 없음.

**모션**: 없음. 페이지는 계속해서 읽혀져야 합니다.

**시그니처 무브**
- 본문 문구와 인라인 스파크라인(문장에 포함된 작은 차트)
- 사이드 노트(여백)가 많이 사용됩니다. 주석은 도구 설명이 아닌 오른쪽 여백에 있습니다.
- 차트에는 차트 정크가 없습니다. 희미한 것 외에는 눈금선이 없고, 테두리 상자도 없고, 3D도 없고, 직접 레이블이 작동하는 경우 범례도 없습니다.
- 작은 배수 — 서로 다른 데이터가 포함된 동일한 차트의 3×3 그리드
- 데이터 계열에 대한 직접 레이블(선은 범례 상자가 아닌 끝점에 레이블이 지정됨)

**피하세요**
- 원형 차트(Tufte는 승인하지 않음)
- 3D 무엇이든
- `#D8D2C2`보다 어두운 격자선
- 동일한 페이지에 여러 차트 유형이 있는 경우
- 장식용 색상(모든 색상에는 의미가 담겨 있어야 함)**AI 프롬프트 시드**
> 편집 과학 그림, 따뜻한 종이 #FBFAF6 배경, 음소거된 빨간색과 슬레이트의 두 데이터 시리즈가 있는 다중 라인 시계열 차트, 라인 끝점에 직접 레이블, 기울임꼴 셰리프의 사이드 노트 콜아웃, 차트 프레임 없음, 범례 없음, 4:3.

**다음과 같은 경우에는 사용하지 마세요**
- 차트는 장식적입니다(Tufte는 차트가 *포인트*가 되도록 요구합니다).
- 독자는 대화형 도구 설명/필터를 기대합니다(Tufte는 정적 편집 수치용입니다).
- 미디엄은 이동성이 있습니다. (작은 체형과 마진 노트가 맞지 않습니다.)
