# bloomberg-businessweek-turley — 블룸버그 비즈니스위크 (털리 시대)

- **분류**: 브루탈리스트 / 날것의 미감
- **분위기**: 타이포그래피의 폭력성, 망가뜨린 잡지 그리드, 이미지가 된 문장
- **적합한 용도**: 에디토리얼 특집, 에이전시 포트폴리오, 강한 관점의 콘텐츠 사이트
- **참고 대상**: Bloomberg Businessweek 2014–2019년 표지 (Richard Turley → Tracy Ma 시대), *Eye* 잡지 아카이브 호

**팔레트**
- 강렬한 색상 — `#FF3D00` (경보 오렌지), `#FFE800` (신호 노랑), `#001AFF` (경보 파랑)
- 최대 대비를 위해 항상 `#FFFFFF` 위에 사용하거나 `#000000` 바탕에 반전 적용
- 읽기 쉬운 경우 흰색 바탕에 검정 `#000000` 텍스트, 그렇지 않으면 대비되는 색조 사용
- 한 지면에 최대 3색

**타이포그래피**
- 디스플레이: Founders Grotesk, Druk, ABC Whyte처럼 말도 안 될 만큼 큰 크기의 굵은 그로테스크체 하나. 굵기 800–900, 200px 이상.
- 헤드라인은 의도적으로 여러 줄로 나누며, 편안함을 넘어설 정도로 자간을 좁히기도 함
- 대비를 위해 본문은 작게 — 12–14px 세리프 (Plantin / Mercury)
- 디스플레이에는 대문자와 콘덴스드체를 자주 사용

**간격**: 의도적으로 그리드를 깨뜨림 — 콘텐츠를 그리드 밖으로 밀거나 가장자리에 닿게 하고, 때로는 의도적으로 넘치게 함

**모서리 반경**: 0

**그림자**: 없음

**모션**: 부드럽게 이어지지 않는 거친 컷. 움직이는 요소가 있다면 제자리에 거칠게 내려앉음.

**시그니처 요소**
- 그리드를 눈에 띄게 깨뜨릴 정도로 크게 설정한 헤드라인 (글자가 페이지 가장자리에 닿음)
- 글자 아래나 뒤에 놓는 채도 높은 오렌지·노랑·파랑 색면
- 사진 오려내기 (피사체를 실루엣으로 따서 색면 위에 배치) — 어색하게 잘라내는 경우가 많음
- UI 컴포넌트가 아닌 잡지 지면처럼 강렬한 대비와 관점을 담아 꾸민 데이터 표
- 예상 밖의 모서리에 배치한 아주 작은 세리프 이탤릭 캡션

**피할 것**
- 세련되고 점잖은 디자인 (의도적으로 점잖음을 거부하는 구성)
- 한 지면에 3색 초과
- 부드러운 전환 효과
- 웹 기본 스타일 (모든 요소를 자동 생성이 아니라 직접 설정한 것처럼 보여야 함)

**AI 프롬프트 시드**
> 거대한 검정 그로테스크체로 200pt 크기의 굵은 단어 하나를 넣은 잡지 표지 구도, 그 뒤에 채도 높은 경보 오렌지 `#FF3D00` 단색 면, 예상 밖 각도로 겹쳐 놓은 서툴게 오려낸 사진 실루엣, 약간 어긋난 인쇄 정합, 3:4.

**사용하지 말아야 할 경우**
- 브랜드 어조가 차분하고 신뢰감을 줘야 할 때 — 털리 시대의 Bloomberg는 시끄러움
- 콘텐츠가 실용성 위주일 때 — 이 구성은 에디토리얼 전용
- 의도적인 추함을 팀이 받아들이기 어려울 때 — 이 구성을 쓰려면 끝까지 밀어붙여야 함
