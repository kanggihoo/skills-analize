# field-io — Field.io (제너레이티브 모션 아이덴티티)

- **분류**: 모션 / 실험적
- **분위기**: 브랜드 자체가 움직임이며, 방문자 앞에서 페이지가 생성됨
- **적합한 용도**: 브랜드 필름, 출시 순간, 에이전시 포트폴리오, “방문 자체가 경험”인 사이트
- **참고 대상**: field.io, FIELD.SYSTEMS 작업물, 키네틱 아이덴티티 사례

**팔레트**
- 주로 어두운 바탕 — `#0B0B0F`에서 `#000000`
- 모션 전반에 반복 사용하는 제너레이티브 그라데이션 색조 하나 또는 둘. 색상 회전을 반복하는 굵은 단일 색조를 자주 사용 (예: 짙은 시안 `#0CE0E5`에서 전기 보라 `#5B2EFF`로 변화) 또는 절차적으로 생성
- 글자용 잉크: 대비가 높은 흰색 `#FFFFFF`
- 보조 텍스트: 차가운 회색 `#A0A4B0`

**타이포그래피**
- 디스플레이: 축을 따라 스스로 움직이는 가변 글꼴 — Söhne Variable, Editorial New Variable, Inter Display Variable
- 스크롤에 따라 글자의 굵기, 너비, 광학 크기를 변화시키기도 함
- 본문은 절제해서 중립적인 굵기의 그로테스크체 하나만 사용. 주인공은 모션이지 본문이 아님.

**간격**: 의도적으로 불규칙 — 콘텐츠를 예상 밖의 위치에 배치하고 그리드가 나타났다 사라지기도 함

**모서리 반경**: 0 — Field.io 작업물은 모서리를 부드럽게 처리하는 경우가 드묾

**그림자**: CSS로 처리하지 않고 WebGL / Canvas 장면의 제너레이티브 조명으로 표현

**모션**: 이 구성의 모든 것. 여러 단계로 안무한 시퀀스. 시차 효과뿐 아니라 상태 전환을 위해 스크롤을 활용. 페이지가 스스로 재생되는 영상처럼 느껴지는 경우가 많음.

**시그니처 요소**
- 스크롤에 따라 글자가 등장하고 변형된 후 헤드라인으로 완성되는 제너레이티브 타이포그래피 시퀀스
- 커서와 스크롤 위치에 반응하는 입자·메시 시스템
- 길게 이어지는 이징 곡선 (expo-out, quint-out) — `cubic-bezier(0.83, 0, 0.17, 1)` 등
- 전체 화면 캔버스가 레이아웃을 덮어쓰는 등 페이지 상태 전체가 바뀌는 섹션 전환
- 여러 요소를 안무하듯 순서대로 등장시킴 — 여섯 요소가 동시에가 아니라 시차를 두고 도착

**피할 것**
- 정적인 구성 (이 구성은 정지 화면만 보여주면 인상이 약함)
- 커서 반응 요소를 너무 많이 사용 (핵심 WebGL 장면 한두 개가 전체 페이지에 깔리는 것보다 적합)
- 텍스트가 많은 콘텐츠 — 읽기보다는 특별한 순간을 위한 구성

**AI 프롬프트 시드**
> 입자장으로부터 문구 하나가 완성되는 제너레이티브 타이포그래피 구성, 전기 보라 `#5B2EFF`와 짙은 시안 `#0CE0E5`의 빛 궤적, 거의 검정색 배경, 길게 늘어진 모션 트레일, 16:9 시네마틱 화면비.

**사용하지 말아야 할 경우**
- 결과물이 정적인 스크린샷으로만 사용될 때 (이 구성의 효과가 약 70% 사라짐)
- 제작 예산이 적을 때 (25개 구성 중 가장 작업량이 많음)
- 대상 사용자가 저사양 기기를 사용하거나 감탄을 주는 효과보다 성능·접근성을 우선할 때
