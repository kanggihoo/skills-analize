# aesop — 이솝 스킨케어

- **분류**: 에디토리얼 / 미니멀
- **분위기**: 약국의 정제된 감성, 세이지와 먹색, 대화처럼 느껴지는 세리프 문장
- **적합한 용도**: 프리미엄 소비재(스킨케어, 양초, 안경), 문학적 감성을 지향하는 식당, 호스피탈리티
- **참고 대상**: aesop.com, 이솝 매장 쇼윈도, 갈색 호박색 병

**팔레트**
- 바탕: `#E8E4D9` (따뜻한 샤무아색) — 때때로 `#F2EFE5`
- 잉크: `#1B1B1B` (문자용에 가까운 검정)
- 차분한 세이지: `#7A8470`
- 호박색 병 강조색: `#7A4623` (선 하나나 인장 표시처럼 아주 제한적으로 사용)
- 크림색 표면: `#F0EDE4`

**타이포그래피**
- 디스플레이와 본문: 모든 크기에 하나의 트랜지셔널 세리프 사용 — Suisse Works, Lyon Text, GT Sectra (굵기 400, 이탤릭 지원). 이솝은 본문 세리프에 UI 라벨용 산세리프(Söhne 또는 Helvetica Now) 하나를 조합함.
- 본문 크기: 16–18px, 행간 약 1.65
- 라벨은 스몰캡스 (10–11px, 자간 0.12em)

**간격**: 8 / 16 / 24 / 40 / 72 / 120

**모서리 반경**: 입력란을 포함해 모두 0. 이솝은 각진 형태를 사용함.

**그림자**: 없음.

**모션**: 은은한 페이드, 느린 서랍식 슬라이드 인(약 450ms ease-out). 스프링처럼 튀는 효과는 사용하지 않음.

**시그니처 요소**
- 본문은 문학 잡지의 제품 소개처럼 읽힘 — 길고 리듬이 잘 잡힌 문장, 양쪽 정렬, 광고식의 짧고 강한 표현은 피함
- 따뜻한 샤무아색 바탕에 세이지 소품 하나(잎, 대리석 접시, 리넨)와 긴 그림자를 두고 제품을 촬영
- 각 콘텐츠 위에 스몰캡스 섹션 라벨(`INGREDIENTS` / `RITUAL`) 배치
- 마스트헤드 내비게이션은 자간을 넓힌 텍스트만 사용
- 비대칭 레이아웃: 이미지는 왼쪽, 넉넉한 오른쪽 여백에 문장을 배치. 모든 요소를 중앙에 맞추지 않음

**피할 것**
- 어디에도 굵은 글꼴을 쓰지 않음 — 이솝은 보통 굵기와 이탤릭만 사용
- 세이지·호박색·먹색 이외의 색상 — 파랑, 보라, UI용 파란 강조색은 사용하지 않음
- 팝업 모달 (이솝의 UI는 정중하게 기다림)
- 웃는 모델의 라이프스타일 스톡 사진 — 소품과 제품만 사용

**AI 프롬프트 시드**
> 따뜻한 샤무아색 `#E8E4D9` 질감의 종이 위에 놓인 호박색 유리 약병, 리넨 냅킨 하나와 말린 세이지 가지, 오후 창문에서 비스듬히 들어오는 빛, 오른쪽 아래로 드리운 깊고 부드러운 그림자, 4:5, 에디토리얼 제품 사진, 따뜻하면서 녹색 기가 살짝 도는 색보정.

**사용하지 말아야 할 경우**
- 소프트웨어나 디지털 우선 제품일 때 — 촉감이 느껴지는 사물 사진이 구성의 절반을 차지하므로 CSS로 대신하기 어려움
- 가격 비교 기능이 중요한 사용자층일 때 — 이솝은 가격을 눈에 띄게 보여주지 않음
- 유머러스하거나 편안한 어조가 필요할 때 — 이솝은 진지하고 느긋한 분위기임
