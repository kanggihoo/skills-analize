# apple-hig — Apple 휴먼 인터페이스

- **분류**: 에디토리얼 / 미니멀
- **분위기**: 넉넉한 여백, 흰 배경 위의 대표 제품, 화면마다 하나의 메시지
- **적합한 용도**: 프리미엄 하드웨어·소프트웨어, “무대에 올릴 만한 제품”이라는 인상
- **참고 대상**: apple.com 제품 페이지, Apple 키노트 슬라이드, HIG 문서

**팔레트**
- 바탕: `#FFFFFF` (종이처럼 깨끗한 흰색), 또는 `#000000` (대표 영상 장면에만 사용하는 짙은 검정)
- 잉크: `#1D1D1F` (Apple 특유의 완전한 검정이 아닌 색)
- 부드러운 표면: `#F5F5F7`
- 차분한 텍스트: `#86868B`
- 강조색 (절제해서 사용): 시스템 파랑 `#0071E3`

**타이포그래피**
- 디스플레이: SF Pro Display (헤드라인 굵기 600, 보조 디스플레이 굵기 400) — SF Pro를 사용할 수 없을 때만 Inter Tight로 대체
- 본문: SF Pro Text 17px, 행간 약 1.47
- 캡션: SF Pro 12–14px, 굵기 400, 색상 `#86868B`

**간격**: 4 / 8 / 16 / 24 / 40 / 64 / 96 / 160. 섹션 사이는 160px 이상으로 넓게 두고 헤드라인에 여유를 줌.

**모서리 반경**: 작은 컴포넌트 12, 카드 18, 큰 패널 22. 날카롭게 각지지도, 젤리처럼 둥글지도 않게 처리.

**그림자**: 거의 보이지 않게. 최대 `0 1px 2px rgba(0,0,0,0.04)`. 그림자보다 여백과 색 대비로 높낮이를 표현.

**모션**: cubic-bezier expo-out. 레이아웃 이동은 350–650ms, 호버는 150–250ms. 튀는 효과는 쓰지 않음. 히어로 이미지에 느린 켄 번스 효과를 자주 사용.

**시그니처 요소**
- 여백 한가운데 제품 사진 하나를 두고 히어로 영역의 약 40%를 차지하게 함
- 큰 디스플레이 굵기의 히어로 헤드라인, 아래에 차분한 회색(` #86868B`) 본문 한 줄, 시스템 파랑 텍스트 링크 형태의 CTA 하나 배치 (히어로에는 큼직한 버튼을 두지 않고 뒤에서 사용)
- 섹션 구성: 작은 상단 라벨 → 큰 헤드라인 → 문단 하나 → 제품 사진 하나를 반복. 탭, 카드, 벤토 레이아웃은 사용하지 않음.
- 섹션 사이에 가는 `#D2D2D7` 구분선만 사용
- 숫자는 디스플레이 굵기로 표현 (예: 통계 `12.9″`에서 `″` 기호는 더 가는 굵기로 표시)

**피할 것**
- 그라데이션 메시, 발광 효과, “기술적 분위기” — Apple의 그라데이션은 배경 장식이 아니라 제품 표면에 은은하게 적용되는 은색에서 차콜색의 변화에 가까움
- 히어로에 CTA 여러 개 배치
- 기능 카드 그리드 (Apple은 카드 그리드보다 하나의 아이디어씩 세로로 길게 보여주는 섹션을 사용)
- 마케팅 페이지의 이모지

**AI 프롬프트 시드** (히어로 이미지용)
> 순백색 `#FFFFFF` 바탕 중앙에 놓인 단일 사물을 스튜디오 조명으로 촬영한 제품 사진, 위쪽에서 확산되는 부드러운 빛, 은은한 바닥 반사, 16:9, 텍스트와 인물 없음, 과장된 그림자 없음, 중립적인 색보정.

**사용하지 말아야 할 경우**
- 촬영할 대표 사물이 없는 소프트웨어 전용 제품일 때 — 무대가 비어 보이게 됨
- 브랜드가 실험적이거나 스타트업답고 친근한 인상을 원할 때 — Apple HIG는 비싸고 진지하게 느껴짐
- 사용자층이 기술 대기업에 반감을 가질 때 — “식상한 Apple 흉내”처럼 보일 수 있음
