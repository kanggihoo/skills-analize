# are-na — Are.na (정직한 웹)

- **분류**: 브루탈리스트 / 날것의 미감
- **분위기**: 의도적인 시스템 글꼴, 장식보다 콘텐츠, 세심하게 다듬은 90년대 후반 웹
- **적합한 용도**: 독립 도구, 창작 플랫폼, “연구 분위기”의 제품, 예술가 커뮤니티
- **참고 대상**: are.na, Are.na 연례 간행물

**팔레트**
- 바탕: `#FFFFFF`
- 잉크: `#000000`
- Are.na 링크 파랑: `#0000EE` (일부러 사용하는 클래식 브라우저 기본 파랑)
- 방문한 링크: `#551A8B` (클래식 브라우저 기본 보라)
- 가는 선: `#CCCCCC`
- 선택 사항: 카드에 쓰는 따뜻한 크림색 표면 `#F4F1E8`

**타이포그래피**
- 디스플레이와 본문: 의도적으로 시스템 세리프(Times / Georgia) 및/또는 시스템 산세리프(OS 기본 글꼴)를 사용
- 웹 브라우저가 글꼴을 선택하도록 두는 구성이므로 커스텀 글꼴을 불러오지 않음
- 본문 14–16px, 행간 약 1.45
- 이탤릭과 밑줄 링크도 브라우저 기본 스타일을 따름

**간격**: 4 / 8 / 16 / 24 / 32. 촘촘하고 콘텐츠 밀도가 높음.

**모서리 반경**: 0

**그림자**: 없음

**모션**: 없음 또는 즉시 전환

**시그니처 요소**
- 밑줄이 있는 파란 링크와 방문한 링크의 보라색을 브라우저 기본값 그대로 사용
- 제목은 특별한 글꼴 없이 본문 글자보다 크게만 표시
- 표, 목록, 문장을 장식 없이 자연스럽게 이어 배치
- 바닥글은 작고 단순하며 링크가 많음 (초기 웹의 “모든 것이 링크”인 바닥글)
- 카드를 쓴다면 그림자 없이 1px 회색 테두리만 있는 평평한 직사각형으로 구성

**피할 것**
- 모든 종류의 커스텀 글꼴
- 링크의 파랑·보라, 잉크와 바탕 이외의 색상
- 호버 애니메이션 및 모든 종류의 전환 효과
- 모달, 툴팁, 미세 상호작용
- 세련되게 다듬은 느낌

**AI 프롬프트 시드**
> 평범한 흰 종이 위에 다양한 출처의 사진을 모아 붙인 콜라주, 포토샵으로 매끈하게 다듬지 않음, 약간의 불완전함과 손으로 자른 느낌, 4:3.

**사용하지 말아야 할 경우**
- 브랜드가 “프리미엄”해 보여야 할 때 — Are.na 구성은 프리미엄을 드러내는 표현을 거부함
- 사용자층이 현대적인 SaaS UX 신호를 기대할 때 — 페이지가 망가졌다고 여기고 떠날 수 있음
- 절충해서 적용하고 싶을 때 — 완전히 적용하거나 다른 구성을 선택해야 함. 일부만 Are.na를 따라 하면 큐레이션이 아니라 미완성처럼 보임
