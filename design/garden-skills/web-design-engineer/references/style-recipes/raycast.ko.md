# raycast — Raycast(생산 도구)

- **학교**: 최신 도구/빌더 SaaS
- **Vibe**: 유리 같은 명령 팔레트 미학, 개성을 위한 색상 확장, 키보드 우선 문화
- **최적의 용도**: 생산성 도구, 명령 팔레트/런처 제품, 개발 유틸리티
- **기준**: raycast.com, Raycast 앱 스크린샷, raycast.com/store 확장 카드

**팔레트**
- 접지: `#0F0F11`(파란색이 가미된 차콜색)
- 표면 반투명: 컬러 그라데이션 배경 위의 `rgba(255,255,255,0.06)`
- 헤어라인 : `rgba(255,255,255,0.10)`
- 기본 텍스트: `#FFFFFF`
- 보조 텍스트: `#B0B3B8`
- 브랜드 레드 액센트: `#FF6363` — 아이콘 및 주요 CTA에 사용되는 Raycast의 시그니처
- 확장 칩: 작은 표면에만 악센트 점으로 사용되는 타일당 밝은 색상(라임, 산호, 라벤더, 청록색)**타이포그래피**
- 디스플레이: Söhne 무게 600 또는 Inter Tight 무게 600
- 본문: Inter 14-15px, 무게 500(Linear의 400보다 약간 무거움 — Raycast가 더 펀치감 있음)
- 모노: 바로가기 칩용 SF Mono 또는 JetBrains Mono
- 디스플레이의 문자 간격: -0.02em

**간격**: 4 / 8 / 12 / 16 / 24 / 40 / 64

**반경**: 8(소형) / 12(중형) / 16(카드) / 24(대형 모달). Raycast의 시그니처 반경은 소프트 코너 명령 팔레트입니다.

**그림자**: 쿠션감 — 명령 팔레트 카드의 `0 16px 40px rgba(0,0,0,0.4)`; 다른 곳에서는 그림자가 거의 없습니다

**모션**: 주요 순간(팔레트 표시, 호버 리프트)에 탄력이 환영됩니다. — 약간의 오버슈트가 있는 스프링 물리학입니다. 그렇지 않으면 150ms의 빠른 이지아웃이 가능합니다.**시그니처 무브**
- 영웅의 부동 명령 팔레트 스크린샷, 약간 기울어져 쿠션이 있는 넉넉한 그림자를 드리우고 흐릿한 다채로운 그라데이션 배경이 보입니다(유리).
- 스타일이 지정된 칩으로 표시되는 모든 키보드 단축키 — `⌘` `↵` `⌥`는 가는 선 테두리와 희미한 배경이 있는 정밀 모노로 설정됩니다.
- 타일 카드의 작은 강조점으로 사용되는 확장별 밝은 색상(Notion 타일에는 작은 라벤더 점이 있고 GitHub 타일에는 차콜색 점이 있음)
- 영웅 뒤의 끈끈한 색상 줄무늬 그라데이션 배경(주황색 → 자홍색이지만 소프트 포커스)
- 타일에 명확한 호버 리프트가 있는 넉넉한 간격의 섹션 해부학

**피하세요**
- 같은 화면에 밝은 확장 색상이 너무 많습니다. 어두운 배경에서 작은 액센트로만 작동합니다.
- 단색의 밝은 색상 버튼(Raycast 버튼은 일반적으로 단축키 칩이 있는 반투명 흰색 알약입니다.)
- 순수한 흑백 장면 - Raycast는 장난스러운 느낌을 주기에 *충분히* 색상에 의존합니다.**AI 프롬프트 시드**
> 생산성 응용 프로그램 인터페이스, 페이지 중앙에 있는 부동 명령 팔레트 카드, 그 뒤에 있는 따뜻한 오렌지색과 자홍색의 소프트 포커스의 다채로운 그라데이션 배경, 어두운 목탄색 전경 UI, 팔레트 아래 쿠션이 있는 그림자, 사람 없음, 16:9.

**다음과 같은 경우에는 사용하지 마세요**
- 제품은 런처/명령 팔레트/키보드 우선 도구가 아닙니다. 그렇지 않으면 중앙 유리 팔레트 이미지가 표시되지 않습니다.
- 청중은 키보드 단축키를 모릅니다. (레시피의 주요 신호를 놓칠 것입니다.)
- 엄격하게 기업적인 톤이 필요합니다. Raycast는 장난스러운 느낌을 왜곡합니다.
