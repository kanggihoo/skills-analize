# y2k-retrofuturism — Y2K / 프루티거 에어로 레트로퓨처리즘

- **분류**: 전문 분야 / 장르
- **분위기**: 90년대 후반~2000년대 초반의 기술 낙관주의: 크롬, 유리 같은 방울, 젤리처럼 비치는 재질, 렌즈 플레어
- **적합한 용도**: 패션·음악·향수를 자극하는 제품, 크리에이티브 캠페인, 1999~2005년 인터넷을 연상시키는 작업
- **참고 이미지**: 90년대 후반 Apple iMac G3 광고, Windows Vista Aero, 초기 iPod의 물빛 버튼, MySpace 페이지

**색상 팔레트**
- 바탕: 전기빛 아이스 블루 `#A3D5FF` 또는 크롬 실버 `#E0E4EA`
- 유리 포인트: 시안 `#5FC9F8` → 마젠타 `#FF66C4`(무지갯빛 기름막 그라데이션)
- 크롬: `#C4C9D2`부터 `#F2F4F8`까지의 브러시드 스틸 하이라이트
- 애시드 그린 포인트: `#A8FF00`(아껴서 사용)
- 잉크: 바탕색에 따라 `#000000` 또는 `#FFFFFF`

**타이포그래피**
- 디스플레이: 개성 있는 두툼하고 둥근 산세리프. Frutiger, Eurostile, Sharp Grotesk의 굵은 웨이트를 사용하거나 크롬 효과를 적용합니다.
- 본문: Frutiger 또는 Avenir 같은 친근한 휴머니스트 산세리프, 14~16px
- 숫자 카운터는 LCD·디지털 표시창 스타일과 잘 어울립니다.
- 링크에 밑줄과 반짝임 효과를 주는 경우가 많습니다.

**간격**: 4 / 8 / 16 / 24 — 촘촘하지만 방울처럼 통통한 느낌

**모서리 반경**: 젤리처럼 16 / 24 / 32 / 9999(완전한 원). 버튼은 알약 모양의 젤리 방울처럼 만듭니다.

**그림자**: 강하고 색이 있는 광택 반사와 그림자를 사용합니다. 예: `0 16px 32px rgba(95, 201, 248, 0.4)`. 유리 느낌을 내도록 안쪽 하이라이트도 넣습니다.

**모션**: 통통 튀는 스프링, 빛나는 펄스, 렌즈 플레어가 훑고 지나가는 움직임. 초기 Flash 인터랙션을 떠올리게 합니다.

**시그니처 요소**
- 안쪽 위쪽에 하이라이트를 넣어 물빛·로젠지 모양을 흉내 낸 반투명 유리 버튼
- 히어로 및 캐릭터 이미지에 적용한 무지갯빛 기름막 그라데이션
- 반짝임 레이어를 더한 크롬 효과 타이포그래피
- 유리 표면에 적용한 렌즈 플레어 또는 정반사 하이라이트
- 3D·입체감이 있는 UI 요소(OS X Aqua Dock 효과)
- 배경에 떠다니는 원형 구체와 방울

**피할 요소**
- 각진 모서리
- 탁하거나 흙빛이 도는 팔레트 — Y2K는 밝고 인공적인 느낌입니다.
- 절제된 타이포그래피 — Y2K는 대담하고 풍성합니다.
- “세련된 2020년대 미니멀리즘”처럼 보이는 요소

**AI 프롬프트 시작 문구**
> Y2K 레트로퓨처리즘 장면, 크롬 실버와 아이스 블루의 무지갯빛 그라데이션 배경, 시안과 마젠타의 기름막 반사가 비치는 유리 구체가 떠 있고 오른쪽 위에는 렌즈 플레어, 밝고 반투명한 알약 모양 버튼 하나, 1990년대 후반 기술 낙관주의 분위기, 16:9.

**사용하지 말아야 할 때**
- 브랜드에 향수나 레트로, 장난스러운 인상이 전혀 없을 때
- 엔터프라이즈·전문가 대상일 때 — 이 레시피는 소비자 패션·음악 분야에 맞춰져 있습니다.
- 긴 글의 가독성이 중요할 때(Y2K는 읽을거리가 아니라 순간적인 인상을 위한 스타일입니다.)
