# headspace-meditation — Headspace / Calm

- **분류**: 따뜻한 휴머니즘
- **분위기**: 부드러운 파스텔, 모든 모서리를 둥글게, 차분한 손그림 일러스트
- **적합한 용도**: 웰니스·명상·건강 앱, 수면·어린이 제품, “친근한 전문가” 서비스
- **참고 대상**: headspace.com, Headspace 앱, Calm.com 잠금 화면 미학

**팔레트**
- 바탕: 따뜻한 복숭아색 `#FFE2C5` 또는 `#FFEDD5`
- 더 짙은 표면: 따뜻한 코럴 `#F4A573`
- 잉크: 따뜻한 짙은 청록 `#1B3A47`
- 보조색: `#5C6B7A`
- 강조색: 차분한 라벤더 `#B0A5D1`, 세이지 `#9DB67A`, 연어색 `#F5867B` 중 장면마다 하나씩 번갈아 사용

**타이포그래피**
- 디스플레이: 둥글고 친근한 산세리프 — Apercu, GT America (둥근 변형), Söhne Breit. 굵기 600.
- 본문: 같은 글꼴 패밀리의 16–17px, 굵기 400
- 감정적인 순간에 선택적으로 손글씨 사용 — Caveat 같은 글꼴로 부드러운 손글씨 한 줄을 아주 제한적으로 넣음

**간격**: 넉넉하게 — 8 / 16 / 24 / 40 / 64 / 96

**모서리 반경**: 크게 — 작은 요소 16 / 중간 24 / 큰 요소 32. 버튼은 알약 형태 (반경 = 높이 / 2).

**그림자**: 부드럽고 따뜻하게 — `0 8px 24px rgba(244, 165, 115, 0.2)`. 바탕색에 맞춰 색을 입히는 경우가 많음.

**모션**: 부드럽고 느리며 호흡하듯 움직임. 이징은 400–800ms. 호버 시 들리는 요소가 가볍게 뜨는 느낌. 주요 요소에 은은한 호흡 애니메이션 (1.5–4초 주기).

**시그니처 요소**
- 둥근 도형으로 그린 중심 캐릭터·마스코트 (Headspace의 오렌지색 원형 캐릭터)
- 본문 문구(“숨을 들이마시고… 내쉬고…”)와 동기화되어 커졌다 작아지는 호흡 원 애니메이션
- 따뜻한 복숭아색 그라데이션 바탕이 색조 사이를 천천히 이동
- 모든 모서리를 둥글게 처리 — 각 컨테이너는 알약 모양이나 모서리가 부드러운 직사각형
- 차분한 마이크로카피 (“잠시 쉬어가세요. 기다릴게요.”)

**피할 것**
- 차가운 팔레트 — 야간 모드에서도 Headspace는 따뜻한 톤을 사용 (차가운 네이비 대신 따뜻한 짙은 청록)
- 날카로운 모서리
- 거친 모션 (튀는 스프링은 놀랄 만큼 갑작스러움. 부드러운 이징만 사용)
- 장면마다 두 가지를 넘는 색상

**AI 프롬프트 시드**
> 따뜻한 복숭아색 `#FFE2C5` 배경의 단순한 플랫 일러스트, 친근한 표정을 지닌 코럴색 둥근 마스코트 하나, 주변의 부드러운 파스텔 도형 (세이지, 라벤더), 날카로운 가장자리 없이 손으로 그린 듯 약간 불완전한 느낌, 4:5.

**사용하지 말아야 할 경우**
- 제품이 날카롭고 세련된 인상을 줘야 할 때 — Headspace 구성은 부드럽고 보살피는 듯함
- 브랜드가 웰니스·돌봄을 지향하지 않을 때 — 유아적으로 느껴질 수 있음
- 권위 있거나 전문가다운 어조가 필요할 때 — 이 구성은 지시하기보다 다정함
