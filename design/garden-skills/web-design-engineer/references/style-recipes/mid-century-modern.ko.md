# mid-century-modern — 미드센추리 모던 (Paul Rand / Saul Bass)

- **분류**: 전문 분야 / 장르 (정보 구조 요소도 포함)
- **분위기**: 1950~60년대 미국 그래픽 모더니즘 — 기하학적 형태, 세심한 손맛, 재즈 앨범 같은 자신감
- **적합한 용도**: 문화·영화·출판 아이덴티티, 헤리티지를 내세우는 프리미엄 소비재 브랜드, “세련된 품격”
- **참고 대상**: IBM 로고 (Paul Rand), Saul Bass의 *현기증* / *살인의 해부* 포스터, Alvin Lustig 책 표지, 미드센추리 재즈 앨범 슬리브 (Reid Miles / Blue Note)

**팔레트**
- 바탕: 따뜻한 크림 `#EBE3D2`, 머스터드 `#D9A441`, 차분한 청록 `#3D6E70` 중 하나
- 잉크: `#1A1A18`
- 한 작업물에 색상 최대 3개 — 굵은 색상 하나와 차분한 색상 둘
- 흔한 미드센추리 조합: 머스터드 + 벽돌색 + 크림, 청록 + 크림 + 검정, 시에나 + 잉크 + 뼈색

**타이포그래피**
- 디스플레이: 큰 크기의 기하학적 그로테스크체 (Futura, Avenir, ITC Avant Garde), 콘덴스드 굵기를 자주 사용
- 또는 에디토리얼 장면에 슬랩 세리프 (이집션 / Memphis) 사용
- 본문: 16–17px의 휴머니스트 세리프 (Sabon, Garamond)
- 숫자는 그래픽 요소처럼 숫자 하나를 크게 설정하는 경우가 많음

**간격**: 구조화된 그리드; 4 / 8 / 16 / 24 / 32 / 48

**모서리 반경**: 전체 0. 미드센추리는 부드럽지 않고 기하학적임.

**그림자**: 없음 — 평평한 색면만 사용

**모션**: 최소한으로 사용. Saul Bass 타이틀 시퀀스처럼 단일 박자에 형태가 제자리로 미끄러져 들어옴.

**시그니처 요소**
- 큰 원 하나, 삼각형, 반달처럼 기하학적 형태 하나를 주요 시각 요소로 삼은 구도
- 손으로 자른 종이 느낌 (형태의 가장자리가 약간 불완전해 직접 자르고 붙인 듯함)
- 글자와 형태를 통합 (원 둘레를 따라 휘는 헤드라인이나 색면 *안에* 놓인 글자)
- 작업 전체를 묶는 일러스트 모티프 하나를 반복 (양식화된 새, 추상 인물)
- 낮은 불투명도의 인쇄 느낌 그레인이나 종이 질감

**피할 것**
- 그라데이션 — 미드센추리는 평평한 색을 사용
- 주요 시각 요소로 쓰는 사진 (일러스트가 주도하고 사진은 보조)
- 작업물 하나에 3색 초과
- 둥글거나 모서리가 부드러운 UI

**AI 프롬프트 시드**
> Saul Bass 스타일의 미드센추리 모던 포스터 구성, 따뜻한 크림색 `#EBE3D2` 종이 배경에 머스터드 `#D9A441` 큰 원 하나를 주요 기하학적 형태로 사용, 평평한 색면, 약한 종이 질감, 손으로 자른 가장자리, 그라데이션과 그림자 없음, 3:4.

**사용하지 말아야 할 경우**
- 기능이 많고 실용성 중심인 제품일 때 (미드센추리는 에디토리얼·포스터 방식)
- 브랜드에 헤리티지·문화·공예 요소가 없을 때
- 메시지 전달에 사실적인 사진이 필수일 때
