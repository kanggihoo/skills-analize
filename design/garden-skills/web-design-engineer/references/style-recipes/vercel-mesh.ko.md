# vercel-mesh — Vercel(그라디언트 메쉬 시대)

- **학교**: 최신 도구/Builder SaaS(모션/실험에도 적용)
- **바이브**: 단일한 반짝이는 그라디언트 메쉬로 인해 흑백의 정밀도가 깨졌습니다.
- **최적의 용도**: 플랫폼/인프라 도구, AI 도구, 현대적인 느낌을 주지만 AI의 진부한 표현은 원하지 않는 심층적인 기술 제품
- **기준**: vercel.com, v0.dev 랜딩, nextjs.org

**팔레트**
- 접지: `#000000`(트루 블랙)
- 표면 1: `#0A0A0A`
- 표면 2: `#111111`
- 헤어라인: `#1F1F1F` 또는 `rgba(255,255,255,0.08)`
- 기본 텍스트: `#EDEDED`
- 보조 텍스트: `#888888`
- 그라디언트 메쉬 액센트(영웅/섹션 나누기에만 사용됨):
  - 청록색 `#0070F3` → 마젠타색 `#FF0080` → 주황색 `#F5A623` — 채도가 낮고 페더링이 높으며 혼합되어 있으며 보라색-분홍색 AI 그라데이션이 결코 강하지 않습니다.
- CTA에 대한 한 가지 날카로운 강조: 검정색 바탕에 흰색 `#FFFFFF` 버튼(고대비)**타이포그래피**
- 디스플레이: Geist Sans(체중 500-600) — Vercel의 가족입니다. 인터 타이트 웨이트 600으로 대체하세요.
- 본문: Geist Sans 15-16px, 무게 400, 줄 높이 1.6
- Mono: Geist Mono — 코드, 터미널 스타일 명령, 로그 배포용

**간격**: 4 / 8 / 16 / 24 / 40 / 64 / 96 / 128

**반경**: 8(소) / 12(중) / 16(대). Linear보다 약간 더 관대하지만 여전히 규율이 있습니다.

**그림자**: 구성 요소 수준에서는 최소화됩니다. *페이지*는 그림자가 아닌 그라디언트 메쉬로 인해 밝아지는 느낌이 듭니다.

**모션**: 빠른 이지 아웃(입방 베지어(0.16, 1, 0.3, 1)), 200ms 호버, 레이아웃의 경우 500~700ms. 메시 자체가 천천히 표류합니다(10~20초 루프).**시그니처 무브**
- 영웅의 풀 블리드 그라디언트 메쉬 - 확산되고 몽환적이며 검은색 가장자리까지 깃털이 있음
- 그렇지 않은 경우 페이지는 헤어라인 디테일과 모노스페이스 액센트가 있는 흑백입니다.
- 영웅 요소로 배포/터미널 로그 판독(로렘이 아닌 실제 느낌)
- 카드에 마우스를 올리면 애니메이션 메시(아래에서 부드러운 빛으로 카드가 "켜짐")
- 흰색 단색 버튼(`#000000`의 `#FFFFFF`) - 고대비, 그라데이션 없음, 그림자 없음

**피하세요**
- 밝고 포화된 보라색 → 분홍색 그라데이션(이것이 레시피가 *대체*하는 AI 진부함입니다)
- 페이지당 하나 이상의 메시
- 모든 구성요소에 빛이 납니다(선택적 사용 — 영웅 한 명, 섹션 나누기 한 명, 그게 전부입니다)
- 컬러 버튼(브랜드 버튼은 흰색)

**AI 프롬프트 시드**
> 순수한 검정색 #000000 배경의 추상 대기 그라데이션, 진한 파란색 #0070F3이 마젠타색 #FF0080 및 주황색 #F5A623으로 페이드되고 깃털 가장자리가 검은색으로 혼합되고 몽환적인 소프트 포커스, 개체 없음, 텍스트 없음, 16:9, 전체적으로 매우 낮은 채도.**다음과 같은 경우에는 사용하지 마세요**
- 브랜드는 플랫폼/인프라/툴링 제품이 아닙니다. 소비자 사이트의 메시에는 "너무 열심히 노력하고 있다"고 읽혀집니다.
- 여러 개의 그라디언트 메쉬가 필요합니다(하나 또는 없음 사용, 여러 개 사용 안 함)
- 관객들은 따뜻한/인간적인 느낌을 기대한다.
