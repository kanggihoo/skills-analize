# 스트라이프 프레스 — 스트라이프 프레스

- **학교**: 따뜻한 휴머니스트(편집본 포함)
- **Vibe**: 사물로서의 책, 크림+잉크, 따뜻한 사진, 성공적인 인프라 기업만이 자금을 지원하는 디자인
- **최적의 용도**: 편집/출판, 장편 기능, "도서 및 아이디어" 제품
- **시금석**: press.stripe.com, 실제 Stripe Press 서적(천 제본, 호일 스탬프)

**팔레트**
- 그라운드 : `#F1ECDE` (웜본)
- 표면이 더 어두움 : `#E6DCC4`
- 잉크: `#1A1A18`(매우 따뜻한 검정색에 가까운)
- 보조 텍스트: `#736D5A`
- 포일 스탬프 액센트: 진한 청록색 `#1B4B5A` 또는 번트 시에나 `#A04A2A`(책 표지별 색상)
- 헤어라인 : `#C8BEA4`**타이포그래피**
- 디스플레이: 세련된 과도기적 또는 현대적인 세리프 — GT Sectra, Domaine Display, Italian Old Style. 모든 곳에서 이탤릭체.
- 본문: 18~19px의 구식 세리프, 줄 높이 1.65 — Source Serif, Lyon Text, ITC Galliard
- UI 전용 Sans: 탐색 및 캡션을 위한 작은 크기의 인문주의자 Sans — Söhne 또는 GT America
- 종종 넓은 디스플레이 세리프체와 슬림한 바디 세리프체를 결합합니다.

**간격**: 4 / 8 / 16 / 24 / 32 / 48 / 96. 편집 호흡 공간.

**반경**: 전체적으로 0(책에는 둥근 모서리가 없음)

**그림자**: 책 개체에 표시 — `0 24px 48px rgba(0, 0, 0, 0.18)` - 책이 페이지에서 3차원처럼 느껴지도록 합니다.

**모션**: 느림, 느림, 느림. 1~2초에 걸쳐 크로스페이드됩니다. 책은 마우스를 올리면 3D로 부드럽게 회전합니다(최대 15°). 영웅 사진에 대한 Ken Burns(~20대)**시그니처 무브**
- 영웅으로서의 책 표지 사진 - 따뜻한 빛과 정직한 그림자가 있는 크림색 종이 위에 촬영된 실제 물리적 대상
- 강조를 위한 넓은 세리프 이탤릭체, 본문 크기 1.5–2배 설정
- 넓은 여백에 매달린 대형 이탤릭 세리프체로 된 저자/장 인용문
- 섹션 구분을 위한 천 질감 배경(낮은 불투명도의 미묘한 직물 패턴)
- 책/챕터당 단일 포일 스탬프 색상(금색, 진한 청록색, 번트 시에나) — 결합되지 않음

**피하세요**
- 순백색 바탕(따뜻한 크림도 레시피에 포함되어 있습니다)
- 산세리프 체형(편집 세리프가 시그니처임)
- 책의 카드 그리드 — Stripe Press는 각 책을 타일이 아닌 기능으로 배치합니다.
- 차가운 중성 회색 — 여기의 모든 회색은 따뜻한 색조를 가집니다.
