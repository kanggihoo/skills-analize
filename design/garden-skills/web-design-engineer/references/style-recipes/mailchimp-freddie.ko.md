# mailchimp-freddie — Mailchimp (프레디 시대, 2018–2022년경)

- **분류**: 따뜻한 휴머니즘
- **분위기**: 손으로 그린 표시, 따뜻한 노랑, 마이크로카피에 담긴 개성
- **적합한 용도**: 소상공인 도구, 크리에이터 제품, 커뮤니티·교육, 친근한 B2C
- **참고 대상**: 2023년 이전 mailchimp.com 리디자인 (Wayback), 프레디 일러스트 모음

**팔레트**
- 바탕: 히어로·브랜드 장면에 Mailchimp 노랑 `#FFE01B`, 본문에는 `#FFFFFF`
- 잉크: `#241C15` (따뜻한 거의 검정색, 순수한 검정은 사용하지 않음)
- 크림색 표면: `#FBEFE3`
- 보조색: `#88837C`
- 강조색: 선명한 팝핑크 `#FF4D74` 또는 따뜻한 코럴. 아주 제한적으로 사용.

**타이포그래피**
- 디스플레이: 친근한 그로테스크체 — Helvetica Now Display, Söhne, 굵기 700–800의 Inter Tight
- 본문: 같은 글꼴 패밀리, 17–18px, 굵기 400, 행간 1.6
- 장식용: 가끔 손으로 그린 듯한 스크립트 또는 직접 쓴 느낌의 텍스트

**간격**: 4 / 8 / 16 / 24 / 40 / 64 — 넉넉하지만 성기지는 않음

**모서리 반경**: 작은 요소 8 / 중간 16 / 큰 알약 형태 24. 버튼은 알약 모양.

**그림자**: 부드럽고 따뜻하게 — `0 4px 12px rgba(36, 28, 21, 0.08)`

**모션**: 튀는 움직임을 환영함. 호버 시 스프링 물리를 적용하고, 이징은 친근하게 설정.

**시그니처 요소**
- 프레디 스타일의 손그림 일러스트 (윙크하는 마스코트, 개성 있는 선화 캐릭터) — AI로 생성하지 말고 의뢰하거나 단일 일러스트레이터의 그림을 사용
- 페이지를 나누는 노란색으로 꽉 채운 섹션 배경
- 검은색 2–3px 테두리의 알약형 버튼 (멤피스 스타일)
- 마이크로카피에 담긴 개성 (“전송 지표를 최적화하세요” 대신 “더 나은 이메일을 보내세요”)
- 그리드 중앙을 피하고 비대칭으로 기울여 배치한 일러스트

**피할 것**
- 순수 검정 — 이 구성은 따뜻한 거의 검정색 사용
- 스톡 일러스트 — 손그림이 차별점
- 한 번에 보이는 색상이 3개 초과 (노랑 + 잉크 + 강조색 하나)
- 차갑고 기업적인 마이크로카피

**AI 프롬프트 시드**
> 따뜻한 크림색 `#FBEFE3` 배경 위에 따뜻한 색상(노랑, 코럴)을 칠한 선화 캐릭터 하나가 윙크하는 손그림 일러스트, 친근하고 다가가기 쉬운 선 스타일, 의도적인 불완전함, 4:5.

**사용하지 말아야 할 경우**
- 브랜드가 프리미엄·럭셔리해야 할 때 — Mailchimp의 따뜻함은 대중적이고 접근하기 쉬운 느낌
- 실제 일러스트레이터의 그림을 구할 수 없을 때 (구성의 효과가 절반으로 줄어듦)
- “친근함”에 회의적인 기업 전용 사용자층일 때
