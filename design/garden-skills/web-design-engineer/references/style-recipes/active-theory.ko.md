# active-theory — 액티브 시어리 (시네마틱 WebGL)

- **분류**: 모션 / 실험적
- **분위기**: 영화 같은 웹 경험, WebGL 히어로, 물리적인 감각의 인터랙션
- **적합한 용도**: 브랜드 출시 사이트, 게임·엔터테인먼트 제품, 경험 마케팅 콘텐츠
- **참고 대상**: activetheory.net, 이들이 만든 NASA / Apple WWDC 개발자 포털, Doritos / 영화 제휴 출시 사이트

**팔레트**
- 프로젝트 콘텐츠에서 가져온 강렬한 단일 색조를 주로 사용 — 검정에 브랜드나 영화의 시그니처 색 하나를 더함
- 높은 대비 — 짙은 검정과 밝은 강조색
- 색조가 있는 중성색 — 평범한 회색은 피하고, 푸른 기가 도는 회색(공상과학)이나 따뜻한 호박색 기가 도는 회색(영화적 분위기)을 사용

**타이포그래피**
- 디스플레이: 캠페인용으로 만든 강한 그로테스크체나 커스텀 디스플레이 서체 — Druk, Editorial New, ABC Diatype Mono
- 본문은 부차적 — 대부분의 콘텐츠는 이미지 위에 놓이며, 읽기보다 장면을 경험하는 데 중점
- 톤에 따라 자간을 매우 좁히거나 넓힌 대문자 디스플레이를 자주 사용

**간격**: 영화적 구성 — 전체 화면 캔버스에서 콘텐츠를 중앙이나 예상 밖의 모서리에 배치

**모서리 반경**: 0

**그림자**: CSS가 아니라 WebGL 조명으로 표현

**모션**: 장편 영화 수준으로 구현. 3D 공간을 가로지르는 카메라 이동, 물리 기반 파편·입자. 페이지 자체가 무대가 됨.

**시그니처 요소**
- 사용자가 이동하며 경험하는 전체 화면 WebGL 히어로 장면 (스크롤이 카메라 경로가 됨)
- 커서나 기기 기울기에 반응하는 실시간 물리 효과 또는 입자 시스템
- 세심하게 연출한 장면 간 전환 (흔한 페이드 효과는 피함)
- 사운드 디자인을 통합 (잔잔한 환경음은 텍스트 구간에서 낮춤)
- 강렬한 순간 하나를 최대치로 끌어올리는 구성 — 모든 요소가 마지막 한 장면을 향해 쌓임

**피할 것**
- 작은 WebGL 장면을 여러 개 넣기 (작은 장면 다섯 개가 아니라 큰 장면 하나가 핵심)
- 콘텐츠가 많은 사이트에 적용하기 (시네마틱 구성은 마케팅 순간에 적합하며 문서 사이트에는 적합하지 않음)
- 기성 Three.js 데모를 가져다 쓰기 (이 구성은 직접 만든 장면을 요구하며, 평범한 WebGL은 저렴해 보임)

**AI 프롬프트 시드**
> 공상과학 출시 영화의 강렬한 한순간을 담은 시네마틱 VFX 스틸, 한 방향에서 들어오는 키 라이트, 짙은 그림자, 장면 속에 떠 있는 브랜드 강조색 하나, 공중의 파편 입자, 2.39:1 화면비.

**사용하지 말아야 할 경우**
- 성능이나 접근성 제약으로 무거운 WebGL을 사용할 수 없을 때
- 실용성이 중요한 제품일 때 (이 구성은 일상적인 사용이 아니라 특별한 순간을 위한 것)
- 제작 예산이 3주 미만일 때
