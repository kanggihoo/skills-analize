# dieter-rams-braun — 디터 람스 / 브라운

- **분류**: 에디토리얼 / 미니멀
- **분위기**: “적지만 더 나은”, 기능에 충실한 정직함, 산업 디자인의 절제
- **적합한 용도**: 하드웨어 제품 페이지, 오디오 장비, 산업·도구 브랜드, 디자인 중심 B2B
- **참고 대상**: Braun T3 라디오, Braun ET66 계산기, 람스의 *좋은 디자인을 위한 10가지 원칙*

**팔레트**
- 바탕: `#E4E1DC` (밝은 콘크리트색) 또는 `#F5F4F0` (종이색)
- 잉크: `#191919`
- 산업용 회색: `#A8A8A8`, `#5C5C5C`
- 강조색: 신호색 하나 — Braun 오렌지 `#E96A26` 또는 신호 노랑 `#F5C518`. 전원 표시 점이나 활성 상태처럼 기능 요소에만 사용.

**타이포그래피**
- 디스플레이와 본문: 정밀한 그로테스크체 — Akzidenz-Grotesk, Helvetica Now, Söhne. 본문은 굵기 400, 강조는 500, 700은 사용하지 않음.
- 사양 표의 숫자는 모노스페이스 변형 글꼴과 잘 어울림

**간격**: 4px 하위 그리드 기반. 눈에 보이는 간격은 4 / 8 / 16 / 24 / 32 / 64 / 128. 기능적이며 “럭셔리한 여백”을 부풀리지 않음.

**모서리 반경**: 최대 2–4px. 기본적으로 각지게 처리.

**그림자**: 없음.

**모션**: 실용적 — 상태를 즉시 바꿈 (약 80–120ms), 불필요한 꾸밈은 없음.

**시그니처 요소**
- 실제 또는 가상의 치수 설명을 붙인 제품 분해도
- 페이지에 “활성” 또는 “전원” 상태를 나타내는 신호 오렌지 점 하나만 사용 — 장식용으로 쓰지 않음
- 사양 표를 핵심 레이아웃 요소로 표시 (“사양” 토글 뒤에 숨기지 않음)
- 모든 라벨을 쉬운 표현으로 정확히 명명 (“상호작용 모드 전환” 대신 “켜기 / 끄기”)
- 페이지 자체가 장비의 일부처럼 느껴짐

**피할 것**
- 제품을 낭만적으로 표현하는 사진 — Braun은 제품을 공학 실험 표본처럼 격자 배경 위에 촬영함
- 여러 강조색
- 어디에나 들어가는 곡선 — 호버 효과도 튀지 않게 처리
- 라이프스타일 이미지

**AI 프롬프트 시드**
> 1960년대 Braun 디자인 언어를 담은 산업 제품 사진, 밝은 회색 `#E4E1DC` 격자 배경 위의 하드웨어 사물 하나, 정면 직교 투영, 가는 산세리프체로 표기한 치수와 라벨, 회색·검정·오렌지 마커 하나로 제한한 팔레트, 4:3.

**사용하지 말아야 할 경우**
- 제품이 부드럽고 감성적이거나 라이프스타일 중심일 때 — 람스의 규율은 스킨케어나 호스피탈리티에 차갑게 느껴짐
- 팀이 따뜻함이나 개성을 원할 때 — 이 구성은 의도적으로 비개인적임
- 일반 소비자나 비기술 사용자층을 대상으로 할 때 — “지루한 사양표”로 여길 수 있음
