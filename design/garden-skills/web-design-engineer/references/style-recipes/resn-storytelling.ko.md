# resn-storytelling — Resn(스크롤을 통한 스토리)

- **학교**: 모션 / 실험
- **Vibe**: 깜짝 보상; 페이지는 스크롤하는 사람들에게 이야기를 전합니다.
- **최적의 용도**: 브랜드 스토리텔링, 대행사 포트폴리오, 캠페인 마이크로사이트
- **기준**: resn.co, Resn의 사례 연구 페이지, awwwards 오늘의 사이트 아카이브

**팔레트**
- 프로젝트 중심 — Resn의 레시피는 고정된 팔레트보다 구성에 더 가깝습니다.
- 종종 한 작품 내에서 따뜻함과 차가움이 대조됩니다(시원한 환경에 대해 따뜻한 성격, 또는 그 반대).
- 스토리가 요구하는 부분이 포화 상태입니다. 숨쉬는 곳에 음소거

**타이포그래피**
- 캠페인별 디스플레이 화면이 거의 항상 존재합니다(맞춤형 또는 특이한 경우).
- 조용한 체형, 작은 사이즈에는 휴머니스트가 없는 경우가 많음
- 텍스트가 장면에 통합되는 경우가 많습니다(제목은 고정 UI 레이어가 아닌 WebGL 공간에 설정됨).

**간격**: 불규칙하고 구성 중심입니다. 그리드 엄격하지 않음

**반경**: 프로젝트에 따라 다름

**그림자**: 구성요소가 아닌 장면에서 구워짐**모션**: 긴 형식의 안무 — 단일 페이지는 8~12개의 스크롤 트리거에 걸쳐 90초 분량의 스토리를 전달할 수 있으며 특정 순간에 보상을 제공합니다.

**시그니처 무브**
- 스크롤 트리거를 통해 내러티브 비트 표시 - 캐릭터가 화면을 가로질러 움직이고, 제품이 공개되고, 펀치라인이 나옵니다.
- 반복 방문자를 위해 숨겨진 부활절 달걀
- 커서 반응형 표면 재료(호버하면 텍스처가 변경되고 오디오 신호가 재생됨)
- 다중 장면 구성 — 각 섹션은 고유한 예술 방향을 지닌 영화 장면으로 처리됩니다.
- 마지막 보상 — 전체 스크롤을 통해서만 공개되는 특별한 상호 작용 또는 장면

**피하세요**
- 비트가 너무 많아 부풀어오르는 경우 - Resn의 레시피는 "더 적고 더 나은" 비트입니다.
- 내러티브가 없는 순수한 장식 - 모든 모션 순간이 스토리를 발전시켜야 합니다.
- 요점을 잊어버림 - 레시피에는 보상 장면이 필요함**AI 프롬프트 시드**
> 브랜드 마이크로사이트의 내러티브 장면, 액션 중간 순간, 의도적인 모션 블러, 웜-쿨 팔레트 대비, 극장용 조명, 16:9를 사용하여 움직이는 캐릭터 또는 개체.

**다음과 같은 경우에는 사용하지 마세요**
- 말할 스토리가 없습니다. (레시피에는 서술형 콘텐츠가 필요합니다.)
- 청중은 참을성 있게 스크롤하지 않습니다. (Resn은 인내심을 보상합니다. 참을성이 없는 청중의 경우 정적 레시피를 선택하십시오.)
- 빌드가 급하게 이루어짐 - Resn의 레시피에는 안무 시간이 필요함
