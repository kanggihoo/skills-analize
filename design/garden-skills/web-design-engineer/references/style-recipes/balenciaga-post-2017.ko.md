# balenciaga-post-2017 — 발렌시아가 (뎀나 시대 이후)

- **분류**: 브루탈리스트 / 날것의 미감
- **분위기**: 브라우저 기본 스타일을 무기로 활용, 비현실적으로 큰 Helvetica, 안티 럭셔리 럭셔리
- **적합한 용도**: 패션·반문화·향수 브랜드, “디자인하기엔 너무 쿨하다”는 포지셔닝
- **참고 대상**: balenciaga.com (Wayback에서 2018년 이후 스냅샷), Vetements 캠페인, 2017년 이후 럭셔리 안티 디자인

**팔레트**
- 잉크: `#000000`
- 바탕: `#FFFFFF`
- 차분한 미색 표면 하나: `#F5F4F0`
- 색상은 사용하지 않음. 사진 한 장에 색이 들어가는 경우를 제외하면 UI 요소에 색을 쓰지 않음.

**타이포그래피**
- 디스플레이와 본문: Helvetica 또는 Arial만 사용. 모든 굵기와 크기를 활용하되 글꼴은 하나로 제한.
- 히어로 크기(140px 이상)의 헤드라인은 대문자로 자주 설정
- 본문은 작게, 11–13px
- 굵기를 섞어도 되지만 글꼴 종류를 섞지 않음

**간격**: 8 / 16 / 24 / 40 — 절제되어 있지만 고급스럽고 널찍하진 않음. “굳이 부드럽게 만들지 않았다”는 느낌.

**모서리 반경**: 0

**그림자**: 없음

**모션**: 없음 — 페이지에 애니메이션을 넣지 않음. 호버 시 밑줄이 바뀌는 정도만 허용.

**시그니처 요소**
- 극단적으로 큰 대문자 Helvetica 헤드라인, 좁은 자간, 페이지 가장자리에 딱 붙인 왼쪽 정렬을 자주 사용
- 에디토리얼 패션 스타일의 제품 사진 — 모델과 제품, 강한 조명, 어색한 포즈. 웃는 스톡 사진 모델의 전형은 피함
- 내비게이션은 평범한 텍스트 링크, 때로는 페이지 상단의 세로 목록으로 구성
- 캡션과 메타데이터는 최소화 (모델명, 디자이너, 장소)
- 버튼처럼 꾸민 버튼을 두지 않고 CTA는 밑줄 친 텍스트 링크로 표시

**피할 것**
- Helvetica / Arial 이외의 글꼴
- 색상
- 둥근 버튼, 그림자, 호버 효과처럼 세련된 UI 표현
- 모든 장식 요소

**AI 프롬프트 시드**
> 평범한 미색 `#F5F4F0` 배경 앞에 선 모델 한 명의 패션 에디토리얼 사진, 정면에서 비추는 강한 플래시, 어색하고 정적인 포즈, 무표정, 4:5.

**사용하지 말아야 할 경우**
- 브랜드에 패션·반문화 이미지가 없을 때 — 이 구성이 코스프레처럼 보일 수 있음
- 사용자가 적극적으로 “판매당하는” 느낌을 기대할 때 — 발렌시아가 구성은 의도적으로 사용자를 무시함
- 전환율이 중요할 때 — 이 구성은 가벼운 방문자보다 특정 취향을 공유하는 사용자에게 전환됨
