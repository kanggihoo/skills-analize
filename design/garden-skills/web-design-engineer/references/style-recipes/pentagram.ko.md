# 오각형 — 오각형 / Paula Scher

- **학교**: 정보 아키텍처
- **Vibe**: 이미지와 같은 대담한 타이포그래피; 유형은 시각적인 작업을 수행합니다. 다른 모든 것은 물러난다
- **최적의 용도**: B2B 정체성, 문화 기관, "비즈니스를 의미합니다" 순간
- **기준**: pentagram.com, Paula Scher의 공공 극장 포스터, MIT Media Lab 아이덴티티

**팔레트**
- 고대비 2색: 지상에 잉크. 일반적인 페어링:
  - 흰색 `#FFFFFF`에 검정색 `#000000`
  - 크림 `#F4F1E7`에 코발트 `#1E3FFF`
  - 뼈 `#EFE9DC`에 벽돌 `#B83A1F`
- 프로젝트에 세 번째 색상이 필요한 경우에만 단일 보조 액센트(아주 드물게 사용됨)

**타이포그래피**
- 디스플레이: 대규모로 사용되는 단일 그로테스크 — Helvetica Now(중량 700-900), Söhne Breit 또는 Druk. 헤드라인은 의도적으로 여백을 깨는 **열보다 크게** 설정되는 경우가 많습니다.
- 본문: 체중, 16~17px, 줄 높이 1.45~1.55의 동일 계열
- 숫자: 같은 계열의 표 형식 숫자**간격**: 엄격한 12열 그리드, 넉넉한 여백(24~32px). 모든 텍스트 요소의 기준선 그리드 정렬입니다.

**반경**: 0.

**그림자**: 없음.

**모션**: 인쇄상의 움직임만 해당됩니다. 문자가 안쪽으로 이동하고 헤드라인이 기준선에서 미끄러집니다. 3D도 없고 탄력도 없고 시차도 없습니다.

**시그니처 무브**
- 헤드라인이 너무 커서 열 가장자리에 닿거나 눈에 띄게 넘어가는 경우
- 이미지로 입력 - 영웅 규모의 단일 단어나 문구가 유일한 그래픽이 됩니다.
- 섹션 구분자로 사용되는 색상 블록(액센트 색상의 평평한 직사각형)은 종종 하나의 큰 숫자가 표시됩니다(`02`).
- 캡션과 메타데이터는 아주 작은 정확한 유형으로 그리드에 고정되어 있으며, 종종 열 홈통에 고정됩니다.
- 때때로 전체 페이지 너비에 걸쳐 단일 규칙선(1px)이 그려져 모든 항목을 고정합니다.**피하세요**
- 시각적 리드로서의 사진(사진이 아닌 활자 리드) — 예외: 영웅 사진이 있는 경우 거대한 활자 뒤에/아래에 있습니다.
- 다양한 유형군
- 그라데이션, 그림자, 장식적인 모든 것
- 콘텐츠의 카드 그리드(Pentagram은 카드가 아닌 스프레드로 생각함)

**AI 프롬프트 시드**
> 편집 포스터 구성, 거대한 검정색 Helvetica 무게 900으로 설정된 단일 문구, 레이아웃 여백을 지나 피가 나는 문자, 그 뒤에는 코발트 #1E3FFF의 평평한 필드, 사진 없음, 일러스트레이션 없음, 3:4.

**다음과 같은 경우에는 사용하지 마세요**
- 헤드라인은 굵게 또는 짧게 만들 수 없습니다(3~6단어 문구) — Pentagram에는 강력한 카피가 필요합니다.
- 다양한 계층의 기능 밀도가 전달되어야 합니다(이것은 기능 카탈로그가 아닌 기관의 의견입니다).
