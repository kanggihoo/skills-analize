# nyt-the-daily — New York Times 사설

- **학교**: 정보 아키텍처
- **Vibe**: 권위 있는 브로드시트, 타이포그래피 기술의 세대
- **최적의 용도**: 긴 형식의 사설, 뉴스/저널리즘 제품, 내러티브 설명자
- **시금석**: nytimes.com 홈페이지, NYT Cooking, NYT 조사 기능

**팔레트**
- 접지 : `#FFFFFF`
- 잉크: `#121212`
- 보조 텍스트: `#666666`
- NYT 레드 `#D0021B` — 뉴스 속보 표시에만 사용되거나 드물게 사용됩니다.
- 소프트 섹션 배경: `#F7F7F7`
- 헤어라인 : `#E2E2E2`

**타이포그래피**
- 디스플레이: Cheltenham(NYT 독점) — Sentinel 또는 Tiempos Headline을 대체합니다. 영웅의 경우 무게 700, 이탤릭체가 널리 사용됩니다.
- 부제목: 무게 400의 Imperial 또는 Lyon 디스플레이
- 본문: Imperial / Georgia / 소스 세리프 18-20px, 줄 높이 ~1.55
- UI/키커용 Sans: Franklin(NYT) — Söhne Mono 또는 Söhne 대체, 무게 500, 종종 작은 대문자로 표시됨

**간격**: 4 / 8 / 16 / 24 / 32 / 48 / 96. 스토리용 다중 열 그리드.**반경**: 전체적으로 0입니다.

**그림자**: 없음.

**모션**: 최소 - 고정된 바이라인, 지연 로드된 이미지 페이드 인, 8~15초 동안 영웅 사진의 느린 확대/축소.

**시그니처 무브**
- 3단 계층 구조: 작은 눈썹(소형 대문자 없이 "OPINION" / "ANALYSIS" / "INVESTIGATION") → 굵은 세리프 헤드라인 → 기울임꼴 세리프 첫 번째
- 항상 헤드라인 아래에 있는 바이라인 + 타임스탬프 블록
- 몸 크기 1.5~2배의 기울임꼴 세리프체로 설정된 인용문, 위와 아래에 헤어라인 규칙 포함
- 넓은 뷰포트의 다중 열 본문 사본; 모바일의 단일 열(항상 읽기 가능)
- 세리프 캡션이 포함된 인라인 이미지 캡션은 중요하며 스타일이 독특합니다.

**피하세요**
- 산세리프 헤드라인(레시피의 시그니처는 세리프체입니다)
- 기사 카드 그리드 — NYT는 기사를 크기별 계층 구조로 첫 페이지로 배치합니다.
- 기사 본문의 예쁜 UI 버튼
- 본문 중앙 정렬(왼쪽 정렬이 공식입니다)**AI 프롬프트 시드**
> 편집 포토저널리즘, 단 하나의 결정적인 순간 이미지, 자연 조명, 3:2 종횡비, 약간 채도가 낮은 뉴트럴 컬러 그레이딩, 연출되지 않은 실제 느낌, 장소 특정적.

**다음과 같은 경우에는 사용하지 마세요**
- 제품은 SaaS 대시보드입니다. NYT 기술은 거기에서 너무 형식적이라고 읽습니다.
- 콘텐츠가 짧고 효과적입니다(한 줄 CTA) - NYT가 게재되려면 긴 형식이 필요합니다.
- 브랜드에 편집/권한 주장이 없습니다. 코스프레로 읽히는 내용 없이 NYT 음성을 사용합니다.
