# linear — Linear (현대적인 빌더 도구)

- **분류**: 현대적 도구 / 빌더 SaaS
- **분위기**: 개발자 도구의 절제된 고급스러움; 따뜻한 어둠, 가는 선의 디테일, 자신감 있는 절제
- **적합한 용도**: 개발자 도구, AI 도구, “진지하면서도 디자인된” 인상이 중요한 B2B SaaS
- **참고 대상**: linear.app, Linear 변경 로그 페이지, Linear Method 사이트

**팔레트**
- 바탕: `#08090A` (순수한 검정이 아니라 따뜻한 기운이 도는 거의 검정색)
- 표면 1: `#16171C`
- 표면 2: `#1E1F25`
- 표면 3 (높이 올린 표면): `#26272E`
- 가는 테두리: `rgba(255,255,255,0.06)`
- 기본 텍스트: `#F7F8F8`
- 보조 텍스트: `#9CA3AF`
- 차분한 텍스트: `#6B7280`
- 강조색: Linear 보라 `#5E6AD2` — 픽셀의 5% 미만에 사용
- 히어로에만 제한적으로 그라데이션 메시를 사용 (불투명도 8% 미만)

**타이포그래피**
- 디스플레이: 굵기 600의 Inter Tight (또는 Söhne, Geist Sans) — 기본 굵기의 평범한 Inter는 AI 기본값처럼 보이므로 사용하지 않음
- 본문: Inter 14–15px, 굵기 400–500, 행간 1.55
- 모노스페이스: 인라인 코드와 단축키 칩에 GeistMono, JetBrains Mono, Berkeley Mono 사용
- 디스플레이 헤드라인 자간: -0.02em으로 좁게 설정

**간격**: 4 / 8 / 12 / 16 / 24 / 40 / 64 / 96

**모서리 반경**: 작은 UI 6 / 중간 카드 12 / 큰 패널 16. **16을 넘지 않음.** Linear의 반경은 “적당하고 정밀하며, 젤리처럼 둥글지 않음”을 나타냄.

**그림자**: 거의 보이지 않게 — 높이를 올린 표면에 부드러운 `0 1px 2px rgba(0,0,0,0.3)`. **발광 효과와 색 그림자는 사용하지 않음.**

**모션**: 호버는 약 150ms ease-out, 레이아웃 이동은 350–450ms의 quint 곡선 (예: 널리 알려진 `cubic-bezier(0.22, 1, 0.36, 1)`). 상태 전환은 “빠르고 경쾌하지만 튀지 않게”.

**시그니처 요소**
- 모든 패널을 곳곳에서 분리하는 `rgba(255,255,255,0.06)` 1px 가는 테두리
- 선택적으로 강조색 사용 — 보라는 포커스·활성 상태, 작은 알약형 요소, 핵심 브랜드 표면에 나타나며 본문 배경에는 쓰지 않음
- 인라인 코드는 모노스페이스 글꼴, 어두운 배경 `#1E1F25`, 색상 `#A78BFA`로 표현
- 히어로의 은은한 그라데이션 메시 (채도를 매우 절제하고 불투명도 8% 미만) — 흔한 밝은 보라·분홍·파랑 AI 스타일과 다름
- 키보드 우선 사용을 중시하는 브랜드를 반영해 UI 곳곳에 키보드 단축키 칩 배치
- 랜딩 페이지 하단에 실제 제품 스크린샷 고정

**피할 것**
- 이모지
- 튀는 스프링이나 탄성 이징
- 채도 높은 색상을 하나 넘게 사용 (Linear 보라만 강조색으로 사용)
- 16을 넘는 테두리 반경
- 사람의 스톡 사진
- 2018년식 SaaS 랜딩 페이지 같은 “무료로 시작하기” 히어로 CTA

**AI 프롬프트 시드**
> 추상적인 제품 UI 스크린샷, 따뜻한 어두운 `#08090A` 배경, 가는 테두리, `#16171C`와 `#1E1F25` 표면으로 구성된 패널, 위쪽 가장자리에 매우 은은한 청자색 주변 조명, 사람 없음, 이미지 자체에 텍스트 없음, 16:9.

**사용하지 말아야 할 경우**
- 브랜드가 소비자 친화적이거나 장난스러워야 할 때 — Linear는 전문적이고 진지한 분위기
- 제품에 따뜻함이나 손으로 만진 듯한 느낌이 필요할 때
- 비기술 사용자층을 대상으로 할 때 (키보드 단축키와 모노스페이스 신호가 와닿지 않음)
