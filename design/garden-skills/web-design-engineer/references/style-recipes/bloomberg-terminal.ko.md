# bloomberg-terminal — 블룸버그 터미널

- **분류**: 정보 구조
- **분위기**: 데이터 잉크를 최대로 활용, 업무상 핵심 정보의 고밀도 배치, 거의 검정색 바탕의 크롬·호박색
- **적합한 용도**: 금융·거래·모니터링 대시보드, “전문가에겐 여백을 즐길 시간이 없다”는 제품
- **참고 대상**: 실제 Bloomberg Terminal 스크린샷 (항상 실물을 참고할 것 — 기억보다 훨씬 빽빽함)

**팔레트**
- 바탕: `#0A0E1A` (짙은 네이비 블랙)
- 표면 1: `#11172A`
- 표면 2: `#1A2138`
- 기본 호박색: `#FFA02F` (시그니처 색상)
- 긍정 (가격 상승): `#00B96B`
- 부정 (가격 하락): `#F23645`
- 차분한 라벨: `#5E6680`
- 중요도가 높은 텍스트: `#E8ECF4`

**타이포그래피**
- 디스플레이와 본문: IBM Plex Mono, JetBrains Mono, Berkeley Mono 같은 실용적인 모노스페이스 글꼴. Bloomberg는 자체 모노스페이스 글꼴을 사용함.
- 크기: 11 / 12 / 13 / 14px로 촘촘하게 구성. 본문에 16px를 쓰지 않고, 32px 헤드라인도 두지 않음.
- 모든 숫자를 표 형식으로 정렬 (숫자 열을 오른쪽 정렬)

**간격**: 2 / 4 / 8 / 12. 고급스러운 여백 없이 여러 창으로 구성.

**모서리 반경**: 0 또는 2px. 터미널의 모서리는 둥글지 않음.

**그림자**: 없음. `#2A3050` 1px 선으로 높낮이를 표현.

**모션**: 일정한 선형 속도의 티커 스크롤, 즉시 바뀌는 상태, 데이터 업데이트 시 50–80ms 동안 깜박이는 효과. 완화 애니메이션은 사용하지 않음.

**시그니처 요소**
- 가는 구분선으로 나눈 여러 창 작업 공간 — 한 번에 4~9개 패널 표시
- 가장 중요한 데이터에는 거의 검정색 바탕에 호박색 텍스트, 보조 정보에는 크롬 화이트 사용
- 위쪽 상태·티커 바에서 시세를 흘려 보내고 상승·하락을 색으로 구분
- 가장자리에 키보드 단축키 칩 배치 (`F9: TRADE`)
- 모노스페이스 숫자와 변화량별 색상으로 표현한 표 형식 데이터

**피할 것**
- 둥근 모서리
- 히어로 섹션이나 마케팅 스타일 헤드라인
- 모든 종류의 사진이나 일러스트
- 장식용 그라데이션 (그라데이션 메시지는 데이터 잉크가 아님)
- 산세리프 본문 (이 구성의 핵심은 모노스페이스 글꼴)

**AI 프롬프트 시드**
> 트레이딩 워크스테이션 UI, 짙은 네이비 `#0A0E1A` 바탕, 호박색 `#FFA02F` 헤드라인을 넣은 여러 창 레이아웃, 모노스페이스 데이터 표, 상단을 가로지르는 티커 스크롤, 둥근 모서리와 일러스트 없이 전체에 고정폭 글꼴 사용.

**사용하지 말아야 할 경우**
- 일반 소비자 대상 제품일 때 (3초 안에 떠날 수 있음 — 터미널의 정보 밀도는 익숙해져야 함)
- 화면을 실제 데이터로 채울 수 없을 때 — 터미널 미학에 “Lorem 1,234” 같은 더미 값을 넣으면 망가져 보임
- 마케팅 랜딩 페이지를 만들 때 — 터미널은 판매용이 아니라 실제 업무용임
