# 비평 모드 - 자세한 참조

워크플로의 7단계(사용자가 검토를 요청하거나 배송 전 자체 점검)를 실행할 때 이 내용을 읽어보세요. 기본 `SKILL.md`는 이미 **5가지 차원 및 출력 형식**을 다루고 있습니다. 이 파일은 **점수 기준표, 출력 유형별 가중치 및 공통 발행 카탈로그**를 제공합니다.

**디자이너가 아닌 디자인을 비판하세요.** 모호한 취향 주장이 아닌 구체적이고 실행 가능하며 디자인 언어에 기반을 두세요.

## 5가지 차원 - 자세한 루브릭

### 1. 철학 정렬

모든 세부 사항이 선택한 디자인 방향(Pentagram 스타일 정보 아키텍처, Kenya Hara 스타일 미니멀리즘 등)을 얼마나 잘 추적합니까?| 점수 | 표준 |
|---|---|
| 9~10 | 모든 세부 사항은 선택한 철학을 구현합니다. "다른 곳에서 빌린 것"으로 읽히는 것은 없습니다 |
| 7~8 | 방향이 정확함, 특징적인 특성이 땅에 닿음, 1~2개의 작은 표류 순간 |
| 5~6 | 의도는 눈에 띄지만 외부 요소가 섞여 있어 순수성이 저하됩니다(예: 행당 6개의 카드가 있는 "미니멀리즘") |
| 3~4 | 표면 흉내만; 기본 가치가 이해되지 않습니다 |
| 1~2 | 명시된 방향과 식별 가능한 관계가 없습니다 |

**찾아볼 사항**:
- 선택한 디자이너/스튜디오의 시그니처 무브가 실제로 존재하나요?
- 색상, 유형, 레이아웃, 모션이 모두 동일한 철학에 동의합니까?
- "자기모순" 요소가 있나요? (하라 켄야를 골랐다가 페이지가 꽉 차서 → 모순)

### 2. 시각적 계층 구조

시선은 디자이너가 의도한 대로 흘러가나요?| 점수 | 표준 |
|---|---|
| 9~10 | 시선은 의도한 경로를 따라 자연스럽게 흐릅니다. 정보를 읽는 마찰 제로 |
| 7~8 | 1차/2차 클리어; 계층 구조가 흐릿한 1~2개 지점 |
| 5~6 | 제목과 본문은 구분 가능하지만 중간 레이어(자막, 캡션)가 함께 접혀 있음 |
| 3~4 | 정보가 명확한 진입점 없이 평평하게 놓여 있음 |
| 1~2 | 혼란스러운 — 시청자는 어디를 먼저 봐야할지 모릅니다 |

**찾아볼 사항**:
- 제목 대 신체 크기 비율 ≥ 2.5×(영웅의 경우 이상적으로는 4–6×)?
- 색상/무게/크기 건물 3~4개 클리어 레벨?
- 공백이 눈을 적극적으로 안내하나요?
- **눈을 가늘게 뜨기 테스트**: 화면을 가늘게 뜨고 — 계층 구조를 여전히 읽을 수 있습니까?

### 3. 공예 품질

픽셀 수준 실행: 정렬, 간격, 색상 규율.| 점수 | 표준 |
|---|---|
| 9~10 | 픽셀 완벽; 정렬, 간격, 색상 모두 완벽함 |
| 7~8 | 전체적으로 세련됨; 1~2개의 사소한 정렬 또는 간격 문제 |
| 5~6 | 기본적으로 정렬은 되어있지만 간격이 일정하지 않고 색상사용이 체계적이지 않음 |
| 3~4 | 명백한 정렬 오류, 혼란스러운 간격, 너무 많은 색상 |
| 1~2 | 엉성함 - 초안처럼 보임 |

**찾아볼 사항**:
- 일관된 간격 시스템(8pt 그리드: 8 / 16 / 24 / 32 / 48 / 64)?
- 동일 클래스 요소는 동일한 간격을 사용합니까?
- 색상 개수가 제어됩니까(일반적으로 4개 — 기본 + 강조 + 중립 스케일 + 강조 1개)?
- 글꼴 모음 ≤ 2(디스플레이 1개 + 본문 1개)?
- 모서리가 정확하게 정렬되어 있나요?

### 4. 기능

각 요소가 그 자리를 차지합니까?| 점수 | 표준 |
|---|---|
| 9~10 | 모든 요소는 목표를 제공합니다. 중복성 없음 |
| 7~8 | 전체적으로 기능 중심, 잘라낼 수 있는 사소한 장식 |
| 5~6 | 사용 가능하지만 명백한 장식 요소가 관심을 끌기 위해 경쟁합니다 |
| 3~4 | 형태 > 기능; 사용자는 정보를 찾기 위해 노력해야 합니다 |
| 1~2 | 장식은 콘텐츠의 의사소통 능력을 저하시킵니다 |

**찾아볼 사항**:
- 삭제 테스트: "이 요소를 삭제하면 디자인이 더 나빠지나요?" 없으면 → 삭제
- CTA/핵심정보가 가장 눈에 띄는 위치에 있는가?
- "좋아 보여서" 추가한 것이 있나요?
- 정보밀도는 매체에 적합한가? (PPT 희소, PDF는 더 조밀할 수 있음, 랜딩 페이지 전환 중심)

### 5. 독창성

철학 내에서 일관성을 유지하면서 진부한 표현을 피합니다.| 점수 | 표준 |
|---|---|
| 9~10 | 상쾌한; 선택한 철학 *내에서* 독특한 표현을 찾습니다 |
| 7~8 | 자신의 아이디어가 있습니다. 숫자별로 템플릿이 아님 |
| 5~6 | 평균; 템플릿 실행으로 읽기 |
| 3~4 | 진부한 표현의 과도한 사용("AI"에 대한 그라데이션 오브, "대화"에 대한 채팅 말풍선) |
| 1~2 | 순수 템플릿/스톡 자산 조립 |

**찾아볼 사항**:
- AI 슬롭 목록(보라색 그라데이션, 이모티콘 아이콘, 왼쪽 테두리 액센트 카드, 디스플레이로서의 Inter)을 피했나요?
- "예기치 못했지만 옳은" 결정이 적어도 하나 이상 있습니까?
- "AI가 만든 것"이라고 외치는 요소가 있나요?

## 출력 유형별 가중치

출력이 다르면 우선순위도 달라야 합니다. 점수를 매길 때 각 상황에 대해 다음 차원에 더 높은 가중치를 부여하세요.| 출력 유형 | 가장 중요한 | 보조 | 긴장을 풀 수 있다 |
|---|---|---|---|
| 랜딩페이지/마케팅 사이트 | 기능성, 시각적 계층 | 독창성 | — (전방면이어야 함) |
| 대시보드/데이터 제품 | 기능성, 공예 품질 | 시각적 계층 | 독창성(명확성이 승리함) |
| HTML 슬라이드 데크 | 시각적 계층 구조, 기능 | 공예 | 독창성(가독성 승리) |
| 모바일 앱 프로토타입 | 기능성, 공예 | 시각적 계층 | 철학 정렬(사용성 승리) |
| 브랜드 런칭 애니메이션/영웅영화 | 독창성, 시각적 계층 | 철학 | 기능성(형태가 아닌 순간) |
| 사설/포트폴리오 | 독창성, 철학 | 시각적 계층 | 기능성(분위기가 가장 중요함) |
| 문서 사이트 | 기능성, 시각적 계층 | 공예 | 독창성(답 찾기 승리) |
| 사용자 테스트를 위한 대화형 프로토타입 | 기능성, 시각적 계층 | 공예 | 독창성(외관이 아닌 흐름 테스트) |

---## 일반적인 문제 - 상위 10개 카탈로그

비평을 실행할 때 이를 체크리스트로 사용하십시오. 각 항목에는 문제, 문제가 중요한 이유 및 수정 사항이 있습니다.

### 1. AI 기술의 진부한 표현
**문제**: 그라데이션 구체, 디지털 비, 파란색 회로 기판, 로봇 얼굴
**문제가 되는 이유**: 청중은 이것 때문에 지쳐버립니다. 귀하의 제품은 구별할 수 없게 됩니다.
**수정**: 문자 그대로의 기호 대신 추상적인 은유를 사용합니다(예: 채팅 풍선 아이콘 대신 '대화' 은유).

### 2. 유형 크기 계층 구조가 부족합니다.
**문제**: 제목과 본문의 크기가 너무 유사합니다(< 2.5×).
**이유**: 사용자가 주요 정보를 빠르게 찾을 수 없습니다.
**수정**: 제목은 본문 최소 3×(본문 16픽셀 → 제목 48~64픽셀, 영웅의 경우 6×가 정상)

### 3. 색상이 너무 많습니다.
**문제**: 명확한 기본/보조 구조 없이 5가지 이상의 색상이 사용됩니다.
**이유**: 시각적 혼란; 약한 브랜드 아이덴티티
**수정**: 기본 1개 + 보조 1개 + 액센트 1개 + 회색조로 제한됩니다. 다른 모든 것은 그 자체로 정당화되어야 한다### 4. 간격이 일정하지 않음
**문제**: 시스템 없이 요소 간격이 임시로 선택됨
**이유**: 비전문적으로 읽힙니다. 시각적 리듬이 깨짐
**수정**: 8pt 그리드 채택({8, 16, 24, 32, 48, 64, 96}의 간격 값만 사용)

### 5. 공백이 부족합니다.
**문제**: 모든 지역이 콘텐츠로 가득 차 있습니다.
**이유**: 인지 과부하는 정보 전달을 감소시킵니다. 밀도가 높다 ≠ 유익하다
**수정**: 공백은 전체 영역의 40% 이상이어야 합니다(미니멀리스트의 경우 60% 이상).

### 6. 글꼴이 너무 많습니다.
**문제**: 3개 이상의 글꼴 모음 사용 중
**이유**: 시각적 소음; 단결을 약화시킨다
**수정**: 최대 2개(디스플레이 1개 + 본체 1개); 풍부함을 위해 무게와 크기 변화를 사용하십시오.

### 7. 일관되지 않은 정렬
**문제**: 왼쪽, 가운데, 오른쪽 정렬 블록이 혼합되어 있음
**이유**: 시각적 순서가 깨집니다.
**수정**: 하나의 정렬(일반적으로 왼쪽)을 선택하고 전체적으로 적용합니다. 영웅/인용문 순간에만 중앙 정렬### 8. 장식 이클립스 콘텐츠
**문제**: 배경 패턴/그라디언트/그림자가 기본 콘텐츠에서 초점을 훔칩니다.
**이유**: 우선순위를 뒤집습니다. 사용자는 장식을 위해 온 것이 아니라 정보를 얻기 위해 왔습니다.
**수정**: 삭제 테스트를 적용합니다. "이 장식을 제거하면 디자인이 더 나빠지나요?" 그렇지 않은 경우 → 제거

### 9. 사이버 네온 남용
**문제**: 다크 네이비 `#0D1117` + 네온 글로우 액센트
**이유**: 이것은 GitHub의 어두운 / "AI 개발 도구" 진부한 표현입니다. 모든 클론은 동일하게 보입니다.
**수정**: 좀 더 독특한 팔레트를 선택하세요. 다크 모드가 필수인 경우 기본이 아닌 베이스를 선택하세요(진하고 따뜻한 회색, 약간의 색상이 있는 검정색에 가까운).

### 10. 정보 밀도가 중간 수준에 맞지 않음
**문제**: 슬라이드에 텍스트 벽이 있습니다. 소셜 커버에 담긴 10가지 요소
**이유**: 매체마다 최적의 밀도가 다릅니다.
**수정**:
- 슬라이드: 페이지당 핵심 아이디어 1개
- 표지 이미지: 시각적 초점 1개
- 인포그래픽: 레이어형(개요 → 세부정보)
- PDF/문서: 조밀할 수 있지만 명확한 탐색이 필요함

## 안티 패턴 비판

❌ **맛이 애매하다는 주장** : "색깔이 흐릿하다" → 나쁨. "액센트 채도가 너무 높습니다. oklch(0.65 0.25 25)에서는 기본 색상과 경쟁합니다. 하위 색상으로 사용하려면 채도를 0.18로 줄입니다." → 좋음.

❌ **구체적인 칭찬**: "멋져요!" 제로 학습을 제공합니다. 항상 *무엇이* 좋고 *왜* 좋은지 말하세요.

❌ **혼합 심각도**: 동일한 목록의 마무리 수준 색상 조정 옆에 중요한 계층 구조 버그를 배치합니다. 항상 ⚠️ → ⚡ → 💡로 정렬하세요.

❌ **수정 항목이 7개 이상**: 인지 과부하. 더 많은 경우 "5개의 간격 불일치"를 5개가 아닌 하나의 항목으로 그룹화합니다.

❌ **근거 없는 비판**: 모든 '수정'은 원칙(계층 구조, 기술, 철학 등)을 참조하여 사용자가 *무엇*이 아니라 *이유*를 이해할 수 있도록 해야 합니다.❌ **디자인 대신 디자이너 비판**: "당신은 이것을 충분히 생각하지 않았습니다"는 도움이 되지 않으며 상담원의 역할이 아닙니다. "이 요소는 자리를 차지하지 않습니다. 제거를 고려하십시오"가 올바른 프레임입니다.
