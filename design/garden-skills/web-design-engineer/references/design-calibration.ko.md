# 디자인 교정

컨텍스트를 수집한 후 디자인 시스템을 선언하기 전에 이 참조를 사용하세요. 그 목적은 응답을 점수로 장식하는 것이 아니라 간략한 내용을 가시적인 결정으로 바꾸는 것입니다.

## 1. 디자인 읽기

다음을 포함하는 컴팩트 읽기를 작성합니다.

- **아티팩트**: 랜딩 페이지, 대시보드, 프로토타입, 슬라이드 데크, 시각화, 캠페인 페이지 등.
- **청중**: 이해하고, 신뢰하고, 행동해야 하는 사람입니다.
- **시각적 언어**: 제한된 빌더 SaaS, 키네틱 편집, 따뜻한 인본주의자 또는 제도적 데이터 우선과 같은 특정 계열입니다. "현대적" 또는 "깨끗함"과 같은 빈 레이블을 피하십시오.
- **모드**: 그린필드, 확장, 재설계-유지 또는 재설계-정밀화.
- **제약조건**: 브랜드, 접근성, 플랫폼, 뷰포트, 콘텐츠, 마감일 및 제공되는 자산.두 가지 그럴듯한 해석이 실질적으로 다른 결과를 낳는다면 하나의 집중적인 질문을 하십시오. 그렇지 않으면 읽기를 명시하고 진행하십시오.

## 2. 다섯 개의 다이얼

1부터 10까지의 정수를 사용하세요.

### 시각적 변화

익숙한 패턴에서 구성적 이탈을 제어합니다.

| 밴드 | 행동 |
|---|---|
| 1~3 | 안정적인 그리드, 대칭, 친숙한 탐색, 낮은 놀라움 |
| 4–6 | 하나 또는 두 개의 비대칭 동작, 다양한 섹션 리듬, 제어된 참신함 |
| 7~8 | 강력한 아트 디렉션, 독립된 순간, 다양한 레이아웃 제품군 |
| 9~10 | 실험적 구성; 이해와 브랜드가 허용되는 경우에만 사용 |

### 모션 강도

시간을 통해 전달되는 의미의 정도를 제어합니다.

| 밴드 | 행동 |
|---|---|
| 1~2 | 공전; 상태 피드백만 |
| 3~4 | 호버, 포커스, 짧은 입력 전환 |
| 5~7 | 순차적 공개, 상태 안무, 제한된 스크롤 응답 |
| 8~10 | 영화적 전환, 고정, 스크러빙, 공간 스토리텔링 |모든 애니메이션은 계층 구조, 피드백, 인과 관계 또는 내러티브를 전달해야 합니다. 모션이 단순 상태 피드백을 초과할 때마다 감소된 모션을 존중합니다.

### 정보 밀도

시각적 혼란이 아닌 뷰포트별로 유용한 정보를 제어합니다.

| 밴드 | 행동 |
|---|---|
| 1~3 | 갤러리 같은, 하나의 지배적인 아이디어, 넉넉한 일시정지 |
| 4–6 | 균형 잡힌 마케팅/제품 밀도 |
| 7~8 | 분석적, 운영적, 비교 중심 |
| 9~10 | 조종석 같은; 강력한 그룹화, 검색 및 점진적 공개가 필요합니다 |

### 자산 의존도

결과가 실제 이미지, 스크린샷, 일러스트레이션, ID 자산 또는 생성된 시각적 참조에 얼마나 의존하는지 제어합니다.

| 밴드 | 행동 |
|---|---|
| 1~3 | 타이포그래피, 데이터 또는 인터페이스 구조는 아티팩트를 전달할 수 있습니다 |
| 4–6 | 몇 가지 핵심 시각적 요소가 인식이나 설명을 실질적으로 향상시킵니다 |
| 7~10 | 충실도가 높은 자산이 없으면 제품, 브랜드, 캠페인 또는 스토리가 실패합니다 |7+에서는 레이아웃 전 자산을 인벤토리합니다. 장식용 CSS로 누락된 자산을 숨기지 마세요.

### 브랜드 충실도

기존 아이덴티티와 상호 작용 언어를 얼마나 엄격하게 보존해야 하는지 제어합니다.

| 밴드 | 행동 |
|---|---|
| 1~3 | 새롭거나 의도적으로 탐구하는 정체성 |
| 4–6 | 의미 있는 진화를 허용하면서 인식 가능한 신호를 적용 |
| 7~8 | 핵심 자산, 토큰, 음성 및 서명 패턴 보존 |
| 9~10 | 확장 수준 충실도 새로운 작업은 기존 시스템에 기본적으로 나타나야 합니다 |

## 4. 갈등 해결- **높은 분산 + 높은 밀도**: 안정적인 탐색 및 그리드 스파인을 유지합니다. 실험을 한 레이어에 집중하세요.
- **높은 모션 + 높은 밀도**: 모든 요소가 아닌 전환 또는 초점에 애니메이션을 적용합니다.
- **높은 자산 + 낮은 충실도**: 세트를 생성하거나 소싱하기 전에 새로운 시각적 성경을 설정합니다.
- **높은 자산 + 높은 충실도**: 공식 자산을 먼저 확보하세요. 세대가 세상을 확장할 수는 있지만 정체성이 중요한 자료를 대체해서는 안 됩니다.
- **고충실도 + 점검 요청**: 시각적 언어를 변경하기 전에 어떤 브랜드 불변성이 살아남는지 명시적으로 식별합니다.
- **접근성 제약**은 미적 점수를 무시합니다. 허락을 구하지 않고도 모션을 줄이고 계층 구조를 명확하게 하며 대비를 유지합니다.

## 5. 선택적 이미지 우선 분기

캠페인 랜딩 페이지, 브랜드 출시, 제품 영웅 또는 고도로 예술적인 포트폴리오와 같이 시각적으로 중요한 신규 필드 또는 점검 작업을 실질적으로 개선하는 경우에만 이미지 우선 탐색을 사용하십시오.

다음과 같은 경우에는 건너뛰세요.- 사용자가 Figma, 스크린샷 또는 성숙한 디자인 시스템을 제공했습니다.
- 작업이 확장, 수리, 대시보드, 양식 또는 데이터 테이블인 경우
- 주요 불확실성은 시각적 방향보다는 행동입니다.
- 이미지 생성은 설계 위험을 줄이지 않고도 비용을 추가합니다.

사용 시:

1. 시각적 성경을 정의하십시오: 팔레트, 타이포그래피 문자, 반경, 재료, 이미지 처리 및 금지된 드리프트.
2. 불확실성을 해결하는 데 필요한 중요한 참고 자료만 생성합니다. 섹션당 하나의 이미지는 필수 사항이 아닙니다.
3. 압축된 전체 페이지 보드에서 작은 세부 사항을 잘라내는 것보다 신선하고 읽기 쉬운 섹션 참조를 선호합니다.
4. 참고자료에서 구현 결정을 추출합니다.
5. 생성된 픽셀과 충돌하는 경우 코드 및 제공된 브랜드 자산을 더 높은 권한의 소스로 처리합니다.

구조화된 생성이 가능한 경우 `gpt-image-2`를 사용하십시오. 그렇지 않은 경우 호스트의 이미지 작업 흐름을 따르거나 정직한 자산 요구 사항을 남겨 두십시오.

## 6. 완료 테스트누군가가 각 다이얼에서 아티팩트의 구체적인 결과를 가리킬 수 있는 경우에만 보정이 성공합니다. 점수를 변경해도 계획이 변경되지 않는 경우 점수를 제거하거나 매핑을 명시적으로 만드세요.
