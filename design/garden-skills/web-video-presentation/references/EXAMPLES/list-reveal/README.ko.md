## 포지셔닝

"세 가지/네 가지 이유/N 특성"을 말할 때 **각 항목을 1단계로 하나씩 공개**합니다.
영상 중간에 가장 많이 사용되는 챕터 유형은 **PPT로 전환될 가능성이 가장 높습니다**. 이것이 바로 앵커가 필요한 이유입니다.

## 적용 가능한 시나리오

- "<주제>의 강점은 무엇인가 → 세 가지"
- "상점<X> → 포앵글"
- "내가 <X>를 좋아하는 이유 → 다섯 가지 이유"
- 모든 "주제 + N 병렬 하위" 구조

## 가상의 outlook.md 섹션 세그먼트(추상)

```markdown
## 4. <chapter-id> — <主题 N 件事>（N+1 steps）

- **step 1** (~3s) — masthead 引子"<N 件事>"
- **step 2** (~6s) — 第 1 件：<标题> + <article 抽来的细节>
- **step 3** (~6s) — 第 2 件：<标题>
- ...
- **step N+1** (~6s) — 第 N 件：<标题>
```

## 중요한 템포 결정

| 단계 | 시각적 레이아웃 |
|---|---|
| 1 | 중앙의 큰 문자 + 일련 번호 01/02/.../N 자리 표시자(**콘텐츠 없음**, 순수 자리 표시자) |
| 2 | "01" 슬롯이 채워졌습니다: 제목 + 간단한 설명 + 악센트 번호; 나머지는 여전히 유령이다 |
| 3 | "02"가 채워졌습니다. 01이 활성화되어 보조가 됩니다. 나머지는 여전히 유령이다 |
| ... | 현재 슬롯 채우기; 이전 활성화 다운그레이드; 후속 유령 |## CHAPTER-CRAFT.md 0부 원칙 8의 핵심 구현

> "레이아웃은 재정렬되지 않고, 셀 내용만 변경됩니다."

전체 챕터에는 **하나의 그리드 레이아웃**만 있으며 N 슬롯의 React 노드 위치는 완전히 변경되지 않습니다.
변경되는 것은 각 슬롯의 콘텐츠 상태(유령/활성/과거)뿐입니다. 이렇게 하면:
- 세포가 재배열되지 않음 → 시각적으로 안정됨
- 포인트당 '1개의 슬롯 변경'만 가능 → 새롭게 공개된 아이템에 시청자들의 시선이 확연히 고정됨

**안티패턴**: 클릭당 한 번 전체 레이아웃을 다시 렌더링 → 공개된 항목도 지터/다시 렌더링
입장 → 관객은 어디를 봐야할지 모릅니다.

## 주요 수단(바닥선)

| 차원 | 이 앵커를 구현하는 방법 |
|---|---|
| 글꼴 크기 | 제목 64px / 큰 144px serif |
| 슬롯 상태 | 점선 → 커다란 빨간색 강조 표시 → 회색 숫자(**위치는 재배열되지 않음**) |
| 일련번호 | Hero-num 글꼴(세리프체 큰 숫자) |
| 선도적인 행동 | 마스크 공개(제목) + 숫자 스매시(악센트 빨간색) |
| 동반 행동 | 표준 이하 스태거 200ms + 액센트 수평선 scaleX |
| 연속적인 마이크로 무브먼트 | 활성 슬롯 번호 액센트 후광 `infinite` 호흡 |
| 소개 | 마스트헤드 이중선 규칙 + 세리프 큰 문자 |

> **새 챕터를 작성할 때**: 구조 복사(단일 그리드 N 슬롯, 단계당 하나의 슬롯과 위치만 채움)
> 재배열 없음), 본 장의 내용 + 본 테마의 기질에 따라 주연액션의 형태를 자유롭게 디자인합니다.

## 다른 주제로 전환할 때

- `bauhaus-bold` → 일련번호를 Archivo Black + 대형 컬러 블록으로 변경합니다. 그것을 부수기 위해 강하게 자르십시오.
- `terminal-green` → 일련 번호 `[01]` `[02]` `[03]` 스타일; 타자기 항목
- `chalk-garden` → 분필 밑줄 손그림 + 흔들기 입력
- `midnight-press` → 디지털 블러 클리어 슬로우 샤프닝 + 따뜻한 오렌지 후광 느린 호흡**구조는 변경되지 않습니다**: N+1 단계, 단일 그리드 N 슬롯, 각 단계마다 하나의 슬롯만 채워집니다.
