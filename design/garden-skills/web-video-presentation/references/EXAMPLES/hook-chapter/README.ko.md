큰 캐릭터의 영웅 인수를 중단하세요**.

## 적용 가능한 시나리오

- 서스펜스 오프닝: 먼저 사람들을 의심/혼란스럽게 만드는 사진 3~4장을 버리고 그 이유를 밝힙니다.
- "오늘은 X의 여러 자동차 롤오버 장면에 대해 이야기하겠습니다.": 먼저 자동차 롤오버를 살펴본 다음 주제를 변경합니다.
- 제품 출시의 '문제감' 오프닝: 먼저 Pain Point 스크린샷을 보고, 이후 새로운 기능 공개

## 가상의 outlook.md 섹션 세그먼트(추상)

```markdown
## 2. hook — <章节标题>（6 steps）

- **step 1** (~4s) — N 张可疑图片占位（虚线 ghost 卡片）
- **step 2** (~5s) — 第 1 张露出：<反例 1 描述>（独占视觉）
- **step 3** (~5s) — 第 2 张露出：<反例 2 描述>（独占视觉）
- **step 4** (~5s) — 第 3 张露出：<反例 3 描述>（独占视觉）
- **step 5** (~4s) — 三张图同时缩入侧栏，中间出 <主题大字> takeover
- **step 6** (~3s) — 切到下一句钩子（被 brush 划掉）
```

## 중요한 템포 결정| 단계 | 리듬 의도 | 비전 |
|---|---|---|
| 1 | 서스펜스 던지기 - 알 수 없는 N장의 카드 | 점선 고스트 카드, 1/3 화면에 1개 |
| 2-N | **각 사진마다 독보적인 비주얼이 있습니다** - '숫자를 맞추는 것'이 아닌, 관객이 각 사진을 바라보며 '이게 진짜일까?'라고 생각하게 하는 것이 포인트입니다. | 큰 사진은 화면의 약 70%를 차지하며 옆에 있는 작은 텍스트는 사진의 출처를 나타냅니다 |
| N+1 | 인수 - 주제 공개 | 3개의 카드가 왼쪽에 미니 카드로 축소되고 중앙에 거대한 단어가 있음 |
| 끝 | 후크 닫기 | 기존 개념을 지우고 다음 장으로 이동 |

## 2-N과 스태거를 동시에 사용할 수 없는 이유는 무엇인가요?

구두 방송은 **하나씩 읽어줍니다** - 1개 항목 = 1단계 필요([CHAPTER-CRAFT.md 파트 0 원칙 8](../../CHAPTER-CRAFT.md#8-多点内容必须逐个揭示绝不同时上)).
동시에 스태거가 켜집니다 = 청중이 그것을 흘끗 보았고 발표자는 여전히 첫 번째 것을 읽고 있습니다 = PPT 직관.

## 주요 수단(바닥선)

| 차원 | 이 앵커를 구현하는 방법 |
|---|---|
| 재료 | `<img src="/hook/<asset>.png" />` 실제 스크린샷 |
| 글꼴 크기 | 영웅 = 144px 세리프(`var(--t-display-1)`) |
| 선도적인 행동 | 붓터치 + 봉인 깨기 (뉴스룸 기질) |
| 동반 행동 | 액센트 빨간색 막대 scaleX + 표준 이하의 스태거 200ms |
| 지속적인 마이크로 모션 | 액센트 레드 바 헤일로 `infinite` 호흡; 사진 켄은 느린 푸시 화상 |
| 카드 스타일 | 그림자 + ​​미세 회전 1deg |
| 인수 | 세 장의 사진 들여쓰기 + 영웅 거대한 단어 버스트 + 악센트 빨간색 막대 침투 |> **새 장을 작성할 때**: 이 장의 내용에 따라 구조 및 글꼴 크기 관계를 복사합니다. + 이 테마의 기질은 자유입니다.
