# outline 발췌 · 기술 리뷰 사례

> **발췌**: 앞의 2개 챕터(10 step)입니다. 기술 리뷰 주제에서 outline의 형태를 보여줍니다. 전체 7개 챕터, 36 step은 이 Skill을 사용하는 실제 프로젝트에 있으며 명세에는 포함하지 않습니다.

> **테마**: `midnight-press`(영화 같은 느린 장면, blur clear, 따뜻한 오렌지 포인트, scanline; 절제되고 무게감 있는 분위기. **금지**: 내려찍는 shake / 스프링 / emoji)
>
> **전체 길이**: 약 6분 30초

---

## 1. coldopen — 정상에 오를지의 긴장감 (5 steps · 약 30초)

- **step 1** (약 5초) — 어두운 원경의 입자 구름 + 후크 자막 “이미지 하나를 봤는데, 3초 동안 멍해졌다”
  · 애니메이션: 순수한 검정 화면에서 어둡고 따뜻한 배경으로 천천히 fade(1.5s ease-out) → 원경의 빛 먼지 입자 구름이 시작 시차를 두고 천천히 떠오름(1.0s) → 모노 타자기 효과로 자막을 한 글자씩 표시(글자당 100ms). 지속 효과: 입자 구름이 브라운 운동처럼 계속 떠다님 + 어두운 오렌지 비네트 후광이 6s 주기로 천천히 호흡 + ken burns로 천천히 당김
  · 사용 기법: CSS 배경을 천천히 fade + Canvas 입자 구름을 천천히 이동 + JS typewriter + `filter: drop-shadow`에 오렌지 호흡 효과 + `transform: scale`로 ken burns를 계속 적용

- **step 2** (약 7초) — 순위표에 느린 심도 초점을 맞추고 + 주요 점수를 hero 숫자로 blur clear 효과를 주어 띄움
  · 애니메이션: 스크린샷을 `blur(12px)` + `scale(1.05)`에서 느리게 선명하게 전환(1.5s ease-out) → 주요 점수도 `blur(20px)`에서 천천히 선명해짐(1.2s, 400ms 시차) → 왕관 SVG가 숫자 바깥을 따라 mask reveal(1.5s). 지속 효과: 주요 점수의 따뜻한 오렌지 후광이 5s 주기로 호흡 + ken burns로 천천히 당김
  · 사용 기법: filter blur를 반대로 적용 + transform scale을 천천히 확대 + path를 따라 clip-path mask reveal + `filter: drop-shadow` 호흡 효과
  · article 보충: 주요 점수(article §1의 구체적인 수치) + 리뷰 기간(“X월 N일 ~ Y월 N일”) + 투표 수(모노 큐 보조 표시). 내레이션은 “1위를 바꿨다”고만 말하지만, 화면에는 “얼마나 앞섰는지 / 몇 표로 결정됐는지”를 표시

- **step 3** (약 6초) — 2위와 비교하는 가로 막대 + “격차 점수”를 천천히 선명하게 띄움
  · 애니메이션: 첫 번째 막대가 왼쪽에서 오른쪽으로 100%까지 느리게 mask reveal(1.2s ease-out) → 두 번째 막대도 같은 방향으로 reveal하되 약 70%까지만 표시(600ms 시차) → 가운데 빈 공간의 격차 점수가 blur(15px)에서 천천히 선명해짐(시차 적용). 지속 효과: 격차 영역의 오렌지 후광이 천천히 호흡 + 포인트 가로선이 8s 동안 계속 느리게 뻗음 + scanline 오버레이가 거의 보이지 않을 정도로 옅게 이동
  · 사용 기법: clip-path inset으로 천천히 reveal + 반전 blur 필터 + 따뜻한 후광의 linear-gradient + 계속 움직이는 scanline linear-gradient
  · article 보충: 2위의 구체적인 이름(article §1) + 격차 점수(구체적인 수치, 막연한 “훨씬 낮다” 대신) + 추세 주석(“최근 N주 만에 처음으로 역전”)

- **step 4** (약 6초) — 공식 발언을 pull-quote로 천천히 표시(영화 같은 인용문)
  · 애니메이션: 커다란 따옴표 SVG 두 개가 opacity 0 + blur(15px) 상태에서 차례로 천천히 선명해짐(1.0s, 200ms 시차, **내려찍지 않음**) → 모노 타자기 효과로 인용문을 한 글자씩 표시(글자당 80ms) → 출처 표기가 blur clear로 천천히 나타남(0.8s). 지속 효과: 따옴표의 따뜻한 오렌지 후광이 호흡 + ken burns로 카메라를 천천히 당김
  · 사용 기법: blur 필터를 반대로 적용해 선명하게 전환 + JS typewriter + transform translateY로 천천히 이동 + `filter: drop-shadow` 호흡 효과
  · article 보충: 원문 인용(article §1에서 1~2문장) + 출처 표기(“— 출처.AI”). 내레이션에서 생략한 권위 있는 뒷받침을 article 인용문으로 보완

- **step 5** (약 5초) — 진행자 소개 + 네 가지 주제를 미리 빠르게 보여줌
  · 애니메이션: 첫 번째 자기소개 행이 blur clear로 천천히 등장(1.2s ease-out) → 자리표시 카드 4장이 blur(15px)에서 천천히 선명해지며 시차를 두고 나타남(카드마다 250ms, 각 1.0s). 카드 안에는 모노 숫자 01/02/03/04와 키워드를 표시합니다. 지속 효과: 각 카드의 오렌지 테두리 후광이 400ms 시차를 두고 호흡 + 원경의 입자는 계속 떠다님
  · 사용 기법: blur 반전 + opacity를 천천히 fade + transform scale로 천천히 당김 + 여러 `filter: drop-shadow` 호흡 효과에 시차 적용
  · article 보충: 네 가지 주제의 키워드(article의 챕터 제목에서 간략히 가져옴)

내레이션 발췌:
> 이미지를 하나 봤는데, 3초 동안 멍해졌어요… 오늘은 네 가지를 정리해 볼게요.

## 2. why-strong — 무엇이 강점인가 (5 steps · 약 80초)

- **step 1** (약 6초) — hero “강점은 네 가지 방향” + 비어 있는 ghost 카드 4장
  · 애니메이션: hero 글자가 blur(20px) + opacity 0 상태에서 천천히 선명해짐(1.5s ease-out) → 아래의 긴 오렌지 선이 중심에서 양옆으로 천천히 뻗음(0.8s) → 아래 ghost 카드 4장이 같은 속도로 blur에서 나타나되 opacity 0.3의 자리표시 상태를 유지. 지속 효과: 오렌지 밑줄의 후광이 8s 주기로 천천히 pulse + ghost 카드의 어두운 테두리가 천천히 깜박임
  · 사용 기법: blur 반전 + transform scaleX로 천천히 늘림 + opacity를 단계적으로 채움 + `filter: drop-shadow`로 계속 호흡
  · article 보충: 네 가지 방향의 각 키워드(모노 큐 레이블 “01 X / 02 Y / 03 Z / 04 W”)

- **step 2** (약 16초) — 1/4 항목을 채우고 큰 이미지로 화면을 장악
  · 애니메이션: 카드 1이 ghost 상태에서 mask로 천천히 채워짐(0.8s, 따뜻하고 어두운 바탕과 테두리 후광이 밝아짐) → 중앙의 큰 hero 이미지가 blur(15px)에서 천천히 선명해짐(1.5s ease-out) → 모노 큐 레이블이 어두운 구석에서 blur clear로 등장(0.8s) → 부제목을 글자 단위 타자기 효과로 표시(글자당 80ms). 지속 효과: 따뜻한 오렌지 포인트 막대가 계속 호흡 + 큰 이미지가 ken burns로 천천히 당겨짐(0.5% scale, 12s 주기) + scanline 이동
  · 사용 기법: blur 반전 + clip-path로 천천히 reveal + JS typewriter + transform scale로 ken burns를 계속 적용 + 계속 움직이는 linear-gradient scanline
  · article 보충: 이 항목의 구체적인 성과(article §2에서 데이터 포인트나 사례 레이블 1~2개 추출). 내레이션은 “X가 강하다”고만 말하고, 화면에는 “구체적으로 N% 강함 / M보다 우수 / 평가 점수 K”를 표시

- **step 3** (약 16초) — 2/4 항목을 채우고 목록 / 시연을 표시
  · 애니메이션: 카드 2가 mask로 천천히 채워짐(0.8s) → 모노 큐 레이블이 blur clear로 등장(0.8s) → 구체적인 세부 항목 네 줄을 한 줄씩 타자기 효과로 표시(줄마다 0.8s, 350ms 시차) → 각 줄 끝의 모노 커서가 깜박인 뒤 따뜻한 오렌지 체크 표시 SVG path를 천천히 그림. 지속 효과: 모노 커서가 계속 깜박임(800ms blink) + scanline 이동
  · 사용 기법: JS typewriter + opacity blink 커서 + SVG path stroke-dashoffset을 천천히 그림 + linear-gradient scanline 오버레이를 계속 이동
  · article 보충: 세부 항목 네 줄의 실제 내용(article §2의 N번째 하위 목록에서 가져옴). 내레이션은 “지시를 잘 따른다”고만 말하고, article에 적힌 네 가지 구체적인 기준(주체를 어디에 둘지 / 배경을 어떻게 구성할지 등)을 한 줄씩 표시

- **step 4** (약 16초) — 3/4 항목을 채우고 전후 비교를 느리게 보여주며 cross-fade를 계속 실행
- **step 5** (약 16초) — 4/4 항목을 채우고 여러 매개변수 미리 보기와 redacted 주석을 표시

내레이션 발췌:
> 실제로 써 보니 네 가지 면에서 강점이 있었어요……

---

> **관찰**: 각 step은 “내레이션에서는 한 가지를 말하고 화면에는 여러 가지를 표시”합니다. 예를 들어 step 2에서는 내레이션이 “첫 번째 항목이 강하다”고만 말하지만, 화면에는 항목 키워드 / 큰 이미지 사례 / 구체적인 데이터 / 부제목 보충 정보를 함께 보여줍니다. 두 출처 원칙을 실제로 적용한 사례입니다.
