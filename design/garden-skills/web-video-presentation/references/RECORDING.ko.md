# 녹화 및 후반 합성

웹 페이지와 오디오 합성이 끝나면 **Auto 모드 + 화면 녹화로 한 번에 녹화**할 수 있습니다. step을 넘기려고 직접 클릭하거나 오디오를 후반 작업으로 맞출 필요가 없습니다.

오디오를 합성하지 않는 경우에는 기존 방식대로 직접 클릭해 진행하고 후반에 오디오를 입힐 수 있습니다(문서 끝 참고).

---

## 권장 흐름: Auto 모드로 한 번에 녹화

### 준비

- 각 챕터 코드를 완성하고 챕터마다 `narrations.ts`를 준비합니다.
- `npm run extract-narrations`와 `npm run synthesize-audio`를 실행해 `public/audio/<id>/<step>.mp3` 파일을 모두 준비합니다.
- `npm run dev`를 실행하고 브라우저에서 페이지가 열리는지 확인합니다.

### 녹화 순서

1. **브라우저를 전체 화면으로 전환**(F11 / Ctrl+Cmd+F)하고 URL을 `http://localhost:5173/?auto=1`로 바꿉니다.
2. “Press SPACE to start” 오버레이가 보이면 Auto 모드가 준비된 것입니다.
3. **화면 녹화를 시작**합니다(QuickTime / OBS / Cmd+Shift+5).
4. **Space를 한 번 누릅니다.** 오버레이가 사라지고 step 0이 나타나며 `1.mp3`가 자동 재생됩니다. 재생이 끝나면 step 1로 자동 이동해 `2.mp3`를 재생합니다. 마지막 step의 재생이 끝나면 종료 상태에 멈춥니다.
5. **녹화를 중지**한 다음 앞뒤를 잘라냅니다(Space를 누른 순간과 종료 상태로 멈춰 있는 꼬리 부분). 그러면 완성본입니다.

과정 내내 마우스를 클릭할 필요가 없습니다. 영상과 오디오는 처음부터 동기화되므로 후반에 트랙을 맞출 필요가 없습니다.

> **Auto 모드는 오디오가 끝나는 시점에 맞춰 진행합니다**(200ms 버퍼 추가). 애니메이션이 끝날 때까지 기다리는 예비 동작은 없습니다. 애니메이션이 중간에 잘린다면 해당 step의 애니메이션이 내레이션보다 긴 것입니다. 챕터 코드에서 내레이션을 늘리거나 step을 나누거나 애니메이션 속도를 조절하세요.

### 화면 녹화 도구

| 플랫폼 | 도구 | 설정 |
|---|---|---|
| macOS | Cmd+Shift+5 → 선택한 윈도우 녹화 | 브라우저 창을 선택합니다. 브라우저를 전체 화면으로 전환하면 결과는 1920×1080입니다. |
| macOS | QuickTime → 파일 → 새로운 화면 녹화 | 위와 동일 |
| 크로스 플랫폼 | OBS Studio | 윈도우 캡처, Canvas 1920×1080, 60fps |

### 모드 빠른 참조

| URL / 단축키 | 동작 |
|---|---|
| 바로 열기(기본값) | Manual: 클릭 / ←→ 키로 진행하며 오디오는 재생하지 않음 |
| `?audio=1` 또는 `M` 키 | Audio: step에 들어가면 오디오가 자동 재생되지만 **마우스 클릭으로 직접 진행** |
| `?audio=1` + `M` 키 다시 누르기 | Auto: step에 들어가면 오디오가 자동 재생되고 자동으로 다음 step으로 이동(녹화용) |
| Auto 모드에서 처음 `Space` 누르기 | Auto 재생을 시작(브라우저의 자동 재생 제한 우회) |

마우스를 오른쪽 위로 가져가면 숨겨진 모드 전환 버튼도 나타납니다.

## 대체 흐름: 오디오 합성 없이 수동으로 녹화

오디오 합성을 건너뛰고(`Checkpoint Audio`에서 “합성하지 않음”을 선택) 기존 방법으로 녹화하는 경우:

1. 브라우저를 전체 화면으로 전환하고 `localhost:5173`을 엽니다(기본 Manual 모드).
2. **한 번 새로고침**해 이전 step 기록을 지웁니다.
3. 화면 녹화를 시작한 다음 내레이션 리듬에 맞춰 빈 곳을 클릭해 step을 진행합니다.
4. 후반 작업에서 원하는 편집 도구로 음성을 입히고 타임라인을 조절합니다.

### 후반 작업 도구

| 도구 | 적합한 경우 |
|---|---|
| **DaVinci Resolve** | 크로스 플랫폼 무료 도구, 여러 오디오 구간을 이어 붙일 때 |
| **iMovie** | macOS에서 간단한 작업을 할 때 |
| **CapCut / Jianying(剪映)** | Bilibili / Douyin 스타일로 자막을 추가할 때 |
