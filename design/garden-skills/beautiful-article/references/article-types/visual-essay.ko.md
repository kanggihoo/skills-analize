# 글 유형 · 비주얼 에세이

전시, 공유, 이미지 중심 스토리텔링, 브랜드 서사, 연말 회고, 문화 논평에 사용합니다. **시각 요소가 중심**이며 텍스트는 짧고 정제되어 리듬을 만듭니다.

- **권장 정보 보존율:** 20–60%(핵심 주장과 가장 힘 있는 자료만 남기고 서사 / 추론 / 데이터 세부를 많이 줄인 뒤 시각적으로 다시 구성합니다).
- **전형적인 구조:** `Hero`(강한 분위기 / 화면을 채우는 비주얼 / 큰 제목) → 짧은 `Section` 연속 구성(각 절은 적은 텍스트 + 큰 비주얼 + 인용 한 문장) → 섹션 사이에 **강한 리듬 대비**(여유 / 밀도 / 밝음 / 어두움) → `Conclusion`(여백으로 마무리 / 한 문장으로 주제 환기). **섹션은 짧게** 구성하며 하나당 읽는 시간은 30초–1분입니다.
- **컴포넌트 선택:** 본문은 **짧은 문장과 끊어 쓰기**를 사용합니다. `Quote`로 인용에서 멈추는 순간을 만듭니다(명언 인용이 아니라 글 속의 “강한 문장”을 섹션 표지처럼 부각). `Image` / `Raw`가 중심입니다. 시각 리듬을 깨는 조밀한 데이터 컴포넌트(`Table` / `RiskList`)는 **적게 씁니다.**
- **Raw 사용 기준:** **시각 블록을 가장 많이 사용합니다.** 큰 스케일의 레이아웃, 리듬 다이어그램, 개념 시각화, 모션, 가벼운 인터랙션(HTML / CSS / React, 필요하면 SVG / canvas)을 활용합니다. 화면을 가득 채우는 배경, 스크롤 트리거 모션, 비대칭 다단 레이아웃 등을 사용할 수 있습니다. 그러나 반드시 **글의 형식**이어야 합니다. 랜딩 페이지나 제품 대시보드가 아닙니다.
- **이미지 성향:** `ai-generated` / `user-assets`의 **대형 이미지**를 사용합니다. 구도 / 여백 / 레이아웃 자체가 표현 수단입니다. 스톡 사진이나 “악수하는 비즈니스맨” 같은 진부한 이미지는 피합니다.
- **테마 성향:** `bodoni`(흑백 대형 잡지), `press`(따뜻한 편집 디자인), `sottsass`(활기찬 색상), `bayer`(모더니즘 / 포스터), `andy`(부드러운 서사). 개성이 뚜렷한 테마가 잘 맞습니다.
- **자체 점검:**
  - 포스터 / 랜딩 페이지 / 대시보드가 아니라 여전히 **글**인가? 모든 시각 요소를 지워도 글이 하나의 주장을 이루는가? 그렇다면 글이고, 아니면 랜딩 페이지입니다.
  - 시각 요소가 장식 / 과시가 아니라 **핵심 주장**을 돕는가?
  - 호흡이 있는 리듬을 만들었는가(밀도 차이 / 명암 차이 / 크기 대비)?
  - 내용을 줄인 뒤에도 “축약된 요약”이 아니라 “편집된 글”로 느껴지는가?
  - 모바일에서도 핵심 주장이 전달되는가? 큰 레이아웃은 모바일에서 무너질 수 있습니다.

> **visual-essay를 사용하지 말아야 할 때:**
>
> - 독자가 의사 결정을 내려야 함 → `briefing`.
> - 독자가 내용을 완전히 이해해야 함 → `longform` / `explainer`.
> - 독자가 **직접 조작해 이해**해야 함 → `interactive-explainer`(이 유형도 시각 중심이지만 독자가 직접 조작함).
> - 전체 논증 / 데이터를 전달해야 함 → `essay` / `full-report`.
