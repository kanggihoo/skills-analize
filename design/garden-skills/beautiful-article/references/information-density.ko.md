# 정보 밀도

정보 밀도(정보 보존 비율)는 **본문과 시각 블록의 비율, 콘텐츠를 덜어내는 정도, 섹션 깊이**를 결정합니다.

**글 유형과의 관계:** 이론적으로 두 요소는 독립적이지만 실제로는 밀접하게 연결됩니다. 각 글 유형에는 표준 보존 비율이 있습니다(아래 표). Plan Checkpoint 1에서 “보존 비율”을 “글 유형”의 의미 선택지 안에 포함해 정하도록 해 `longform + 20%` 같은 가짜 조합을 피합니다(자세한 내용은 `article-types.md` 상단 참고). 사용자가 명시적으로 정밀 편집을 원할 때(예: “longform이지만 60%만”)만 `plan/plan.md`의 Brief 단락에 비표준 조합으로 기록합니다.

기본값: **정보 보존율 100%**(기본 글 유형인 `longform`을 따름).

## 정보 밀도 단계

| 정보 보존율 | 권장 글 유형 | 적합한 상황 | 표현 특성 |
| --- | --- | --- | --- |
| 100% | longform | 전체 아카이브, 원문에 가까운 심층 읽기 | 장문 중심, Raw 보강, 완전한 섹션과 세부 내용 |
| 80–90% | tutorial / full-report / explainer / dialogue | 단계 안내 / 정리된 보고서 / 개념 설명 / 대화 편집 | 반복을 덜어내되 주요 논증, 절차, 대화는 보존 |
| 60–70% | review / essay | 엔지니어링 검토 / 의견과 논평 | 핵심 근거, 논증, 주요 발견을 남김 |
| 약 50% | briefing | 의사 결정자용 | 결론 + 핵심 근거 + 실행만 남기고 시각 요소 비율을 높임 |
| 40% | visual-essay | 공유, 전파, 이미지 중심 소개 | 시각 블록 비중이 가장 높고 텍스트는 짧아지지만 글의 형식 유지 |
| **약 25%(원문 발췌 비율)** | interactive-explainer | Raw 인터랙션을 주요 매체로 삼아 개념을 직접 다루며 학습 | **특수 사례: 비율의 뜻이 다름** — “75%를 삭제”한다는 뜻이 아니라 결과물의 문장 / 문단 중 원문에서 직접 가져온 비율이 약 25%이고 나머지 75%는 핵심 지식을 중심으로 새로 만든 안내 문구 + 인터랙티브 시연 + 직접 시도 + 이해 확인이라는 뜻 |
| 20% | one-page teaser / 표지형 표현 | 읽기를 유도하는 티저, 표지 | 핵심 주장과 가장 강력한 자료만 유지(등록된 유형과 20% 조합은 모두 비표준이며 plan.md에 표시) |

## 정보 밀도와 컴포넌트 / 시각 비율

| 정보 보존율 | 본문 비율 | Raw / 이미지 비율 | 컴포넌트 전략 |
| --- | --- | --- | --- |
| 100% | 높음 | 낮음~중간 | 장문 우선, Raw로 핵심 개념 강조 |
| 80% | 중간~높음 | 중간 | 각 절마다 시각적 보강 하나 정도 |
| 60% | 중간 | 중간~높음 | 주요 내용을 구조화하고 시각 요소로 이해 보조 |
| 40% | 중간~낮음 | 높음 | 글과 이미지의 리듬을 강화하되 글의 형식은 유지 |
| 20% | 낮음 | 높음 | 비주얼 에세이에 가까우며 세부 정보는 남기지 않음 |

## 세 가지 결정의 관계

```text
文章类型 = 结构决策
信息密度 = 内容保留决策   ← 与类型实际绑定（每类有标配比例），仅在用户精修时解耦
主题     = 审美气质决策   ← 与前两者完全解耦
```

- 테마는 유형 / 밀도와 **완전히 독립**입니다. 어떤 테마든 어떤 유형과 밀도에도 적용할 수 있습니다(표현 전략만 달라짐).
- 유형과 밀도는 **실무에서 연동**됩니다. SKILL.md Phase 3의 통합 질문을 참고하세요. “non-standard” 조합일 때만 명시적으로 분리합니다.

## Plan Checkpoint 필수 질문

1. 글 유형(표준 정보 보존율 포함) — SKILL.md Phase 3의 필수 질문 네 가지 중 하나.
2. 편집, 축약, 재구성, 어조 변경을 허용하는가? — 기본적으로 허용하며 시작 안내에서 명시합니다.
3. 어떤 정보를 100% 보존해야 하는가? — Brief의 “반드시 보존할 정보” 목록에 기록합니다.
4. 어떤 내용을 축약하거나 삭제할 수 있는가? — Brief의 “축약 / 삭제 가능한 정보” 목록에 기록합니다.
