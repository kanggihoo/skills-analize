# Theme Profile · bodoni(신문 / Didone 고대비)

> 이 문서는 **AI가 글을 쓸 때 읽는** authoring profile이지 CSS가 아닙니다. CSS 토큰은 컴포넌트 라이브러리의 runtime theme(`data-theme="bodoni"`)에서 관리합니다. 이 파일은 테마를 고르고 사용하는 법을 안내합니다. 자세한 기준 문서는 `src/theme/themes/bodoni/bodoni.md`에 있습니다(코드 / 공식 / 미디어 / Raw 작성 전에 읽을 것).

- **runtime theme id:** `bodoni`(`<ThemeProvider theme="bodoni">`)
- **분위기:** 인쇄의 전당(Didone 신문 / 패션 잡지 머리글). 순백의 종이, 진짜 검정 잉크, 가는 선의 칼럼 구분, 극적인 굵기 대비. Playfair Display의 아주 굵은 머리글이 여유 있는 올드스타일 세리프 본문 위에 놓입니다. 인쇄 관습(굵기가 다른 이중 머리글 선, 첫 글자 드롭 캡, 작은 대문자 도입부, 칼럼 구분선)이 특징입니다. 색상은 거의 위험 표시용으로만 제한합니다.

## 적합한 글 유형 / 적합하지 않은 글 유형

- **적합:** 선언문, 심층 특집, 무게감 있는 에세이와 장문 리뷰, 문화 / 정치 / 패션 보도. 권위, 극적 분위기, 의식적인 격식이 필요한 도입과 표지형 장문.
- **부적합:** 따뜻하고 친근한 표현(`press` / `freddie`), 부드럽고 치유하는 분위기(`andy`), 차가운 사양(`vignelli`), 어두운 엔지니어링(`shannon` / `fuller`), 학술 논문(`knuth`), 밝고 다채로운 스타일(`bayer` / `sottsass`), 슬라이드.

## 타이포그래피 분위기

- 제목 / 머리글은 고대비 Didone인 Playfair Display, 본문은 읽기 편한 올드스타일 세리프인 Source Serif 4 / Newsreader를 사용합니다.
- 본문은 약 17px, 행간은 1.62. 디스플레이 굵기는 900으로 하고 매우 큰 글자를 사용해 얇은 본문과 대비시킵니다.
- 도입부 / 표 머리글 / TOC 제목 / 결론 레이블은 **small caps + 자간**으로 통일합니다. 강조에 이탤릭을 쓰지 않습니다(프로토콜 수준에서 금지).
- **위계는 글자 크기 / 굵기 / 가는 선으로 만듭니다.** 색으로 만들지 않습니다. 전체적으로 흑백을 유지하고 빨강은 정말 위험한 내용을 표시할 때만 사용합니다.

## Raw 스타일

대형 신문 판면에 직접 편집한 도표나 인용문처럼 보이게 합니다.

- 제한하는 것은 매체가 아니라 **분위기**입니다(흑백, 가는 선, Didone 큰 글자, 절제된 인쇄 스타일).
- 잘 어울리는 요소: 흑백 데이터 / 선 그래프, 레이아웃 인용문, 타임라인, 비교 칼럼, 신문 머리글 블록, 드롭 캡으로 시작하는 도입부.
- 가는 선 + 흑백 + 큰 제목을 사용합니다. 채우기 색은 최소화하고 빨강은 포인트로만 사용합니다. 모서리 반경과 그림자를 쓰지 않습니다.
- 모션은 절제하고 거의 정적으로 유지합니다. 반복 장식과 바운스는 피합니다.

## 미디어(이미지 / 비디오 / 오디오) 스타일

- 잘 어울리는 요소: 흑백 / 저채도 사진, 질감이 고급스러운 인물 / 정물, 다큐멘터리 사진, 단색 인포그래픽, 판화 질감.
- 여백을 단호하게 사용하고 이미지가 화면을 가득 채우거나 잘려도 괜찮습니다. 캡션은 small caps 또는 작은 세리프 글자를 사용하고 alt를 반드시 제공합니다.
- 흑백과 회색을 기본으로 하고 편집용 빨강 한 점만 신중하게 사용합니다.

## 코드 / 공식 스타일

- `CodeBlock`은 책 페이지 안에 조심스럽게 배치한 코드처럼 보이게 합니다. 따뜻하고 밝은 surface + 가는 선, 둥근 모서리와 어두운 창 스타일은 사용하지 않습니다.
- Prism token은 잉크색 / 따뜻한 편집용 빨강 / 채도를 낮춘 초록을 사용합니다. 무지개처럼 다채롭게 만들지 않습니다.
- `Formula`는 세리프 숫자를 사용해 중앙에 절제되게 배치합니다.

## 금지

- 편집용 빨강 외에 장식 색상을 추가하는 것, 둥근 모서리 / 그림자 / 카드 스타일 / 그라데이션 / 네온.
- Didone을 긴 본문에 사용하는 것(본문에는 올드스타일 세리프 사용). 이탤릭으로 강조하는 것(프로토콜 수준에서 금지).

## 정보 밀도별 표현 제안(권고이며 제한 아님)

- `100% longform / 特稿`: 드롭 캡으로 시작하고 칼럼선으로 구획하며 중앙에 인용문을 둡니다. 본문이 중심입니다.
- `60-80% 评论`: 핵심 인용과 small caps 도입부를 남기고 흑백 도판으로 강조합니다.
- `40% briefing`: Raw는 흑백 데이터 차트 / 타임라인에 활용하고 텍스트는 짧게 유지하되 신문 형식은 지킵니다.
