# 테마 프로필 · tufte(Data-Ink)

> CSS가 아닌 **AI가 글을 쓰면서 읽을 수 있는** 저작 프로필입니다. 구성 요소 라이브러리별 CSS 토큰
> 런타임 주제가 보류됩니다(`data-theme="tufte"`). 이번 문서는 "이 테마를 선택하고 사용하는 방법"입니다.
> 자세한 버전은 구성요소 라이브러리 표준 md: `src/theme/themes/tufte/tufte.md`(코드 작성 /
>공식/미디어/Raw).

- **런타임 테마 ID**: `tufte` (`<ThemeProvider theme="tufte">`)
- **기질**: Edward Tufte 데이터 잉크 비율. 페이지의 모든 잉크 방울에는 정보가 담겨 있습니다. 카드를 제거하고,
  채우기, 그림자, 둥근 모서리, 장식 색상. 텍스트, 가는선 안내선, 충분한 여백, 타이포그래피가 담고 있는 의미를 남겨두세요.

## 적합한/부적합한 기사 유형

- **맞춤**: `longform`, `full-report`, `explainer`, `review`(기술/데이터 유형),
  `tutorial`. 주장과 증거를 담은 긴 독서.
- **적절하지 않음**: 10미터 떨어진 곳에서 보아야 하는 슬라이드(텍스트 크기는 의도적으로 작습니다) 모바일이 선호되며 많은 양의 작업이 필요합니다.
  사이드노트 장면.

## 조판 기질

- 본문과 제목은 옛날 스타일의 세리프체(et-book → Palatino / Georgia / Song Wang)를 사용하고, 글꼴 두께는 400입니다.
- 라벨/메모/테이블 헤더에는 작은 글꼴 크기의 휴머니즘적 산세를 사용합니다.
- 본문은 의도적으로 작게(~16px), 줄 간격은 1.6입니다. 타이틀 레벨은 제한됩니다(h1≒2.5rem, h2≒1.7rem).
- 강조는 글꼴 두께/색상/간격에 따라 달라지며 이탤릭체(이탤릭체는 프로토콜 수준에서 비활성화됨)나 두꺼운 굵은 글씨체가 아닙니다.

## 원시 스타일

현재 단락에서 저자가 손으로 그린 작은 그림처럼 이는 마케팅 구성 요소가 아닙니다.

- 제약을 받는 것은 **미디어**가 아니라 **기질**(제약, 선형성, 데이터 집약적, 낮은 장식)입니다. 어떤 것이든 사용할 수 있습니다.
  HTML/CSS/React, SVG/캔버스 온디맨드.
- 일반: 얇은 폴리라인/산점/경사도, 작은 좌표축, 드래그 가능한 임계선, 로컬 강조 표시, 텍스트 주석,
  마이크로 스파크라인, 경량 조절 가능 매개변수 제어, 간결한 대비 조판.
- 구성: 채우기가 적고 선이 많습니다. 정보 밀도는 높을 수 있지만 모든 줄/요소에는 의미가 있어야 합니다.
- 애니메이션: 기본적으로 없음; 상호 작용이 필요한 경우에만 즉각적인 응답이나 매우 가벼운 전환을 사용하고 바운싱/플로팅/루프 장식은 사용하지 마세요.
- 색상/글꼴/간격은 `--ra-*`에서 가져와야 하며, 직접 팔레트를 만들지 마세요.

## 미디어(이미지/비디오/오디오) 스타일

- 적합 대상: 실제 데이터 그래프, 논문/보고서 스크린샷, 표 스크린샷, 제품 인터페이스 일부, 채도가 낮은 사진, 흑백 또는
  따뜻한 종이 느낌의 선 그리기, 지도/타임라인/가는 선 다이어그램.
- 구도에는 여백이 충분하고 피사체가 선명하며 가장자리가 깨끗해야 합니다. 명확한 캡션/소스/대체 내용이 포함되어야 합니다.
- 먼저 브라우저 크롬에서 스크린샷을 찍으세요.

## 코드/수식 스타일

- `CodeBlock`는 텍스트의 정확한 표본과 같습니다. 밝은 표면 + 헤어라인, 어두운 편집기 쉘이 필요 없음 / 빛나는 테두리 /
  컬러 제목 표시줄. 줄 번호가 표시되지만 다시 설정됩니다.
- 프리즘 토큰 색상은 테마에서 파생됩니다. 구조/레이블은 청록색 액센트를 사용하고 키워드/경고는 따뜻한 빨간색 위험을 사용합니다.
  문자열에는 채도가 낮은 녹색을 사용합니다.
- `Formula` 텍스트의 수학적 주석과 마찬가지로 블록 수준 공식은 가는 선과 공백으로만 전달됩니다.

## 금지 품목

- 카드, 패널, 채우기 블록, 그림자, 둥근 모서리; `#D8D2C2`보다 더 깊은 그리드 선.
- 이모티콘/아이콘은 장식으로 사용됩니다. 색상은 "의미 전달" 이외의 다른 목적으로 사용됩니다.
- 스톡 같은 영웅 사진, 3D 일러스트레이션, 그라데이션 배경, 장식적인 점, 강렬한 포화 기술의 파란색과 보라색, 만화 캐릭터.
- 장식 구성 요소(대시보드 대형 화면, 입자 배경, 유리 모방)를 Data-Ink가 아닌 Raw로 작성합니다.

## 다양한 정보 밀도에서의 성능 제안(제한이 아닌 제안)

- `100% longform / full-report`: 긴 기사를 피하고 Raw에서 핵심 개념을 강조하며 데이터와 증거에 우선순위를 둡니다.
- `60-80% explainer / review`: 핵심 증거+일러스트를 유지하고, 본문은 그대로 유지합니다.
- `40% visual-essay`: 여전히 사실이지만 Raw는 더 도식적이고 증거적이어야 하며 장식이 적고 텍스트가 더 짧아야 합니다.
