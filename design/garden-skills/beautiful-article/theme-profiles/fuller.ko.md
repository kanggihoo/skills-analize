# Theme Profile · fuller(청사진 / 엔지니어링 제도)

> 이 문서는 **AI가 글을 쓸 때 읽는** authoring profile이지 CSS가 아닙니다. CSS 토큰은 컴포넌트 라이브러리의 runtime theme(`data-theme="fuller"`)에서 관리합니다. 이 파일은 테마를 고르고 사용하는 법을 안내합니다. 자세한 기준 문서는 `src/theme/themes/fuller/fuller.md`에 있습니다(코드 / 공식 / 미디어 / Raw 작성 전에 읽을 것).

- **runtime theme id:** `fuller`(`<ThemeProvider theme="fuller">`)
- **분위기:** 엔지니어링 제도 / 청사진. 짙은 청사진 파랑 바탕 + 청록빛 흰 잉크 + 제도용 청록색 한 줄기 + 희미한 사각 격자. 제도판의 구성으로 정체성을 만듭니다. 모눈종이 위의 제목 블록 Hero, 고정폭 치수 표기, 점선으로 나눈 섹션, 청록색 헤어라인. `shannon`(따뜻한 앰버 터미널)의 차가운 반대편입니다. 둘 다 어두운 바탕이지만 이 테마는 명령행이 아니라 제도 작업대 분위기입니다.

## 적합한 글 유형 / 적합하지 않은 글 유형

- **적합:** 기술 사양, 시스템 / 아키텍처 설계, 프로토콜 / 인터페이스 문서, RFC, 하드웨어 / 기계 설명. 정밀하고 차분하며 엔지니어링 감각이 있는 다크 장문과 도식 / 주석 / 토폴로지 그림에 적합합니다.
- **부적합:** 인쇄해야 하는 문서(다크 테마는 잉크를 많이 쓰며 인쇄 시 강제로 흰 배경이 될 수 있음), 따뜻한 서사(`press` / `freddie`), 부드러운 치유 감성(`andy`), 화려하고 장난스러운 구성(`bayer` / `sottsass`), 학술 논문(`knuth`), 흑백 대형 잡지(`bodoni`), 슬라이드.

## 타이포그래피 분위기

- 본문 / 제목은 기술 문서에 어울리는 sans(IBM Plex Sans → Söhne → system-ui), 굵기 400을 사용하고 크기로 위계를 만듭니다.
- **고정폭 글꼴을 의도적으로 강조**합니다(IBM Plex Mono / Berkeley Mono). 섹션 번호, 타임스탬프, 지표, key-value는 고정폭으로 표시해 엔지니어링 로그의 느낌을 냅니다.
- 본문은 약 17px, 행간은 1.62. 디스플레이 굵기는 600(절제된 엔지니어링 감각)입니다. 이탤릭으로 강조하지 않습니다(프로토콜 수준에서 금지).
- **청록색만 구조색으로 사용하고 위험은 따뜻한 오렌지로 표시**해 청록 화면에서도 쉽게 구분합니다. 어두운 바탕이며 모든 soft 색상은 어두운 패널입니다.

## Raw 스타일

어두운 제도판 위에 저자가 직접 치수를 적어 넣은 도식처럼 보이게 합니다.

- 제한하는 것은 매체가 아니라 **분위기**입니다(어두운 바탕, 선 중심, 절제된 신호색, 엔지니어링 근거).
- 일반적인 요소: 어두운 배경의 인라인 SVG, 가는 선 그래프 / 산점도 / flame graph / 타이밍 다이어그램, 드래그 가능한 임계선, 고정폭 주석, 작은 sparkline, 터미널 상태 막대.
- 채우기는 적게 하고 선을 중심으로 구성합니다. 모든 선에 의미가 있어야 합니다. 색상은 `--ra-*`만 사용하며 강조는 청록색이나 경고 빨강으로 합니다.
- 기본적으로 움직임은 없습니다. 꼭 필요한 인터랙션은 즉각 반응하거나 120ms 이하의 아주 가벼운 전환만 사용합니다. 반복 장식은 금지합니다.

## 미디어(이미지 / 비디오 / 오디오) 스타일

- 잘 어울리는 요소: 실제 모니터링 차트 / flame graph / trace, 터미널 스크린샷, 아키텍처 / 타이밍 / 토폴로지 선 도식, 어두운 배경의 데이터 시각화, 채도를 낮춘 제품 UI 일부.
- 어두운 바탕에 여백을 충분히 두고 주제를 분명히 보여 줍니다. 명확한 caption / source / alt를 반드시 제공합니다. 스크린샷에서 관련 없는 크롬을 잘라냅니다.
- 어두운 종이색을 따르고 데이터 강조에는 청록색이나 경고 빨강만 씁니다.

## 코드 / 공식 스타일

- `CodeBlock`은 어두운 배경에서 중요한 엔지니어링 근거처럼 보이게 합니다. 어두운 종이 느낌의 가벼운 surface + 어두운 헤어라인을 사용합니다. 빛나는 테두리 / 컬러 제목 막대 / 글래스모피즘은 금지합니다. 줄 번호는 보이되 시선을 빼앗지 않게 합니다.
- Prism token은 테마에서 파생합니다. 구조 / 레이블 / 함수에는 청록색 강조, 키워드 / 위험에는 위험용 오렌지-빨강, 문자열 / 성공 경로에는 채도 낮은 초록을 사용합니다.
- `Formula`는 계기판 주석처럼 표현합니다. 블록 공식은 가는 선과 여백만으로 절제합니다.

## 금지

- 어두운 바탕을 “사이버펑크 네온”으로 바꾸지 않습니다. 차분한 청사진 테마이며 발광이나 글리치 효과가 없습니다.
- 모서리 반경 / 그림자 / 밝은 카드 / 따뜻한 생활 사진 삽화를 사용하지 않습니다. 위험을 청록색으로 표시하지 않습니다(위험은 따뜻한 오렌지로 고정). 이탤릭 강조는 금지합니다.

## 정보 밀도별 표현 제안(권고이며 제한 아님)

- `100% spec / system-design`: 제목 블록 Hero + 점선 구획 + 사양 표 + 토폴로지 도식. 텍스트와 그림을 비슷한 비중으로 구성합니다.
- `60-80% 文档`: 핵심 치수 도식을 남기고 고정폭 메타데이터로 강조합니다.
- `40% briefing`: Raw는 선 도식 / 타이밍 다이어그램 중심으로, 텍스트는 줄이되 청사진 스타일을 유지합니다.
