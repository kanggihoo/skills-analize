# Theme Profile · sottsass(멤피스 / 80년대 대비 색상)

> 이 문서는 **AI가 글을 쓸 때 읽는** authoring profile이지 CSS가 아닙니다. CSS 토큰은 컴포넌트 라이브러리의 runtime theme(`data-theme="sottsass"`)에서 관리합니다. 자세한 기준 문서는 `src/theme/themes/sottsass/sottsass.md`에 있습니다(코드 / 공식 / 미디어 / Raw 작성 전에 읽을 것).

- **runtime theme id:** `sottsass`(`<ThemeProvider theme="sottsass">`)
- **분위기:** 포스트모던 / 멤피스(밀라노, 1981). 따뜻한 크림색 종이와 검정 잉크에 대담하게 충돌하는 멤피스 파스텔(선명한 분홍 / 청록 / 햇빛 노랑 / 코발트)을 사용합니다. 80년대 게임 같은 표현이 정체성입니다. 흐림 없는 단단한 그림자, 약한 회전, 모서리가 둥근 컬러 pill, 물결 밑줄, 기하학적 confetti. 활기차고 시끄럽지만 읽기 쉽습니다.

## 적합한 글 유형 / 적합하지 않은 글 유형

- **적합:** 장난스러운 과학 설명 / explainer, 디자인 / 문화 / 트렌드 글, 출시 및 행사 글, 가벼운 입문 안내. “세련됨”보다 “개성”, 과감한 색 대비와 편안한 태도가 필요한 콘텐츠.
- **부적합:** 학술(`knuth`), 흑백 대형 잡지(`bodoni`), 차가운 사양(`vignelli`), 어두운 엔지니어링(`shannon` / `fuller`), 진지하고 절제된 글, 조용하고 치유하는 콘텐츠(`andy`가 더 부드러움), 슬라이드.

## 타이포그래피 분위기

- 제목 / 레이블은 장난스러운 기하학 글꼴 Space Grotesk, 본문은 깔끔한 grotesque인 Hanken Grotesk.
- 본문은 약 17px, 행간은 1.65. display 굵기 700을 사용합니다. 이탤릭(프로토콜 수준에서 금지)은 사용하지 말고 색면 / highlight로 강조합니다.
- **충돌하는 색상은 표현에, 코발트 블루는 구조에 사용합니다.** 링크 / 번호에는 코발트를 고정 사용해 가독성을 확보합니다. 분홍 / 청록 / 노랑은 과감한 채움에만 사용하고 작은 텍스트에는 쓰지 않습니다.

## Raw 스타일

멤피스 포스터 스타일의 도식처럼 보이게 합니다.

- 제한하는 것은 매체가 아니라 **분위기**입니다(충돌하는 색상 블록, 흐림 없는 단단한 그림자, 다양한 모서리 반경, 약한 회전, confetti / 물결).
- 일반적인 요소: 단단한 그림자 카드, 대비색 기하학 도형, confetti / 물결 장식, 기울어진 레이블, 활기찬 비율 / 단계 다이어그램.
- 검은 윤곽선 + 오프셋 단단한 그림자 + 충돌하는 색 + 여러 모서리 반경을 조합합니다. 약간 회전할 수 있습니다.
- 튀어 오르며 진입하거나 이동하는 모션은 허용합니다. 무한 네온 반복은 피합니다.

## 미디어(이미지 / 비디오 / 오디오) 스타일

- 잘 어울리는 요소: 기하학적 confetti 일러스트, 대비색 포스터, 물결 / 테라조 질감, 단단한 그림자가 있는 콜라주, 활기찬 인물 / 정물.
- 대담한 색 대비, 회전 / 비대칭 구성, 검은 윤곽선 + 단단한 그림자를 씁니다. 캡션은 짧고 장난스럽게 쓰며 alt를 반드시 제공합니다.
- 분홍 / 청록 / 노랑 / 파랑을 검정·흰색과 과감히 대비합니다. 부드러운 빛 그라데이션이나 네온은 사용하지 않습니다.

## 코드 / 공식 스타일

- `CodeBlock`은 패션 잡지의 코드 카드처럼 표현합니다. 따뜻하고 밝은 surface + 검은 테두리 + 적당히 둥근 모서리, 단단한 그림자는 선택 사항입니다. 어두운 터미널은 사용하지 않습니다.
- Prism token은 레이블 / 함수에 코발트, 키워드에 위험 장밋빛, 문자열에 성공 청록을 씁니다. 대비색은 테두리 / 하이라이트에 사용하고 구문 색상은 무지개처럼 만들지 않습니다.
- `Formula`는 둥근 surface와 포인트 색 한 가지를 사용할 수 있지만 정렬을 절제합니다.

## 금지

- 분홍 / 청록 / 노랑을 본문 / 작은 글자 / 링크에 사용(가독성을 위한 구조색은 코발트로 고정).
- 부드럽게 흐리는 그림자(이 테마는 흐림 없는 단단한 그림자를 사용), 저렴한 그라데이션, 네온.
- “충돌하는 색 + 단단한 그림자”를 지나치게 강조해 읽기 어렵게 만들기(본문은 여유 있게 읽혀야 함). 이탤릭 강조(프로토콜 수준에서 금지).

## 정보 밀도별 표현 제안(권고이며 제한 아님)

- `100% 玩味 explainer`: 대비색 장문 + 기울어진 섹션 블록 + 단단한 그림자 callout + confetti 포인트. 본문은 중심으로 유지합니다.
- `60-80% 内容`: 핵심 단단한 그림자 카드와 대비색 도식을 남기고 물결 밑줄로 강조합니다.
- `40% briefing`: Raw는 대비색 비율 / 단계 도식 중심, 텍스트는 짧게 하되 멤피스 스타일을 유지합니다.
