# Theme Profile · knuth(학술 프리프린트)

> 이 문서는 **AI가 글을 쓸 때 읽는** authoring profile이지 CSS가 아닙니다. CSS 토큰은 컴포넌트 라이브러리의 runtime theme(`data-theme="knuth"`)에서 관리합니다. 이 파일은 테마를 고르고 사용하는 법을 안내합니다. 자세한 기준 문서는 `src/theme/themes/knuth/knuth.md`에 있습니다(코드 / 공식 / 미디어 / Raw 작성 전에 읽을 것).

- **runtime theme id:** `knuth`(`<ThemeProvider theme="knuth">`)
- **분위기:** 학술 / 과학 편집 디자인. 보고서를 저널 / arXiv 프리프린트처럼 보이게 합니다. Computer Modern 세리프, 번호가 붙은 섹션, 그림 / 표 / 공식 번호, 양쪽 정렬 본문, 풍부한 인용, 공식을 앞세운 구성. data-ink 규칙을 완전히 따릅니다. `tufte`의 에세이형 여백 주석과는 다르며 `knuth`는 “공식 논문을 읽는” 느낌입니다.

## 적합한 글 유형 / 적합하지 않은 글 유형

- **적합:** `paper` / `preprint`, `research` / 연구 조사, `literature-review` / 문헌 리뷰, 기술 백서, 형식 분석, 공식 / 정리 / 인용이 많은 `explainer` / `full-report`.
- **부적합:** 따뜻한 서사(`press`), 중립적인 제품 문서(`vignelli`), 어두운 엔지니어링 현장(`shannon`), 슬라이드.

## 타이포그래피 분위기

- 본문과 제목은 Computer Modern / Latin Modern 계열의 세리프를 쓰고 Source Serif 4 / Georgia / 송체를 fallback으로 둡니다.
- 레이블 / 그림 캡션 / 표 머리글은 CMU Sans 계열의 작은 글꼴을 사용합니다. 수식은 KaTeX(`Formula`)로 표시합니다.
- 본문은 약 16.5px, 행간은 1.58. 논문 제목의 무게감은 굵은 세리프(굵기 700)로 표현합니다. 이탤릭 강조는 금지합니다(프로토콜 수준에서 금지).
- **양쪽 정렬을 권장**해 인쇄 논문의 단정한 블록을 만듭니다.

## Raw 스타일

논문에 저자가 직접 배치한 Figure처럼 표현합니다.

- 제한하는 것은 매체가 아니라 **분위기**입니다(공식적, 절제, 공식 / 번호를 우선, 검증 가능).
- 일반적인 요소: 인라인 SVG 차트, 좌표축 / 함수 곡선 / 유도 도식, 인터랙티브 매개변수 시연, 정리 / 증명 구조도, “Figure N.” 캡션이 있는 도판.
- 여백을 절제되게 사용하고 좌표축과 주석을 명확히 둡니다. 학술 파랑으로 구조를 나타내고 모든 선에는 의미가 있어야 합니다. 색상은 `--ra-*`만 사용합니다.
- 기본은 애니메이션 없음입니다. 인터랙션이 꼭 필요하면 즉시 반응하는 아주 가벼운 전환만 사용하고 반복 장식은 금지합니다.

## 미디어(이미지 / 비디오 / 오디오) 스타일

- 잘 어울리는 요소: 데이터 그래프 / 실험 결과, 도식 / 흐름도 / 아키텍처 그림, 논문 스크린샷, 표, 저채도 사진, 원고 / 유도 과정.
- 모든 이미지에는 “Figure N.” 형식의 caption / source / alt를 붙입니다. 여백은 충분히 두고 주제를 분명히 보여 줍니다.
- 종이와 잉크의 저채도 색을 사용합니다. 정보 강조는 학술 파랑 또는 경고 빨강으로만 표현합니다.

## 코드 / 공식 스타일

- `CodeBlock`은 단행본에 실린 절제된 코드 목록처럼 보이게 합니다. 밝은 종이색 surface + 가는 선을 사용하고 어두운 편집기 창은 피합니다. 줄 번호는 은은하게 둡니다.
- Prism token은 테마에서 파생합니다. 레이블 / 함수에는 학술 파랑, 키워드 / 위험에는 경고 빨강, 문자열에는 초록, 주석에는 muted를 사용합니다.
- `Formula`는 이 테마의 중심입니다. 블록 공식은 위아래에 여백을 충분히 두고 번호는 오른쪽에 배치합니다((1)(2)(3)). 인라인 수식은 본문과 자연스럽게 이어집니다.

## 금지

- 카드, 패널, 채움 색면, 그림자, 모서리 반경을 사용하지 않습니다. `#C7C6BB`보다 어두운 격자선도 금지합니다.
- 학술 파랑을 장식용으로 쓰지 않습니다. 경고 목적이 아닌 두 번째 빨강, 장식 이모지 / 아이콘도 사용하지 않습니다.
- 재고 일러스트, 3D 일러스트, 그라데이션 배경, 장식용 빛 번짐, 네온, 대비가 강한 터미널식 검정 코드 창을 넣지 않습니다.
- Raw / 미디어를 논문 도판이 아니라 마케팅 이미지나 SaaS 랜딩 페이지처럼 만들지 않습니다.

## 정보 밀도별 표현 제안(권고이며 제한 아님)

- `100% paper / full-report`: 공식 섹션 번호, 수식 / 그림 번호, 풍부한 인용이 있는 정식 장문.
- `60-80% research / review`: 핵심 유도 과정과 주요 그림을 남기고 본문을 중심으로 구성.
- `40% explainer`: Raw는 공식 / 함수 시각화에 사용하고 텍스트는 줄이되 논문 분위기를 유지합니다.
