# 테마 프로필 · vignelli (스위스 국제주의 문서)

> CSS가 아닌 **AI가 글을 쓰면서 읽을 수 있는** 저작 프로필입니다. 구성 요소 라이브러리별 CSS 토큰
> 런타임 주제가 보류됩니다(`data-theme="vignelli"`). 이번 문서는 "이 테마를 선택하고 사용하는 방법"입니다.
> 자세한 버전은 구성요소 라이브러리 표준 md: `src/theme/themes/vignelli/vignelli.md`(코드 작성 /
>공식/미디어/Raw).

- **런타임 테마 ID**: `vignelli` (`<ThemeProvider theme="vignelli">`)
- **기질**: 스위스 국제주의 타이포그래피. ReActicle **몸이 없는 상태 + 멋진 중립** 테마. 찬 중립 종이,
  그로테스크한 글꼴 모음은 다양한 글꼴 크기, 가는 격자선, 약간의 스위스 레드, 메타데이터를 전달하기 위한 고정 폭 글꼴의 계층 구조를 설정합니다.
  구조적 원칙을 완전히 계승합니다(프레임을 선으로 교체, 정크 테이블 제거, 의미를 전달하는 색상).

## 적합한/부적합한 기사 유형

- **적합**: `docs` / 제품 문서, `spec` / 기술 사양, `changelog` / 릴리스 노트,
  `reference` / SDK·API 참조, AI 도구 / 플랫폼 문서, `explainer`, `tutorial`.
  강력하게 구조화되고 검색 가능하며 중립적인 콘텐츠가 필요합니다.
- **적합하지 않음**: 따뜻한 이야기(`press`); 공식 학술 논문(`knuth`); 어두운 바닥 엔지니어링 현장(`shannon`); 슬라이드.

## 조판 기질

- 텍스트와 제목에는 단일 그로테스크 글꼴 모음(Söhne → Aktiv Grotesk → Helvetica Neue → Arial)을 사용합니다.
  **계층 구조를 만들려면 글꼴을 쌓는 대신 글꼴 크기와 공백을 사용하세요.
- 라벨/헤더는 동일한 글꼴 계열의 작은 글꼴 크기를 사용합니다. 메타데이터/코드는 모노스페이스 글꼴을 메타데이터 "칩"(줄 및 글꼴 두께로 표시됨)으로 사용합니다.
  컬러 캡슐이나 카드로 만들지 마세요.)
- 본문 ~17px, 줄 간격 1.6; 빽빽하게 유지하기 위해 음수 간격으로 큰 제목을 지정합니다. 기울임꼴 없이 강조합니다(프로토콜 수준에서는 비활성화됨).

## 원시 스타일

그리드에 엄격하게 설계된 시스템 문서 일러스트레이션 페이지와 같습니다.

- 제약을 받는 것은 **미디어**가 아니라 **기질**(차가운 중립성, 강력한 그리드, 체계적, 스캔 가능)입니다.
- 일반: 그리드 다이어그램, 프로세스/상태 다이어그램, 사양 비교표, 키보드/단축키 다이어그램, 전환 가능한 매개변수 설명,
  모노 주석이 포함된 SVG.
- 구성: 강력한 그리드 정렬, 명확한 계층 구조, 식별 단서로서의 스위스 레드; 절제된 착색, 서비스 이해. 색상에는 `--ra-*`만 사용하세요.
- 애니메이션: 짧고 선명한 일회성 전환(~120ms)을 허용합니다. 무한 루프 장식을 피하십시오.

## 미디어(이미지/비디오/오디오) 스타일

- 적합 대상: 인터페이스 스크린샷(크롬 트림), 정보 그래픽/흐름도/그리드 다이어그램, 아이콘 시스템 설명, 와이어프레임/사양 다이어그램,
  채도가 낮은 중립 사진.
- 구도는 강력한 격자 정렬, 억제된 공백, 선명한 피사체를 갖추고 있습니다. 캡션은 출처를 간략하게 설명합니다. alt가 포함되어야 합니다.
- 색상은 콜드 뉴트럴 시스템에 가깝고 정보 전달에 스위스 레드만을 사용한다는 점을 강조합니다.

## 코드/수식 스타일

- `CodeBlock`는 조판과 같은 엄격한 기술 사양을 갖추고 있습니다. 차가운 종이의 밝은 표면 + 헤어라인, 어두운 편집기 창 없음. 줄 번호 제한.
- 프리즘 토큰은 다음 테마에서 파생됩니다. 태그/기능은 스위스 빨간색 악센트(제한)로, 키워드/위험은 위험 진홍색으로,
  문자열은 녹색이고 나머지는 잉크/음소거 상태입니다.
- `Formula` 이미지 사양의 공식: 구속, 정렬, 헤어라인 및 공백 전달.

## 금지 품목

- 카드, 패널, 컬러 블록, 그림자, 둥근 모서리, **색상이 있는 왼쪽 테두리 액센트 카드**(slop이라는 이름).
- 스위스 레드를 장식으로 사용하세요. 두 번째 빨간색은 "경고" 이외의 용도로 사용됩니다. 글꼴 크기 계층 대신 더미 가중치를 사용합니다.
- 보라색 분홍색 그라데이션 SaaS 영웅, 네온, Tailwind 기본 버전, 장식용 이모티콘/아이콘, 3D 렌더링 아이콘.
- 원시/미디어는 마케팅 랜딩 페이지 또는 대형 대시보드 화면이 됩니다.

## 다양한 정보 밀도에서의 성능 제안(제한이 아닌 제안)

- `100% docs / reference`: 본문을 본문으로 하는 긴 텍스트 + 사양표 + 그리드 다이어그램을 체계화했습니다.
- `60-80% spec / changelog`: 주요 사양 + 흐름도, 스캔 판독 편의성을 갖춘 모노 메타데이터를 유지합니다.
- `40% briefing`: 원시 부분 그리드 다이어그램, 더 짧은 텍스트가 포함되어 있으며 여전히 문서 형식입니다.
