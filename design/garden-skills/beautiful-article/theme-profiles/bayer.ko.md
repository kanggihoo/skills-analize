# Theme Profile · bayer(바우하우스 / 삼원색 기하학)

> 이 문서는 **AI가 글을 쓸 때 읽는** authoring profile이지 CSS가 아닙니다. CSS 토큰은 컴포넌트 라이브러리의 runtime theme(`data-theme="bayer"`)에서 관리합니다. 이 파일은 테마를 고르고 사용하는 법을 안내합니다. 자세한 기준 문서는 `src/theme/themes/bayer/bayer.md`에 있습니다(코드 / 공식 / 미디어 / Raw 작성 전에 읽을 것).

- **runtime theme id:** `bayer`(`<ThemeProvider theme="bayer">`)
- **분위기:** 바우하우스 / 구성주의. 따뜻한 종이 바탕과 거의 검정인 잉크에 삼원색(빨강 / 파랑 / 노랑)을 장식이 아닌 **구조색**으로 사용합니다. 기하학적 형태가 정체성을 만듭니다. 파란색 단색 원 안의 섹션 번호, 빨강·노랑·파랑의 삼색 머리글 줄, 소문자 산세리프 도입부, 모서리가 날카로운 사각형 등이 특징입니다. 기하학적 산세리프(Josefin / Poppins)를 사용합니다. 강렬하지만 절제되어 있습니다.

## 적합한 글 유형 / 적합하지 않은 글 유형

- **적합:** 튜토리얼 / 과학 설명, 제품 소개, 선언문, 브랜드 스토리. “전문적이지만 개성 있고, 다채롭지만 과하지 않은” 분위기이며 기하학적 인포그래픽 / 흐름도 / 구성주의 일러스트와 잘 맞습니다.
- **부적합:** 학술 논문(`knuth`), 흑백 대형 잡지(`bodoni`), 어두운 엔지니어링 UI(`shannon` / `fuller`), 부드럽고 치유하는 분위기(`andy`), 극도로 중립적인 사양(`vignelli`), 활기찬 다색 표현(`bayer` / `sottsass`), 슬라이드.

## 타이포그래피 분위기

- 제목 / 레이블은 기하학적인 Josefin Sans, 본문은 기하학적이면서 인간적인 Poppins를 사용합니다.
- 본문은 약 17px, 행간은 1.65. 디스플레이 글자는 굵기 700을 사용합니다. 강조에 이탤릭을 쓰지 않습니다(프로토콜 수준에서 금지).
- **파랑은 구조, 빨강은 위험, 노랑은 채우기용입니다.** 링크 / 섹션 원은 파랑, 경고는 빨강, 노랑은 색면에만 사용하며 텍스트 색으로 쓰지 않습니다.
- 도입부 / kicker는 소문자로 표시합니다(Bauhaus 단일 알파벳 원칙, 라틴 문자에만 적용).

## Raw 스타일

구성주의 인포그래픽 한 페이지처럼 표현합니다.

- 제한하는 것은 매체가 아니라 **분위기**입니다(빨강·파랑·노랑, 강한 격자, 날카로운 모서리, 원형 포인트).
- 일반적인 요소: 기하학적 흐름도, 원 / 사각형 / 삼각형 조합, 원색 막대 / 비율 차트, 격자 도식, 파란 원 번호가 붙은 단계.
- 구도는 강한 격자, 날카로운 모서리, 삼원색 + 흑백을 사용합니다. 둥근 사각형 카드는 없습니다.
- 모션은 빠르고 명확하게 이동하거나 나타났다 사라지게 합니다. 바운스와 반복 장식은 쓰지 않습니다.

## 미디어(이미지 / 비디오 / 오디오) 스타일

- 잘 어울리는 요소: 기하학적 구성 일러스트, 원색 포스터, 대비가 강한 흑백 / 원색 사진, 격자 / 원·사각형·삼각형 도식.
- 강한 격자를 쓰고 여백은 단호하게 배치합니다. 원색의 평평한 면을 활용하며 캡션은 간결하게 씁니다. alt를 반드시 제공합니다.
- 빨강 / 파랑 / 노랑 + 흑백 팔레트를 사용하고 보라·분홍의 차가운 그라데이션은 넣지 않습니다.

## 코드 / 공식 스타일

- `CodeBlock`은 구성주의 문서의 코드 블록처럼 보이게 합니다. 따뜻하고 밝은 surface + 가는 선, 모서리 반경 없음, 어두운 창 스타일 없음.
- Prism token은 레이블 / 함수에 파랑 강조색, 키워드에 위험 빨강, 문자열에 초록을 사용합니다. **노랑은 문법 색상에 사용하지 않습니다.**
- `Formula`는 중앙에 절제된 형태로 두며 매우 옅은 surface를 사용할 수 있습니다.

## 금지

- 바우하우스 노랑을 텍스트 / 링크 / 문법 강조색으로 사용(대비 부족).
- 둥근 사각형 카드와 그림자를 쌓기, 보라·분홍 그라데이션, 네온, Tailwind 기본 스타일, 이모지 장식. 이탤릭 강조도 사용하지 않습니다(프로토콜 수준에서 금지).

## 정보 밀도별 표현 제안(권고이며 제한 아님)

- `100% explainer / 教学`: 장문 + 파란 원 번호 + 기하학 인포그래픽 + 노란색 원칙 영역. 본문이 중심입니다.
- `60-80% 内容`: 핵심 절차를 유지하고 구성주의 도식과 삼색 줄로 포인트를 줍니다.
- `40% briefing`: Raw는 기하학 도식 / 비율 차트에 활용하고 텍스트를 줄이되 구성주의 형태를 유지합니다.
