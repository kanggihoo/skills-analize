# Theme Profile · press(책 / 에디토리얼)

> 이 문서는 **AI가 글을 쓸 때 읽는** authoring profile이지 CSS가 아닙니다. CSS 토큰은 컴포넌트 라이브러리의 runtime theme(`data-theme="press"`)에서 관리합니다. 자세한 기준 문서는 `src/theme/themes/press/press.md`에 있습니다(코드 / 공식 / 미디어 / Raw 작성 전에 읽을 것).

- **runtime theme id:** `press`(`<ThemeProvider theme="press">`)
- **분위기:** Stripe Press를 참고한 출판물 수준의 장문. `tufte`와 같은 계열로 Data-Ink 구조 규율(상자 대신 선, 인라인 주석, 불필요한 표 제거, 카드와 그림자 금지)을 공유하지만 개성은 더 강합니다. 보고서를 정성껏 디자인한 책처럼 편집합니다. `tufte`가 “가까이 다가가 읽기”라면 `press`는 “한 팔 거리에서 책을 읽기”입니다.

## 적합한 글 유형 / 적합하지 않은 글 유형

- **적합:** `essay`, `briefing`, `visual-essay`, 서사 / 출판 스타일의 `longform`, 인문학 성격의 `explainer`. 여유롭게 읽는 장문, 에세이, 백서, 제품 일지.
- **부적합:** 여백 주석이 많이 필요한 극도로 밀집된 데이터 보고서(`tufte`의 주 영역), 프레젠테이션 슬라이드.

## 타이포그래피 분위기

- 본문과 제목에는 현대적인 transitional serif(Newsreader → Source Serif 4 / Spectral / Georgia / 송체)를 사용합니다. `tufte`보다 현대적이고 완성된 책 같은 분위기입니다.
- 본문은 크게(약 17px), 행간은 1.7. 제목 크기(h1 약 3rem)를 키워 무게감을 주며 아주 굵은 고딕체에는 의존하지 않습니다.
- 강렬한 주 색상(산화된 짙은 빨강) 하나를 섹션 번호, 강조선, Hero, TOC 강조에 반복합니다. 이탤릭은 사용하지 않습니다.

## Raw 스타일

`tufte`보다 레이아웃 감각을 더 강하게 줄 수 있지만, 글을 위해 별도로 디자인한 내지의 삽화처럼 보여야 합니다.

- 우선 고려할 요소: 출판물 스타일 다단 도식, 따뜻한 인포그래픽, 작은 인터랙티브 자, 섹션 사이 리듬 다이어그램, 세밀한 caption이 있는 SVG, 약하게 펼치거나 전환할 수 있는 설명 컨트롤.
- 여백은 더 넉넉하고 제목 위계는 더 강하게 둡니다. 산화된 짙은 빨강을 인식용 포인트로 사용하고 `tufte`보다 채움 색을 조금 더 사용할 수 있지만 절제합니다.
- 짧고 부드러운 일회성 전환은 허용합니다. 무한 반복 장식 애니메이션은 피합니다.
- 사용자 지정 CSS / SVG / React에서도 `--ra-*` 토큰을 사용하고 새 브랜드 색이나 차가운 그라데이션을 추가하지 않습니다.

## 미디어(이미지 / 비디오 / 오디오) 스타일

- 잘 어울리는 요소: 따뜻한 사진, 책 / 종이 / 작업대 세부, 제품 UI 스크린샷, 저채도 에디토리얼 일러스트, 정교한 인포그래픽, 원고 / 메모 / 레이아웃 스케치.
- 주제는 명확하게 두고 여백을 넉넉하게 사용하며 색온도는 따뜻하게 맞춥니다. `tufte`보다 제품 맥락을 더 온전히 보여 줘도 되지만 노이즈는 잘라냅니다.
- 캡션은 출판물처럼 짧게 출처와 맥락을 설명하며 마케팅 슬로건을 쓰지 않습니다.

## 코드 / 공식 스타일

- `CodeBlock`은 기술 서적의 코드 페이지처럼 표현합니다. 따뜻하고 읽기 쉬우며 세밀하게 다듬되 IDE 스크린샷처럼 보이지 않게 합니다. 크림색 종이 위 밝은 코드 surface + 선 경계, 줄 번호는 `tufte`보다 여유롭게 둡니다.
- Prism token은 press 토큰에서 파생합니다. 레이블 / 함수에는 산화된 짙은 빨강 강조색, 문자열에는 저채도 초록, 키워드 / 위험에는 더 따뜻한 위험색을 사용합니다.
- `Formula`는 책 페이지의 조판된 수식처럼 보이게 합니다. 블록 수식은 여백을 넉넉히 두고 캡션은 출판물의 설명처럼 씁니다.

## 금지

- 카드, 패널, 색면 채우기, 그림자, 둥근 모서리.
- 주 색상을 장식처럼 남용하지 않습니다(구조와 브랜드 식별에만 사용). 경고 이외의 목적에 두 번째 빨강을 쓰지 않습니다.
- 장식용 이모지 / 아이콘을 사용하지 않습니다.
- 이미지나 Raw를 출판물 도판이 아니라 마케팅 랜딩 페이지 / SaaS 홈페이지 / 대시보드 화면처럼 만들지 않습니다.
- 차가운 파랑·보라 SaaS 스톡 이미지, 저렴한 그라데이션 배경, 정보가 없는 분위기용 히어로 이미지를 피합니다.

## 정보 밀도별 표현 제안(권고이며 제한 아님)

- `100% longform`: 깊이 있는 출판용 글. 분량이 위계를 만들고 Raw는 정교한 삽화로 사용합니다.
- `40-60% briefing / visual-essay`: 편집 리듬과 이미지가 놓일 여백을 더 강조하고 시각 블록 비중을 높이되 여전히 글의 형태를 유지합니다.
