# Theme Profile · andy(Headspace의 차분함 / 부드러움)

> 이 문서는 **AI가 글을 쓸 때 읽는** authoring profile이지 CSS가 아닙니다. CSS 토큰은 컴포넌트 라이브러리의 runtime theme(`data-theme="andy"`)에서 관리합니다. 이 파일은 테마를 고르고 사용하는 법을 안내합니다. 자세한 기준 문서는 `src/theme/themes/andy/andy.md`에 있습니다(코드 / 공식 / 미디어 / Raw 작성 전에 읽을 것).

- **runtime theme id:** `andy`(`<ThemeProvider theme="andy">`)
- **분위기:** 따뜻한 휴머니즘(Headspace). 따뜻한 크림색 종이, 친근한 호박색 오렌지, 따뜻한 회색 잉크(순수 검정 아님), 전반적으로 둥근 산세리프체(Quicksand + Nunito). **일곱 테마 중 큰 모서리 반경과 부드럽고 따뜻한 그림자를 함께 쓰는 유일한 테마입니다.** 부드럽고 차분하며 치유하는 느낌을 주고 편안함을 우선합니다. 의미 기반 컴포넌트 규약을 완전히 따릅니다.

## 적합한 글 유형 / 적합하지 않은 글 유형

- **적합:** 건강 / 심리 / 라이프스타일, 안내형 `tutorial`, 부드러운 입문 및 안심시키는 문구, 제품 가치 서사, 부드러운 UI와 친근함이 필요한 `explainer`. 일반 독자 대상이며 부담을 낮춥니다.
- **부적합:** 학술 논문(`knuth`), 차가운 사양 문서(`vignelli`), 어두운 엔지니어링 UI(`shannon`), 빽빽한 데이터 보고서(`tufte`), 장난스러운 노랑·검정(`freddie`), 날카롭고 엄숙한 콘텐츠, 슬라이드.

## 타이포그래피 분위기

- 제목 / 레이블에는 기하학적 둥근 글꼴 Quicksand, 본문에는 인간적인 둥근 글꼴 Nunito를 사용합니다. Headspace의 미소 곡선을 떠올리게 합니다.
- 본문은 약 17px, 행간은 1.7로 넉넉하게 둡니다. 제목은 `display: 700`을 사용하고 둥근 글꼴을 굵게 처리해 친근하게 만듭니다. 이탤릭 강조는 사용하지 않습니다(프로토콜 수준에서 금지).
- **밝은 오렌지는 채우기에, 더 짙은 오렌지는 글자에 사용합니다.** 원형 섹션 번호 / pill에는 밝은 호박색 오렌지, 링크 / 구조에는 읽기 쉽도록 짙은 번트 오렌지를 사용합니다.

## Raw 스타일

부드럽고 둥글며 긴장을 풀어 주는 일러스트 페이지처럼 구성합니다.

- 제한하는 것은 매체가 아니라 **분위기**입니다(따뜻한 오렌지 계열, 큰 모서리 반경, 부드러운 그림자, 넓은 여백, 차분함).
- 일반적인 요소: 모서리가 둥근 단계 카드, 부드러운 진행 표시 / 호흡 애니메이션, 원형 차트, 친근한 질문과 답, blob / 불완전한 원 장식.
- 구도는 넓은 여백, 큰 모서리 반경, 부드러운 그림자를 사용합니다. 색상은 `--ra-*` 토큰만 쓰며 오렌지색은 `--hs-orange`를 사용합니다.
- 모션은 잔잔하고 부드럽게 합니다. 호흡 안내 같은 안정적인 반복은 가능하지만 부산스럽지 않아야 합니다.

## 미디어(이미지 / 비디오 / 오디오) 스타일

- 잘 어울리는 요소: 둥근 마스코트 / blob 일러스트, 따뜻한 일상 사진, 따뜻한 오렌지색의 부드러운 그라데이션 배경, 모서리가 둥근 친근한 아이콘.
- 여백은 넉넉히 두고 둥근 프레임으로 자르며 주제는 차분하게 표현합니다. 캡션은 부드러운 어조로 쓰고 alt를 반드시 제공합니다.
- 따뜻한 오렌지를 중심으로 부드러운 파랑 / 초록을 감정 색상으로 더하며 채도는 낮춥니다.

## 코드 / 공식 스타일

- `CodeBlock`은 친근한 앱 문서 속 코드 카드처럼 표현합니다. 따뜻하고 연한 surface + 큰 모서리 반경을 사용하며 아주 은은한 그림자는 가능하지만 어두운 터미널 스타일은 사용하지 않습니다.
- Prism token은 레이블 / 함수에 짙은 오렌지 강조색(절제해서), 키워드에 위험 빨강, 문자열에 초록을 사용합니다. 나머지는 따뜻한 잉크 / muted 계열입니다.
- `Formula`는 부드러운 주석처럼 절제되고 정렬된 형태로 만듭니다. 모서리가 둥근 surface를 쓸 수 있습니다.

## 금지

- 순수한 검정 잉크, 딱딱한 직각, 차가운 색은 “부드럽고 치유하는” 정체성을 즉시 무너뜨립니다.
- 밝은 호박색 오렌지를 본문 / 작은 글자에 쓰지 않습니다(대비가 부족하므로 어두운 강조색을 사용).
- 부드러운 그림자와 큰 모서리 반경을 남용해 과장된 카드 더미를 만들지 않습니다. 보라·분홍 네온, Tailwind 기본 스타일, 이탤릭 강조도 금지합니다.

## 정보 밀도별 표현 제안(권고이며 제한 아님)

- `100% explainer / tutorial`: 부드러운 장문 + 둥근 단계 카드 + 베개처럼 편안한 callout. 본문이 중심입니다.
- `60-80% 引导内容`: 핵심 단계와 부드러운 삽화를 유지하고 원형 섹션 번호로 포인트를 줍니다.
- `40% briefing`: Raw는 부드러운 도식 / 호흡 애니메이션에 쓰고 글을 짧게 유지하되 치유하는 분위기는 유지합니다.
