# Theme Profile · shannon(다크 엔지니어링 근거)

> 이 문서는 **AI가 글을 쓸 때 읽는** authoring profile이지 CSS가 아닙니다. CSS 토큰은 컴포넌트 라이브러리의 runtime theme(`data-theme="shannon"`)에서 관리합니다. 자세한 기준 문서는 `src/theme/themes/shannon/shannon.md`에 있습니다(코드 / 공식 / 미디어 / Raw 작성 전에 읽을 것).

- **runtime theme id:** `shannon`(`<ThemeProvider theme="shannon">`)
- **분위기:** `tufte`의 “야간 엔지니어링 버전”. 따뜻한 흑연색 다크 바탕, 따뜻한 흰 잉크, 제한적인 앰버 신호색 한 줄기. Data-Ink 규율을 모두 따릅니다(상자 대신 선, 인라인 주석, 불필요한 표와 색상 장식 배제). 무대만 어두운 엔지니어링 공간으로 옮깁니다. **순수 검정 아님, `#0D1117` 사이버 다크 아님, 네온이나 발광 없음.**

## 적합한 글 유형 / 적합하지 않은 글 유형

- **적합:** `postmortem` / 장애 회고, `system-design` / 아키텍처 결정, `benchmark` / 성능 분석, 기술 / AI / 알고리즘 `explainer`, `review`, `tutorial`. `CodeBlock`, `DiffReview`, `Incident`, `RiskList`, `Decision`이 많이 나오는 콘텐츠와 특히 잘 맞습니다.
- **부적합:** 인쇄가 필요한 공식 문서(다크 바탕은 잉크를 많이 쓰며 인쇄 시 흰 배경으로 강제될 수 있음), 따뜻한 서사 / 출판 에세이(`press` / `knuth`), 10미터 거리에서 보여 줄 슬라이드.

## 타이포그래피 분위기

- 본문과 제목에는 기술 문서에 어울리는 sans(IBM Plex Sans → Söhne → system-ui)를 쓰고 굵기는 400으로 유지합니다. 크기로 무게감을 줍니다.
- **고정폭 글꼴을 의도적으로 크게 활용합니다**(IBM Plex Mono / Berkeley Mono). 섹션 번호, 타임스탬프, 지표, key-value를 고정폭으로 표시해 엔지니어링 로그 느낌을 만듭니다.
- 본문은 약 16px, 행간은 1.6. 이탤릭(프로토콜 수준에서 금지)이나 두꺼운 블랙을 쓰지 않고 글자 굵기 / 색 / 간격으로 강조합니다.

## Raw 스타일

저자가 어두운 배경에 손으로 그린 작은 계기판 그래픽처럼 보이게 합니다.

- 제한하는 것은 매체가 아니라 **분위기**입니다(어두운 바탕, 선 중심, 절제된 신호, 엔지니어링 근거).
- 일반적인 요소: 어두운 배경의 인라인 SVG, 가는 선 그래프 / 산점도 / flame graph / 타이밍 다이어그램, 드래그 가능한 임계선, 고정폭 주석, 작은 sparkline, 터미널 상태 표시줄.
- 채움은 적게 하고 선을 중심으로 구성합니다. 모든 선은 의미가 있어야 합니다. 색상은 `--ra-*`만 사용하고 강조에는 앰버색이나 위험 빨강을 씁니다.
- 기본은 움직임 없음입니다. 인터랙션이 꼭 필요하면 즉시 반응하거나 120ms 이하의 아주 약한 전환만 사용하고 반복 장식은 넣지 않습니다.

## 미디어(이미지 / 비디오 / 오디오) 스타일

- 잘 어울리는 요소: 실제 모니터링 차트 / flame graph / trace, 터미널 스크린샷, 아키텍처 / 타이밍 / 토폴로지 선 도식, 어두운 배경의 데이터 시각화, 저채도 제품 UI 일부.
- 어두운 바탕에 여백을 충분히 두고 주제를 분명하게 보여 줍니다. caption / source / alt를 분명히 표시합니다. 스크린샷에서 관련 없는 크롬은 잘라냅니다.
- 어두운 종이색을 유지하고 정보 강조에만 앰버색이나 위험 빨강을 사용합니다.

## 코드 / 공식 스타일

- `CodeBlock`은 어두운 배경의 핵심 엔지니어링 근거처럼 보이게 합니다. 어두운 종이색의 은은한 surface + 어두운 헤어라인. 발광 테두리 / 색상 제목 바 / 글래스모피즘은 사용하지 않습니다. 줄 번호는 보이되 뒤로 물립니다.
- Prism token은 테마에서 파생합니다. 구조 / 레이블 / 함수에는 앰버 강조색, 키워드 / 위험에는 위험 빨강-오렌지, 문자열 / 성공 경로에는 저채도 초록을 씁니다.
- `Formula`는 계기판 주석처럼 처리합니다. 블록 수식은 가는 선과 여백으로 절제합니다.

## 금지

- 카드, 패널, 색면 채우기, 그림자, 둥근 모서리, 발광 테두리. `#45423A`보다 밝은 격자선.
- 순수 검정 / `#0D1117` 사이버 다크, 네온 하이라이트, 무지개식 구문 강조, 과포화된 기술 파랑·보라.
- 앰버 신호색을 장식용으로 남용하거나 경고 이외의 목적으로 두 번째 빨강을 사용. 장식용 이모지 / 아이콘.
- 미디어 / Raw가 엔지니어링 근거가 아니라 사이버펑크 분위기 연출(계기판형 대형 대시보드, 입자 배경, 글래스모피즘)로 변함.

## 정보 밀도별 표현 제안(권고이며 제한 아님)

- `100% longform / postmortem`: 절제된 장문 + 엔지니어링 근거. Raw로 핵심 신호 / 타이밍을 강조합니다.
- `60-80% system-design / explainer`: 핵심 아키텍처 도식 + 코드 근거를 유지하고 본문이 중심이 되게 합니다.
- `40% briefing`: Raw는 어두운 배경의 도식 / 지표 중심, 글은 줄이되 문서 형태를 유지합니다.
