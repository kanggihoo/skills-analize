# 사운드: 사운드트랙, 음향 효과, 믹싱

사운드는 비디오의 나머지 절반입니다. 음향 효과가 붙어 있든 없든 동일한 그림은 다른 수준으로 보이고 느껴집니다. 사운드 트랙과 사운드 효과는 모두 코드로 작성되었으며, 시점은 `timeline.js`에서 읽혀지므로 화면과 동일한 일정에 있습니다.

먼저 BGM 소스와 음향 효과(AI 합성/사용자 제공/해제)를 확인한 후 엔진을 선택합니다. 소스가 혼합될 수 있습니다. 다음은 입으로 방송하지 않고 원래의 합성, 재밍, 믹싱 방법을 그대로 유지한 것입니다. 음성 방송이 있는 경우 `narration.md`를 먼저 읽으십시오. 사용자는 원본 원고 또는 녹음을 제공하고 먼저 실제 문장 시간 축을 획득하고 보컬이 우선 순위가 지정되며 BGM 및 음향 효과가 수렴됩니다. 최종 3트랙 믹싱 뒤에는 통일된 음량이 이어집니다. 2분 이상 후에 `long-form.md`를 읽으십시오. 오디오는 전체 오프라인 배열이 너무 많은 메모리를 차지하지 않도록 챕터별로 구성됩니다.

이 문서의 레시피, 곡선 및 용어집은 **규칙이 아닌 시작점 및 용어**입니다. 선택한 스타일과 벤치마킹이 우선하며 여기서는 글쓰기 방법을 전혀 사용할 필요가 없습니다.

## 1. 어느 것을 선택할 것인가?

| 파일 | 파일 | 엔진 | 강점 | 약점 |
|---|---|---|---|---|
| 레벨 1 · 내장 합성(기본값) | `score.mjs` | 노드의 합성기, 의존성 없음, 완전히 결정적 | 전자드럼, 봉고, 합성베이스, 패드, 현악기, 마림바/강판/칼림바, 오르간, 보컬 패드, FM 차임, 칩 뮤직, 주변 소음 플로어, lo-fi 처리, UI 음향 효과, 사이드 체인 | 실제 피아노, 현악기, 실제 드럼은 동일하지 않습니다 |

| 침묵 | — | — | 루핑 애니메이션, 다른 영화에 포함될 자료 | — |두 가지 레벨을 쌓을 수 있습니다. 먼저 `audio.mjs build score.tone.js --raw --out audio/tone.wav`는 마스터링되지 않은 음악 레이어를 가져온 다음 `score.mjs`는 `S.load('audio/tone.wav')`를 버스에 넣고 첫 번째 레벨의 사운드 효과를 쌓고 마지막으로 함께 마스터링합니다. `scaffold.sh --audio layer`는 `score.mjs`의 복사본을 제공합니다(첫 번째 줄에 `audio/tone.wav`를 로드하고 나중에 사운드 효과만 작성). `build.sh`의 `AUDIO=layer`는 ​​이 순서대로 자동으로 빌드됩니다. `score.mjs`가 `tone.wav`를 참조하지 않으면 빌드에서 오류를 보고하므로 톤 레이어가 렌더링되지만 혼합되지는 않습니다.

`build.sh`는 `AUDIO=`에서 지정한 악보(신디사이저/톤/레이어/없음)만 빌드합니다. 다른 파일이 존재하는 경우 해당 파일을 무시하라는 메시지가 표시되며 조용히 다른 사운드트랙으로 대체되지 않습니다. 반복적인 합성 없이 최종 오디오를 믹싱하기 위해 독립적인 트랙을 사용하는 `AUDIO=file AUDIO_FILE=audio/final.wav`를 추가했습니다. 파일 길이는 `timeline.js`와 일치해야 하며 충돌을 먼저 확인해야 하며 입 방송이 자동으로 끊어질 수 없습니다.

**선택 방법**: 선택한 스타일 파일의 "사운드 팔레트"를 살펴보세요. 전자, 인터페이스, 복고풍, 추상적, 대부분의 수공예품 및 장난감 스타일의 경우 첫 번째 장비로 충분합니다. 실제 피아노, 현악기, 넓은 공간이 필요한 영화 및 고급 제품의 경우 두 번째 기어를 사용하거나 두 개의 기어를 쌓을 수 있습니다.

## 2. 먼저 소리의 방향을 결정하세요

사운드와 그래픽은 기본 설정으로 적용됩니다. 방향이 없으면 합성된 사운드트랙은 동일한 노래로 수렴됩니다. A 단조, 120BPM의 4개 탭, 충격 + 각 비트의 충돌, 드롭의 차임(섹션 12 참조). 그러므로 브리핑을 작성할 때 사운드를 그림과 동일한 축으로 취급하고 **먼저 사운드의 기준점**을 찾으세요: 음악 스타일, 작곡가, 영화의 사운드트랙, 밴드, 일종의 포크 음악. 배워야 할 것(그루브, 화성색, 오케스트레이션, 구조, 공간)과 배우지 말아야 할 것(멜로디, 샘플, 가사)을 적어보세요.

`sound:`는 간략하게 다음 항목으로 확장될 수 있습니다. 문체와 비교를 통해 유추할 수 있는 한 단어를 적는 것만으로도 충분하다. 각 항목을 반드시 입력할 필요는 없습니다.```yaml
sound:
  benchmark: [声音对标 · 学什么 · 不学什么]
  role: [音乐在这支片子里的角色：推动 / 托底 / 抢戏 / 几乎不出现，让拟音说话]
  groove: [拍号 · BPM · 直拍 / swing / half-time / 无拍]
  harmony: [调和调式 · 进行或持续音 · 色彩]
  palette: [主奏 / 节奏 / 低音 / 纹理分别用什么]
  arc: [戏剧曲线，见第 5 节]
  motif: [可选：一个 2–4 音的动机，以及它怎么变奏]
  mix: [空间大小、宽度、侧链与否、是否 lo-fi]
```

- **후보도 2~3명 정도 생각하고 있어요**: 시각적인 구조와 마찬가지로 처음 떠오르는 사운드 방향은 스타일의 진부한 표현인 경우가 많습니다. 한 줄에 두세 가지씩 쓰고 한 가지를 선택하세요.
- **자신에게서 벗어나세요**: 작업 디렉토리에 이전에 수행한 프로젝트가 있으면 브리핑에서 `sound`를 살펴보세요. 사용자가 통일된 시리즈를 요구하지 않는 한, 이 시리즈는 모드, 리듬, 오케스트레이션, 커브에서 최소한 두 가지 항목을 대체해야 합니다.
- **데모(선택)**: 사운드가 영화의 주인공 중 하나인 경우(음악, 갇힌, 텍스트가 없는 감성 영화) 3단계의 스타일 프레임 중에 `audio.mjs build score.a.mjs --dur 8 --out audio/sketch-a.wav`와 같이 2~3 6~8초의 사운드 데모를 사용자에게 보낼 수 있습니다. 렌더링에는 몇 초밖에 걸리지 않으며 사용자는 들을 수 없지만 사용자는 들을 수 있습니다. 필요하지 않으면 일시 중지 지점을 추가하지 않고 건너뜁니다.

## 3. 레벨 1: 내장 합성(세션 API)

`score.mjs`는 `DUR` 및 `S` 세션을 허용하는 기본 기능을 내보냅니다.```js
import { DUR, BPM, CUES } from './timeline.js';
export { DUR };
export default function score(S) {
  S.tempo(BPM);                                         // S.beat(n)、S.bar(n) → 秒
  const drums = S.bus('drums', { gain: 0.9 });
  const music = S.bus('music', { gain: 0.5, reverb: 0.3, duck: 0.6, highpass: 160 });
  drums.add(S.kick(), S.beat(0)); S.duck(S.beat(0));    // 侧链：music 在每个 duck 点被压低
  music.add(S.pad(S.chord('A3', 'min7'), S.bar(2)), S.bar(0));
}
```**버스 옵션**: `gain`, `pan`(−1…1), `reverb`(전송 볼륨 0–1), `delay`(전송 볼륨), `delayTime`(초, 기본 3/4 비트), `duck`(사이드 체인 깊이) 0–1), `duckRelease`(초), `highpass` / `lowpass`(Hz), `drive`(0–1), `crush`(비트 심도, 예: 6–12, 0 = 꺼짐), `crushRate`(Hz 단위로 다운샘플링), `wow`(0–1, 테이프 지터 및 테이프 전송 불안정성), `width`(0 = 모노).
**`bus.add(sound, t, { gain, pan })`**: t는 음수일 수 있습니다(제목 앞에서 사운드가 시작되고 일부가 잘림).
**`S.duck(t, depth)`**: 사이드 체인 트리거 포인트를 등록합니다(보통 킥 이후 또는 임팩트 위치에 위치).
**`S.space({ room, damp, width })`**: 영화 전체에서 공유되는 잔향은 어떤 모습인가요? 방 0.3(작은 방)… 0.95(홀), 습기 0(밝음)… 0.9(어두움). 기본 `{ room: 0.84, damp: 0.3 }`.
**리듬**: `S.tempo(bpm, { beatsPerBar })`(3/4, 6/8, 5/4 모두 허용됨); `S.steps('x..x..x.', step = 0.25)`는 스텝 스트링을 비트 위치로 바꿉니다(`x`는 히트, 다른 문자는 쉼표, 공백 및 `|`는 무시됨). `S.swing(n, amount = 1/3, grid = 0.5)`는 스윙으로 비트 위치를 초 단위로 바꿉니다(⅓ ⅓ 삼중음 느낌, 그리드 0.25는 스윙의 16포인트입니다). `S.humanize(t, ms = 8)`는 고정 시드에 작은 시간 오프셋을 제공합니다.
**하모니**: `S.midi('C#4')`, `S.hz('A4')`, `S.chord(root, quality, inversion)` (maj, min, sus2, sus4, 희미한, aug, 5, 6, m6, 7, 9, 7b9, 7sus4, maj 7. min7, m7b5, 희미한7, maj7#11, m9, maj9, add9, madd9, min11, quartal, quartal4, 클러스터), `S.scale(루트,이름)(도)`(메이저, 마이너, 도리안, 프리지안, 리디안, 믹솔리디안, 로크리안, 하모닉, 멜로딕, 히자즈, 홀톤, 블루스, 펜타, 민펜타, 히라조시, 인센, 공, 상, 주에, 지, 유). 음표는 이름이나 MIDI 번호로 기록될 수 있습니다.

**악기**(모노 Float32Array를 반환하고 패드, 오르간, 복스, 쉭, 앰비언스는 스테레오 `{L, R}`를 반환함):| 카테고리 | 기능 | 공통 매개변수 |
|---|---|---|
| 드럼 | `kick()` | 톤 48, 시작 165, 감쇠 0.42, 클릭 0.5, 드라이브 0.35 |

**기본 도구**(자신만의 사운드를 만들 때 사용): `osc(len, freqOrFn, wave)`, `noise(sec, seed)`, `adsr`, `expEnv`, `biquad(buf, type, cutoffOrFn, q)`, `lowpass`, ZXQPH 22QXZ, `bandpass`, `drive`, `crush(buf, bits, rate)`, `reverse`, `fade`, `mul`, `S.SR`(48000). `S.load(file)` ffmpeg를 사용하여 모든 오디오를 `{L, R}`로 디코딩합니다. 내장된 사운드는 완제품이 아니라 재료입니다. 매개변수 변경, 시드 변경, 두 개의 레이어 쌓기, 기본 도구를 사용하여 영화에 고유한 사운드(브람, 카툰 휘파람, 펜촉 긁기 등)를 만드는 것은 기본값을 직접 사용하는 것보다 "이 영화의 사운드"에 더 가까운 경우가 많습니다.빌드: `node <skill>/scripts/audio.mjs build <slug>/score.mjs [--out audio/music.wav] [--stems]`. 마스터링은 자동으로 -14 LUFS로 처리되고 피크 리미터를 사용하여 -1.5 dBFS로 억제됩니다. `--stems`는 문제가 있는 트랙에 대한 문제 해결을 용이하게 하기 위해 각 버스를 `audio/stems/`로 별도로 내보냅니다.

## 4. 레벨 2: Tone.js

`score.tone.js`는 `timeline.js`와 함께 사용되는 **브라우저 ES 모듈**입니다.

```js
import { DUR, BPM, CUES, b } from './timeline.js';
export { DUR };
export default async function score(Tone, kit) {
  kit.transport.bpm.value = BPM;
  const verb = new Tone.Reverb({ decay: 2.8, wet: 0.25 }).toDestination();
  const piano = new Tone.Sampler({ urls: kit.salamander(), baseUrl: kit.baseUrl('salamander'), release: 1.2 }).connect(verb);
  await kit.loaded();                                        // 采样解码完再排音符
  piano.triggerAttackRelease(['A3', 'C4', 'E4'], b(4), 0);   // 时间用秒（从 timeline 来）
}
```- **빌드**: `node <skill>/scripts/audio.mjs build <slug>/score.tone.js`, −14 LUFS의 WAV 출력(`--raw`는 마스터링을 건너뜁니다). `scaffold.sh <slug> --audio tone`는 전체 예제 `score.tone.js`를 복사하고 `build.sh`를 `AUDIO=tone`로 설정합니다. 두 파일을 함께 사용하는 경우 `--audio layer`를 선택하세요.
- **키트**: `DUR`, `transport`, `loaded()`, `baseUrl(pack)`, `sample(pack, file)`, `salamander()` (Salamander 피아노용 `Sampler` URL 표).
- **샘플링**: `node <skill>/scripts/audio.mjs samples`는 다운로드 가능한 패키지를 나열합니다. `samples salamander`는 Salamander Grand Piano(CC BY 3.0, 배송 시 저작자 표시 필요)를 다운로드합니다. 다른 CC0/승인된 샘플은 `<slug>/samples/<名字>/`에 넣을 수 있으며 페이지에서 `/samples/<名字>/文件`를 참조할 수 있습니다. 출처와 승인을 알 수 없는 샘플을 사용하지 마십시오.
- **일반적으로 사용되는 부품**: `Sampler`(샘플링 악기), `PolySynth(FMSynth | AMSynth | Synth)`, `MonoSynth`(베이스), `MembraneSynth`(베이스 드럼), `MetalSynth`(심벌즈), `NoiseSynth`; 효과 `Reverb`(컨볼루션), `FeedbackDelay`, `PingPongDelay`, `Chorus`, `Phaser`, `Distortion`, `BitCrusher`, `Filter`, `AutoFilter`, `Compressor`, `Limiter`.
- **참고**: 모든 사운드는 `.toDestination()`에 연결되어야 합니다(직접 또는 효과 체인을 통해). 그렇지 않으면 음소거로 렌더링됩니다. 시간에 절대 초를 사용하고(`timeline.js`에서), `Tone.now()`에 의존하지 마십시오. 메모를 정렬하기 전에 샘플을 `await kit.loaded()` 이후에 정렬해야 합니다.
- 피아노만이 기어2의 용도가 아닙니다: 샐러맨더피아노는 레이어(저음 부분은 단음, 고음 부분은 장식)로만 사용할 수 있고, 메인 부분은 1단에서 할 수 없는 FM, 코러스, 콘볼루션 공간 등으로 남겨둔다.

## 5. 구조와 드라마틱한 곡선

## 8. 시간 규칙- 사운드 효과의 트리거 시간**은 timeline.js**에서 동일한 숫자를 직접 사용하므로 직접 작성하지 마십시오.
- 휙의 피크는 절단점(`t − peak × dur`)과 정렬됩니다. 충격은 정확히 액션 프레임에 떨어집니다.
- **"흡입 → 폭발" 곡선**을 사용할 때 낙하하기 전에 묵음의 비트(최소 절반 비트)를 남겨두십시오. 드럼과 바닥이 멈추고 라이저의 꼬리만 남거나 전혀 남지 않습니다. 침묵 이후의 첫 번째 소리는 영화 전체에서 가장 중요한 소리 중 하나임이 틀림없다. 다른 곡선에는 고유한 초점이 있습니다. 음성이 장면에 들어오는 시기를 확인하기 위해 합산하고 음성이 제거되는 순간이 깨끗한지 확인하는 데 시간을 투자합니다.
- 사운드를 전환으로 사용할 수 있습니다. 다음 샷의 사운드가 2~4프레임 먼저 나오거나(J-컷), 이전 샷의 꼬리 소리가 컷 포인트를 지나 계속됩니다(L-컷).
- 루프 필름: 마지막 섹션의 리버브 테일이 필름 시작 부분에서 갑자기 끊어집니다. 마지막 비트를 깔끔하게 모아야 하며, 그렇지 않으면 테일을 필름 시작 부분으로 다시 접어야 합니다.
- **이미지가 먼저 결정되고 음악이 나중에 추가되는 장편**(연대순 검토, 여러 세계를 여행하는 롱샷): 단락의 경계는 이미지에 의해 결정됩니다. 모든 경계를 다시 차지할 수 있도록 통일된 BPM을 설정하는 것은 어렵습니다. 각 섹션이 자체 속도를 설정하도록 할 수 있습니다. 각 섹션에는 정수 소절 수가 포함되어 있으며 비트 길이 = 섹션 길이 ¼ 비트 수이며 인접한 섹션 간의 속도 차이는 ±8% 이내로 제어됩니다. 귀로는 들을 수 없지만 오케스트레이터를 바꿀 때 항상 소절의 첫 박자를 친다. 이때 음표 시간은 글로벌 `S.beat`를 사용하지 않고 "섹션의 시작점 + 해당 섹션의 비트 수 × 이 섹션의 비트 길이"로 기록됩니다. 크로스페이드 없이 세그먼트 간 하드 어택.

## 9. 믹싱

- **최소 버스**: 드럼, 베이스, 음악, SFX 최소 4개, 밸런스 조정이 쉽습니다.
- **사이드체인**: 베이스와 음악용 `duck`는 0.5~0.7로 설정하고, 각 킥 드럼과 히트용은 `S.duck(t)`로 설정하면 그루브가 즉시 드러납니다. 하지만 사이드체인 펌프는 일렉트로닉 댄스 음악의 시그니처이자 스타일이지 기본이 아닙니다.
- **저주파 제어**: 합성된 음악의 저주파는 쉽게 너무 무거워질 수 있습니다. 패드와 음악에 `highpass: 150–250`를 추가하세요. 킥의 감쇠는 0.45를 초과해서는 안 됩니다. 베이스의 `sub`는 0.3~0.6으로 조절되어야 합니다. MIDI 48보다 낮은 패드 노트를 사용하지 마십시오.
- **소형 스피커**: 60Hz 이하의 스피커는 휴대폰 외부 스피커를 통해 들을 수 없습니다. 베이스에는 2차 및 3차 고조파가 있어야 합니다(`sub({ harm })` 및 `bass`의 톱니파에는 이미 해당 고조파가 있음).
- **Space**: 리버브는 음악과 sfx에만 전송되며(0.15-0.35), 드럼과 베이스는 건조한 상태로 유지됩니다.
- **음량**: 마스터링은 자동으로 −14 LUFS(모든 주요 플랫폼의 표준), 실제 피크 ≤ −1 dBTP로 처리됩니다.**철학과 스타일의 혼합**(다음은 전부는 아니지만 여러 가지 방향입니다):

| 오시는 길 | 방법 |
|---|---|
| 클럽/일렉트로닉 댄스 음악 | 사이드 체인 펌프, 완전하고 넓은 저주파 |
| 영화 | 폭, 넓은 공간(`S.space({ room: 0.9 })`), 측면 체인 없음; 역학은 커야하며 조용한 부분은 정말 조용합니다 |
| 오리지널 사운드 / 핸드메이드 | 사이드 체인 없음, 작은 공간(`room: 0.5`), 근거리, 일시적 보존 |
| 로파이 | 드럼 버스 `crush: 10–12` + `lowpass: 6000–9000`; 음악 `wow: 0.3–0.6`; 하단 레이어 `ambience` 테이프 또는 비닐; `width`는 0.6 |
| 칩/픽셀 | 건식, 모노 또는 하드 팬, `crush: 4–6`, `crushRate: 11000–22000` |
| 미니멀리스트 / 기술 | 건조하고 정확하며 많은 침묵을 남깁니다. 리버브가 짧고 밝습니다(`room: 0.5, damp: 0.1`) |
| 오리엔탈/프리핸드 | 큰 리버브(0.4-0.5 전송), 소수의 보이스, 긴 공백, 사이드 체인 없음 |

## 10. 확인(들리지 않음)

모든 빌드 후에 실행합니다.

```bash
node <skill>/scripts/audio.mjs check <slug>/audio/music.wav --out <slug>/qa/music
```

전체 음량(목표 −14 ± 1 LUFS), 실제 피크(< −1 dBTP), 옥타브별 에너지(핑크 노이즈는 1kHz에 대해 모두 0입니다. 일반적인 혼합은 63~125Hz에서 +4~+12, 4~8kHz에서 −6~−18), 예상치 못한 침묵 부분을 인쇄하고 경고를 제공합니다. 주파수 대역의 대표적인 값은 전자믹싱을 참고로 한 것인데, 원음이나 단선영화, 동양영화 등 의도적으로 가벼운 영화에서는 낮은 주파수를 갖는 것이 정상이다. "얇음"이 보이면 의도적인 것인지 확인하세요.**드롭 전 호흡**: `timeline.js`에서 `DROPS = [T.drop, …]`를 내보내고(또는 임시로 `--drops 12,24.5`를 업로드) 확인하면 각 재촬영 전 ​​마지막 반 비트가 이전 섹션보다 낮은 dB 수와 재촬영이 이전 섹션보다 높은 dB 수를 측정합니다. 우울증이 4dB 미만이면 "호흡 없음"을 의미합니다. 이는 드럼이나 베이스가 멈추지 않았거나 라이저가 너무 시끄럽다는 것을 의미합니다. 리비트는 이전 소절보다 크지 않습니다. 이는 WARN을 의미합니다. 이것이 드롭을 "들을" 수 있는 유일한 방법입니다. "흡입 → 폭발" 곡선을 사용하지 않는 필름에는 `DROPS`를 쓸 필요가 없습니다. 그런 다음 **참조** `-wave.png`(상단 클리핑이 있는지 여부, 볼륨 변동이 그림 구조와 일치하는지 여부 및 선택한 곡선: 드롭 곡선이 드롭에서 가장 가득 차고 누적 곡선이 끝까지 두꺼워지며 대피 곡선이 대피 지점에서 끊어짐) 및 `-spectrum.png`(저주파수가 항상 붐을 일으키는지 여부, 고주파수가 완전히 없는지 여부)를 참조하세요.

영화가 완성된 후 `inspect.mjs qa`는 혼합된 MP4를 다시 확인합니다.

## 11. 사용자가 제공한 노래1. 승인 여부(상업적 이용 가능 여부, 본인 소유 여부)를 확인하고 배송지시사항을 기재합니다.
2. `node <skill>/scripts/audio.mjs beats track.mp3 --out <slug>/audio/beats.json`(librosa가 설치되면 자동으로 librosa를 사용하여 더 안정적인 비트 그리드를 결정합니다. `--engine js`는 내장 알고리즘을 강제로 사용합니다.): BPM, 비트, 다운비트, 시작 히트, 마디당 에너지, 드롭(에너지가 갑자기 증가하는 마디) 및 브레이크(에너지가 갑자기 감소하는 마디)를 가져옵니다.
3. **그리드 확인**: 비트 감지는 절반 속도 또는 두 배 속도로 잠기거나 백비트로 떨어질 수 있습니다. BPM이 일관성이 없는 것으로 알려진 경우 `--bpm`를 추가하세요. 샷 포인트가 백핸드에 있으면 `--shift 0.5`를 추가하세요. `-wave` 다이어그램을 열어 드롭 위치가 `drops`와 일치하는지 확인하세요.
4. 섹션 선택: 단편 영화는 일반적으로 한 마디를 포함하여 전체 문구(4 또는 8마디)를 캡처합니다. `score.mjs`에서:
   ```js
   const song = S.load('audio/track.mp3'), a = Math.round(START * S.SR), n = Math.round(DUR * S.SR);
   const cut = { L: S.fade(song.L.slice(a, a + n), 0.01, 0.4), R: S.fade(song.R.slice(a, a + n), 0.01, 0.4) };
   S.bus('song', { gain: 1 }).add(cut, 0);
   ```
   그런 다음 맨 위에 sfx를 스택합니다(명령을 실행할 때 `S.load`의 경로는 현재 디렉터리에 상대적이므로 프로젝트 디렉터리에서 빌드를 실행하는 것이 좋습니다).
5. 가로채는 비트 시간(시작점 제외)을 `timeline.js`: `export const BEATS = [...]`, `export const DROP = ...`에 쓰고 여기부터 모든 그림을 읽습니다.
6. 노래 자체가 마스터링되었습니다. 버스의 게인을 1로 설정하고 드라이브를 추가하지 마십시오. 마스터링을 하면 전체가 -14 LUFS로 돌아갑니다.
