## 모션 효과 포트폴리오

가장 인기 있는 카테고리인 원래 프롬프트 단어는 일반적으로 "이력서의 포트폴리오처럼 15초짜리 애니메이션 비디오를 만들어 보세요."라는 한 문장으로 구성됩니다. 상한선은 높지만 결과는 통제할 수 없습니다. 이러한 유형의 접근 방식은 "모두 나가기"를 구체적인 구조로 변환합니다.

- **구조**(8마디): 훅(첫 비트의 강력한 그래픽 액션) → 다양한 기법(타이포그래피, 인터페이스, 기하학 또는 입자)의 2~3개 단락, 각 2마디 → 가속 → 흡입 → 메모리 포인트 → 드롭(이름 또는 문장) 또는 처음으로 원활하게 돌아갑니다.
- **포인트**: 각 단락의 기법을 변경하되 색상 일치, 글꼴, 스포츠 캐릭터는 영화 전체에서 선택한 스타일을 따라야 합니다. 그렇지 않으면 템플릿 모음이 됩니다. 단락 사이의 전환은 콘텐츠에서 확장되어야 합니다(craft.md 섹션 5).
- ** 함정 **: 기술이 많을수록 분산되기 쉽습니다. 각 문단의 길이는 약 2초이며, 텍스트에는 1~3개의 단어만 포함될 수 있습니다. 최종본이 있어야 합니다.

## B제품 홍보영상

- **재료 우선**: 제품 스크린샷, UI, 로고, 실제 기능 이름 및 판매 포인트. 사용자가 URL 또는 코드 저장소를 제공하면 Playwright를 사용하여 실제 페이지(2×DPR)를 캡처하고 요소 좌표를 기록한 다음 카메라가 실제 버튼을 누르도록 할 수 있습니다. **기능, 데이터, 고객 및 리뷰는 포함하지 마세요**. 누락된 항목이 있으면 문의하거나 공백으로 남겨두세요.
- **구조**(16개 섹션, 약 30초): 후크(질문 또는 대조) → 제품 데뷔 → 3가지 판매 포인트(각각 인터페이스 샷, 문장, 증거 작업(예: 디지털 점프 또는 프로세스 안내) 포함) → 요약 → 마무리(로고 + 슬로건 + 웹 사이트 또는 날짜). 15초 버전에는 단 하나의 판매 포인트만 유지됩니다.
- **기술**: 스크린샷을 찍어 플로팅 스크린을 만들고, 커서를 클릭하면 인터페이스 상태가 변경됩니다. 다중 장면 장편 영화에서는 Remotion을 사용할 수 있지만 사용자가 요청했거나 이미 사용 중인 경우에만 가능합니다. 기본값은 단일 HTML입니다.
- ** 함정 **: 가까이 다가가면 스크린샷이 흐려집니다. 말이 너무 많아요; 브랜드 색상이 변경되었습니다.

## C UI 애니메이션 데모

공개된 '인터페이스 변형' 프롬프트 단어 템플릿을 참조하세요. 전체 영화에는 단 하나의 요소만 있고 처음부터 끝까지 잘린 부분이 없습니다.- **구조**: 비트 그리드에 배열된 8~12개의 인터페이스 상태, 예: 버튼 → 로딩 → 확인 표시 → 플레이어 → 진행률 표시줄 → 슬라이더 → 스위치 → 탭 → 차트 → 명령 패널 → 알림 → 뒤로 버튼.
- **기술**: 동일한 용기의 크기, 둥근 모서리, 색상을 변경합니다( recipe.md 섹션 3). 커서가 실제로 드래그되고 있습니다(섹션 4). 표시 막대의 앞쪽 가장자리와 뒤쪽 가장자리가 분리됩니다(섹션 2). 컨테이너에서 전환된 콘텐츠에는 자체 진입 및 종료가 있어야 합니다.
- **구덩이**: `will-change`를 추가하면 크기가 조정된 텍스트가 흐려집니다. 이전 텍스트와 새 텍스트가 함께 쌓입니다. 루프 이음새에 있는 커서의 위치나 속도가 일치하지 않습니다.

## D 다이나믹 조판 / 황금문장 카드 포인트

- **구조**: 카피는 "박자당 한 단어" 또는 "한 절과 한 문장"으로 나누어지며, 나머지 박자에는 핵심 단어가 배치됩니다. 문장이 끝난 후에는 끝날 때까지 기다리세요(craft.md 섹션 7).
- **기술**: 캔버스 또는 DOM; 축어적 마스킹이 제공됩니다(recipes.md 섹션 1). 세로 화면의 경우 단어는 안전한 영역에 배열되어야 합니다.
- **구덩이**: 말이 너무 많고 체류 시간이 너무 짧습니다. 중국어 글꼴은 하위 집합이 아니며 렌더링 중에 블록이 나타납니다.

## E 로고 해석/제목

- **구조**(4~8초): 준비(로고를 암시하는 요소) → 폭발 → 형성 → 동결(로고 + 브랜드 이름, 체류 ≥ 1.5초).
- **재료**: **실제 로고 파일을 사용해야 합니다**, SVG가 가장 좋습니다. 스트로크 경로를 분할하거나 블록으로 조합할 수 있습니다. 이해할 수 없다면 멈춰서 물어보세요. 컬러 블록으로 가장하지 마세요.
- ** 함정 **: 로고의 비율이나 색상이 모양이 맞지 않습니다. 프레임이 너무 짧습니다.

## F 루프 애니메이션

- **구조**: 한 번의 완전한 호흡(모임 → 흩어짐 → 모임), 마지막 프레임은 첫 번째 프레임과 동일합니다.
- **기술적**: 모든 모션은 `θ = TAU * t / DUR`의 정수 주파수 함수로 작성되고 노이즈는 원에서 샘플링됩니다( recipe.md의 섹션 11). 프레임별 누적 시뮬레이션을 사용하지 마세요.
- **적용**: `inspect.mjs qa … --loop` (또는 `LOOP=1 sh build.sh`), 솔기 단계(마지막 프레임 → 첫 번째 프레임)는 일반 프레임 사이의 단계만큼 매끄러워야 합니다. 소리는 필요하지 않습니다. 만약 있다면 소리가 순환될 수 있어야 합니다.

## G데이터 폭발점- **구조**: 복선(질문 또는 대조면) → 숫자 스크롤(1.5~2.5초) → 정착(충격 또는 반전 색상) → 한 문장 설명(스테이 ≥ 2.5초) → 출처(작은 글씨).
- **기술**: 카운터(recipes.md 섹션 9), 너비가 같은 숫자; 대비는 차원으로 표현되며 열은 0부터 시작합니다.
- **구덩이**: **숫자는 사용자나 신뢰할 수 있는 소스에서만 얻을 수 있습니다**. 확실하지 않은 경우 사용자가 확인할 수 있도록 표시하세요.

## H 녹색 화면 문자 + 코드 장면

코드는 사실적인 캐릭터와 복잡한 액션을 그리는 데 능숙하지 않기 때문에 영상 모델은 캐릭터만 담당하고 나머지는 모두 코드로 처리합니다.

1. 사용자는 비디오 모델(Seedance, Keling, Jimeng, Grok 등)을 사용하여 캐릭터 클립을 생성합니다. **순수한 녹색 배경**, 거울 속의 전신, 페인팅 없음. 이 단계는 사용자가 완료하며, 이 Skill은 비디오 모델을 호출하지 않습니다.
2. 키잉: `ffmpeg -i dancer.mp4 -vf "chromakey=0x19FF0A:0.16:0.08,despill=type=green,format=yuva444p10le" -c:v prores_ks -profile:v 4444 dancer_alpha.mov`. 색상 값은 추출된 프레임에서 가져옵니다. 먼저 프레임을 선택하여 가장자리를 확인합니다.
3. 비트에 따라 변화하는 코드를 사용하여 배경, 큰 문자, 스티커, 분할 화면을 비디오 레이어로 렌더링합니다.
4. 합성: `ffmpeg -i bg.mp4 -i dancer_alpha.mov -filter_complex "[0][1]overlay=(W-w)/2:H-h" …`. 캐릭터 앞에 요소가 필요한 경우 캐릭터를 그림 순서로 내보내고 페이지에서 t를 눌러 그릴 프레임을 선택합니다.
5. 전달할 때 어떤 이미지가 비디오 모델에서 왔는지, 어떤 이미지가 코드에서 왔는지 명확하게 표시하십시오.

## 아이시대 리뷰

공개적으로 배포된 "비디오 게임 개발 역사"의 코드 버전을 참조하세요. 2분, 여러 미디어와 혼합, 사운드트랙 합성, 화면이 음악과 함께 잘립니다.- **구조**: 오프닝(픽셀, 광점, 단어 등 영화 전체를 관통할 수 있는 요소) → 4~7단계, 각 섹션은 8~20초, 각 섹션은 해당 단계의 매체로 그려짐 → 클라이막스(모든 단계가 수렴) → 엔드(오프닝과 동일)
- **포인트**: 영화 전체를 관통하는 스레드(동일한 주인공, 동일한 전환, 점진적으로 업그레이드된 오케스트레이션이 포함된 사운드트랙). 이 스레드가 없으면 스타일 플래터가 됩니다. 구성 뼈대의 각 섹션이 정렬되고, 요소 전체의 작업이 전체 영화 시간에 따라 수행되며, 다음 매체의 모양을 빌려 진행 과정에서 전환이 가속화될 수 있습니다. 스타일 규칙은 `styles/mixed-media-era.md`를 참조하세요.
- **프로덕션**: 60초를 초과할 경우 먼저 저화질 샘플(`--size 960x540`)을 만들어 전체적인 리듬을 확인한 후 단락별로 별도로 다듬어줍니다. 느린 렌더링 단락(3D, 셰이더)을 별도로 테스트하려면 `--start --duration`를 사용하세요.
- **구덩이**: **역사적 사실이 정확해야 합니다**: 연도, 이름, 창작자가 확인되어야 합니다. 확실하지 않은 경우에는 기록하지 말고 사용자가 확인할 수 있도록 나열하세요.

## J 구두 방송 설명/챕터 길이 영화

- TTS 원고는 사용자가 제공해야 합니다. 사용자 녹음을 사용할 수도 있고, 구두 방송 없이 장 길이의 영화를 제작할 수도 있습니다. 이 목적은 기사를 음성 버전으로 대필하는 것에 대해 책임을 지지 않습니다.
