# 리퀴드 셰이더 (liquid-shader)

> 프래그먼트 셰이더가 픽셀 단위로 계산하는 유체: 메타볼이 서로 당겨져 합쳐지고, 액체 금속이 반사되며, 노이즈 장이 천천히 흐른다. 형태 하나가 액체처럼 다음 형태로 흘러간다.
> 참고 (문법만 참고): Shadertoy의 SDF 및 노이즈 작품, 액체 금속 브랜드 모션, 라바 램프. 기법만 참고하고 구체적인 셰이더 코드는 복제하지 않는다.

## 본질 / 본질이 아닌 것
- 본질: **형태를 거리장 (SDF)으로 정의**하고 smooth min으로 부드럽게 합쳐 액체처럼 융합시킨다. 표면 법선과 환경 반사로 금속 / 유리 질감을 만들거나 domain warping 노이즈로 흐르는 색상장을 만든다.
- 본질이 아닌 것: 그라데이션 원을 몇 개 겹쳐 놓은 것, 구조 없이 계속 흔들리는 화면 보호기.

## 식별 신호: 영상마다 2–3개 선택
| 신호 | 어떤 모습인가 | 적합한 주제 |
|---|---|---|
| 메타볼 융합 | 구 여러 개가 가까워지고 실처럼 이어져 하나로 합쳐짐 | 협업, 융합 |
| 액체 금속 | 크롬색 표면이 주변을 비춰 수은처럼 보임 | 고급스러움, 기술 |
| 라바 램프 | 따뜻한 색 덩어리가 천천히 오르내림 | 휴식, 복고 |
| 물속으로 번지는 잉크 | 물 안에서 물감이 말리며 퍼짐 | 예술, 기원 |
| 도메인 왜곡 색상장 | 유화 물감처럼 색이 천천히 흐름 | 감정, 배경 |
| 표면 파문 | 한 점의 교란에서 물결이 번져 나감 | 영향, 트리거 |
| 액체 방울과 튐 | 방울 하나가 떨어져 튄 뒤 되돌아옴 | 충격, 음료 |
| 유리 액체 | 투명한 액체 너머 사물이 굴절되어 보임 | 산뜻함, 순수함 |
| 굳으며 형태 형성 | 흐르던 액체가 마지막에 형태 하나로 굳음 | 엔드카드, 완성 |
| 등고선 | 액체 높이를 동심 등고선으로 표현 | 데이터, 지형 |

규칙:
- 영상마다 2–3개를 고르고 적어도 하나는 아래의 “가장 진부한 버전”에 없는 신호로 선택한다.
- 신호는 주제에 맞춰 고르며 순서대로 모두 쓰지 않는다.

## 이 스타일의 가장 진부한 버전
- 화면: 거의 검정 바탕에서 크롬색 메타볼이 천천히 회전하고 무지개가 표면을 한 바퀴 돌며 액체 방울 둘이 합쳐져 로고가 됨.
- 사운드: 저음 drone, 물방울, 큰 리버브 패드.
- brief의 style 항목에 뒤집은 규칙이나 고전적 표현을 유지한 이유를 쓴다. 유지한다면 구도, 카메라, 리듬 또는 예상 밖의 기억점에 공을 들인다.

## 적합성
- 용도: 오프닝, 전환, 액체에서 굳어 나오는 로고 연출, 포트폴리오의 시그니처 순간.
- 콘텐츠: AI, 음악, 뷰티, 음료, 추상 개념, 브랜드 무드 필름.

## 기술 구현
전체 화면 WebGL2 프래그먼트 셰이더를 사용합니다 (recipes.md 12절의 템플릿에서 콘텐츠 텍스처를 셰이더 계산으로 대체). t, 해상도, 박자 pulse를 uniform으로 전달합니다. 텍스트나 로고는 먼저 Canvas에 그려 SDF 텍스처를 만들거나 (또는 흐린 alpha를 거리장의 근사로 직접 사용) 셰이더에서 다른 형태와 합칩니다. 한 프레임을 먼저 렌더해 효과를 확인합니다. 소프트웨어 렌더링은 느립니다.

## 재질과 렌더링
- 메타볼 융합: smin(a, b, k)로 원 / 구의 SDF를 결합하고 k로 “점성”을 조정.
- 2D 액체 금속: SDF에서 법선을 계산 (유한 차분) → 법선으로 코드에서 만든 “환경” 그라데이션을 샘플링 → 가장자리에 프레넬 하이라이트 추가.
- 흐름장: fbm(p + fbm(p + t))로 domain warping한 뒤 3–4개 색상 정지점을 가진 팔레트에 매핑.
- 가장자리 안티앨리어싱: smoothstep(-px, px, d) 사용. px는 픽셀 하나의 거리.

## 색상
아래 값은 예시이며 방향만 참고하고 그대로 복사하지 않습니다.
- 근흑색 #08090B 위의 크롬 은색 #E6E8EB. 환경 반사는 한 색조만 사용 (예: 얼음 파랑 #9FD8FF).
- 용암: 짙은 빨강 #3A0A0A → 오렌지 #FF5A1F → 크림 #FFE7C2.
- 부드러운 안개: 라벤더 #CBB8FF / 피치 #FFC9B5 / 우유빛 흰색 #FFF7F0 (낮은 대비, 안개 질감).
- 규칙: OKLab 보간으로 색상표를 3–4개 정지점으로 제한하고 무지개 팔레트는 금지.
- 색상 도출: 역시 OKLab 보간을 사용한 3–4개 색상 정지점. 브랜드 / 주제에서 가져옵니다: 금속의 단색 반사, 용암의 따뜻한 단계, 저대비 안개색, 고대비 두 색 등. 크롬 은색 + 얼음 파랑이 흔한 조합입니다.

## 글꼴
로고 / 제목 자체가 액체 변형에 참여합니다. 정적인 설명 문구는 깔끔한 산세리프를 사용하고 액체 바깥에 둡니다.

## 움직임
- 흐름은 느리게 (주기 4–12초). 박자가 올 때 k 값이나 크기에 pulse를 한 번 줍니다.
- 형태 간 변환은 SDF 두 개를 mix(d1, d2, ease(p))로 보간하고 smooth min과 결합해 자연스러운 “실처럼 늘어남”을 만듭니다.
- 루프 작업은 주기 함수 sin(TAU * t / DUR)로 만들어 시작과 끝이 자연스럽게 이어집니다.

## 화면에 생동감 더하기
- 계속 흐르는 것이 본질이므로 과하게 더하지 않습니다. 표면 하이라이트가 천천히 움직이고 아주 작은 파문이 생기는 정도면 충분합니다.
- 박자에 맞춘 k 값이나 크기의 pulse가 이미 생동감을 주므로 루프를 더 얹을 필요가 없습니다.

## 카메라 문법
| 카메라 움직임 | 표현하는 것 | 적합한 콘텐츠 |
|---|---|---|
| 고정 카메라, 형태 자체가 변함 | 흐름 자체가 주인공 | 대부분의 장면 |
| 표면으로 천천히 전진 | 몰입 | 기억점 |
| 좌표계 회전 | 소용돌이 | 전환 |

## 사운드 팔레트
유체감 표현: 천천히 필터를 스윕하는 패드 (pad cutoff를 시간에 따라 변화), 입자 shimmer, 저음 sub, 융합 순간의 “물방울” 소리 (빠르게 하강하는 pop). 2단계 리버브와 코러스 효과가 더 잘 맞습니다.

리듬과 화성 (예시이며 한 가지로 한정하지 않음): 느린 half-time 또는 박자 없음, Dorian, Lydian, 4도 쌓기, 지속 저음, 파도 곡선. vox를 흐르는 보컬 패드로 쓰고 music bus에 약한 wow를 줘 음높이도 액체처럼 움직이게 할 수 있습니다.

## 이 매체만의 표현
- 액체 방울 둘이 가까워져 실처럼 늘어나 하나의 로고로 합쳐짐: 브랜드 등장에 적합.
- 전체 화면이 액체처럼 흘러 다음 장면으로 이어짐: 전환에 적합.
- 액체 금속 표면에 다음 장면이 반사되어 나타남: 공개 / reveal에 적합.

## 변주 여지
- 구조: 액체 한 방울의 여정, 형태 세 개가 하나로 융합, 혼돈스러운 흐름에서 굳은 형상으로 변화.
- 도입: 평면 위에 액체 한 방울이 떨어져 퍼짐, 화면 중앙에 호흡하는 메타볼.
- 끝맺음: 액체가 로고로 굳고 마지막 반사가 표면을 스침.

## 함정
- 픽셀별 계산량이 너무 많아 렌더링이 매우 느림: 960×540에서 먼저 시간을 측정하고 raymarch 반복 수에 상한 설정.
- 안티앨리어싱 없는 딱딱한 가장자리가 인코딩 후 계단처럼 보임: smoothstep으로 픽셀 수준 AA를 만들거나 --dpr 2 사용.
- 색상이 너무 많고 채도가 높아 환각적 화면 보호기로 변함: 팔레트를 엄격히 제한.
