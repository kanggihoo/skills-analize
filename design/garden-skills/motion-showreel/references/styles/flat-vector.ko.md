# 플랫 벡터 (flat-vector)

> 외곽선 없는 색면으로 끝없이 확대할 수 있는 세계를 그린다. 사람, 기계, 행성은 단순한 기하 도형이고 카메라는 규모 사이를 이동하며 복잡한 이야기를 쉽게 풀어낸다.
> 참고 (문법만 참고): 플랫 스타일의 과학 영상 채널, 현대적인 플랫 상업 일러스트, Material 시대의 일러스트 시스템. 특정 채널의 캐릭터, 색상 체계, 화면을 복제하지 않는다.

## 본질 / 본질이 아닌 것
- 본질: **개념을 걸어 들어갈 수 있는 작은 세계로 그린다.** 아이도 그릴 수 있을 만큼 단순한 형태지만 빛, 레이어, 비율은 세심하게 설계한다. “확대”, “분해”, “변형”으로 정보를 설명하며 화면은 계속 미세하게 움직인다.
- 본질이 아닌 것: 아이콘을 쌓은 PPT, 등각 투영 방식의 공학 아키텍처도 (`isometric-infographic`에 해당).

## 식별 신호: 영상마다 2–3개 선택
| 신호 | 어떤 모습인가 | 적합한 주제 |
|---|---|---|
| 외곽선 없는 색면 | 검은 윤곽선 없이 색면만으로 형태를 구분 | 모든 주제 |
| 같은 색조의 그림자 | 회색이 아니라 본색보다 한 단계 어두운 색으로 그림자 표현 | 입체감, 온기 |
| 콩 모양 캐릭터 | 둥근 머리, 얼굴이 없거나 점 두 개, 팔다리는 모서리가 둥근 막대 | 사용자, 군중, 캐릭터 |
| 규모 사이를 여행 | 세포에서 도시, 행성에서 사람으로 카메라가 이동 | 규모, 원리 |
| 단면도 | 사물을 잘라 내부 층을 보여줌 | 내부 메커니즘 |
| 빛나는 점 | 어두운 배경에 소수의 발광 요소 | 에너지, 데이터, 밤 |
| 레이어 시차 | 전·중·후경이 서로 다른 속도로 이동 | 공간, 여정 |
| 둥근 기하학 기계 | 톱니, 관, 버튼으로 구성한 귀여운 기계 | 흐름, 시스템 |
| 곡선 이동 경로 | 사물이 직선 대신 원호를 따라 움직임 | 전달, 흐름 |
| 개념별 색 하나 | 개념마다 고정된 색을 배정하고 영상 내내 바꾸지 않음 | 설명, 비교 |
| 종이 입자감 | 플랫 색 위에 아주 옅은 입자 질감 | 따뜻함, 수작업 느낌 |

규칙:
- 영상마다 2–3개를 고르고, 그중 하나 이상은 아래의 “가장 진부한 버전”에 없는 신호로 선택한다.
- 신호는 주제에 맞춰 선택하며 순서대로 전부 쓰지 않는다.
- 색상은 곧 의미다. 개념마다 색 하나를 배정하고 영상 내내 유지한다. 의미 색상이 4개를 넘으면 관객이 기억하기 어렵다.

## 이 스타일의 가장 진부한 버전
- 화면: 짙은 청보라 우주 배경, 빛나는 행성과 소행성, 지구에서 손을 흔드는 콩 모양 캐릭터, 우주에서 지구로 줌인.
- 사운드: 글로켄슈필과 현악 패드, 부드러운 과학 설명 어조.
- brief의 style 항목에 이번 영상에서 뒤집은 규칙이나 고전적인 표현을 유지한 이유를 쓴다. 유지한다면 구도, 카메라, 리듬 또는 예상 밖의 기억에 남는 순간에 공을 들인다.

## 적합성
- 용도: 원리 설명 제품 홍보, 기능 설명, 브랜드 스토리, 데이터 이면의 이야기, 로고 연출.
- 콘텐츠: 기술 원리, 건강, 금융 개념, 환경, 교육, “어떻게 작동하는가”.
- 부적합: 실제 제품 UI를 보여줘야 할 때 (`minimal-ui` 사용, UI는 실제 스크린샷 사용), 신뢰할 수 있는 데이터 그래프가 필요할 때 (`data-motion` 사용).

## 기술 구현
Canvas 2D 또는 SVG. 장면 전체를 화면보다 훨씬 큰 월드 좌표계로 만들고 카메라를 뷰포트 (중심, 확대, 회전)로 둔다. 확대는 로그 보간 (매 프레임 같은 배율로 확대)을 사용한다. 벡터를 매번 다시 그려 50배 확대해도 흐려지지 않게 한다. 모양은 둥근 사각형, 원, 베지어 곡선으로 구성하고 그림자는 같은 형태를 오프셋한 뒤 본체 안에서 한 톤 어두운 색으로 clip 처리한다. 입자는 `--grain 2–3` 사용.

## 재질과 렌더링
- 형태: 둥근 모서리를 주로 사용하고 날카로운 각은 피한다. 같은 종류의 물체는 같은 기하 부품 체계로 조립한다.
- 빛과 그림자: 고정된 광원 방향 하나를 둔다. 빛을 받는 면은 한 톤 밝게, 그늘 면은 한 톤 어둡게 하며 같은 색조를 유지하고 회색을 쓰지 않는다.
- 발광: “에너지”를 나타내는 소수 요소에만 적용하고 같은 색의 원을 2–3겹, 점점 크고 흐리게 겹친다.
- 레이어: 먼 배경은 채도와 대비를 낮추고 전경은 높인다. 가장 앞에 큰 흐린 형태를 프레임처럼 둘 수 있다.
- 캐릭터: 콩 모양 몸통과 둥근 머리, 입이 없거나 곡선 하나만 사용. 표정보다 자세와 동작으로 감정을 전달.

## 색상
아래 색상은 예시다. 방향만 참고하고 그대로 베끼지 않는다.
- 밤: 배경 `#14213D` / 중경 `#2A3B6B` / 따뜻한 빛 `#FCA311` / 청록 `#4CC9F0` / 피부 `#F4A261`
- 밝은 장면: 배경 `#FDF6EC` / 초록 `#2A9D8F` / 노랑 `#E9C46A` / 코럴 `#E76F51` / 짙은 파랑 `#264653`
- 단색 계열: 한 색조의 명도 5단계 + 주인공에게만 대비색 하나
- 색상 도출: 먼저 배경이 어두울지 밝을지 정하고 개념마다 색 하나씩 배정한다 (브랜드색을 시작으로 OKLab에서 인접색 도출). 그림자는 항상 본색보다 한 톤 어둡게 한다. 짙은 청보라 우주와 따뜻한 노란 발광이 가장 흔한 조합이다.

## 글꼴
둥근 산세리프: Nunito, Poppins, Baloo 2, Quicksand (OFL). 중국어는 Source Han Sans Bold 또는 ZCOOL KuaiLe. 라벨은 작고 적게 쓰며 화면이 설명하도록 한다. 글자는 보조 역할만 한다.

## 움직임
- 주 이징은 대칭형 ease-in-out (`bezier(0.75, 0, 0.25, 1)` 등). 카메라와 큰 사물에 적용.
- 사물은 곡선을 따라 움직인다. 등장할 때 0에서 튀어나옴 (스프링 `{2.6, 0.6}`), 퇴장할 때는 더 빠르게 작아짐.
- 캐릭터 동작은 pose-to-pose 방식: 주요 자세 사이를 빠르게 전환하고 멈춘다.
- 화면은 완전히 정지하지 않는다. 무언가가 항상 천천히 떠다니거나 회전하거나 깜박인다.

## 화면에 생동감 더하기
- 먼 곳의 작은 요소가 천천히 떠다님 (주기 3–6초), 빛나는 점은 부드럽게 호흡하고 캐릭터는 눈을 깜빡이거나 살짝 흔들림.
- 기계의 톱니와 관 속 공은 천천히 계속 회전하거나 흐름.
- 떠다니는 움직임의 폭은 주 동작보다 한 단계 작게 해 초점을 빼앗지 않게 한다.

## 카메라 문법
| 카메라 움직임 | 표현하는 것 | 적합한 콘텐츠 |
|---|---|---|
| 로그 스케일로 확대하며 규모 사이를 통과 | 거시에서 미시로 | 원리, 규모 |
| 후퇴하며 전체 모습 공개 | 더 큰 것의 일부였음을 드러냄 | 반전, 엔딩 |
| 캐릭터를 따라 수평 이동 | 여정 | 흐름, 이야기 |
| 사물을 잘라 내부로 들어감 | 내부 | 메커니즘 |
| 둥근 사물로 전진하고 그 안에서 다음 장면 등장 | 진입 | 전환 |

## 사운드 팔레트
부드러운 `mallet({ material: 'glock' })`, `pluck`, 패드. 사물이 나타날 때 `pop`, 이동할 때 가벼운 `whoosh`. 1단계로 충분하며 다큐멘터리 같은 공간감이 필요할 때 2단계에 피아노 샘플을 더한다.

리듬과 화성 (예시이며 한 가지로 한정하지 않음): 드럼 없이 패드와 선율로 진행하거나 가벼운 플럭에 4/4 작은 북을 넣어 활기찬 버전으로 만들 수 있다. 장조, Lydian (호기심과 놀라움), Dorian (약간의 우수). 개념이 하나 추가될 때마다 성부를 하나 더하는 누적 곡선이 잘 어울린다.

## 이 매체만의 표현
- 둥근 사물 하나 (세포, 버튼, 행성)를 확대하면 안에 다음 장면이 있음: 단계적으로 탐구할 때 적합.
- 사물 하나를 잘라 안에서 톱니가 돌아가는 모습을 공개: 원리 설명에 적합.
- 같은 형태가 다음 개념으로 바뀜 (원 → 동전 → 지구): 비유와 전환에 적합.
- 작은 캐릭터들이 모여 형태나 숫자가 됨: “사용자”, “군중”을 표현할 때 적합.
- 우주에서 지구로 확대: 고전적 기법이며 누구나 먼저 떠올리는 방식.

## 변주 여지
- 구조: 가장 작은 단위에서 가장 큰 단위까지 개념 설명, “만약 …라면?”이라는 사고 실험, 흐름 전체를 따라 걷는 캐릭터 하나, 비유 세 개를 연속해서 변형.
- 도입: 점 하나가 확대되어 세계가 됨, 캐릭터가 고개를 들어 문제를 발견.
- 끝맺음: 뒤로 빠져 모든 장면이 로고 안에 있음을 공개, 캐릭터가 마지막 조각을 끼움.

## 함정
- 색이 너무 많고 의미가 뒤섞임: 개념마다 색 하나를 정해 끝까지 유지한다.
- 검은 외곽선을 추가해 다른 스타일 (만화나 카툰)이 됨.
- 초점 없이 화면 전체가 계속 움직임: 같은 순간에는 주 동작 하나만 둔다.
- 선형 확대: 처음엔 느리다 마지막에 급격해져 마지막 프레임이 튐. 로그 보간을 사용한다.
- 유명 과학 채널의 색상과 캐릭터를 복제: 문법만 참고한다.
