# 페인터리 (painterly)

> 움직이는 그림 한 장: 모든 붓질에 방향, 두께, 안료 입자가 있고 캔버스 위 빛이 흐르며 그림 속 사물이 살짝 살아난다.
> 참고 (문법만 참고): 인상파 / 후기 인상파의 붓질 언어, 임파스토, 외광파의 빛과 색, 현대 디지털 페인팅의 브러시 애니메이션. 구체적인 그림 구성이나 명화의 화면을 복제하지 않는다.

## 본질 / 본질이 아닌 것
- 본질: **화면은 붓질을 하나씩 쌓아 그린다.** 형태는 붓 자국으로 이루어지고 방향은 사물 구조와 빛을 따른다. 색은 한 색을 평평하게 채우고 노이즈를 더하는 것이 아니라 영역 안에 여러 색을 병치한다. 화면은 살아 있지만 붓질은 불규칙하게 튀지 않는다.
- 본질이 아닌 것: 사진에 유화 필터를 씌운 것, 매 프레임 붓 자국을 새로 무작위 생성하는 것 (이는 생동감이 아니라 깜박임).

## 식별 신호: 영상마다 2–3개 선택
| 신호 | 어떤 모습인가 | 적합한 주제 |
|---|---|---|
| 방향장 붓질 | 하늘은 회전하듯, 땅은 원근 방향으로, 벽은 수직으로 구조를 따르는 붓질 | 풍경, 공간 |
| 짧은 색점 | 차갑고 따뜻한 짧은 붓질이 섞여 멀리서 색을 이룸 | 빛, 공기, 야외 |
| 임파스토 | 두께와 하이라이트가 있어 안료가 쌓인 듯함 | 질감, 강한 감정 |
| 영역별 색상 그룹 | 각 영역에 비슷한 색 5–8개가 섞임 | 모든 주제 |
| 보이는 캔버스 질감 | 붓질 사이에 캔버스 섬유가 드러남 | 수공예, 진정성 |
| 그려지는 과정 | 한 획씩 화면이 그려짐 | 오프닝, 창작 |
| 빛의 흐름 | 물 표면이나 나뭇잎의 빛 반점이 깜박임 | 시간, 감정 |
| 굵은 윤곽선 | 짙고 굵은 선으로 사물을 감싸며 선 자체도 붓질임 | 표현력, 강렬함 |
| 팔레트 나이프 자국 | 넓고 평평하게 밀어낸 자국 | 현대적, 거친 느낌 |
| 미완성 가장자리 | 화면 가장자리에서 밑그림과 캔버스를 일부 노출 | 과정, 솔직함 |

규칙:
- 영상마다 2–3개를 고르고 적어도 하나는 아래의 “가장 진부한 버전”에 없는 신호로 선택한다.
- 주제에 맞춰 신호를 고르며 순서대로 모두 쓰지 않는다.
- 특정 명화가 아니라 붓질 언어를 배운다. “인상파처럼 빛을 다룬다”는 가능하지만 명화의 구도는 복제하지 않는다.

## 이 스타일의 가장 진부한 버전
- 화면: 별이 소용돌이치는 하늘, 해바라기, 노랑과 파랑의 대비, 모든 것이 회전.
- 사운드: 클래식 피아노 또는 현악 사중주.
- brief의 style 항목에 뒤집은 규칙이나 고전 표현을 유지한 이유를 쓴다. 유지한다면 구도, 카메라, 리듬 또는 예상 밖의 기억점에 힘을 줍니다.

## 적합성
- 용도: 브랜드 무드 영상, 오프닝, 문화·예술 홍보, 명절·기념일, 포트폴리오 구간.
- 콘텐츠: 예술, 문화, 음식, 여행, 계절, 향수, 고급 수공예 브랜드.
- 부적합: 많은 정보를 명확하게 전달해야 하는 제품 설명, 텍스트가 많은 영상 (작은 글자와 붓질이 경쟁), 렌더 시간이 촉박한 프로젝트 (스타일이 느림).

## 기술 구현
Canvas 2D에서 두 단계로 처리합니다. 먼저 평면 색의 밑그림을 오프스크린에 그려 구도와 명암을 정한 뒤 브러시 렌더러로 전체를 다시 그립니다. 격자에 붓질을 배치하고 (위치는 고정 시드로 한 번만 계산) 각 획은 밑그림에서 색을 가져와 영역 색상 그룹에 따라 조정하고 방향장에 맞춘 각도로 짙은 가장자리가 있는 곡선형 짧은 획으로 그립니다. 작은 물건과 주체는 별도 레이어로 더 가는 붓질을 씁니다. 그렇지 않으면 큰 획에 묻힙니다. 정적 부분은 캐시하고 프레임마다 움직이는 영역만 다시 그립니다. 먼저 960×540에서 단일 프레임 시간을 측정합니다. 일반적으로 50–150ms가 걸립니다.

## 재질과 렌더링
- 방향장: 영역별로 설정합니다 (하늘은 구름 방향, 물은 수평, 벽은 수직, 땅은 원근 방향). 프레임마다 무작위로 바꾸지 말고 시간에 따라 연속적으로 흔듭니다.
- 영역 색상 그룹: 각 영역에 비슷한 색 5–8개를 정하고 획마다 그룹에서 색을 선택한 다음 밑그림 색을 30–40% 섞어 명암을 유지합니다. 색상만 흔들면 “같은 색 노이즈”가 됩니다.
- 붓질: 영역별로 길이와 너비를 조절 (먼 곳은 짧고 가늘게, 가까운 곳은 굵고 길게). 모든 획에 아주 가는 짙은 테두리를 두고 임파스토에는 하이라이트 테두리를 더합니다.
- 캔버스: 가장 아래에 천 질감을 두고 붓질 사이에서 가끔 드러냅니다.
- 주체: 별도 레이어와 매개변수를 사용하고 마지막에 선명한 윤곽이나 하이라이트로 배경에서 분리합니다.

## 색상
예시 색은 방향만 참고하고 그대로 복사하지 않습니다.
- 외광: 하늘색 #6FA8DC / 풀색 #93C47D / 따뜻한 노랑 #F6D365 / 보라색 그림자 #8E7CC3 / 캔버스 #EFE6D2
- 따뜻한 실내: 황토 #B5651D / 짙은 빨강 #7B2D26 / 금빛 노랑 #E1B44C / 올리브 #6B6B3A / 어두운 갈색 #2B1D14
- 차가운 밤: 짙은 파랑 #1B2A49 / 군청 #3A5BA0 / 달빛 노랑 #F2E2A0 / 먹빛 초록 #1F3B2D
- 색상 도출: 먼저 빛 조건 (외광, 실내, 밤)을 정한 뒤 영역별 색 그룹을 정합니다. 빛을 받는 면은 따뜻하게, 그림자는 보색을 약간 섞어 차갑게 처리합니다. 그림자에 검은색을 쓰지 않습니다. 노랑과 파랑의 강한 대비가 가장 흔한 조합입니다.

## 글꼴
붓질 화면에는 글자를 적게 둡니다. 제목은 손글씨 느낌이나 고전적인 세리프 (Cormorant Garamond, EB Garamond, Playfair Display)를 쓰거나 실제 붓으로 그립니다. 중국어에는 Source Han Serif, LXGW WenKai를 사용할 수 있습니다. 화면의 차분한 부분이나 평평한 색면에 글자를 배치합니다.

## 움직임
- 붓 자국 위치는 고정하고 방향장의 연속적인 흔들림, 빛의 움직임, 주체 일부 동작으로 움직임을 만듭니다.
- 오프닝은 화면을 “그리는” 방식으로 만들 수 있습니다: 영역 순서에 따라 붓질을 0.5–1.5초 동안 하나씩 드러냄.
- 카메라는 천천히 전진하거나 옆으로 이동하고 붓질 크기는 화면 픽셀 기준으로 유지합니다 (확대할 때 다시 그리며 붓질 자체를 두껍게 키우지 않음).
- 주체 동작은 붓질의 수작업 느낌과 맞춰 12fps 스텝으로 처리할 수 있습니다.

## 화면에 생동감 더하기
- 방향장이 시간에 따라 천천히 흔들려 붓질이 바람에 흔들리는 풀처럼 보임. 물과 나뭇잎의 빛 반점도 반짝임.
- 주체의 작은 동작 한두 개 (굴뚝 연기, 날아가는 새, 바람에 부푸는 커튼).
- 방향장과 빛만 연속적으로 바꾸고 화면 전체를 새 시드로 다시 그리지 않습니다. 깜박임으로 보입니다.

## 카메라 문법
| 카메라 움직임 | 표현하는 것 | 적합한 콘텐츠 |
|---|---|---|
| 붓질 하나로 아주 천천히 전진 | 그림 속으로 들어감 | 기억점, 디테일 |
| 프레임 밖에서 그림 안으로 이동 | 그림이 살아남 | 오프닝 |
| 긴 그림을 지나 미술관처럼 수평 이동 | 시간, 여정 | 이야기 |
| 고정 시점, 빛만 변화 | 하루, 계절 | 감정 |

## 사운드 팔레트
어쿠스틱한 질감: 2단계의 피아노 샘플, pluck으로 현악기 모방, 부드러운 pad를 현악 패드처럼 사용. 바람, 새, 물 같은 환경음도 잘 어울립니다. 리버브는 중간보다 조금 크게.

리듬과 화성 (예시이며 한 가지로 한정하지 않음): 3/4 왈츠 느낌, 느린 아르페지오, 드럼 없음; 인상파 화성 (maj7, 9화음, 온음 음계, 병행 화음). 반대로 붓질 화면에 현대 전자 음악을 붙여 대비를 만들 수도 있습니다.

## 이 매체만의 표현
- 화면이 획마다 그려짐: 오프닝, 창작 주제에 적합.
- 한 영역의 붓질이 회전해 다음 장면으로 재구성: 전환에 적합.
- 프레임 밖은 현실 (또는 다른 스타일), 카메라가 프레임 안으로 들어감: “작품 속으로” 진입하는 장면에 적합.
- 빛이 한쪽에서 훑어 화면이 차가운 색에서 따뜻한 색으로 이동: 시간 흐름에 적합.
- 소용돌이 별하늘과 해바라기: 고전적인 방식이며 누구나 먼저 떠올리는 구성.

## 변주 여지
- 구조: 같은 풍경을 새벽에서 밤까지 그려감, 빈 캔버스를 채움, 사물 하나를 사계절별로 그림, 화가의 시점에서 제품을 획마다 그림.
- 도입: 빈 캔버스에 첫 획이 내려옴, 밑그림만 있는 프레임에 색을 겹겹이 올림.
- 끝맺음: 카메라가 후퇴하며 그림이 벽에 걸려 있고 옆 라벨이 로고임을 드러냄; 물감이 마르고 화면이 멈춤.

## 함정
- 매 프레임 붓질을 무작위로 새로 생성: 화면 전체가 깜박임. 붓질 위치는 고정하고 방향장만 연속적으로 변화.
- 영역 색상 그룹 없이 색만 흔듦: 화면이 같은 색 노이즈가 됨.
- 큰 붓질에 작은 물건과 주체가 묻힘: 별도 레이어와 매개변수 사용.
- 렌더링이 너무 느림: 정적 부분 캐시, 단일 프레임 시간 측정, 렌더 전에 예상 시간 알림.
- 복잡한 붓질 위에 글자를 놓아 읽기 어려움: 평면 영역에 놓거나 글자 뒤에 차분한 바탕을 둠.
- 명화의 구도를 복제: 붓질과 빛의 언어만 참고.
