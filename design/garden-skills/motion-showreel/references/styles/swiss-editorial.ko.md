# 스위스 에디터 (swiss-editor)

> 국제주의적인 타이포그래피 스타일은 모듈식 그리드, 서체, 신호 색상, 인쇄기만큼 정확한 움직임 등을 움직입니다.
> 참조(문법만): 1950년대~1970년대 취리히 포스터의 격자 및 크기 비교(Müller-Brockmann, Hofmann, Gerstner, Crouwel); 현대 동적 인식 시스템(Experimental Jetset, Pentagram)의 비트에 갇힌 인쇄상의 점프. 특정 포스터의 구성을 복사하거나 Helvetica/Akzidenz 글꼴 파일을 사용하지 마세요.

## 본질 / 그것이 아닌 것
- 본질: 종이 위의 2차원 그래픽 디자인이 그리드 위에서 움직입니다. **모든 요소가 그리드에 맞춰져 있고 모든 움직임이 비트에 맞춰 움직이며 아무것도 튕겨나오지 않습니다**; 전체 그림은 시스템에 복종하며, 복종하지 않는 유일한 요소는 주인공입니다.
- 그렇지 않습니다: 기자 회견 기조 연설(그라디언트, 글로우, 장비 렌더링 없음) 가사 비디오(단어가 날거나 회전하거나 재생되지 않음); 바우하우스의 삼원색 콜라주.

## 신호 식별: 각 영화에 대해 2~3개 선택
| 신호 | 그것은 어떻게 생겼는가 | 적합한 주제 |
|---|---|---|
| 보이는 모듈 그리드 | 얇은 선 그리드, 열 번호, 기준선 자체가 그림에 나타납니다 | 시스템, 방법론, 도구 |
| 엄청난 숫자 | 하나의 숫자는 화면의 절반을 차지하고 시각적으로 왼쪽에 정렬됩니다. | 데이터, 연도, 가격 |
| 유일한 신호 색상 블록 | 전체 그림에 색상이 있는 요소는 하나만 있습니다 | 주인공, 작품, 결론 |
| 극단적인 크기 대비 | 거대한 텍스트 12~16px 옆의 기술 노트 | 제목, 브랜딩 |
| 왼쪽 정렬된 텍스트 열 | 사용 설명서와 같은 오른쪽의 작은 텍스트 설명 | 설명, 사양 |
| 기본 기하학적 모양 | 원, 사각형, 바가 그리드에 배열되어 점프 | 추상, 브랜드 아이덴티티 |
| 시간표/표 | 행과 열은 행 단위로 채워지며 숫자는 너비가 같습니다 | 프로세스, 시간, 목록 |
| 세로로 배열되거나 90° 회전된 단어 | 제목이나 메모의 읽기 방향 변경 | 회전 및 리듬 변화 |
| 반대 페이지 구조 | 왼쪽 페이지의 규칙, 오른쪽 페이지의 작동 | 포트폴리오, 사례 |
| 전체 색상 블록 지우기 | 전체 색상 블록을 스윕하고 레이아웃 변경 | 챕터 전환 |

규칙:
- 각각 2~3개를 선택하세요. 그 중 적어도 하나는 아래의 "가장 뻔한 버전"이 아닙니다.
- 순서대로가 아닌 테마별로 신호를 선택하세요.
- 그리드는 뼈대에만 있을 수 있습니다. 요소는 그리드에 연결되며 그리드 선 자체는 그릴 필요가 없습니다.## 이 스타일의 가장 저속한 버전
- 이미지: 흰색 배경에 검정색 텍스트가 있는 크고 새로운 그로테스크한 글꼴 + 빨간색 정사각형 또는 원 + 전체적으로 보이는 격자선 + 기준선에서 드러난 단어 + 끝에 중앙에 있는 로고.
- 사운드: 클릭과 틱만으로 미니멀한 일렉트로닉 비트를 즐길 수 있습니다.
- 간략한 스타일 열에는 영화에서 어떤 항목이 제거되었는지 또는 해당 항목이 의도적으로 유지된 이유(예: 사용자가 클래식 버전을 원함)가 나와 있습니다. 기억할 때는 구성, 샷, 리듬 또는 예상치 못한 기억 지점에 집중하세요.

## 적응
- 목적: 포트폴리오, 로고 해석, 데이터 폭발 지점, 레이아웃 정체 지점. 홍보 영상도 허용되지만 스크린샷이 필요한 경우 스크린샷을 그리드의 일부로 취급해야 합니다.
- 내용: 합리적이고 전문적이며 디자인을 고려한 테마 기관, 도구 및 방법론.

## 기술 경로
캔버스 2D(또는 DOM 레이아웃) + 2D 카메라 매트릭스. WebGL 텍스처 레이어도 없고 파티클도 없습니다(`--grain 0`). 무브먼트는 하드컷팅과 슬라이딩이 대부분인데 `--subframes 2`면 충분합니다.

## 재료 및 렌더링
-화면 그리드: 12개 열의 1920 너비, 왼쪽 및 오른쪽 여백 약 96px, 열 간격 24px, 기준선 24px. 그림은 마주보는 페이지로 취급될 수 있습니다. 왼쪽 페이지에는 규칙(번호, 지침, 메모)이 포함되어 있고 오른쪽 페이지에는 작업이 포함되어 있습니다.
- 그리드의 의미는 내용(Gerstner의 "디자인 프로세스")에 따라 결정됩니다. 열과 행이 나타내는 것은 디자인 결정입니다. 모듈은 요소에 가중치를 부여할 만큼 충분히 커야 하며 열은 너무 가늘고 차트처럼 보여야 합니다.
- 플랫 컬러 블록 및 스트립: 동일한 유형의 인접한 단위가 하나의 스트립으로 병합되고 앤티앨리어싱 및 미세한 이음새 노출을 방지하기 위해 이음새에 추가로 1px가 그려집니다.
- 2차 보이스의 검정색 요소 아래에 밝은 회색 요소를 사용하여 2차 색상이 필요 없이 레이어링을 추가할 수 있습니다.

## 컬러 매칭
아래 색상 값은 예시이므로, 아이디어를 보시고 정확하게 복사하지 마세요.
- 종이 `#EAE9E5` / 흰색 `#FFFFFF` / 잉크 `#111111` / 시그널 레드 `#E30613`
- 종이 `#F2F0EA` / 잉크 `#141414` / 시그널 오렌지 `#FF5A00`
- 종이 `#E9ECEF` / 잉크 `#0B0B0B` / 시그널 울트라마린 `#1F3FFF`
- 규칙: **단 하나의 신호 색상이 있습니다**, 이는 부정확성을 허용하는 유일한 요소이자 주인공입니다. 신호 색상에 잉크가 중복 인쇄될 수 있습니다.
- 파생: 종이 색상(웜 화이트, 쿨 화이트, 라이트 그레이 또는 매우 밝은 브랜드 색상) + 잉크 + 신호 색상. 신호 색상은 브랜드나 테마에서 비롯됩니다. 빨간색이 가장 일반적인 색상이므로 먼저 다른 것을 생각해 보세요.## 글꼴
- 영화 전반에 걸쳐 다양한 가중치를 사용하는 OFL 네오그로테스크 계열: Archivo, Schibsted Grotesk, Instrument Sans, Inter Tight. 글꼴 크기가 90px 이상인 경우 간격은 약 -2%입니다.
- 왼쪽 정렬, 오른쪽 정렬, 모든 것이 그리드 선에 놓입니다. 큰 숫자는 시각적으로 왼쪽 정렬됩니다(글리프의 왼쪽 여백 제외).
- 기술 노트와 같은 설명에는 동일한 계열의 작은 글꼴 또는 고정 너비 글꼴을 사용하십시오.

## 스포츠
- 완화: `snap`(하드 스타트, 롱 코스팅) 및 `whip`; 스프링은 댐핑이 0.9 이상인 기어만 사용합니다.
- 요소가 그리드에 따라 점프하고 재촬영 시 전환이 멈춥니다. 마스크 와이프(기준선에서 드러나기)가 페이드 인보다 낫습니다.
- 리듬: 고요함과 정확한 점프를 번갈아 가며 고요함 그 자체가 디자인입니다.

## 사진을 사는 방법
- 주로 정적: 레이아웃이 확정된 후 전체 블록이 움직이지 않고 생명력이 뛰어납니다. (이것이 이 스타일의 문법이며, 정착 문단은 `HOLDS`로 작성되었습니다.)
- 모서리에만 배치할 수 있습니다. 신호 색상의 얇은 선이 그리드를 따라 천천히 확장됩니다. 페이지 번호와 좌표 주석은 매 비트마다 숫자씩 점프합니다. 밟으면 마스크 가장자리에 있는 작은 사각형이 깜박입니다. 진폭이 작고 주요 단어를 파악하지 못합니다.

## 렌즈 구문
| 카메라 움직임 | 무엇을 표현할 것인가 | 어떤 유형의 콘텐츠가 적합한가요 |
|---|---|---|
| 카메라 위치 고정, 포맷 자체 변경 | 시스템이 실행 중입니다 | 규칙, 단계, 비교 |
| 그리드 정렬 패닝 | 다음 페이지로 이동 | 장 전환, 목록 |
| 축소하여 공개 | 세부 사항으로 밝혀졌습니다 | 큰 숫자는 실제로 작은 레이아웃의 일부입니다 |
| 90° 회전 | 읽는 방향 변경 | 회전, 역방향 |

## 사운드 팔레트
깨끗한 전자 드럼, 정확한 틱 그리드, 짧은 뽑기, 클릭; 작은 잔향(≤ 0.15). 레벨 1 합성이면 충분합니다. 모든 전환이 들리도록 많은 침묵을 남길 수 있습니다.

그루브 및 하모니(예를 들어 더 있음): 직선 비트 또는 5/4, 7/8의 정확한 비대칭; 코드 그리드, 겹치는 4도, 무조 음조; `rim`, `tick`, `mallet({ material: 'wood' })`가 정확한 타격을 가합니다. 리버브는 거의 사용되지 않습니다.

## 네이티브 메소드
- 그리드는 한 지점에서 커집니다. "처음부터 시작" 및 "시스템" 테마에 적합합니다.
- 큰 숫자는 실제로 데이터, 연도, 가격에 적합한 작은 형식의 일부입니다.
- 색상 블록 삭제 및 버전 변경: 목록, 비교 및 ​​장에 적합합니다.
- 예외 요소가 화면을 떠나고 시스템이 붕괴됩니다. 엔딩과 클로징에 적합합니다.## 공간 변경
- 구조: 시간표(행별로 채워진 24행 그리드) 알파벳(A부터 Z까지, 각 문자에 대해 하나의 모듈) 요소가 기둥 간격을 지날 때까지 왼쪽 및 오른쪽 시스템을 비교합니다.
- 열기: 점이 페이지에 배치되고 그 점에서 그리드가 늘어납니다. 완성된 작업이 먼저 주어진 다음 규칙으로 분류됩니다. 엄청난 숫자가 화면을 가득 채웁니다.
- 끝: 모든 요소가 잘린 후 빈 그리드입니다. 모서리에 왼쪽 정렬된 단어; 예외 요소가 남습니다.

## 구덩이
- 열이 너무 가늘면 이미지가 차트처럼 보입니다. 요소가 그리드에 연결되어 있지 않으면 무작위로 보입니다.
- 두 번째 강조 색상을 추가하면 시스템이 무너집니다.
- 리바운드 스프링을 사용하거나 여기저기 페이드인을 하면 일반 PPT 애니메이션이 됩니다.
