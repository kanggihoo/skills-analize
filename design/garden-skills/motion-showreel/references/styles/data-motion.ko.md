# 데이터 역학(데이터-모션)

> 숫자와 차트 자체가 주인공입니다. 열이 늘어나고, 선이 그려지고, 숫자가 굴러가며 고정되며, 모든 변화는 사실에 해당합니다.
> 참조(구문만): 데이터 저널리즘을 위한 동적 그래픽(The Pudding, NYT, Bloomberg의 시각화), Tufte의 데이터 잉크 비율, Hans Rosling 스타일 동적 차트. 특정 다이어그램은 복사되지 않습니다.

## 본질 / 그것이 아닌 것
- 본질: **각각의 시각적 변화는 데이터 조각을 인코딩합니다**(길이, 면적, 위치, 색상). 정보를 전달하지 않는 모든 장식을 제거합니다. 차트는 움직이면서 말합니다.
- 아닙니다: 장식적인 "기술적" 가짜 차트입니다. 3D 원형 차트도 아닙니다.

## 신호 식별: 각 영화에 대해 2~3개 선택
| 신호 | 그것은 어떻게 생겼는가 | 적합한 주제 |
|---|---|---|
| 성장하는 기둥 | 0부터 시작하여 동시에 계산 | 비교·순위 |
| 그려진 폴리라인 | 시간이 지남에 따라 선이 그려지고 레이블은 선 끝 | 추세, 시간 |
| 롤링 횟수 | 숫자를 최종 값으로 굴린 다음, 결정되면 가볍게 두드립니다 | 단일 점수 |
| 하나를 강조 표시하면 나머지는 회색으로 변합니다 | 하나의 데이터는 색상으로 남아 있고 다른 데이터는 회색으로 변합니다 | 우리 대 다른 사람 |
| 규모 변화 | 축소하여 규모를 변경하면 큰 기둥이 작은 점으로 변합니다 | 기하급수적인 성장, 규모 |
| 단위 다이어그램 | 점이나 작은 아이콘은 전체로 쌓인 단위를 나타냅니다 | 인원수, 양감 |
| 면적과 비율 | 원과 사각형의 면적은 비율을 나타냅니다 | 공유, 구성 |
| 지도 | 지도의 포인트, 핫스팟 및 선 | 지역 분포 |
| 순위 경주 | 시간이 지남에 따라 바 위치가 바뀐다 | 역사적 변화 |
| 주석 | 포인트를 포인트로 연결하고 결론을 작성하세요 | 변곡점, 핵심 이벤트 |

규칙:
- 각각 2~3개를 선택하세요. 그 중 적어도 하나는 아래의 "가장 뻔한 버전"이 아닙니다.
- 순서대로가 아닌 테마별로 신호를 선택하세요.
- 차트 유형은 시계열을 위한 선, 비교를 위한 열, 구성을 위한 영역 또는 단위 차트 등 데이터에 따라 결정됩니다. 신호의 선택은 데이터가 허용하는 범위 내에서 어떻게 말하는가이다.

## 이 스타일의 가장 저속한 버전
- 그림: 어두운 배경, 빛나는 막대 그래프 경주, 모서리의 스크롤 카운터, 끝에 반전 색상의 큰 숫자.
- 소리: 점점 촘촘해지는 틱과 숫자가 안정될 때의 충격.
- 간략한 스타일 열에는 영화에서 어떤 항목이 제거되었는지 또는 해당 항목이 의도적으로 유지된 이유(예: 사용자가 클래식 버전을 원함)가 나와 있습니다. 기억할 때는 구성, 샷, 리듬 또는 예상치 못한 기억 지점에 집중하세요.## 적응
- 용도: 데이터 폭발 지점, 제품 홍보 시 성과 표시, 연간 검토.
- 내용 : 성장, 비교, 순위, 분포, 시간 변화. **데이터는 사용자 또는 신뢰할 수 있는 소스에서 제공되어야 합니다**.

## 기술 경로
캔버스 2D 또는 SVG, 나만의 스케일 작성(`scale = v => lerp(r0, r1, (v - d0) / (d1 - d0))`) 곡선은 SVG 경로 + `stroke-dashoffset`를 사용하여 그려지거나 캔버스를 사용하여 현재 진행 상황을 점 단위로 그립니다. 숫자에는 고정폭 글꼴을 사용하세요.

## 재료 및 렌더링
- 중복된 그리드 선과 테두리를 제거합니다. 좌표축에 필요한 스케일만 유지하면 색상이 매우 밝아집니다.
- 열과 영역의 길이는 0부터 시작합니다. 선에는 시작점과 끝점 레이블이 있습니다.
- 하나의 데이터를 강조 표시하고 나머지는 회색으로 표시합니다(이것이 가장 강력한 방법입니다).
- 라벨은 범례 없이 데이터 바로 옆에 배치됩니다.

## 컬러 매칭
아래 색상 값은 예시이므로, 아이디어를 보시고 정확하게 복사하지 마세요.
- 하단 `#FAFAF7` / 잉크 `#1A1A1A` / 그레이 `#BDBAB3` / 액센트 `#E4572E`
- 하의 `#0E0F12` / 화이트 `#EDEDED` / 그레이 `#4A4D55` / 액센트 `#4FD1C5`
- 규칙: 색상은 의미론적 의미(강조/기타, 증가/감소)만 가지며 장식은 없습니다. 최대 2개의 의미 색상.
- 파생: 밝거나 어두운 배경이 허용됩니다. 색상에는 브랜드 또는 데이터 의미에서 파생된 최대 2개의 의미 색상(강조 및 기타, 성장 및 쇠퇴)만 포함됩니다. 주황색-빨간색과 회색이 가장 일반적인 조합입니다.

## 글꼴
숫자에는 일정한 너비의 글꼴 또는 일정한 너비의 숫자 글꼴(JetBrains Mono, IBM Plex Sans, Inter Tight's tnum)을 사용하십시오. 제목에는 편집용 산세리프체나 세리프체를 사용하세요.

## 스포츠
- 기둥 및 영역: `glide` 또는 스프링 `{2.4, 0.85}`, 피크 오프셋 40–80 ms.
- 선: 시간이 지남에 따라 일정한 속도로 그리며(시간 축은 선형이며 여기서는 균일한 속도가 정확함) 현재 점이 그려지면 레이블이 실행됩니다.
- 디지털 스크롤: `outExpo` 1.5~2.5초, 안정되면 가볍게 탭합니다.
- 정렬 변경: 요소의 위치가 원활하게 바뀌고(스프링) 순간이동하지 않습니다.

## 사진을 사는 방법
- 주로 정적: 이 스타일에서는 데이터가 모션으로 인코딩됩니다. 정착 후에도 데이터가 흔들리는 경우에는 변화하는 값으로 읽혀집니다.
- 살아 있을 수 있는 유일한 것은 "현재"입니다. 라인 끝의 숨쉬는 점, 최신 데이터 포인트의 약간의 펄스, 라인 끝을 따르는 레이블입니다.## 렌즈 구문
| 카메라 움직임 | 무엇을 표현할 것인가 | 어떤 유형의 콘텐츠가 적합한가요 |
|---|---|---|
| 고정된 카메라 위치 | 데이터가 스스로 말하게 하세요 | 대부분의 차트 |
| 데이터 포인트 확대 | 집중 | 주요 수치, 전환점 |
| 축척을 변경하려면 축소 | 규모의 충격 | 기하급수적 성장, "이렇게 큰 것으로 밝혀졌다" |
| 시간 축을 따라 패닝 | 시간 발전 | 긴 시계열 |

## 사운드 팔레트
틱(각 데이터를 클릭하면 밀도가 점점 더 높아짐), 숫자가 안정되면 `impact` 또는 `bell`, 그리고 부드럽게 포장됩니다. 첫 번째 합성 수준이면 충분합니다.

리듬과 하모니(예를 들어 이것보다 더 많은 것이 있습니다): 직선 비트 또는 데이터 자체가 리듬을 생성하도록 합니다(값 변화의 밀도는 틱의 밀도입니다). 값이 올라가면 스케일이 올라가고, 내려가면 내려갑니다. 누적 곡선(각 데이터 세트에 대해 하나의 부분)이 적합합니다.

## 네이티브 메소드
- 하나를 강조 표시하고 나머지는 회색으로 표시: "우리 대 다른 사람"에 적합합니다.
- 축소하여 규모를 변경하면 원래의 큰 기둥이 작은 점으로 변합니다. 지수적 성장 및 규모 비교에 적합합니다.
- 숫자가 최종 값으로 스크롤되고 화면이 반전됩니다. 단일 결과에 적합합니다.

## 공간 변경
- 구조: 하나의 숫자가 이야기를 말해줍니다. 비교 전과 후; 순위경쟁.
- 열기: 거대한 물음표 또는 0; 축은 한 점에서 확장됩니다.
- 엔딩: 가장 중요한 숫자가 고정되어 있으며 아래에 소스 텍스트 줄이 있습니다.

## 구덩이
- **가짜 데이터**: 불확실한 숫자를 표시하여 사용자가 확인할 수 있도록 합니다. 소스는 화면에 써있습니다.
- 열이 0에서 시작하지 않고 축이 잘려서 보는 사람에게 오해를 불러일으킬 수 있습니다. 잘림이 필요한 경우 화면에 "세로축은 0부터 시작하지 않습니다."라고 표시됩니다.
- 숫자가 너무 짧아 읽을 수 없음: 주요 숫자가 최소 2.5초 동안 유지됩니다.
- 배수가 잘못 기재되어 있습니다. "9배 증가했습니다"는 원래 금액의 10배이고, "9배 증가했습니다"는 9배입니다. 화면에 나오는 결론은 사진의 숫자로 계산할 수 있어야 하며, 영화 리뷰 중에 실제로 계산을 해야 합니다.
- 도식 데이터에 대한 라벨이 없습니다. 사용자가 실제 데이터를 제공하지 않고 효과만 시연하는 경우 차트가 나타나는 모든 샷에 "도식 데이터"가 표시됩니다. 실제 데이터에는 이 자막이 없습니다.
- 동일한 그룹의 숫자가 일치하지 않는 경우: 썸네일의 최종 값이 확장 후 최종 값과 일치하지 않거나 확대 또는 확장 후 카운트가 0부터 다시 시작됩니다.
- 단위, 통화, 시간 범위가 누락되었거나 사용자가 제공한 것과 일치하지 않습니다.
- 데이터를 먼저 출력하고 좌표축을 출력하는 방식: 좌표계가 먼저 나오고 데이터가 늘어나서 마지막으로 한 가지만 마킹하는 순서로 해야 합니다.
