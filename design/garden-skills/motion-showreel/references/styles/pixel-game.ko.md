# 16비트 픽셀 게임(픽셀-게임)

> 모든 것이 정수배로 확대된 작은 논리적 캔버스에 그려집니다. 캐릭터의 자세가 하나씩 바뀌고, 특수 효과가 매 프레임마다 움직이며 마치 절묘한 16비트 게임 애니메이션처럼 보입니다.
> 참고 자료(문법만 익히기): SNES/MD 시대의 캐릭터 애니메이션과 컷씬, 현대 픽셀 게임의 빛과 그림자. 어떤 게임의 캐릭터, 레벨, UI도 복사하지 마세요.

## 본질 / 그것이 아닌 것
- 필수 사항: **낮은 논리적 해상도**(128×96, 160×90, 320×180) + **고정 팔레트** + **포즈 스테핑**(초당 8~12프레임) + 프레임별 특수 효과; 모든 픽셀이 선명합니다.
- 아님: 축소된 후 확대된 흐릿한 벡터 이미지입니다. 사진에 추가된 픽셀화된 필터도 아닙니다.

## 신호 식별: 각 영화에 대해 2~3개 선택
| 신호 | 그것은 어떻게 생겼는가 | 적합한 주제 |
|---|---|---|
| 캐릭터 액션 | 대기, 실행, 충전, 해제, 초당 8~12가지 포즈 | 능력, 행동 |
| 횡스크롤 수준 | 플랫폼, 벽돌, 시차 배경이 뒤로 스크롤 | 여행, 도전 |
| 하향식 RPG | 그리드 맵과 대화 상자가 그대로 나타납니다. | 서사, 탐색 |
| HUD | 체력 바, 점수, 심장, 타이머 | 데이터, 진행상황 |
| 전투 특수 효과 | 플래시, 폭발 지점, 피해 수치 팝업 | 충격, 대비 |
| 인벤토리 및 업그레이드 | 소품 그리드, 레벨업 깜박임 | 기능, 성장 |
| 타이틀 화면 | 시작을 누르세요, 메뉴 커서, 슬롯 저장 | 오프닝, 엔딩 |
| 세계지도 | 검문소를 연결하는 경로 | 노선도, 단계 |
| 픽셀 글꼴 인터페이스 | 대화 상자, 버튼, 픽셀 단어 | 카피라이팅, 지침 |
| 4색 휴대용 | 회색-녹색 레벨이 4개만 있는 1비트/2비트 그래픽 | 향수를 불러일으키는 미니멀리스트 |
| 아이소메트릭 픽셀 | 작은 방이나 마을의 등각 투영 뷰 | 공간, 장면 |

규칙:
- 각각 2~3개를 선택하세요. 그 중 적어도 하나는 아래의 "가장 뻔한 버전"이 아닙니다.
- 순서대로가 아닌 테마별로 신호를 선택하세요.
- 낮은 해상도, 고정된 색상 팔레트 및 자세 스테핑은 이 스타일의 제약입니다. 당신이 그것을 선택했다면 당신은 그것을 고수해야 합니다. 신호는 무엇을 그릴지, 어떤 유형의 게임인지 선택하는 것입니다.## 이 스타일의 가장 저속한 버전
- 화면 : 보랏빛 푸른 밤하늘, 작은 남자가 화면 속으로 뛰어들고, 벽돌 꼭대기에서 금화가 뽑히며, 엔딩은 "GAME OVER" 또는 "PRESS START"입니다.
- 소리: 구형파 칩 멜로디, 점프 소리, 금화 딩 소리.
- 간략한 스타일 열에는 영화에서 어떤 항목이 제거되었는지 또는 해당 항목이 의도적으로 유지된 이유(예: 사용자가 클래식 버전을 원함)가 나와 있습니다. 기억할 때는 구성, 샷, 리듬 또는 예상치 못한 기억 지점에 집중하세요.

## 적응
- 용도: 포트폴리오, 반복 애니메이션, 로고 해석, 게임화된 제품 홍보.
- 내용: 게임, 향수, 개발자 문화, 사랑스러운 캐릭터, 마법/모험 비유.

## 기술 경로
오프스크린 캔버스(논리적 해상도)에 각 프레임을 그린 다음 `drawImage`를 사용하여 최대 정수 배수 `imageSmoothingEnabled = false`, CSS `image-rendering: pixelated`에 따라 디스플레이 캔버스를 확대합니다. 모든 좌표는 `Math.round`입니다. CRT 모양이 필요할 때 `crt-vhs.md` 셰이더를 오버레이하세요. `--grain` 없음, `--dpr` 없음.

## 재료 및 렌더링
- 캐릭터는 채워진 직사각형과 픽셀 문자열(예: 24×32 픽셀 캐릭터)로 절차적으로 조립되고, 자세는 매개변수(팔 각도, 몸 흔들림, 소품 각도)로 만들어지며 매개변수는 각 프레임의 그리드로 양자화됩니다.
- 그라데이션 없음, `shadowBlur`, 반투명; 그림자와 하이라이트는 팔레트의 색상 블록입니다.
- 림 라이트: 주 광원은 캐릭터에 1픽셀의 밝은 가장자리를 그립니다.
- 입자: 일련번호에 따라 미리 생성된 픽셀(결정론적), 탄생과 사망을 시간별로 계산합니다.

## 컬러 매칭
아래 색상 값은 예시이므로, 아이디어를 보시고 정확하게 복사하지 마세요.
- 16~32가지 색상 고정: 밤하늘 `#0D0B1E` `#1E1A3A` `#2E2860`, 따뜻한 캐릭터 `#C9563C` `#E8A54B` `#F4D58D`, 매직 컬러 `#4FD8FF` `#B77CFF` `#FFF1A8`, 지상 `#3B3A4A` `#5B5A6B`.
- 규칙: 그림의 모든 픽셀은 이 색상 세트에서 나옵니다. "그라디언트"가 필요할 때 디더링을 사용하십시오.
- 파생: 먼저 야경, 숲, 사막, 휴대용 기기의 4가지 색상, 브랜드 색상에서 파생된 색상 레벨 등 테마를 기반으로 16~32개의 색상 팔레트 세트를 결정합니다. 그림의 각 픽셀은 이 색상 세트에서만 나옵니다. 보라색-파란색 밤하늘과 따뜻한 색감의 캐릭터가 가장 흔한 그룹입니다.## 글꼴
픽셀 글꼴(Press Start 2P, Silkscreen, Pixelify Sans, OFL); 중국어는 비트맵 스타일 글꼴을 사용하거나 논리 캔버스에서 ≥ 18px 단어를 사용하고 이를 알파 임계값에 따라 하드 에지 픽셀로 변환합니다.

## 스포츠
- `stepped(t, 10)`는 캐릭터 포즈를 양자화하고 매개변수는 키 프레임 간 이징 전환을 사용하지만 값은 단계 프레임에 따라 샘플링됩니다.
- 특수 효과(스파크, 미사일, 섬광)가 프레임마다 움직입니다.
- 상태 머신을 사용하여 구성: 대기 → 충전 → 해제 → 철회 → 주기.
- **카메라와 조명은 매 프레임마다 부드럽게 유지됩니다**. 그렇지 않으면 프레임이 떨어지는 것처럼 보입니다.

## 사진을 사는 방법
- 캐릭터 대기 애니메이션(2프레임의 호흡, 깜박임) HUD 하트 모양 또는 점수 플래시; 4~8fps 단계로 배경 주기의 물, 횃불, 구름; 물음표 블록이 가끔씩 나타납니다.
- 작은 루프 단계로 영상이 프레임별로 부드럽게 유지됩니다.

## 렌즈 구문
| 카메라 움직임 | 무엇을 표현할 것인가 | 어떤 유형의 콘텐츠가 적합한가요 |
|---|---|---|
| 전체 픽셀 가로 스크롤 | 사전, 여행 | 레벨 기반 내러티브 |
| 충격 시 화면 흔들기 1~2 논리 픽셀 | 힘 | 릴리스, 히트 |
| 클로즈업으로 전환(더 작은 논리 영역으로 변경) | 강조 | 주요 소품, 표현 |
| 흑점 원형수축(홍채) | 종료, 전환 | 단락 전환 |

## 사운드 팔레트
칩튠: 사각파 멜로디(`lead({ wave: 'square' })`), 사각파 또는 삼각파 베이스, 노이즈 드럼(짧은 `hat`, `snare`), `blip`, `glitch`, 슬라이드업 `pop`. BPM 130~160. 레벨 1 합성이 가장 적합합니다.

그루브 및 하모니(예 등): 스트레이트 130-160, 셔플(RPG Village) 또는 6/8; 메이저, 믹솔리디안(어드벤처), 하모닉 마이너(보스전), ♭VI – ♭VII – I(패스). 칩센스는 버스 `crush: 4–6`, `crushRate: 11000–22000`, 드라이 사운드를 사용합니다.

## 네이티브 메소드
- 하전 입자가 함께 나선 → 플래시 방출: "능력"과 "버스트"에 적합합니다.
- 픽셀 블록이 다음 샷으로 디졸브되어 전환에 적합합니다.
- 시대당 하나의 해상도(64픽셀~320픽셀): 진화, 역사적 주제에 적합합니다.

## 공간 변경
- 구조: 캐릭터의 주문 시전; 미시적 수준; 아이템의 업그레이드 경로.
- 열기: 검은색 화면에 픽셀이 켜집니다. 화면 밖에서 캐릭터가 뛰어옵니다.
- 종료: 대기 모드로 원활하게 루프백됩니다. 점수판/보관 화면에 로고가 나타납니다.## 구덩이
- 하위 픽셀 위치로 인해 가장자리가 흐릿해집니다. 모든 그리기 좌표가 둥글게 표시됩니다.
- 중국어 획이 흐릿합니다.
- 카메라도 앞으로 나가서 사진이 멈춘 것 같아요.
