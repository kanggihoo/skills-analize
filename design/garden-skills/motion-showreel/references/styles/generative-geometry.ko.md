# 제너레이티브 기하학 (generative-geometry)

> 규칙이 만드는 그래픽: 배열, 파동, 회전하는 고리, 대칭 무늬. 요소마다 위상만 조금씩 달라 함께 움직임과 질서를 만든다.
> 참고 (문법만 참고): 제너레이티브 아트 (Vera Molnár, Manfred Mohr), bees & bombs풍 루프 GIF, 바우하우스 기하학, 오실로스코프 그래픽. 규칙을 만드는 사고방식만 참고하고 특정 작품을 복제하지 않는다.

## 본질 / 본질이 아닌 것
- 본질: **간단한 요소 몇 개 × 규칙 하나 × 서로 다른 위상**. 화면 대부분은 주기 함수로 움직이고 구조가 명확해 어떤 규칙인지 말할 수 있다.
- 본질이 아닌 것: 무작위로 흩뿌린 형태, 장식용 테크 배경.

## 식별 신호: 영상마다 2–3개 선택
| 신호 | 어떤 모습인가 | 적합한 주제 |
|---|---|---|
| 격자 배열 | 점, 선, 사각형이 규칙적으로 배치되고 위상차에 따라 움직임 | 질서, 시스템 |
| 동심원 | 여러 고리가 서로 다른 속도로 회전 | 리듬, 순환 |
| 전파되는 파동 | 파동 하나가 배열 전체를 통과 | 전파, 영향 |
| 대칭 무늬 | 거울·회전 대칭으로 만화경처럼 보임 | 장식, 의식 |
| 오실로스코프 그래픽 | 리사주 곡선, 사인파 | 소리, 신호 |
| 선의 직조 | 여러 선이 교차해 모아레 무늬를 형성 | 복잡성, 연결 |
| 재귀적 분할 | 사각형 하나가 계속 더 작은 사각형으로 나뉨 | 성장, 프랙탈 |
| 한 획의 연속선 | 선 하나가 계속 그려져 형태를 만듦 | 연속, 과정 |
| 실제 측정값 | 시간, 주파수, 인원 등 데이터에서 규칙을 가져옴 | 데이터 아트 |
| 최소한의 이동 | 사각형 하나가 격자 안을 한 칸씩 움직임 | 절제, 시적 표현 |

규칙:
- 영상마다 2–3개를 고르고, 그중 하나 이상은 아래의 “가장 진부한 버전”에 없는 신호로 선택한다.
- 신호는 주제에 맞춰 선택하며 순서대로 전부 쓰지 않는다.

## 이 스타일의 가장 진부한 버전
- 화면: 검은 바탕 위 흰 선의 회전 동심원이나 도트 파동이 처음부터 끝까지 일정하게 움직이다 마지막에 도트가 로고를 만듦.
- 사운드: 변화 없이 계속되는 아르페지에이터와 긴 패드 하나.
- brief의 style 항목에 이번 영상에서 뒤집은 규칙이나 고전적인 표현을 유지한 이유를 쓴다. 유지한다면 구도, 카메라, 리듬 또는 예상 밖의 기억에 남는 순간에 공을 들인다.

## 적합성
- 용도: 루프 GIF, 포트폴리오, 오프닝, 로고 연출 (로고가 배열로 구성되거나 배열에서 떠오름), 음악 시각화.
- 콘텐츠: 디자인, 수학, 알고리즘, 음악, 브랜드 무드.

## 기술 구현
Canvas 2D로 충분하다 (요소 수천 개까지). 요소가 매우 많거나 픽셀 단위 계산이 필요하면 WebGL 셰이더를 사용한다. 모든 움직임은 `θ = TAU * t / DUR`의 정수배 주파수 함수로 작성해 루프가 자연스럽게 이어지게 한다. 검수에 `--loop`을 추가한다.

## 재질과 렌더링
- 요소: 점, 선분, 고리, 사각형, 삼각형. 선 굵기나 크기를 통일.
- 배열: 격자, 극좌표, 육각형, 피보나치 나선. 각 요소의 위상은 `f(인덱스, 위치)`로 정한다. 예: `phase = dist(center) * k` (파문), `phase = angle * n` (회전).
- 겹치기: 같은 배열을 두 번 그리고 두 번째는 위상을 옮기거나 색을 바꾼 다음 `difference` / `multiply`로 합성.
- 안티앨리어싱: 가는 선은 `--dpr 2` 사용.

## 색상
아래 색상은 예시다. 방향만 참고하고 그대로 베끼지 않는다.
- 단색: 검은 바탕에 흰 선 또는 흰 바탕에 검은 선.
- 2색: `#111` / `#F2EEE6` + 강조색 하나 (`#FF4D2E`).
- 점진 변화: 같은 색조의 명도 그라데이션을 위상에 따라 적용.
- 규칙: 색상 자체도 위상의 함수로 설정할 수 있지만 명도 체계를 분명하게 둔다.
- 색상 도출: 먼저 명도 체계를 정하고 색을 고른다. 단색, 강조색을 더한 2색, 한 색조의 명도 그라데이션 모두 가능하며 색상을 위상의 함수로 만들 수 있다. 검은 바탕에 흰 선이 가장 흔하지만 밝은 바탕에 어두운 선이나 브랜드색 바탕도 시도할 수 있다.

## 글꼴
텍스트가 없는 경우가 많다. 필요하면 Space Grotesk, Outfit 같은 미니멀한 기하학 산세리프를 사용하고 작게 설정해 모서리나 마지막에 배치한다.

## 움직임
- 주기 운동, 일정한 회전과 사인파 진동이 자연스러운 스타일이다.
- 리듬: 2박 또는 4박마다 펼침 → 수축으로 전체 변환을 한 번 완료하고 강박에서 뒤집거나 반전.
- “호흡”: 전체 배율을 1.0 ↔ 1.04 사이에서 느리게 순환.

## 화면에 생동감 더하기
- 주기 운동 자체가 핵심이다. 장면을 유지할 때는 배열 한 층의 위상만 천천히 어긋나게 해 일제히 움직이던 형태가 흐트러지게 할 수 있다. 변화는 보이되 피로하지 않게 한다.
- 강박에서는 격자 하나나 고리 하나를 반전해 작은 강조를 준다.

## 카메라 문법
| 카메라 움직임 | 표현하는 것 | 적합한 콘텐츠 |
|---|---|---|
| 고정 | 규칙 자체 | 루프 |
| 아주 느린 회전 | 최면적인 느낌 | 배경, 오프닝 |
| 뒤로 빠지며 배열이 더 큰 그래픽의 일부임을 발견 | 규모 | 기억점 |

## 사운드 팔레트
박자와 엄격히 맞춘 전자음: tick 격자, 구형파 아르페지오, 필터 스윕 패드. 또는 무음 (GIF용). 1단계 합성으로 충분하며 사운드도 루프해야 한다.

리듬과 화성 (예시이며 한 가지로 한정하지 않음): 복합 리듬 (3:4, 5:4 중첩), 위상이 다른 반복 (Reich풍), 온음 음계, 4도 쌓기, 화음 하나만 사용. drop보다 누적이나 파동형 곡선이 더 잘 어울리는 경우가 많다.

## 이 매체만의 표현
- 배열 전체를 한 박자에 뒤집거나 반전: 비트에 맞춘 전환에 적합.
- 위상차가 만든 파동이 배열을 통과: 전파와 영향의 표현에 적합.
- 도트가 점차 로고 형태로 정렬 (각 점의 목표 위치는 로고에서 샘플링): 엔드카드에 적합.

## 변주 여지
- 구조: 규칙 하나에 매개변수를 차례로 추가, 같은 배열에 위상 함수를 네 가지로 적용, 전체 펼침과 수축 한 번.
- 도입: 점 하나가 원으로 분열, 선 하나를 복제해 배열 전체를 만듦.
- 끝맺음: 모든 요소가 한 점으로 돌아가 처음과 연결, 배열이 멈춰 로고가 됨.

## 함정
- 프레임을 누적하는 시뮬레이션을 사용해 루프가 연결되지 않음: 주기 함수를 사용한다.
- 요소가 많아 프레임 시간이 급증: 단일 프레임을 먼저 측정하고 필요하면 WebGL로 바꾼다.
- 규칙이 없어 무작위처럼 보임: 모든 변화에 설명할 수 있는 규칙이 있어야 한다.
