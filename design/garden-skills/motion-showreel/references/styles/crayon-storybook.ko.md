# 크레용 그림책 (crayon-storybook)

> 크레용, 색연필, 수채화로 종이에 그린 뒤 초당 열 장 남짓한 그림으로 움직인다. 선은 살짝 떨리고 한 권의 움직이는 동화책처럼 보인다.
> 참고 (문법만 참고): 손으로 그린 그림책 일러스트, 색연필 애니메이션 단편, p5.brush의 브러시 기능. 특정 그림책의 캐릭터나 장면을 복제하지 않는다.

## 본질 / 본질이 아닌 것
- 본질: **붓 자국에 방향, 굵기, 입자감, 종이결이 있다.** 색이 윤곽을 완전히 채우지 않으며 화면은 12fps로 진행되고 그림마다 작은 차이 (boiling line)가 있다. 카메라 움직임은 매끄럽다.
- 본질이 아닌 것: 벡터 플랫 일러스트에 종이 질감 필터를 얹은 것, SVG로 사실적인 얼굴을 그린 것.

## 식별 신호: 영상마다 2–3개 선택
| 신호 | 어떤 모습인가 | 적합한 주제 |
|---|---|---|
| 살아 있는 선 | 12fps로 선화가 가볍게 떨림 | 손그림, 동심 |
| 크레용 채색 | 색이 윤곽을 다 채우지 않아 종이색과 붓 방향이 보임 | 따뜻함, 천진함 |
| 수채화 번짐 | 종이에서 색이 번지고 가장자리에 물 자국이 있음 | 부드러움, 감정 |
| 색연필 해칭 | 촘촘한 사선이 겹쳐 명암을 만듦 | 섬세함, 고요함 |
| 오려 붙인 종이 | 손으로 그린 종이 조각을 잘라 이동 | 놀이, 수공예 |
| 작은 캐릭터 | 단순한 콩 모양이나 막대 인간 캐릭터 | 이야기, 마스코트 |
| 책 페이지 | 페이지 여백, 쪽수, 페이지 넘김 동작 | 이야기, 장 |
| 지우고 다시 그림 | 한 부분을 지우개로 지운 뒤 다시 그림 | 수정, 변화 |
| 손글씨 | 삐뚤빼뚤한 손글씨 제목과 대화 | 카피, 대화 |
| 화면에 들어오는 붓 | 화면 밖에서 붓이 들어와 다음 장면을 그림 | 창작, 시작 |
| 낙서 노트의 격자 | 모눈종이나 줄 노트를 바탕으로 사용 | 학습, 기록 |

규칙:
- 영상마다 2–3개를 선택하고, 그중 하나 이상은 아래의 “가장 진부한 버전”에 없는 신호로 고른다.
- 신호는 주제에 맞춰 선택하며 순서대로 전부 쓰지 않는다.

## 이 스타일의 가장 진부한 버전
- 화면: 미색 종이에 토마토색과 하늘색 크레용으로 그린 작은 사람, 모서리에 웃는 태양, 끝에서 책을 덮고 표지에 로고가 나타남.
- 사운드: 실로폰, 우쿨렐레, 휘파람, 경쾌한 장조.
- brief의 style 항목에 이번 영상에서 뒤집은 규칙이나 고전적인 표현을 유지한 이유를 쓴다. 유지한다면 구도, 카메라, 리듬 또는 예상 밖의 기억에 남는 순간에 공을 들인다.

## 적합성
- 용도: 이야기 중심 홍보 단편, 설명 영상, 명절 인사, 브랜드 무드 필름.
- 콘텐츠: 교육, 어린이, 라이프스타일, 공익, 개인 이야기, 따뜻한 브랜드.

## 기술 구현
p5.js (인스턴스 모드 + `noLoop()`, `render(t)`에서 시간을 설정하고 `redraw()` 호출) + p5.brush (색연필, 크레용, 수채화 브러시), 또는 Canvas로 직접 붓 자국을 구현 (경로를 따라 반투명하고 떨리는 짧은 선을 여러 개 그림). **브러시는 느립니다.** 한 프레임 처리 시간을 먼저 측정하고 길이와 프레임률을 결정합니다 (24fps 출력, 화면은 12fps 스텝으로 진행할 경우 두 프레임마다 같은 그림 재사용 가능). 종이결은 미리 생성한 노이즈 텍스처 하나를 매 프레임 최상단에 겹칩니다.

## 재질과 렌더링
- 붓 자국의 무작위 시드는 `floor(t * 12)`로 설정: 초당 12회 바뀌어 손그림 특유의 “살아 있는 선”을 만듦.
- 윤곽선은 짙은 색연필로 그리고 약간 닫히지 않게 둔다. 채색은 크레용이나 수채화로 하며 종이색 테두리를 남긴다.
- 수채화는 불규칙한 반투명 도형을 겹치고 가장자리를 더 짙게 처리 (물감이 쌓인 느낌).
- 종이는 따뜻한 흰색에 섬유결과 미세한 불균일함이 있음.

## 색상
아래 색상은 예시다. 방향만 참고하고 그대로 베끼지 않는다.
- 종이 `#F7F1E3` / 선 `#3B2F2A` / 토마토색 `#E8664A` / 하늘색 `#6FA8DC` / 풀색 `#8CBF6B` / 거위알색 `#F4C95D`
- 밤: 종이 `#E9E4F2` / 짙은 파랑 `#2E3A66` / 달빛 노랑 `#F2D77B` / 분홍 `#E89BB5`
- 규칙: 종이색을 드러내는 한정된 물감 팔레트, 순수한 검정은 사용하지 않음.
- 색상 도출: 종이색을 드러내고 순수한 검정을 쓰지 않는 한정 팔레트를 사용한다. 종이색과 물감은 주제에 맞춘다. 밤, 가을, 단색 연필, 크레용 두 자루만 쓰는 구성도 가능하다. 미색 종이에 토마토색과 하늘색이 가장 흔한 조합이다.

## 글꼴
손글씨 또는 수작업 느낌의 글꼴: Patrick Hand, Gaegu, Caveat. 중국어는 ZCOOL KuaiLe, LXGW WenKai (OFL). 글자도 붓으로 한 획씩 “쓰는” 방식으로 만들 수 있다.

## 움직임
- 12fps 스텝, 동작은 과장하되 느리게. 캐릭터는 몸통, 머리, 팔다리로 된 단순한 2.5D 뼈대를 쓰고 핵심 자세 사이를 이징 처리.
- 전환은 자주 “다시 그리기”로 표현: 새 장면을 한 획씩 그리면서 이전 장면을 지움.

## 화면에 생동감 더하기
- 선화는 “끓어오르듯” 움직임: 8–12fps로 시드를 바꿔 선을 가볍게 흔든다. 선화와 작은 영역에만 적용하고 전체 색면을 몇 프레임마다 다시 그리면 깜박임으로 읽힌다.
- 구름, 풀, 나뭇잎은 12fps 스텝으로 흔들리고 캐릭터는 눈을 깜빡이거나 숨을 쉰다.

## 카메라 문법
| 카메라 움직임 | 표현하는 것 | 적합한 콘텐츠 |
|---|---|---|
| 천천히 전진 | 이야기 속으로 들어감 | 오프닝, 감정의 순간 |
| 레이어별 시차로 수평 이동 (종이 앞·뒤 레이어) | 깊이, 여정 | 장면 이동 |
| 페이지 넘김 | 다음 장 | 구간 전환 |

## 사운드 팔레트
어쿠스틱한 느낌: 플럭 (`pluck`), 실로폰 느낌의 `bell`, 부드러운 `keys`; 종이와 연필 폴리 (대역 통과 노이즈). 2단계의 피아노 샘플 (Salamander)이 이 따뜻한 스타일에 잘 맞는다.

리듬과 화성 (예시이며 한 가지로 한정하지 않음): 3/4 또는 6/8의 흔들리는 박자, 가벼운 swing; 장조, Lydian, 6도·9도를 더한 화음. 그림을 한 획씩 그릴 때마다 음을 붙이는 방식이 잘 어울린다. `mallet` (glock, marimba), `pluck`, 부드러운 드로바 `organ`을 주선율로 사용할 수 있다. 작은 공간감, 사이드체인은 사용하지 않음.

## 이 매체만의 표현
- 한 획으로 다음 장면을 그림: 아이디어가 현실이 되는 이야기.
- 수채화 번짐이 화면을 채우며 다음 장면의 바탕이 됨: 전환.
- 지우고 다시 그림: 변화와 수정.

## 변주 여지
- 구조: 작은 캐릭터의 한 번의 모험, 같은 종이에서 사계절이 바뀜, 편지를 써서 보내기까지.
- 도입: 빈 종이 위에 첫 획이 떨어짐, 화면 밖에서 붓이 들어옴.
- 끝맺음: 장면이 책 속 한 페이지 크기로 줄어들고 책을 덮으며 표지에 로고 표시 (고전적인 결말). 마지막 획에서 멈추거나 종이가 치워져 책상이 드러나는 방식도 가능.

## 함정
- 매 프레임 붓 자국을 새로 무작위 생성하고 12fps 고정 시드를 쓰지 않으면 화면이 심하게 깜빡임.
- 붓이 너무 느려 렌더링 시간이 폭증함: 먼저 측정하고 결정.
- 사실적인 인물이나 얼굴을 그림: 단순하고 스타일화된 형태를 유지.
