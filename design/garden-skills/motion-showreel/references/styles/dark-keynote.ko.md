# 다크 키노트 (dark-keynote)

> 어두운 무대, 스포트라이트 하나, 거대한 숫자와 한 문장, 영웅처럼 등장하는 제품. 여기서 어두움은 디자인된 것이며 AI 기본값이 아니다.
> 참고 (문법만 참고): 기술 기업 출시 키노트의 메인 비주얼과 영상, Apple풍 제품 스토리 영상. 어떤 브랜드의 기기 외형, 글꼴, 색상 템플릿도 복제하지 않는다.

## 본질 / 본질이 아닌 것
- 본질: **층이 있는 어둠** (거의 검정인 배경 + 천천히 움직이는 부드러운 광원, 칠흑 같은 검정이 아님). 한 화면에 하나의 메시지, 큰 숫자와 짧은 문구. 제품이나 인터페이스가 빛 속에서 천천히 돌아 나오고 리듬은 “정적 → 공개 → 정적”.
- 본질이 아닌 것: 어두운 배경 + 가운데 큰 글자 + 보라·파랑 그라데이션 + 사방의 발광 효과라는 AI 기본 스타일. 차이는 빛의 방향과 출처가 있고 강조색 하나만 쓰며 글자 위치가 설계되어 있고 공개에 리듬이 있다는 점.

## 식별 신호: 영상마다 2–3개 선택
| 신호 | 어떤 모습인가 | 적합한 주제 |
|---|---|---|
| 움직이는 부드러운 광원 | 거의 검정 배경 위를 천천히 움직이는 빛 덩어리, 완전한 검정은 아님 | 고급스러움, 감정 |
| 거대한 숫자 | 매개변수 하나가 화면을 채웠다가 문구 속에 들어갈 만큼 작아짐 | 성능, 성과 |
| 한 화면에 한 문장 | 큰 짧은 문구가 가운데나 왼쪽 정렬로 표시되고 앞뒤는 어두운 장면 | 슬로건, 약속 |
| 빛이 윤곽을 드러냄 | 빛이 제품 가장자리를 훑으며 실물보다 윤곽이 먼저 나타남 | 제품 첫 공개 |
| 제품 히어로 숏 | 제품이나 인터페이스가 빛 안에서 천천히 돌아 나옴 | 하드웨어, 앱 |
| 유리 카드 | 스크린샷이나 매개변수를 반투명 무광 카드에 담음 | 기능 소개 |
| 카운트다운과 공개 | 3, 2, 1 후 화면이 밝아짐 | 출시, 공개 |
| 사양 표 | 정렬된 사양 숫자가 한 줄씩 켜짐 | 비교, 사양 |
| 반사 바닥 | 제품 아래에 희미한 반영이 보임 | 하드웨어, 고급스러움 |
| 흐림에서 나타나는 글자 | 제목이 초점 흐림에서 선명해지며 살짝 확대 | 제목, 장 |

규칙:
- 영상마다 2–3개를 고르고, 그중 하나 이상은 아래의 “가장 진부한 버전”에 없는 신호로 선택한다.
- 신호는 주제에 맞춰 선택하며 순서대로 전부 쓰지 않는다.

## 이 스타일의 가장 진부한 버전
- 화면: 검은 배경 + 파란 빛 한 줄이 지나감 + 중앙의 거대한 숫자 + 천천히 회전하는 제품 + 마지막에 빛 속에서 멈추는 로고.
- 사운드: 저음 boom, 올라가는 riser, 리버브를 많이 넣은 피아노 단음 패드.
- brief의 style 항목에 이번 영상에서 뒤집은 규칙이나 고전적인 표현을 유지한 이유를 쓴다. 유지한다면 구도, 카메라, 리듬 또는 예상 밖의 기억에 남는 순간에 공을 들인다.

## 적합성
- 용도: 제품 홍보 영상, 데이터 성과 강조, 로고 엔드카드, 출시 카운트다운.
- 콘텐츠: 하드웨어, AI 제품, 플랫폼, 주요 업데이트.

## 기술 구현
DOM / Canvas 조판 + 한 겹의 조명: 방사형 그라데이션 광점을 시간에 따라 천천히 움직인다. 제품 사진은 사용자가 제공한 실물 사진이나 스크린샷을 사용하거나 Three.js로 3D 표현할 수 있다 (`glass-material.md` 참고). `--dpr 2`로 작은 글자를 선명하게 하고, `--grain 2–3`으로 어두운 배경의 색 띠를 줄인다.

## 재질과 렌더링
- 배경: `#050506`–`#0B0B0E`, 크고 부드러운 광점 하나를 겹침 (`radial-gradient`, 매우 낮은 밝기) 카메라와 함께 느리게 이동.
- 글자 하이라이트: 대각선 빛이 큰 글자를 가로지름 (마스크 + 그라데이션, 0.6–1초).
- 기기 / 스크린샷: 약하게 반사되는 테두리와 아래쪽의 희미한 반영. 중요한 순간에만 가장자리 빛을 조금 줌.
- 숫자: 초대형 글꼴, 고정폭 숫자. 값이 바뀔 때는 스크롤하거나 숫자별로 뒤집음.

## 색상
아래 색상은 예시다. 방향만 참고하고 그대로 베끼지 않는다.
- 거의 검정 `#07070A` / 흰색 `#F5F5F7` / 회색 `#86868B` / 강조색 하나 (얼음 파랑 `#5AC8FA` 또는 브랜드색)
- 거의 검정 `#0A0A0A` / 따뜻한 흰색 `#F2EDE4` / 금색 `#C9A96E`
- 규칙: 화면마다 강조색은 최대 하나. 그라데이션은 “빛”으로만 사용하며 “장식용 색면”으로 쓰지 않는다.
- 색상 도출: 거의 검정인 배경 (차갑거나 따뜻하거나 브랜드색 기운이 있어도 됨) + 흰색 또는 따뜻한 흰색 글자 + 강조색 하나. 강조색은 브랜드나 제품 재질 (금속색, 제품 색상)에서 가져온다. 얼음 파랑이 가장 흔하다.

## 글꼴
아주 가늘거나 중간 굵기의 산세리프, 큰 크기와 넓은 자간의 짧은 소제목: Inter Tight (200–600), Manrope, Space Grotesk. 숫자는 tabular 사용. 중국어는 Source Han Sans Light / Medium.

## 움직임
- 느리고 정확하게: 큰 제목은 `{1.6, 0.95}`, 공개 동작은 `glide` (0.8–1.2초); 퇴장은 진입보다 빠르게.
- 공개 순서: 어두운 화면 → 빛이 윤곽을 훑음 → 주체가 완전히 밝아짐 → 텍스트가 뒤따름.
- 숫자는 `outExpo`로 굴리고 도착할 때 아주 약한 확대 펄스를 한 번 줌.

## 화면에 생동감 더하기
- 주체 표면을 하이라이트가 천천히 한 번 훑음 (2–4초), 배경 광점은 아주 느리게 이동, 카메라는 계속 아주 느리게 전진. 이 자체가 움직임이다.
- 글자가 자리를 잡으면 움직이지 않고 읽을 시간을 줌.

## 카메라 문법
| 카메라 움직임 | 표현하는 것 | 적합한 콘텐츠 |
|---|---|---|
| 어두운 장면에서 천천히 전진 | 기대감 | 오프닝, 공개 전 |
| 주체를 중심으로 회전 | 완전함, 정교함 | 제품 공개 |
| 정면에서 살짝 전진 | 선언 | 숫자나 이름 하나 |
| 큰 여백으로 후퇴 | 글자가 들어갈 공간 마련 | 슬로건, 엔딩 |

## 사운드 팔레트
sub drone, 부드러운 kick, FM 벨 / 유리 음색, 넓은 패드, 정확한 tick. 공개 직전에는 짧게 완전한 정적을 둔다. 제품 공개에 공간감을 더하려면 2단계 (Tone.js 컨볼루션 리버브, 피아노 샘플)를 사용할 수 있다.

리듬과 화성 (예시이며 한 가지로 한정하지 않음): 느린 half-time 또는 심장 박동 같은 sub만 사용, Lydian (제품 공개의 “놀라움”), 4도 쌓기, 혹은 영상 전체에서 화음 하나만 쓰고 밀도로 변화를 줌. 악기 전체에서 벨 하나만 남기듯 소리를 비우는 곡선도 가능하며 반드시 drop을 쓸 필요는 없다. 깨끗하고 넓게, 사이드체인은 아주 약하게 쓰거나 사용하지 않는다.

## 이 매체만의 표현
- 빛이 윤곽을 훑어 제품을 처음 공개: 제품 첫 등장에 적합.
- 화면을 채운 숫자가 작아져 문장 속 단어 하나가 됨: 데이터에 적합.
- 스크린샷 속 요소 하나가 “떠올라” 큰 글자로 변함: 기능 설명에 적합.

## 변주 여지
- 구조: 제품을 숫자 세 개로 설명, 질문 하나와 답 하나, 카운트다운 3·2·1 뒤 공개.
- 도입: 완전한 어둠 속 빛 하나, 화면보다 먼저 들리는 소리.
- 끝맺음: 빛 속에서 로고가 멈춤, 빛이 꺼지고 이름만 남음.

## 함정
- AI 기본 스타일로 퇴화: 매 화면에 그라데이션과 발광, 모든 요소가 동시에 페이드 인. “빛에 출처를 둔다, 강조색 하나, 리듬 있는 공개” 세 규칙으로 돌아간다.
- 배경이 너무 어두워 색 띠가 나타남: 약한 그레인을 더한다.
- 사양이나 숫자를 지어냄: 사용자가 제공한 정보만 사용.
