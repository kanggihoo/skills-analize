# 키네틱 브루탈리즘 (kinetic-brutalist)

> 글자 자체가 화면이다. 거대한 글자, 블리드, 하드 컷, 강한 대비, 거친 리듬으로 계속 뜯고 다시 붙이는 포스터처럼 만든다.
> 참고 (문법만 참고): Bloomberg Businessweek 표지 시기의 에디토리얼 디자인, 뉴 브루탈리즘 웹, 음악 페스티벌 포스터의 대형 타이포그래피, Saul Bass 이후의 강한 리듬을 가진 오프닝. 특정 표지나 글꼴 파일을 복제하지 않는다.

## 본질 / 본질이 아닌 것
- 본질: **극단적인 크기** (단어 하나가 화면을 채우거나 넘침), **매우 빠른 전환** (반 박자마다 바뀜), **매우 강한 대비** (흑백 + 눈에 띄는 색 하나). 레이아웃은 일부러 불편하게 보일 수 있지만 모든 프레임은 의도적으로 설계되어야 함.
- 본질이 아닌 것: 무질서한 랜덤 타이포그래피, 화면 여기저기 튀는 템플릿식 가사 영상.

## 식별 신호: 영상마다 2–3개 선택
| 신호 | 어떤 모습인가 | 적합한 주제 |
|---|---|---|
| 화면 밖으로 잘리는 거대 글자 | 단어 하나가 커서 가장자리에 잘림 | 슬로건, 태도 |
| 색상 반전 겹침 | 글자가 지나간 부분의 색이 반전됨 (difference) | 정오, 전후, 대비 |
| 외곽선 글자와 채운 글자 교대 | 같은 단어가 속이 빈 글자와 채운 글자로 번갈아 보임 | 리듬, 반복 |
| 굵은 구조선과 프레임 | 검은 띠, 굵은 밑줄, 두꺼운 테두리로 화면을 분할 | 에디토리얼, 강조 |
| 잘리고 어긋난 글자 | 단어를 반으로 나눠 어긋나게 했다가 합침 | 파괴, 재구성 |
| 단어 하나씩 하드 컷 | 반 박자마다 전환하고 사이 효과 없음 | 빠른 비트 편집 |
| 반복 패턴 채우기 | 같은 단어를 화면 전체에 반복 | 집착, 강조, 집단 |
| 늘어나고 변형되는 글자 | 글자가 가로로 늘어나거나 한 줄로 눌림 | 긴장, 속도 |
| 가공되지 않은 웹 요소 | 시스템 글꼴, 기본 링크 파랑, 커서, 스타일 없는 버튼 | 인터넷, 개발자, 안티 디자인 |
| 경고 띠와 봉인 테이프 | 노랑·검정 사선, 포장 테이프가 화면을 가로지름 | 경고, 공사, 금지 |

규칙:
- 영상마다 2–3개를 고르고 그중 하나 이상은 아래 “가장 진부한 버전”에 없는 신호로 선택한다.
- 신호는 주제에 맞춰 고르며 나열된 순서대로 모두 쓰지 않는다.

## 이 스타일의 가장 진부한 버전
- 화면: 검은 배경에 흰색이나 형광 노랑, Anton / Bebas 대문자, 박자마다 단어 하나, 강박 때마다 한 번 색을 반전해 깜박임, 마지막에 커다란 마침표.
- 사운드: 단어가 나올 때마다 hit 하나, trap 하이햇 롤.
- brief의 style 항목에 뒤집은 규칙이나 고전 표현을 유지한 이유를 쓴다 (사용자가 원한 것이 고전 버전인 경우 등). 고전 표현을 유지한다면 구도, 카메라, 리듬, 예상 밖의 기억점에 공을 들인다.

## 적합성
- 용도: 비트에 맞춘 문구, 포트폴리오, 홍보 영상 오프닝 / 클라이맥스, 행사 예고.
- 콘텐츠: 태도가 분명하고 에너지가 필요한 주제, 음악, 트렌드, 슬로건, 대비.

## 기술 구현
Canvas 2D (fillText + 변환 + 합성 모드) 또는 DOM. 동작이 빠르므로 60fps를 권장합니다. 하드 컷에는 모션 블러가 필요 없고 빠른 슬라이드에는 --subframes 2를 사용합니다.

## 재질과 렌더링
- 글자를 화면 바깥까지 밀어내며 (블리드) 행간을 0.8–0.9로 줄입니다. 색면이 글자의 절반을 잘라도 됩니다.
- globalCompositeOperation = 'difference'로 색 반전 겹침을 만듭니다. 글자가 지나가는 부분의 색이 반전됩니다.
- 굵은 검은 띠, 테두리, 밑줄 등 “구조적” 요소를 쓸 수 있지만 장식 그림자는 추가하지 않습니다.
- 가끔 외곽선 글자와 채운 글자를 교대로 사용합니다.

## 색상
아래 값은 예시이며 방향만 참고하고 그대로 복사하지 않습니다.
- 흰색 #FFFFFF / 검정 #000000 / 형광 노랑 #E8FF00
- 검정 #0A0A0A / 흰색 #F4F4F4 / 경고 빨강 #FF2A1F
- 분홍 바탕 #FF4FD8 / 검정 글자 / 흰색 글자 (drop에서만 반전)
- 규칙: 화면마다 최대 두 색상. 반전은 리듬으로 사용할 수 있으며 강박마다 한 번 뒤집습니다.
- 색상 도출: 흑백 외에 눈에 띄는 색 하나까지만 주제에서 선택합니다 (브랜드색이 강렬하면 사용). 형광 노랑이 가장 흔합니다. 전체 영상에서 흑백이 아닌 두 색만 사용할 수도 있습니다.

## 글꼴
- 매우 굵거나 좁은 디스플레이 글꼴: Anton, Archivo Black, Bebas Neue, Big Shoulders Display, Unbounded (OFL). 중국어는 Source Han Sans Heavy 또는 ZCOOL Kuhei.
- 대문자를 사용하고 자간을 −4%까지 좁힐 수 있습니다. 화면마다 단어 하나를 쓰거나 단어 하나로 화면 전체를 채웁니다.

## 움직임
- 리듬 구동: 단어는 박자에 맞춰 하드 컷으로 나타납니다. 준비 동작은 최대 2–4프레임 (예: 110%에서 100%로 축소).
- 큰 이동은 whip easing으로 3–6프레임 안에 끝냅니다. 멈출 때 화면 흔들림을 1–2프레임 넣을 수 있습니다.
- 가끔 슬로모션이나 정지 화면을 넣어 대비를 만들고 다음 충격을 강하게 합니다.

## 화면에 생동감 더하기
- 단어가 자리 잡은 뒤 빈 공간을 남기지 않음: 가변 글꼴의 굵기나 너비를 8분음표에 맞춰 미세하게 흔들고 배경 색면을 박자별로 바꾸거나 외곽선 뒤의 채운 글자가 한두 프레임 어긋난 뒤 정렬됨.
- 의도적인 정지가 대비를 위한 장치라면 실제로 정지합니다. HOLDS에 기록하고 작은 동작을 더하지 않습니다.

## 카메라 문법
| 카메라 움직임 | 표현하는 것 | 적합한 콘텐츠 |
|---|---|---|
| 글자 하나로 급격히 전진 | 충격, 진입 | 구간 전환, drop |
| 다음 단어로 whip 이동 | 속도 | 이어지는 슬로건 |
| 90° / 180° 하드 회전 | 관점 전환 | 대비, 반문 |
| 고정 시점 + 색 반전 플래시 | 타격 | 강박, 강조 |

## 사운드 팔레트
강한 드럼 (kick, clap, snare의 drive를 높임), 짧은 glitch와 hit를 사용하고 단어가 착지할 때마다 소리를 냅니다. BPM은 120–150이며 사용자가 곡을 제공했다면 박자에 정확히 맞춥니다.

리듬과 화성 (예시이며 한 가지로 한정하지 않음): breakbeat, half-time, trap 롤 또는 7/8의 불안정한 박자; Phrygian, 음군, 근음 + 5도만 사용할 수 있습니다. 화면을 폭격한 뒤 단어 하나와 소리 하나만 남기는 식으로 소리를 비워 대비를 만들 수도 있습니다. 드럼 버스에 crush: 10과 강한 drive를 적용할 수 있습니다.

## 이 매체만의 표현
- 단어 하나를 화면 밖으로 확대하고 획 안에서 다음 단어를 드러냄: 슬로건 연속에 적합.
- 색 반전으로 화면을 지움: “맞음 / 틀림”, “이전 / 이후”에 적합.
- 글자를 반으로 자르고 어긋나게 한 뒤 다시 합침: 파괴 / 재구성 주제에 적합.

## 변주 여지
- 구조: 문장 하나를 16개의 반 박자로 나눔, 반의어 쌍을 충돌시킴, 같은 단어를 여덟 가지 레이아웃으로 표현.
- 도입: 검은 화면에 첫 글자가 떨어짐, 글자 하나를 화면 전체까지 확대해 단어 전체를 공개.
- 끝맺음: 마지막 단어가 2초 동안 멈추고 주변을 모두 비움, 커다란 마침표가 화면을 덮음.

## 함정
- 글자가 너무 빨리 바뀌어 읽을 수 없음: 리듬을 빠르게 하려면 문구 수를 줄이고 단어마다 최소 0.4–0.5초 유지. 핵심 문장은 다 읽을 때까지 유지.
- 매 화면이 똑같이 강렬해져 강렬함이 사라짐: 반드시 느린 구간을 둠.
- 중국어 글꼴 subset을 준비하지 않아 렌더링 때 네모 글리프가 나타남.
