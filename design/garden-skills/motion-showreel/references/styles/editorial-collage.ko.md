# 에디토리얼 콜라주 (editorial-collage)

> 오려낸 사진과 색종이, 찢어진 가장자리, 테이프, 스티커, 손글씨 메모를 겹겹이 붙여 움직이는 잡지 한 페이지를 만든다.
> 참고 (문법만 참고): 패션·음악 잡지의 콜라주 레이아웃, 다다 콜라주, 현대 소셜 미디어 스크랩북 스타일. 구체적 작품이나 저작권이 있는 이미지를 복제하지 않는다.

## 본질 / 본질이 아닌 것
- 본질: **각 요소가 오려 붙인 종이 조각처럼 보인다** (흰 테두리, 찢긴 가장자리, 그림자). 일부러 정렬을 맞추지 않는다. 손글씨, 낙서, 화살표는 두 번째 레이어이며 요소는 손으로 붙인 듯하다.
- 본질이 아닌 것: 단정한 그리드 레이아웃, 밈으로 가득 찬 저렴한 스티커 스타일.

## 식별 신호: 영상마다 2–3개 선택
| 신호 | 어떤 모습인가 | 적합한 주제 |
|---|---|---|
| 오려낸 종이의 흰 테두리 | 사진과 색종이 가장자리에 흰 테두리와 희미한 그림자 | 인물, 작업물 |
| 찢긴 가장자리 | 종이 가장자리가 뜯겨 거칠게 남음 | 공개, 돌파 |
| 테이프 | 반투명하고 양끝이 톱니 모양인 테이프로 종이 조각을 고정 | 수공예, 기록 |
| 하프톤 사진 | 사진을 단색 하프톤으로 바꾼 뒤 색종이를 겹침 | 패션, 음악 |
| 손글씨 주석 | 마커로 그린 원, 화살표, 밑줄, 별표 | 장점 강조 |
| 협박 편지 글자 | 글자마다 서로 다른 종이에서 오려냄 | 미스터리, 선언 |
| 색종이 기하 도형 | 오린 원, 막대, 불규칙한 면 | 추상, 리듬 |
| 스티커와 라벨 | 가격표, 원형 스티커, 번호 라벨 | 제품, 목록 |
| 스테이플러 심과 클립 | 작은 금속 물체로 종이 조각을 고정 | 기록 보관, 문서 |
| 잡지 지면 요소 | 페이지 번호, 섹션 이름, 제호, 바코드 | 출판, 브랜드 |
| 폴라로이드 사진 | 아래쪽 흰 여백이 넓은 사진 | 추억, 인물 |

규칙:
- 영상마다 2–3개를 고르고, 그중 하나 이상은 아래의 “가장 진부한 버전”에 없는 신호로 선택한다.
- 신호는 주제에 맞춰 선택하며 순서대로 전부 쓰지 않는다.

## 이 스타일의 가장 진부한 버전
- 화면: 크라프트지 바탕, 테이프, 폴라로이드, 빨간 손글씨 원, 협박 편지 제목, 모든 종이가 비스듬히 떨어짐.
- 사운드: 종이 효과음과 경쾌한 플럭 셔플.
- brief의 style 항목에 이번 영상에서 뒤집은 규칙이나 고전적인 표현을 유지한 이유를 쓴다. 유지한다면 구도, 카메라, 리듬 또는 예상 밖의 기억에 남는 순간에 공을 들인다.

## 적합성
- 용도: 프로모션 영상, 문구 박자 맞추기, 인물·팀 소개, 행사 예고.
- 콘텐츠: 트렌드, 라이프스타일, 크리에이티브 팀, 젊은 브랜드, 개인 포트폴리오.

## 기술 구현
Canvas 2D. 자료는 사용자가 제공한 사진이나 제품 이미지 (불규칙한 모양으로 자름), 또는 코드로 그린 색종이와 그래픽을 사용한다. 찢긴 가장자리는 노이즈로 만든 다각형 경로를 clip으로 사용한다. 그림자는 `shadowBlur`와 오프셋을 작게 둔다. 손글씨 주석은 SVG 경로 스트로크나 Canvas에서 선을 구간별로 그려 표현한다.

## 재질과 렌더링
- 종이 조각: 불규칙 다각형 clip + 2–4px 흰 테두리 + 희미한 그림자. 각 종이는 시드에 따라 고정된 작은 회전각 (±6°)을 가짐.
- 테이프: 양 끝이 톱니 모양인 반투명 직사각형, 약간 기울임.
- 하프톤 사진: 사진을 단색 하프톤으로 처리한 뒤 색종이를 겹칠 수 있음.
- 손글씨 레이어: 둥근 끝과 약간의 떨림이 있는 마커 선으로 원, 화살표, 밑줄, 별표를 그린다.

## 색상
아래 색상은 예시다. 방향만 참고하고 그대로 베끼지 않는다.
- 크라프트지 `#E8DCC6` / 잉크 `#1B1B1B` / 토마토 빨강 `#E8452C` / 코발트 블루 `#2A4BD7`
- 흰색 `#FAFAF7` / 검정 `#111` / 형광 초록 `#B6FF3B` / 핑크 `#FFB4D9`
- 규칙: 바탕색 하나, 종이 조각 색상 2–3개, 손글씨 주석은 색상 하나만 사용.
- 색상 도출: 바탕색 하나 (종이색, 흰색, 어두운색 모두 가능) + 종이 조각 2–3색 + 손글씨 주석색 하나를 주제나 브랜드에서 가져온다. 크라프트지와 토마토 빨강이 가장 흔한 조합이다.

## 글꼴
- 제목: 굵은 세리프나 그로테스크체를 종이 조각처럼 오림 (DM Serif Display, Archivo Black, Rubik Mono One). 글자마다 종이 하나씩 사용해 협박 편지 스타일을 낼 수 있음 (주의).
- 주석: 손글씨 글꼴 (Caveat, Gochi Hand, ZCOOL KuaiLe).

## 움직임
- “손으로 올려놓기”: 종이 조각이 화면 밖이나 위에서 떨어지며 조금 회전. 스프링 `{2.8, 0.55}`으로 안착하고 그림자가 작아져 종이에 붙은 듯함.
- 손글씨 주석은 획 순서대로 그리며 (`stroke-dashoffset`) 실제 쓰는 속도처럼 표현.
- 수작업 느낌을 높이기 위해 12fps 스텝을 사용할 수 있음.

## 화면에 생동감 더하기
- 테이프 한쪽 모서리가 들렸다 돌아붙음, 핵심 단어 위에 손글씨 원이 한 획 더해짐, 사진 조각이 천천히 내려앉으며 그림자가 작아짐.
- 이런 작은 동작도 12fps 스텝으로 표현해 “손으로 올려놓는” 질감과 맞춘다.

## 카메라 문법
| 카메라 움직임 | 표현하는 것 | 적합한 콘텐츠 |
|---|---|---|
| 큰 책상 위를 내려다보며 이동 | 훑어보기, 둘러보기 | 목록, 작업물 벽 |
| 종이 조각 하나로 전진 | 초점 집중 | 핵심 정보 |
| “손”이 종이 조각을 가져감 | 페이지 전환 | 구간 전환 |

## 사운드 팔레트
종이 효과음 (`swipe`에 `highpass`, 테이프를 뜯는 소리에는 `click`), 마커가 선을 긋는 소리 (대역 통과 노이즈). 음악은 경쾌한 드럼, 플럭, 키보드. 1단계 합성만으로 충분하다.

리듬과 화성 (예시이며 한 가지로 한정하지 않음): breakbeat, shuffle, tresillo에 수작업 같은 느슨함 (`S.swing`, `S.humanize`)을 조금 추가. 장조, Mixolydian, Dorian. `rim`, `shaker`, `cowbell`로 손맛 나는 타악기를 만든다. 작은 공간감, 사이드체인은 사용하지 않음.

## 이 매체만의 표현
- 종이를 찢어 다음 장면을 드러냄: 전환과 공개에 적합.
- 종이 조각을 한 장씩 붙여 포스터나 로고 전체를 완성: 끝맺음에 적합.
- 손글씨로 핵심을 표시: 숫자나 장점을 강조할 때 적합.

## 변주 여지
- 구조: 하루를 적은 다이어리, 점점 채워지는 무드보드, 한 인물의 스크랩북.
- 도입: 빈 책상에 첫 종이가 떨어짐, 테이프 롤을 뜯는 소리와 화면.
- 끝맺음: 종이 조각이 모여 제목이 됨, 카메라가 뒤로 빠지며 벽 전체가 잡지 표지로 드러남.

## 함정
- 요소가 너무 많고 산만해 소음이 됨: 한 화면에 종이 조각은 최대 5–7개.
- 권한 없는 사진이나 이미지를 사용함: 사용자가 제공한 자료나 코드로 그린 그래픽만 사용.
- 그림자가 너무 진하거나 흐려 저렴한 PPT처럼 보임.
