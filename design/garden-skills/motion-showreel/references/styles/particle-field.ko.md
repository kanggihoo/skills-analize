# 입자장 (particle-field)

> 수천 개의 점이 혼돈에서 단어로 모이고 보이지 않는 힘의 장을 따라 흐르며 강박에서 폭발한 뒤 다시 모입니다.
> 참고 (문법만 참고): 데이터 시각화의 입자 애니메이션, 브랜드 영상의 입자 타이포그래피, 유동장 아트. 특정 작품은 복제하지 않습니다.

## 본질 / 본질이 아닌 것
- 본질: **입자는 목적을 갖는다.** 단어와 형태를 이루고 힘의 장을 따라 흐르며 주체를 따라갑니다. 흩날리는 빛점이 아니라 하나의 물질처럼 느껴져야 합니다.
- 본질이 아닌 것: 일반적인 “입자 폭발 + 렌즈 플레어” 템플릿, 구조 없는 별하늘 배경.

## 식별 신호: 영상마다 2–3개 선택
| 신호 | 어떤 모습인가 | 적합한 주제 |
|---|---|---|
| 입자 타이포그래피 | 혼돈 속 점들이 단어나 로고 형태로 모임 | drop, 기억점 |
| 유동장 | 입자들이 보이지 않는 힘의 흐름을 따라 이동 | 흐름, 추세 |
| 강박 폭발 | 점 하나가 강박에 입자 덩어리로 폭발 | 충격, 폭발 |
| 꼬리 궤적 | 입자가 주체를 따라 궤적을 만듦 | 속도, 경로 |
| 먼지와 빛 점 | 깊이감 있는 입자가 천천히 떠다님 | 분위기, 고요함 |
| 모래 입자 | 모래처럼 쌓이거나 무너지는 입자 | 시간, 침식 |
| 군집 | 새 떼나 물고기 떼처럼 모이고 흩어짐 | 집단, 협력 |
| 데이터 입자 | 점 하나가 단위 하나를 나타내고 데이터 모양을 이룸 | 규모, 수량 |
| 점 구름 | 입자가 3D 사물을 구성하고 카메라가 둘러봄 | 제품, 공간 |
| 먹 점과 수채화 점 | 빛 점이 아니라 불규칙한 먹 점 | 수작업, 동양적 주제 |

규칙:
- 영상마다 2–3개를 고르고, 그중 하나 이상은 아래의 “가장 진부한 버전”에 없는 신호로 선택한다.
- 신호는 주제에 맞춰 선택하며 순서대로 전부 쓰지 않는다.
- 입자에는 목적이 있어야 한다. 모든 움직임에서 입자가 어디로 가는지 설명할 수 있어야 한다.

## 이 스타일의 가장 진부한 버전
- 화면: 검은 배경에서 빛나는 입자 덩어리가 폭발하고 회전한 뒤 로고로 모이며 주변에는 렌즈 플레어가 조금 더해짐.
- 사운드: 상승 riser, 폭발 impact, 반짝이는 shimmer.
- brief의 style 항목에 이번 영상에서 뒤집은 규칙이나 고전 표현을 유지한 이유를 씁니다. 유지한다면 구도, 카메라, 리듬 또는 예상 밖의 기억점에 힘을 줍니다.

## 적합성
- 용도: 시그니처 순간, 로고 연출, 오프닝, 홍보 영상의 “모이기” 장면.
- 콘텐츠: AI, 데이터, 네트워크, 커뮤니티, 브랜드, 우주, 자연.

## 기술 구현
- 입자 5,000개 이하: Canvas 2D fillRect.
- 5,000–100,000개: WebGL 포인트 스프라이트 또는 Three.js InstancedMesh / Points 사용. 위치는 vertex shader에서 t와 입자별 속성 (시드, 목표점)으로 계산합니다.
- **무상태 계산**: 입자 위치는 f(인덱스, t)로 결정합니다 (recipes.md 7, 8절). 이전 프레임의 속도를 누적 적분하지 않습니다.
- 목표 형태: 글꼴이 로드된 뒤 오프스크린 캔버스에 글자나 로고를 그려 격자로 샘플링해 목표점을 한 번만, 결정론적으로 만듭니다.

## 재질과 렌더링
- 입자는 작게 (2–5px). 크기와 밝기는 고정 시드로 약간 무작위화하고 10–15%에는 강조색을 적용.
- 밀도가 형태 가독성을 결정합니다: 1080p에서 샘플링 간격 5–8px.
- 잔상은 선택 사항: recipes.md 13절의 시간 역샘플링 또는 --subframes 4 모션 블러.
- 어두운 배경에서는 가산 혼합 (lighter)이 입자를 더 밝게 합니다. 밝은 배경에서는 일반 혼합.

## 색상
아래 값은 예시이며 방향만 참고하고 그대로 복사하지 않습니다.
- 거의 검정 #0B0B0D / 종이색 입자 #EFEBE3 / 강조 #16C172
- 흰 바탕 #F7F6F2 / 먹색 입자 #151515 / 강조 #FF4A1C
- 규칙: 입자 색은 최대 두 가지이며 강조색 입자의 비율을 고정합니다.
- 색상 도출: 최대 두 색만 사용하고 강조색 입자 비율을 고정합니다. 밝은 바탕에는 어두운 입자, 어두운 바탕에는 밝은 입자를 쓸 수 있으며 브랜드색을 우선합니다. 검은 배경의 발광 입자가 가장 흔한 조합입니다.

## 글꼴
입자 타이포그래피는 획이 굵을수록 또렷하므로 굵은 디스플레이 글꼴을 사용합니다: Archivo Black, Anton, Unbounded Black.

## 움직임
- 응집: 스프링 {1.5, 0.82}, 입자별 무작위 지연 0–0.9초, 모이기 전 약간의 노이즈 표류.
- 폭발: outExpo, 0.4–0.8초. 중심에서 바깥으로 향하면서 약간 무작위 방향을 추가.
- 흐름: 입자 위치는 시작점 + 유동장을 따른 해석적 경로 (예: 사인 곡선) 또는 주기적인 노이즈 오프셋으로 계산.
- 다음 형태로 바꾸기 전에 읽을 수 있도록 최소 1.5초 머뭅니다.

## 화면에 생동감 더하기
- 형태가 만들어진 뒤에도 입자는 완전히 정지하지 않습니다. 각 점이 목표점 주변에서 2–4px 정도 조금 떠다니게 합니다 (원 위에 샘플한 노이즈를 사용하면 루프 가능). 전체가 호흡하는 듯 보입니다.
- 가장자리 입자 몇 개가 가끔 떨어져 떠다니게 해 형태가 입자로 만들어졌음을 알립니다.

## 카메라 문법
| 카메라 움직임 | 표현하는 것 | 적합한 콘텐츠 |
|---|---|---|
| 급격히 전진 + 폭발 순간 흔들림 | 충격 | drop |
| 천천히 후퇴하며 더 큰 형태의 일부임을 공개 | 규모 | 공개 |
| 입자 구름을 통과 | 몰입 | 전환 |

## 사운드 팔레트
폭발은 impact + crash, 응집은 shimmer와 상승 riser, 흐름은 패드와 입자감 있는 고음을 사용합니다. drop 전에는 박자 하나를 무음으로 둡니다. 1단계 합성으로 충분합니다.

리듬과 화성 (예시이며 한 가지로 한정하지 않음): four-on-the-floor 추진감 또는 복합 리듬의 입자감 (3연음 아르페지오를 4박 위에 겹침), 단조, Dorian, 필터 변화만 있는 화음 하나. 입자가 모이며 성부도 쌓이는 누적 방식이나 들숨 → 폭발 곡선 모두 적합합니다.

## 이 매체만의 표현
- 점 하나가 폭발해 입자가 되고 입자들이 단어로 모임: drop과 기억점에 적합.
- 한 단어의 입자가 흐르며 다른 단어로 재구성: A에서 B로 변하는 장면에 적합.
- 입자가 주체를 따라 꼬리 궤적을 만듦: 속도와 경로에 적합.

## 변주 여지
- 구조: 혼돈 → 질서 → 다시 혼돈, 단어 하나가 세 단어로 변함, 화면 모서리 네 곳의 입자가 중앙으로 모임.
- 도입: 점 하나, 떠다니는 먼지 덩어리.
- 끝맺음: 입자들이 로고를 만들고 멈춤, 흩어져 점 하나만 남고 루프.

## 함정
- 입자에 목적이 없어 템플릿처럼 보임: 모든 움직임에서 “어디로 가는가?”에 답할 수 있어야 합니다.
- 가운데 구멍이 남음: 폭발 시작 거리 분포가 0부터 시작하도록 합니다.
- 형태가 너무 짧게 보여 글자를 읽지 못함.
- 입자 수가 지나치게 많아 프레임 시간이 급증: 5,000개를 넘으면 WebGL로 전환.
