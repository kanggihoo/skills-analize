# 홀로그램 공간 인터페이스 (hologram-hud)

> 공간 관계가 있는 물체가 어둠 속에 떠 있고 와이어프레임, 단면, 주석이 주위를 둘러싼다. 정보는 항상 가리키는 물체와 연결되어 있다.
> 참고 (문법만 참고): SF 공간 인터페이스, 와이어프레임 시각화, 체적 스캔 그래픽. 영화 화면, 군용 표식, 구체적인 제품 화면을 복제하지 않는다.

## 본질 / 본질이 아닌 것
- 본질: **발광 정보가 이해할 수 있는 3D 공간에 붙어 있다.** 물체는 앞뒤가 있고 주석은 기준점에 고정되며 단면과 스캔이 내부 관계를 설명한다. 시점을 움직여도 관객이 무엇을 보는지 알 수 있다.
- 본질이 아닌 것: 어두운 발광 버전의 `minimal-ui`, 장식용 네온의 `synthwave-neon`. 선, 고리, 숫자는 물체를 설명해야 한다. 화면 전체를 빙빙 돌고 깨진 글자를 띄워 기술적인 척하지 않는다.

## 식별 신호: 영상마다 2–3개 선택

| 신호 | 어떤 모습인가 | 적합한 주제 |
|---|---|---|
| 깊이감 있는 와이어프레임 | 앞뒤 모서리의 밝기가 다르고 회전해도 구조가 선명함 | 제품, 시스템, 공간 |
| 고정된 주석 | 리더선 한쪽은 물체에 붙고 다른 쪽은 읽을 수 있는 라벨과 연결 | 기능, 구성, 위치 |
| 스캔 단면 | 물체를 관통하는 단면이 지나가는 부분의 정보를 보여줌 | 검사, 내부, 발견 |
| 부분 실체화 | 일부가 와이어프레임에서 불투명한 면으로 바뀌고 주변에는 원근감이 유지 | 강조, 상태, 선택 |
| 깊이 레이어 | 전경 눈금, 중심 물체, 원거리 기준물이 각각 다른 깊이에 놓임 | 위계, 복잡한 시스템 |
| 공간 눈금자 | 길이, 방향, 범위가 물체 좌표에 붙어 있음 | 규모, 방향, 경계 |
| 층의 분리 | 구조층이 평행하게 벌어지고 리더선이 대응 관계를 유지 | 아키텍처, 모듈, 원리 |
| 제한된 잔상 | 스캔이 지나간 뒤 윤곽이 잠시 남았다가 사라짐 | 감지, 경로, 변화 |
| 투영 기준면 | 물체 아래의 약한 격자나 범위 면이 위치 판단을 돕는다 | 내비게이션, 배치, 레이아웃 |
| 특정 상태만 색상 변화 | 구조 일부나 연결 하나만 색이 바뀌고 나머지는 유지 | 진단, 진행, 차이 |

규칙:
- 영상마다 2–3개를 고르고, 그중 하나 이상은 아래의 “가장 진부한 버전”에 없는 신호로 선택한다. 주제에 맞춰 고른다.
- 인터페이스의 각 레이어는 구체적인 질문 하나에 답해야 한다. 정성 상태나 설명용 구조는 가능하지만 실제 원격 계측, 의료, 성능 데이터에는 출처가 있어야 한다.

## 이 스타일의 가장 진부한 버전
- 화면: 가운데서 지구가 회전하고 주위에 청록색 동심원이 있으며 무작위 백분율이 계속 바뀌다가 마지막에 한 번 흰색으로 스캔됨.
- 사운드: 계속되는 저음 허밍, 패널이 열릴 때마다 삑 소리와 금속 충격음.
- brief의 style 항목에 뒤집은 규칙 또는 고전 표현을 유지한 이유를 적는다. 일부 단면, 따뜻한 색의 투영, 고정 라벨 몇 개만 사용하는 방향을 고려한다.

## 적합성
- 용도: 기술 개념 영상, 제품 구조 설명, 시스템 다이어그램, SF 오프닝, 데이터 상태 표시.
- 콘텐츠: 공간 관계, 탐지, 연결, 복잡한 물체의 계층 구조.
- 부적합: 실제 조작 UI 튜토리얼, 긴 문장을 읽는 콘텐츠, 근거 없이 전문가 진단처럼 보이는 내용.

## 기술 구현
- **공간 물체**: Three.js에서 와이어프레임, 단면, 깊이 관계를 시작할 수 있다. 단순한 메시, 모서리선, 일부 투명 면을 탐색하고 단색에서도 구조가 읽히도록 먼저 구성한다.
- **라벨 레이어**: SVG, Canvas, DOM에 문자와 리더선을 배치한다. 위치는 공간 기준점을 투영해 얻은 다음 가림과 겹침을 처리한다. 필요하면 읽기 영역을 고정하고 리더선으로 물체에 연결한다.
- **발광과 스캔**: WebGL의 국소 밝기, 깊이에 따른 감쇠, 후처리 bloom을 살펴볼 수 있다. 비교적 평면적인 HUD 레이어에는 PixiJS가 적합하다. 화면 전체를 흐리게 해 글자와 물체를 모두 뭉개지 않는다.
- 지정한 시간에 스캔 진행률, 잔상 기록, 물체 자세를 모두 복원할 수 있어야 하며 이전 프레임 누적에 의존하지 않는다. 노이즈는 고정 시드를 사용한다. `--dpr`은 글자와 가는 선이 읽힐 만큼, `--subframes`는 약하게 시작한다. `--grain`은 기본 효과가 아니다.

후보 도구이며 투영 알고리즘, 셰이더, 기존 HUD 컴포넌트를 지정하지 않는다.

## 재질과 렌더링
- 시각적 근거: 실제 홀로그램 광학을 재현한다고 주장하지 않고 SF 투영 영상을 모방한다. 얇은 발광 면, 와이어프레임, 깊이 감쇠로 규칙을 세우고 영상 전체에 같은 규칙을 적용한다.
- 모서리는 선명한 밝은 중심과 제한된 광륜을 가진다. 전경선, 뒷면선, 보조선의 밝기를 구별해 투명 물체가 알아보기 힘든 선 뭉치가 되지 않게 한다.
- 뒷면 구조를 가릴지, 어둡게 할지, 점선으로 표시할지 정하고 물체 위계 전체에 일관되게 적용한다. 투명도만으로 가림 관계를 대신하지 않는다.
- 스캔은 지나가는 부분에만 영향을 주며 단면은 물체와 정확히 맞아야 한다. 읽을 수 있는 주석은 안정적으로 유지하고 스캔 빛에 따라 깜박이지 않게 한다.
- 발광은 기준면에 약하게 비칠 수 있고 범위는 물체의 위치에 따라 달라진다. 주체, 연결선, 라벨의 공간상 소속을 명확히 한다. 화면 모서리의 보조 범례는 2D로 유지한다.

## 색상
아래 색상은 예시다. 방향만 참고하고 그대로 베끼지 않는다.

- 청록 투영: 바탕 `#101B27` / 주선 `#70D8DE` / 상태 `#F0B66C`.
- 호박색 계측기: 바탕 `#211D19` / 주선 `#E7BD73` / 보조 `#A9C5B9`.
- 차가운 흰색과 빨강: 바탕 `#18242D` / 주선 `#DCE7EA` / 상태 `#D76A60`.
- 색상 도출: 발광 주색 하나를 정하고 깊이는 명도로 구분한다. 강조색은 한 가지 상태에만 사용한다. 브랜드색이 너무 어두우면 광륜만 키우지 말고 선의 밝은 중심을 높인다.

## 글꼴
영문 제목은 Space Grotesk, 숫자와 짧은 라벨은 IBM Plex Mono, 중국어는 Source Han Sans를 사용할 수 있다. 모두 OFL 글꼴을 자체 호스팅한다. 텍스트에 행별 스캔이나 색 분산을 적용하지 않는다. 짧은 제목은 라벨보다 한 단계 크게 하고 숫자는 실제 자릿수에 맞춰 공간을 남긴다. 장식 눈금이 본문처럼 보이지 않게 한다.

## 움직임
- 물체 회전은 구조를 알아볼 수 있을 만큼 느려야 한다. 특정 부분을 볼 때 감속하거나 멈춘다. 라벨은 기준점과 함께 움직이지만 정방향으로 읽혀야 하며 가려지면 페이드 아웃한다.
- 패널은 설명하는 구조에 맞춰 등장시킨다. 모든 고리 요소가 계속 제각각 돌게 하지 않는다. 스캔, 단면, 상태 변화 중 한 번에 하나만 강조한다.
- 등장 시 실물 윤곽을 먼저 만들고 정보를 보충할 수 있다. 퇴장 시 레이어 하나를 접거나 투영을 질서 있게 끌 수 있다. 탄성은 가벼운 UI 피드백에만 쓰고 공간 물체 전체에 적용하지 않는다.

## 화면에 생동감 더하기
- 약한 스캔 면이 일부를 천천히 통과하고 스캔 뒤의 물체는 안정적으로 유지한다. 노이즈가 계속 변하지 않게 한다.
- 투영 가장자리 밝기를 아주 미세하게 호흡시킬 수 있지만 텍스트와 중요한 상태는 깜박이지 않는다.
- 실제 동적 데이터가 있으면 해당 영역만 데이터 리듬에 따라 갱신한다. 데이터가 없으면 수치를 고정하고 미세한 시차로 공간감을 유지한다.

## 카메라 문법
| 카메라 움직임 | 표현하는 것 | 적합한 콘텐츠 |
|---|---|---|
| 작은 각도로 공전한 뒤 멈춤 | 공간 구조 확인 | 제품, 시스템, 물체 소개 |
| 단면을 따라 전진 | 외부에서 내부로 진입 | 원리, 층, 검사 |
| 고정 시점에서 레이어를 벌림 | 구성과 연결 구분 | 아키텍처, 모듈 |
| 일부에서 기준면 전체로 후퇴 | 현재 물체의 위치 | 네트워크, 배치, 전체 관계 |

## 사운드 팔레트
1단계에서는 부드러운 FM 음, 저음 펄스, 짧은 노이즈 스윕, 드문 안내음을 사용할 수 있다. 공간 사운드가 더 세밀하게 필요하면 2단계 Tone.js 합성과 효과 처리를 사용하고 트랙을 오프라인으로 재구성할 수 있어야 한다. 스캔 사운드는 단면이 지나가는 범위에 맞추고 안내음은 의미 있는 상태 변화에만 사용한다. 내레이션이 있으면 지속 허밍과 고음 삑 소리를 낮춘다.

리듬과 화성 (예시이며 한 가지로 한정하지 않음): 간격이 있는 전자 펄스, 천천히 변하는 지속 화음, 또는 경쾌하지만 빽빽하지 않은 기술적 리듬. 탐색, 소개, 오류는 서로 다른 감정이며 전부 경고 음악으로 통일하지 않는다.

## 이 매체만의 표현
- 스캔선이 지나가며 윤곽과 일부 정보가 드러남: 탐지와 첫 소개에 적합 (고전 기법).
- 단면 레이어가 바깥으로 벌어지고 리더선으로 원래 연결을 보존: 계층 아키텍처와 내부 구조에 적합.
- 일부가 투명 와이어프레임에서 실체화되고 다른 구조가 어두워짐: 초점과 상태 설명에 적합.
- 물체의 단면에서 2D 다이어그램 안으로 들어감: 개요에서 상세 설명으로 전환할 때 적합.
- 공간 물체의 기준점을 관계 그래프의 중심으로 확장: 시스템 간 연속 전환에 적합.

## 변주 여지
- 구조: 물체 하나를 층층이 검사, 연결을 따라 노드에서 시스템으로 이동, 같은 물체의 두 상태 비교.
- 도입: 문제가 있는 일부만 보임, 기준면이 먼저 켜지고 물체 등장, 전체 물체에서 정보 레이어가 분리됨.
- 끝맺음: 보조 레이어를 접고 핵심만 남김, 읽기 쉬운 단면 요약에서 멈춤, 투영이 다음 물체의 기준점으로 줄어듦.

## 함정
- 숫자가 작동하는 것처럼 보이지만 의미가 없음: 장식 수치를 지우고 실제 데이터에는 출처와 단위를 표시한다.
- 라벨이 물체와 함께 돌아 뒷면을 향함: 라벨은 관객을 향하고 기준점만 공간에 둔다. 가려지면 숨기거나 이동한다.
- 모든 투명 모서리가 같은 밝기: bloom 전에 앞뒤 위계를 세운다.
- 잔상이 이전 프레임에 의존해 렌더 순서가 달라지면 깨짐: 잔상 구간을 시간으로 재구성한다.
- 물체, 고리, 카메라가 모두 동시에 회전: 대부분의 기준은 고정하고 현재 초점만 움직인다.
- bloom 때문에 글자가 하얀 덩어리가 됨: 글자는 별도로 선명하게 유지하고 광륜을 줄인다.
- 설명용 그래픽이 실제 탐지 능력을 암시: 용도와 자료가 일치해야 하며 개념도는 예시라고 표시한다.
