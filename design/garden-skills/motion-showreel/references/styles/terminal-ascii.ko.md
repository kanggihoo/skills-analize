# 터미널 / ASCII(터미널-ascii)

> 모든 것이 고정 너비 문자로 구성되어 있습니다. 명령줄이 입력되고, ASCII 그래픽이 흐르고, 커서가 깜박이고, 차분하고 괴상합니다.
> 참고자료(문법만 학습): 명령줄 인터페이스, ASCII 아트, 데모씬의 텍스트 모드 작품, 해커 영화의 터미널 화면(좋은 부분만 가져옴).

## 본질 / 그것이 아닌 것
- 본질: **문자 격자는 픽셀입니다**; 그래픽은 문자 밀도(` .:-=+*#%@`)를 사용하여 밝고 어두움을 표현합니다. 텍스트는 실제로 문자별로 나타납니다. 커서는 리듬 장치입니다.
- 아닙니다: 녹색 캐릭터의 비가 내리는 진부한 표현입니다. 의미 없는 스크롤 코드로 가득한 화면도 없습니다.

## 신호 식별: 각 영화에 대해 2~3개 선택
| 신호 | 그것은 어떻게 생겼는가 | 적합한 주제 |
|---|---|---|
| 명령을 단어별로 입력하세요 | 프롬프트 뒤의 단어가 하나씩 나타납니다. Enter를 눌러 출력 | 도구, 설치, 하나의 명령 |
| ASCII 밝은 이미지와 어두운 이미지 | 문자 밀도로 그려진 그래픽이나 로고 | 레이아웃, 그래픽 |
| 커서 | 깜박이는 블록 커서 또는 밑줄 커서 | 리듬, 잠깐만 |
| 캐릭터 진행률 표시줄 | `[#####     ] 50%` 진행 유형 | 빌드, 다운로드 |
| 로그 스크롤 | 타임스탬프가 있는 로그는 한 줄씩 위로 스크롤됩니다. | 운영, 모니터링 |
| TUI 패널 | 탭으로 그려진 테두리, 열, 메뉴 | 대시보드, 관리 도구 |
| 색상 차이 | 빨간색 삭제된 줄, 녹색 새 줄 | 코드 변경, 수정 |
| 디렉토리 트리 | ├──와 └──로 구성된 트리 구조 | 프로젝트 구조 |
| 테이블 출력 | 정렬된 열, 머리글 구분 기호 | 데이터, 비교 |
| 인광 스크린 | 약간의 잔광이 있는 황색 또는 녹색 단색 화면 | 레트로, 하드웨어 |
| 다중 창 | 여러 터미널 창이 동시에 나란히 스크롤됨 | 병렬, 협업 |

규칙:
- 각각 2~3개를 선택하세요. 그 중 적어도 하나는 아래의 "가장 뻔한 버전"이 아닙니다.
- 순서대로가 아닌 테마별로 신호를 선택하세요.
- 명령과 출력은 실제여야 하며, 사용자에게 문의하거나 실제 실행 가능한 명령을 사용해야 합니다.

## 이 스타일의 가장 저속한 버전
- 그림: 검정색 배경에 녹색 텍스트, 비처럼 쏟아지는 문자, 화면 전체에 스크롤되는 가짜 코드, 그리고 끝에 "접속 승인됨"이 표시됩니다.
- 사운드: 기계식 키보드 사운드, 저주파 윙윙거리는 소리, 전자 경고음.
- 간략한 스타일 열에는 영화에서 어떤 항목이 제거되었는지 또는 해당 항목이 의도적으로 유지된 이유(예: 사용자가 클래식 버전을 원함)가 나와 있습니다. 기억할 때는 구성, 샷, 리듬 또는 예상치 못한 기억 지점에 집중하세요.## 적응
- 목적: 개발자 제품의 홍보 영상, 타이틀, 로고 해석, 포트폴리오 작품.
- 내용: CLI 도구, AI 에이전트, 오픈소스 프로젝트, 보안, 데이터.

## 기술 경로
캔버스 2D, 고정 문자 그리드(예: 1920×1080 아래의 120×45 그리드, 글꼴 측정에 따라 계산된 그리드 너비 및 높이). 먼저 오프 스크린 캔버스에 표시할 그래픽을 그리고 그리드 샘플링에 따라 문자의 밝기를 매핑합니다. 타이핑 효과는 표시된 문자 수만큼 계산됩니다. 옵션 CRT 포스트(`crt-vhs.md`).

## 재료 및 렌더링
- 문자는 상자별로 정렬되며 글꼴 크기는 균일합니다(제목 그리드가 더 커질 수 있음).
- ASCII 그래픽: 샘플 밝기 → 문자표; 밝기에 따라 다양한 색상을 부여할 수 있습니다.
- 커서: 블록 커서, 0.53초 주기로 깜박임(t를 사용하여 계산, 타이머 없음).
- 명령 출력은 실제처럼 보여야 합니다. 경로, 프롬프트 및 매개변수는 모두 사용자 제품의 실제 명령을 사용합니다(사용자에게 물어보고 꾸며내지 마십시오).

## 컬러 매칭
아래 색상 값은 예시이므로, 아이디어를 보시고 정확하게 복사하지 마세요.
- 검정색 `#0C0C0C` / 밝은 회색 `#D0D0D0` / 녹색 `#5FD75F` / 노란색 `#FFD75F` (표준 터미널 색상의 하위 집합)
- 따뜻한 블랙 `#1C1B19` / 오프화이트 `#E8E3D3` / 오렌지 `#FF8C3B` (레트로 앰버 스크린)
- 밝은 색상 터미널: `#F6F6F2` / `#1E1E1E` / 파란색 `#2F6FEB`
- 규칙: 의미론적 색상 일치(성공 녹색, 경고 노란색, 오류 빨간색), 장식용으로 사용되지 않습니다.
- 파생: 터미널 색상 일치 자체에는 의미(성공 녹색, 경고 노란색, 오류 빨간색)가 있습니다. 배경색은 검정색, 따뜻한 검정색, 밝은 터미널 또는 브랜드 색상의 어두운 버전일 수 있으며 강조 색상은 브랜드에서 나옵니다. 검정색 배경에 녹색 텍스트가 가장 일반적인 그룹입니다.

## 글꼴
JetBrains Mono, IBM Plex Mono, Fira Code, Space Mono(OFL). 영화 전체에는 단 하나의 고정 폭 글꼴만 사용됩니다.

## 스포츠
- 입력: 문자당 20~45밀리초, 구두점 다음에 일시 중지; 출력은 한꺼번에 나타나거나 Enter 명령 후에 덩어리로 나타납니다.
- ASCII 그래픽 변경: 매 프레임마다 리샘플링되며 그래픽 자체가 부드럽게 변경될 수 있습니다(문자가 분리되어 자연스럽게 "거칠게" 보입니다).
- 스크롤: 부드러운 스크롤 없이 전체 줄이 위로 올라갑니다(이것이 터미널이 하는 일입니다).

## 사진을 사는 방법
- 커서가 0.5초마다 깜박입니다. 로그는 백그라운드에서 한 줄씩 팝업됩니다. 캐릭터 진행률 표시줄 `[####    ]`가 실행 중입니다.
- 리샘플링과 흐름을 계속하려면 ASCII 그래픽에 작은 영역을 남겨두십시오. 나머지 캐릭터들은 움직이지 않아 눈이 착지점을 가질 수 있게 되었습니다.## 렌즈 구문
| 카메라 움직임 | 무엇을 표현할 것인가 | 어떤 유형의 콘텐츠가 적합한가요 |
|---|---|---|
| 고정 터미널 창 | 실제 운영 | 명령 시연 |
| 캐릭터에 가까이 다가가면 다음 화면이 됩니다 | 입력 | 전환 |
| 축소하면 하나의 터미널이 여러 터미널의 배열이 됩니다 | 규모, 병렬성 | 에이전트, 유통 |

## 사운드 팔레트
키보드 사운드(음정은 다양하지만 시드가 고정된 짧은 `click`), 캐리지 리턴 사운드, 낮은 드론, 소량의 `blip`. 첫 번째 합성 수준이면 충분합니다.

리듬과 하모니(예를 들어, 이것보다 더 많은 것이 있습니다): 비트 없음(타이핑 리듬이 리듬임) 또는 기계적인 16분음표; 코드, 지속 베이스, 온음계; 폴리도미넌트가 적당하고, 밑에는 `ambience({ kind: 'room' })`가 들어가고, 칩맛을 원하시면 `crush`를 추가하셔도 됩니다.

## 네이티브 메소드
- 한 줄의 명령이 실행된 후 출력에서 ASCII 그래픽이 나옵니다. "하나의 명령으로 하나의 작업을 완료"하는 데 적합합니다.
- 문자 그리드는 전체적으로 로고의 밝고 어두운 이미지가 되어 최종 레이아웃에 적합합니다.
- 여러 터미널을 동시에 스크롤하여 하나로 병합할 수 있어 병렬/협업에 적합합니다.

## 공간 변경
- 구조: 한 번의 설치부터 성공까지의 프로세스입니다. 하나의 에이전트에 하나의 작업; 보고부터 수정까지 하나의 버그.
- 열기: 깜박이는 커서; `$` 프롬프트 뒤의 첫 번째 단어입니다.
- 종료 : 마지막 줄에서 "✓" 출력 후 문자 그리드가 로고를 형성합니다.

## 구덩이
- 명령 구성 및 출력: 명령은 실제적이고 사용 가능해야 하며 사용자에게 요청해야 합니다.
- 녹색 캐릭터는 비와 기타 진부한 표현을 사용합니다.
- 글꼴 크기가 너무 작아 휴대폰에서 명확하게 읽을 수 없습니다. 기본 명령줄은 최소 28px(1080p) 이상이어야 합니다.
