# 중국풍 트렌드 문양 (guochao)

> 전통 문양, 공예품, 색을 현대적인 레이아웃과 리듬으로 다시 구성한다. 상서로운 구름, 회문, 금선, 주홍색을 통해 명절과 옛 분위기를 담되 트렌디한 브랜드 포스터처럼 만든다.
> 참고 (문법만 참고): 중국 전통 문양 (운문, 회문, 해수강애, 덩굴무늬), 전통색 체계, 연화와 문신 형상, 최근 중국 브랜드와 명절 마케팅 비주얼. 특정 브랜드 디자인, 문화재 고해상도 원본, 저작권이 있는 일러스트를 복제하지 않는다.

## 본질 / 본질이 아닌 것
- 본질: **전통의 재료를 현대적인 방식으로 만든다.** 문양, 공예품, 색상은 전통에서 가져오되 구도, 글꼴, 리듬, 모션은 현대적으로 구성한다. 넓은 색면, 강한 대비, 격자 조판, 경쾌한 전환을 사용.
- 본질이 아닌 것: 수묵화의 사의적 표현 (`ink-wash`에 해당하며 여백과 먹의 성질을 다룸), 용과 봉황, 등롱, 중국 매듭을 화면에 가득 쌓은 춘절 갈라 배경.

## 식별 신호: 영상마다 2–3개 선택
| 신호 | 어떤 모습인가 | 적합한 주제 |
|---|---|---|
| 상서로운 구름 | 둥글게 말린 선의 구름무늬가 무리 지어 나타남 | 길상, 하늘, 오프닝 |
| 회문 / 만자문 | 직각으로 꺾이는 연속 테두리 무늬 | 프레임, 전환, 질서 |
| 해수강애 | 겹겹이 쌓인 곡선 파도무늬 | 아래쪽 장식, 기세 |
| 금선 | 가는 금색 선으로 윤곽과 테두리를 그림 | 고급스러움, 선물 상자, 명절 |
| 전통색의 넓은 색면 | 주홍, 남색, 솔잎색, 거위알색을 평면으로 크게 사용 | 브랜드, 포스터 |
| 연화 형상 | 통통한 어린아이, 문신, 둥글고 풍성한 인물 | 춘절, 축하 |
| 공예품 실루엣 | 도자기병, 솥, 부채, 등롱의 기하학적 윤곽 | 문화, 제품 |
| 인장과 전각 | 사각 인장, 주문·백문 | 서명, 인증 |
| 창살과 월문 | 격자 창이나 둥근 달문을 화면 프레임으로 사용 | 전환, 프레임 구성 |
| 덩굴꽃무늬 | 연속되는 덩굴과 꽃 문양 | 장식, 성장 |
| 세로쓰기 서예 제목 | 붓글씨나 큰 명조 글자를 세로로 배치 | 제목, 문구 |
| 현대적 대비색 | 전통 문양에 형광색이나 고채도 대비색을 조합 | 트렌드, 젊은 분위기 |

규칙:
- 영상마다 2–3개를 고르고, 그중 하나 이상은 아래의 “가장 진부한 버전”에 없는 신호로 선택한다.
- 신호는 주제에 맞춰 선택하며 순서대로 전부 쓰지 않는다.
- 문양을 정확히 그린다. 회문은 직각으로 연속되고 상서로운 구름에는 일정한 말림 구조가 있다. 확실하지 않으면 어설픈 장식선을 그리는 대신 해당 문양을 쓰지 않는다.

## 이 스타일의 가장 진부한 버전
- 화면: 진한 빨강 바탕, 금색 구름무늬가 양쪽에서 흘러들고 모서리에 등롱과 중국 매듭을 걸며 중앙에 서예 “복” 자, 끝에 불꽃놀이.
- 사운드: 징과 북, 수오나의 경쾌한 음악과 폭죽 소리.
- brief의 style 항목에 이번 영상에서 뒤집은 규칙이나 고전적인 표현을 유지한 이유를 쓴다. 유지한다면 구도, 카메라, 리듬 또는 예상 밖의 기억에 남는 순간에 공을 들인다.

## 적합성
- 용도: 명절 마케팅 (춘절, 중추절, 단오절), 중국 브랜드와 신소비 브랜드 홍보, 로고 연출, 문화창의 상품, 행사 개막.
- 콘텐츠: 차 음료, 식품, 뷰티, 문화 관광, 게임, 전통 공예의 현대적 표현.
- 부적합: 절제된 이성적 표현이 필요한 기술·데이터 주제, 국제적이고 지역색을 배제한 표현이 필요한 브랜드.

## 기술 구현
Canvas 2D 또는 SVG. 문양은 재사용 가능한 경로 함수 (구름 단위 하나, 회문 단위 하나)로 만들고 격자나 경로를 따라 반복한다. 금선은 가는 선에 선을 따라 움직이는 하이라이트를 더한다. 종이 질감이 필요하면 바탕 위에 옅은 선지나 비단 질감을 겹친다. 반복 문양의 modulo 주기는 단위 문양의 실제 주기와 같아야 스크롤할 때 튀지 않는다.

## 재질과 렌더링
- 문양 단위: 표준 단위를 먼저 그린 뒤 회전, 반전, 반복. 선 굵기를 통일하고 모서리 처리도 일관되게.
- 금선: 금색은 노랑이 아니다. 어두운 금색 → 밝은 금색 → 흰 하이라이트의 그라데이션으로 만들고 하이라이트는 면 전체를 채우지 말고 선을 따라 이동.
- 색면: 평면 색과 깨끗한 가장자리. 층위가 필요하면 같은 계열의 밝고 어두운 색을 쓰고 그라데이션은 사용하지 않음.
- 연화 인물: 둥글고 통통하게, 윤곽선 굵기를 통일하고 양 볼에 홍조.
- 질감: 선지 섬유, 비단의 잔결, 칠기의 광택 중 하나를 선택해 영상 전체에서 통일.

## 색상
아래 색상은 예시다. 방향만 참고하고 그대로 베끼지 않는다.
- 주홍과 금: 주홍 `#C8102E` / 어두운 금 `#B8860B` / 밝은 금 `#E9C46A` / 먹 `#1C1A17` / 선지 `#F3EBDD`
- 청록 산수: 남색 `#1E3A5F` / 솔잎색 `#2E8B57` / 석청 `#5B9BD5` / 황토 `#A0522D` / 미색 `#F5F0E6`
- 트렌디 대비색: 거위알 노랑 `#F6C445` / 연지 `#E03C6E` / 공작 파랑 `#0F7C8C` / 검정
- 색상 도출: 전통 색상 중 주색 2–3개 (주홍, 남색, 솔잎색, 거위알색, 연근색, 월백색 등)를 고르고 금색은 선과 장식에만 쓴다. 넓은 면을 금색으로 채우지 않는다. 브랜드색이 전통색에 대응하면 색 이름과 함께 조합한다. 주홍과 금색이 가장 흔하다.

## 글꼴
- 제목: 서예 글꼴 (ZCOOL XiaoWei, LXGW WenKai, Source Han Serif Heavy; 서예 글꼴은 상업 사용 허가를 확인), 또는 디자인된 굵은 명조체. 세로쓰기도 가능.
- 영어와 숫자: 세리프 (Cormorant, EB Garamond) 또는 현대 레이아웃에 맞는 좁은 산세리프.
- 한 화면에 글꼴 최대 두 종류. 세로 제목과 가로 작은 글자를 조합할 수 있음.

## 움직임
- 수묵화보다 빠르고 신스웨이브보다 안정적. 문양 펼침과 색면 전환은 `snap` 또는 스프링 `{2.4, 0.85}`을 사용하고 반동은 거의 주지 않음.
- 문양의 “성장”: 회문을 경로를 따라 차례로 그리고 상서로운 구름은 말림 한 곳에서 시작해 여러 겹으로 펼침.
- 금빛 하이라이트가 선을 따라 한 번 쓸고 지나감 (0.8–1.5초).
- 연화 인물의 동작은 그림자극이나 인형극처럼 12fps 스텝을 적용할 수 있음.

## 화면에 생동감 더하기
- 상서로운 구름이 천천히 수평으로 흐르고 금선 하이라이트는 몇 초마다 지나가며 등롱의 술은 가볍게 흔들림.
- 해수강애 파도무늬가 주기적으로 물결침 (modulo 주기 = 문양 주기).
- 넓은 색면과 제목이 자리 잡으면 정지. 움직임은 문양과 장식에만 둔다.

## 카메라 문법
| 카메라 움직임 | 표현하는 것 | 적합한 콘텐츠 |
|---|---|---|
| 문을 밀거나 월문을 통과 | 세계 안으로 진입 | 오프닝, 전환 |
| 긴 두루마리를 따라 수평 이동 | 시간, 여정 | 이야기, 제품군 |
| 펼친 문양을 내려다보며 회전 | 질서, 패턴의 아름다움 | 오프닝, 로고 |
| 금선 디테일로 전진 | 공예, 질감 | 고급 제품 |
| 세로 두루마리가 펼쳐짐 | 공개 | 제목, 엔드카드 |

## 사운드 팔레트
전통 악기 음색: 고쟁과 비파는 `pluck`으로 모방 (bright, 짧은 감쇠), 미끄러지는 `lead`로 피리 표현, `mallet({ material: 'wood' })`로 목어와 나무 타악기. 명절에는 큰 북 (`tom` 저음과 긴 리버브)과 심벌을 더할 수 있다. 1단계만으로 가능하며 현악기 소리가 더 실제 같아야 할 때 2단계를 사용한다.

리듬과 화성 (예시이며 한 가지로 한정하지 않음): 오음 음계 (`scale(r, 'gong')`, `'zhi'`, `'yu'`), 또는 오음 선율을 현대 전자 드럼이나 trap 비트에 얹을 수 있다 (중국풍 트렌드에서 흔히 쓰는 방식). 느린 고전풍 패드, 타악기만으로 시작하는 오프닝도 가능하다. 매번 징과 북의 축제 분위기를 낼 필요는 없다.

## 이 매체만의 표현
- 회문이 화면 테두리를 따라 자라 사각 프레임이 되고 제목을 둘러쌈: 오프닝과 엔드카드에 적합.
- 양쪽 문을 밀거나 월문을 통과해 다음 장면으로 이동: 전환에 적합.
- 문양 단위 하나가 반복·회전·확대되어 화면 전체의 바탕 무늬가 된 뒤 다시 로고로 모임: 로고 연출에 적합.
- 두루마리가 세로로 펼쳐지며 세로 제목이 나타남: 제목과 엔드카드에 적합.
- 상서로운 구름이 양쪽에서 들어오고 가운데 “복” 자가 놓임: 고전적인 방식이며 춘절 영상의 첫 아이디어.

## 변주 여지
- 구조: 흙덩이에서 완성품까지 공예품 하나를 보여줌, 1년의 24절기, 전통 문양을 분해해 현대 로고로 다시 조합, 차 한 잔을 따고 마시기까지.
- 도입: 문 하나가 천천히 열림, 흰 종이에 문양 단위 하나를 그림, 인장 하나를 찍음.
- 끝맺음: 두루마리를 말아 로고 봉인을 남김, 인장을 찍음, 문양이 모여 브랜드 표식이 됨.

## 함정
- 요소를 많이 쌓아 춘절 갈라 배경처럼 됨: 한 화면에 문양은 한두 종류만 쓰고 넓은 색면을 남긴다.
- 금색을 노랑처럼 사용: 금색에는 어두운 부분, 밝은 부분, 하이라이트가 있어야 하며 선과 장식에만 쓴다.
- 문양을 잘못 그림: 회문이 아무렇게나 꺾인 선이 되거나 구름이 보통 구름처럼 됨. 적게 쓰더라도 정확히 그린다.
- 간체와 번체 글꼴 혼용, 상업 허가가 없는 서예 글꼴: 글꼴을 통일하고 상업 이용을 확인한다.
- 문화재 고해상도 이미지나 타인의 일러스트를 자료로 사용: 직접 그린 문양이나 사용자가 제공한 자료만 사용한다.
