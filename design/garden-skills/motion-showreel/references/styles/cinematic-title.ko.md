# 시네마틱 타이틀 (cinematic-title)

> 와이드스크린, 필름 그레인, 느린 카메라 전진, 어둠 속에서 떠오르는 큰 세리프 글자. 영화의 오프닝이나 예고편 같은 분위기.
> 참고 (문법만 참고): 영화 타이틀 디자인 (Saul Bass의 그래픽 타이틀, 현대 타이틀 제작사의 타이포그래피 타이틀), 예고편의 리듬 (정적 → 충격 → 타이틀 카드). 특정 영화의 타이틀 디자인이나 화면을 그대로 복제하지 않는다.

## 본질 / 본질이 아닌 것
- 본질: **영화 오프닝의 의식적인 분위기**. 화면은 직접 그린 디스플레이가 아니라 촬영하고 색보정한 듯 보여야 함. 느리고 묵직한 리듬, 적지만 강한 충격, 글자와 화면 사이의 충분한 여백. 와이드 화면비, 필름 그레인, 타이틀 카드는 흔히 쓰이는 수단이며 아래 신호에서 주제에 맞춰 선택.
- 본질이 아닌 것: 검은 레터박스만 둘러친 평범한 영상, 렌즈 플레어를 남용하는 예고편 템플릿.

## 식별 신호: 영상마다 2–3개 선택
| 신호 | 어떤 모습인가 | 적합한 주제 |
|---|---|---|
| 와이드스크린 레터박스 | 2.39:1, 또는 강박에서 레터박스가 조여듦 | 영화적 분위기, 의식 |
| 필름 질감 | 그레인, 은은한 광륜, 비네팅 | 시대감, 질감 |
| 타이틀 카드 리듬 | 암전 → 한 줄의 문구 → 암전 | 예고, 긴장감 |
| 느린 전진 | 카메라가 계속 아주 천천히 다가옴 | 긴장, 무게감 |
| 큰 세리프 글자 | 자간을 넓힌 세리프 영화 타이틀 | 서사시, 고전 |
| Saul Bass풍 그래픽 | 종이를 오려낸 듯한 평면 도형과 선 | 그래픽 타이틀, 서스펜스 |
| 빛과 먼지 | 빛줄기 속 부유하는 먼지, 빛샘 | 분위기, 공개 |
| 사물 접사 | 얕은 피사계 심도의 사물 초근접 촬영 | 디테일, 단서 |
| 손글씨 또는 타자기 글자 | 타자기로 한 글자씩 찍히는 자막 | 다큐멘터리, 시대감 |
| 엔드 크레딧 스크롤 | 출연·제작진 목록처럼 흐르는 글자 | 감사, 마무리 |
| 필름 카운트다운 | 오래된 필름의 숫자 카운트다운 | 복고, 시작 |

규칙:
- 영상마다 2–3개를 선택하고, 그중 하나 이상은 아래의 “가장 진부한 버전”에 없는 신호로 고른다.
- 신호는 주제에 맞춰 선택하며 순서대로 전부 쓰지 않는다.

## 이 스타일의 가장 진부한 버전
- 화면: 틸 앤 오렌지 색보정, 레터박스, 렌즈 플레어, 빛 속에서 현상되는 세리프 타이틀, 묵직한 braam 한 번 뒤 암전.
- 사운드: 저음 boom, braam, 올라가는 스트링 라이저, 피아노 단음.
- brief의 style 항목에 이번 영상에서 뒤집은 규칙이나 고전적인 표현을 유지한 이유를 쓴다 (예: 사용자가 원한 것이 고전 버전인 경우). 유지한다면 구도, 카메라, 리듬 또는 예상 밖의 기억에 남는 순간에 공을 들인다.

## 적합성
- 용도: 오프닝, 예고편, 브랜드 무드 필름, 로고 엔드카드, 출시 카운트다운.
- 콘텐츠: 서사시, 이야기, 역사, 주요 출시, 게임, 기념.

## 기술 구현
Canvas / DOM 타이포그래피 + 화면 콘텐츠 (그래픽, 입자, 3D 등 주제에 따라 선택) + WebGL 후처리 (비네팅, 은은한 광륜, 약한 색수차) + `--grain 6–10`. 16:9 화면 안에 2.39:1 레터박스를 둔다 (위아래 약 12%). 중요 순간에는 레터박스를 열거나 조이는 애니메이션을 줄 수 있다.

## 재질과 렌더링
- 색조: 하이라이트는 따뜻하게, 그림자는 차갑게 (틸 앤 오렌지) 또는 단색조. 대비가 높고 블랙 레벨을 낮춤.
- 빛: 화면의 빛에는 창문, 불, 화면 등 출처가 있어야 함. 체적광 (방사형 블러 광선)을 사용할 수 있음.
- 타이틀 카드: 자간이 넓은 큰 세리프 글자. 중앙 또는 왼쪽 아래 (영화 자막 위치)에 둔다. 카드가 유지되는 동안 아주 느리게 확대 (1.0 → 1.05)할 수 있음.
- 렌즈 플레어는 최대 한 번, 실제 강한 광원이 있을 때만 사용.

## 색상
아래 색상은 예시다. 방향만 참고하고 그대로 베끼지 않는다.
- 틸 앤 오렌지: 그림자 `#0E1A22` / 중간톤 `#3A4A50` / 하이라이트 `#F2C48D` / 글자 `#F4EEE4`
- 따뜻한 단색: `#0B0806` / `#5A4632` / `#E9D8BC`
- 차가운 분위기: `#05080C` / `#2B3A48` / `#C9D6E3` / 빨강 약간 `#B3261E`
- 색상 도출: 영화 색보정은 주제에 맞춘다. 틸 앤 오렌지, 따뜻한 단색, 빨강을 약간 더한 차가운 색, 흑백, 바랜 Kodak 따뜻한 톤 모두 가능하다. 글자 색은 영상 내내 통일한다. 틸 앤 오렌지가 가장 흔한 조합이다.

## 글꼴
세리프 또는 자간이 넓은 디스플레이 글꼴: Cormorant Garamond, Cinzel (주의해서 사용), Playfair Display, Bodoni Moda, Big Shoulders (산업적 분위기). 중국어는 Source Han Serif Heavy 또는 상업적으로 사용 가능한 FZ 계열 세리프 글꼴.

## 움직임
- 느리고 정밀하게: 타이틀 카드는 `{1.6, 0.95}`로 페이드 인 0.6–1.2초 (이 스타일에서는 느린 확대와 빛 변화에 맞춘 페이드를 허용). 카메라는 장면 내내 계속 전진.
- 충격: 암전 전환이나 타이틀 카드의 낙하에 큰 `impact`를 한 번 붙이며 영상 전체에서 2–3회만 사용.
- 리듬: 정적 (긴 숏) → 가속 (컷 간격이 짧아짐) → 충격 → 타이틀 카드 → 암전.

## 화면에 생동감 더하기
- 정적인 구성을 중심으로 한다. 긴 숏의 느린 전진 자체가 움직임.
- 빛줄기 속 먼지, 흐르는 안개, 타이틀 위의 느린 빛 훑기, 전진에 따라 서서히 변하는 렌즈 플레어는 움직여도 됨.

## 카메라 문법
| 카메라 움직임 | 표현하는 것 | 적합한 콘텐츠 |
|---|---|---|
| 암흑 속에서 아주 느리게 전진 | 장중함, 기대 | 오프닝, 공개 전 |
| 초점이 어둠에서 맞아감 | 공개 | 주인공 등장 |
| 빠른 편집 몽타주 | 에너지 상승 | 예고편 클라이맥스 |
| 레터박스가 조이거나 열림 | 감정 전환 | 클라이맥스, 엔딩 |

## 사운드 팔레트
예고편 사운드: sub drone, 저음 `boom`, braam (저음 금관 느낌: 여러 옥타브 낮은 톱니파를 겹쳐 강하게 필터를 여닫음. `pad`의 저음역 + `drive`로 근사 가능), 상승하는 라이저, 충격 직전의 완전한 정적, 피아노 단음 (2단계 Salamander 샘플이 가장 적합).

리듬과 화성 (예시이며 한 가지로 한정하지 않음): half-time 또는 박자 없음, 단음계, 화성단음계, 장3화음의 3도 관계 (웅장한 공개), 지속 저음. 곡선은 숨을 들이쉰 뒤 폭발할 수도 있고 (점점 쌓이다 타이틀에서 정점), 악기가 모두 멈추고 피아노 한 음만 남도록 비울 수도 있다. 넓은 공간감 (`S.space({ room: 0.9 })`), 사이드체인은 사용하지 않음.

## 이 매체만의 표현
- 암전 → 소리 하나 → 한 줄의 글자: 오프닝에 적합.
- 충격 순간 레터박스가 급격히 조이고 다음 숏으로 전환: 클라이맥스에 적합.
- 빛 속에서 영화 타이틀이 현상됨: 엔드카드에 적합 (고전 기법).
- Saul Bass풍 평면 도형이 화면을 가르고 도형 사이에 타이틀을 놓음: 그래픽 오프닝에 적합.

## 변주 여지
- 구조: 세 장의 타이틀 카드 (과거 / 현재 / 미래), 영상 전체를 관통하는 질문 하나와 마지막 줄의 답, 공개일까지 카운트다운.
- 도입: 완전한 암전 속의 빛 하나, 화면보다 먼저 들리는 소리 하나.
- 끝맺음: 빛 속에서 멈춘 로고, 천천히 꺼지는 빛과 이름만 남는 화면.

## 함정
- 모든 화면을 “서사시”처럼 만들면 서사시가 되지 않는다. 정적인 구간을 둔다.
- 그레인이 너무 강하고 화면이 너무 어두워 휴대폰에서 보이지 않는다. 휴대폰 크기로 프레임을 뽑아 확인한다.
- 렌즈 플레어와 슬로모션을 남용한다.
