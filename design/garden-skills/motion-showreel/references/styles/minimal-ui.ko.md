# 미니멀 UI (minimal-ui)

> 깔끔한 무대 위에서 실제처럼 보이는 인터페이스 요소가 변형되고 클릭되고 드래그됩니다. 모든 상태 변화에 스프링 감각이 있습니다.
> 참고 (문법만 참고): Dribbble 수준의 UI 모션, Apple / Linear / Vercel 제품 모션, 공개된 “인터페이스 변형” 프롬프트 예시. 특정 브랜드의 UI나 아이콘을 복제하지 않습니다.

## 본질 / 본질이 아닌 것
- 본질: **인터페이스 자체가 주인공**이며 조용하고 깨끗한 무대에서 실제로 사용됩니다. 요소 하나가 다음 상태로 연속 변형되고 커서가 직접 클릭하고 드래그합니다. 크기와 모서리도 스프링처럼 반응합니다. 무대는 밝은색, 브랜드색, 어두운색 모두 가능하지만 인터페이스보다 눈에 띄지 않아야 합니다.
- 본질이 아닌 것: 사이버 HUD, 어두운 배경 + 네온, 스큐어모피즘, 스크린샷을 이동시키기만 하는 슬라이드쇼.

## 식별 신호: 영상마다 2–3개 선택
| 신호 | 어떤 모습인가 | 적합한 주제 |
|---|---|---|
| 연속 변형 | 버튼 하나가 장면 전환 없이 로딩 → 체크 → 카드로 변함 | 기능 연결, 흐름 |
| 커서 조작 | 커서가 자연스러운 가속 / 감속으로 이동, hover, 누르기, 드래그 | 상호작용, 튜토리얼 |
| 떠오르는 카드 | 부드러운 그림자가 있는 흰 카드가 무대에서 떠오름 | 제품 공개 |
| 앞뒤 가장자리 늘이기 | 표시 막대 이동 시 앞은 빠르고 뒤는 느려져 길게 늘어남 | 전환, 내비게이션 |
| 실제 스크린샷 확대 | 실제 제품 UI의 버튼 하나로 카메라가 다가감 | 제품 홍보 |
| 시스템 컨트롤 | 토글, 슬라이더, 세그먼트 컨트롤, 키보드 단축키 힌트 | 도구 제품 |
| 명령 팔레트 / 검색 | 입력창에 검색어가 한 글자씩 입력되고 결과 목록이 나타남 | 생산성 도구, 개발자 |
| 알림과 toast | 모서리에서 알림이 미끄러져 들어온 뒤 몇 초 후 사라짐 | 상태, 알림 |
| 밝기 테마 전환 | 같은 UI가 라이트와 다크 사이에서 바뀜 | 테마, 설정 |
| 휴대폰 / 창 프레임 | 인터페이스가 미니멀한 기기나 창 프레임 안에 놓임 | 멀티 플랫폼 제품 |

규칙:
- 영상마다 2–3개를 고르고, 그중 하나 이상은 아래 “가장 진부한 버전”에 없는 신호로 선택한다.
- 신호는 주제에 맞춰 고르며 순서대로 모두 쓰지 않는다.
- 실제 제품 UI는 실제 스크린샷을 우선 사용합니다 (stack.md 10절). 신호는 그것을 어떤 방식으로 보여줄지 결정합니다.

## 이 스타일의 가장 진부한 버전
- 화면: 연회색 바탕 + 중앙의 흰 카드 하나 + 파란 강조색, 버튼 → 로딩 원 → 체크 표시, 마지막에 후퇴해 로고 공개.
- 사운드: 부드러운 click, pop, 깔끔한 전자 pluck 선율.
- brief의 style 항목에 뒤집은 규칙이나 고전적인 표현을 유지한 이유를 씁니다 (사용자가 원한 것이 고전 버전인 경우 등). 고전 표현을 유지한다면 구도, 카메라, 리듬, 예상 밖의 기억점에 공을 들입니다.

## 적합성
- 용도: UI 모션 데모, 제품 홍보 영상, 기능 소개, 포트폴리오의 인터페이스 구간.
- 콘텐츠: 앱, SaaS, 개발자 도구, AI 제품, 디자인 시스템.

## 기술 구현
텍스트 렌더링 품질이 우선이면 DOM / SVG, 아니면 Canvas를 사용합니다. render(t)에서 직접 스타일을 설정합니다. 빠른 변형이 많으면 --subframes 4, 가는 선과 작은 글자는 --dpr 2를 사용합니다. 60fps가 더 부드럽습니다.

## 재질과 렌더링
- 둥근 카드 (12–28px), 가는 1.5–3px 테두리 또는 테두리 없음, 부드러운 그림자 (떠오른 레이어에만: 0 20px 60px rgba(0,0,0,.08)).
- 아이콘 선 굵기를 1.75–2px로 통일하고 이모지는 사용하지 않음.
- 커서는 단순한 벡터 화살표. 누르는 순간 0.88배로 줄고 원형 파문이 퍼짐.
- 매우 옅은 그레인 한 겹 ( --grain 2–3 )은 선택 사항.

## 색상
아래 값은 예시이며 방향만 참고하고 그대로 복사하지 않습니다.
- 배경 #EFEDE8 / 카드 #FFFFFF / 잉크 #111111 / 회색 #8A8780 / 강조 #3B5BFF
- 배경 #F5F4F1 / 카드 #FFFFFF / 잉크 #0F0F10 / 강조색은 브랜드색
- 규칙: 강조색은 현재 조작 중인 요소 하나 또는 성공 상태에만 사용합니다.
- 색상 도출: 무대색 (따뜻한 회색, 차가운 회색, 매우 옅은 브랜드색, 어두운색 모두 가능) + 카드 + 잉크 + 강조색 하나. 강조색은 브랜드색 우선이며 파랑이 가장 흔합니다.

## 글꼴
깔끔한 UI 글꼴과 모노스페이스 글꼴 하나를 조합합니다: Geist, Instrument Sans, Manrope, Inter Tight; 모노스페이스는 Geist Mono 또는 JetBrains Mono. 중국어는 Source Han Sans Medium / Bold.

## 움직임
- 스프링 설정: 표시 막대 / 토글은 {3.6, 0.8}, 컨테이너는 {2.4, 0.75}, 큰 제목은 {1.6, 0.95}. 반동은 약간만 허용.
- 앞뒤 가장자리를 분리합니다 (recipes.md 2절). 이동하는 막대가 늘어납니다.
- 컨테이너 안 콘텐츠가 바뀔 때 이전 콘텐츠는 0.1초 동안 흐려지며 사라지고 새 콘텐츠는 0.08초 뒤에 나타남.
- 드래그: 누르고 있는 동안 커서 위치로 값을 계산하고 놓으면 현재 위치에서 스냅 값으로 스프링 복귀.

## 화면에 생동감 더하기
- 대기 커서는 아주 조금 떠다니거나 버튼 위에 부드럽게 머뭅니다. 배경 진행 표시와 수치는 계속 갱신되고 상태 점 (온라인, 녹화 중)은 천천히 맥동합니다.
- 인터페이스 밖에 장식용 모션을 더하지 않습니다. 움직이는 모든 것은 인터페이스에 실제로 있을 법한 상태여야 합니다.

## 카메라 문법
| 카메라 움직임 | 표현하는 것 | 적합한 콘텐츠 |
|---|---|---|
| 현재 상태에 맞춰 확대 / 축소 | 현재 동작에 집중 | 각 UI 상태 |
| 살짝 기울였다가 원래대로 | 상태 전환의 에너지 | 변형 순간 |
| 전체 페이지가 보이도록 후퇴 | 전체 맥락 | 엔딩, 요약 |
| 버튼 하나로 전진 | 다음 기능 진입 | 구간 전환 |

## 사운드 팔레트
UI 효과음이 앞에 옵니다: click, tick, pop, swipe, 성공 시 bell. 음악은 뒤로 둡니다 (gain 0.3–0.4). 플럭 아르페지오 (오음 음계), 가벼운 킥, 부드러운 clap. 1단계 합성으로 충분합니다.

리듬과 화성 (예시이며 한 가지로 한정하지 않음): 곧은 박자, 가벼운 swing (장난스러운 UI), 또는 6/8. 장조 오음계, Lydian. 조작 → 인터페이스 응답의 문답 구성이 잘 맞습니다. mallet (marimba, kalimba)로 pluck을 대체할 수 있습니다. 소리는 짧고 건조하게, 사이드체인은 없거나 아주 약하게.

## 이 매체만의 표현
- 버튼 → 로딩 → 체크 표시 → 카드의 연속 변형을 한 숏에 보여줌: 기능 연결에 적합.
- 끝까지 드래그했을 때 요소가 늘어남: 슬라이더, 음량, 진행 상태에 적합.
- 토글의 점이 다음 컴포넌트의 진행 막대로 바뀜: 단계 연결에 적합.

## 변주 여지
- 구조: 사용자가 작업을 완료하는 전체 흐름, 컴포넌트 하나의 상태 열 개, 같은 카드가 밝고 어두운 테마 사이를 오감.
- 도입: 커서가 버튼을 누르는 프레임 하나, 빈 화면에 커서가 들어옴.
- 끝맺음: 모든 상태가 원래 버튼으로 돌아가 루프를 만들거나, 후퇴해 제품 전체 화면과 로고를 공개.

## 함정
- 확대되는 요소에 will-change를 추가하면 텍스트가 흐려질 수 있음.
- 이전 텍스트와 새 텍스트가 겹침.
- 그림자가 너무 진하거나 테두리가 두꺼워 저렴하게 보임.
- 사용자 제품을 대신해 CSS로 가짜 UI를 그림: 실제 제품은 실제 스크린샷으로 보여줘야 함.
