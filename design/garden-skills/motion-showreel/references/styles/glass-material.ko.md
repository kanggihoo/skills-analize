# 유리와 금속 재질 (glass-material)

> 유리, 금속, 빛으로 이루어진 주체가 끝없이 어두운 공간에 떠 있다. 막대 조명이 윤곽을 훑고 카메라는 느리고 정밀하게 움직인다.
> 참고 (문법만 참고): 고급 제품 출시 영상의 어두운 공간 속 막대 조명 촬영, 투명 하드웨어 분해도, 매크로 초점 이동. 실제 제품의 외형, 브랜드, 글꼴을 복제하지 않는다.

## 본질 / 본질이 아닌 것
- 본질: **재질과 빛이 주인공이다.** 투명한 유리 윤곽과 색 분산 가장자리, 금속의 빛 띠, 비쳐 보이는 내부 부품. 모든 움직임은 느리고 정밀하며 박자에 맞춰 움직임.
- 본질이 아닌 것: 흰 배경의 상품 사진, 와이어프레임 HUD, 코드로 실제 브랜드 제품을 모방해 만드는 것.

## 식별 신호: 영상마다 2–3개 선택
| 신호 | 어떤 모습인가 | 적합한 주제 |
|---|---|---|
| 막대 조명이 윤곽을 훑음 | 어두운 공간에서 긴 막대 빛이 가장자리를 따라 이동 | 제품 공개 |
| 투명한 외피 | 외피를 통해 내부 부품이 보임 | 원리, 공예 |
| 색 분산 가장자리 | 두꺼운 유리 가장자리에 얇은 무지개색 띠 | 광학, 정밀함 |
| 집광 고리 | 바닥에 퍼지고 흔들리는 빛의 고리 | 범위, 신호 |
| 분해도 | 부품이 축을 따라 벌어지고 떠 있다가 다시 결합 | 구조, 구성 |
| 무광에서 투명으로 | 거칠기가 0으로 낮아지며 내부가 나타남 | 프라이버시, 투명성 |
| 내부의 빛 | 에너지나 데이터가 내부를 흐르는 빛으로 표현 | 배터리, 네트워크, 프로세서 |
| 렌즈 확대 | 두꺼운 유리가 뒤의 사물을 확대 | 렌즈, 필터링 |
| 금속 빛 띠 | 헤어라인 금속 위로 하이라이트가 움직임 | 제작, 질감 |
| 매크로 초점 이동 | 두 디테일 사이로 초점이 이동 | 세부, 비교 |
| 유리 속 액체나 기포 | 투명한 용기 속 액체가 천천히 흐름 | 음료, 향, 화학 |

규칙:
- 영상마다 2–3개를 고르고, 그중 하나 이상은 아래의 “가장 진부한 버전”에 없는 신호로 선택한다.
- 신호는 주제에 맞춰 선택하며 순서대로 전부 쓰지 않는다.

## 이 스타일의 가장 진부한 버전
- 화면: 검은 배경에서 유리구나 정육면체 하나가 천천히 회전, 무지개 분산이 표면 전체에 번지고 파랑·보라 조명, 마지막에 로고가 떠오름.
- 사운드: 저음 drone, 유리 종소리, 상승하는 riser.
- brief의 style 항목에 이번 영상에서 뒤집은 규칙이나 고전적인 표현을 유지한 이유를 쓴다. 유지한다면 구도, 카메라, 리듬 또는 예상 밖의 기억에 남는 순간에 공을 들인다.

## 적합성
- 용도: 제품 홍보 영상, 로고 연출 (로고를 유리로 표현), 기술 주제 오프닝.
- 콘텐츠: 하드웨어, 웨어러블, 에너지, 고급 브랜드, 추상 개념을 “실물화”하는 영상.

## 기술 구현
Three.js (로컬 설치, importmap 사용). `MeshPhysicalMaterial`: 투명 유리는 transmission 1, roughness ≈ 0.02, ior ≈ 1.5. 굴절 강도는 thickness로 조절한다. 무광 유리는 transmission ≈ 0.85, roughness ≈ 0.4로 설정하고 안쪽이나 뒤에 밝은 물체를 둔다. 그렇지 않으면 어두운 공간에서 회색 플라스틱처럼 보인다. 금속은 낮은 roughness를 사용한다. 조명 환경은 창문이나 잡동사니가 유리에 비치는 스튜디오 HDRI 대신 발광 평면 막대 조명으로 작은 장면을 코드로 구성하고 `PMREMGenerator.fromScene`으로 환경 맵을 만든다. 후처리는 피사계 심도 (매크로 촬영에서는 얕게), bloom은 밝기 > 1인 부분에만 적용. `--dpr 2`로 렌더링하고 그레인은 넣지 않는다.

## 재질과 렌더링
- 막대 조명: 윤곽을 드러내도록 높은 발광 평면을 주체의 뒤와 옆에 두고, 약한 위쪽 조명 하나, 시간에 따라 훑는 “스윕” 조명 평면 하나를 둔다. 실제 기하 도형이므로 하이라이트, 굴절, 색 분산이 물리적으로 움직인다. 2D 하이라이트를 그리지 않는다.
- 바닥: 검은 광택 바닥, 흐린 반사, 방사형 페이드, 수평선 없음.
- 내부 부품: 투명 외피 안의 물체는 불투명 재질이어야 한다 (굴절 채널은 불투명한 사물만 볼 수 있음).
- 내부를 흐르는 빛: 도광판의 UV 방향을 따라 움직이는 발광 펄스 (`onBeforeCompile`로 셰이더 수정).

## 색상
아래 색상은 예시다. 방향만 참고하고 그대로 베끼지 않는다.
- 공간은 중립적: 검정, 회색, 막대 조명의 흰색, 금속 자체의 색조.
- **강조 색조 하나만 빛에 사용** (발광, 집광 고리, 색 분산선): 얼음 파랑 → 연보라, 호박색 → 장미색, 초록 → 청록.
- 무지개 색 분산은 두꺼운 유리 가장자리와 집광에만 나타나고 표면이나 글자에는 사용하지 않는다.
- 색상 도출: 공간은 중립적 (검정, 회색, 막대 조명의 흰색, 금속 원색)으로 두고 강조 색조 하나만 빛에 사용한다. 강조색은 브랜드나 제품 재질에서 가져온다. 얼음 파랑에서 연보라로 이어지는 조합이 가장 흔하다.

## 글꼴
매우 가는 굵기 (200)와 넓은 자간의 산세리프 제목을 화면의 위쪽 1/3에 배치하고 대각선 빛과 스윕 조명이 동시에 지나가게 한다. 작은 글자는 자간을 넓힌 대문자를 사용.

## 움직임
- 모든 상태는 `render(t)` 안에서 설정하고 `THREE.Clock`은 사용하지 않는다.
- 카메라는 천천히 공전하거나 전진하며 계속 떠다닌다. 고정하거나 핸드헬드처럼 흔들지 않는다.
- 분해도: 부품을 축을 따라 벌린다 (ease-out, 제품 크기의 약 2배). 잠시 띄웠다가 강박에서 짧은 ease-in으로 결합.
- 빛 펄스와 스윕은 모두 박자에 맞춘 이벤트.

## 화면에 생동감 더하기
- 환경 맵이 천천히 돌아 유리와 금속의 반사가 계속 흐르고 바닥의 집광 패턴이 느리게 이동.
- 카메라는 계속 떠다니지만 (움직임 규칙에 포함) 사물 자체는 완전히 정지해도 된다.

## 카메라 문법
| 카메라 움직임 | 표현하는 것 | 적합한 콘텐츠 |
|---|---|---|
| 어둠 속 주체를 훑으며 천천히 전진 | 먼저 윤곽, 다음에 내용 | 미지의 대상, 공개 |
| 높은 3/4 시점에서 천천히 공전 | 전체 모습 관찰 | 구조 전개, 여러 버전 |
| 외피에서 내부 부품으로 초점 이동 | 숨겨진 것이 없음 | 성분, 센서 |
| 시선에서 약 40° 축을 둔 분해도 | 기술적 아름다움, 부유감 | 구조, 전환 전 정지 |
| 낮은 시점에서 올려다봄 | 기념비적 느낌 | 내구성, 플래그십 |
| 천천히 후퇴해 여백으로 들어감 | 글자 공간 확보 | 슬로건, 엔딩 |

## 사운드 팔레트
미니멀 전자음: 유리 같은 FM 벨 (`bell`, ratio 3.5), 입자 shimmer, 정밀한 tick 격자, 따뜻한 패드, sub drone, 짧고 부드러운 킥. 스윕에는 대역 통과 노이즈를 섞은 유리 마찰음, 결합에는 몇 ms 간격의 click 여러 개와 비화성 유리 화음 하나를 사용. 결합 전에 완전히 조용한 구간을 둔다. 공간감이 중요할 때 2단계 (Tone.js 컨볼루션 리버브).

리듬과 화성 (예시이며 한 가지로 한정하지 않음): 느리고 정밀하거나 박자가 없는 구성, Lydian, maj7#11, 4도 쌓기. `vox` (모음 'o' / 'u')로 투명한 보컬 패드를 만들 수 있다. 소리를 비우는 곡선이 잘 어울린다. 밝고 긴 공간감 (`S.space({ room: 0.88, damp: 0.1 })`).

## 이 매체만의 표현
- 투명도: 초점을 외피에서 내부 부품으로 옮김. 원리를 “볼 수 있음”을 나타낼 때 적합.
- 렌즈: 두꺼운 유리가 뒤의 물체를 확대. 렌즈, 필터링, 확대 기능에 적합.
- 내부의 빛: 에너지, 데이터, 열이 눈에 보이는 빛으로 흐름. 배터리, 네트워크, 프로세서에 적합.
- 집광: 내부 펄스가 바닥에 퍼지는 빛의 고리로 바뀜. 범위, 신호, 향에 적합.
- 무광에서 투명으로: roughness를 0으로 애니메이션해 내부를 공개. 프라이버시, 투명성, 솔직함에 적합.

## 변주 여지
- 구조: 내부에서 빛나는 요소가 무엇인지 버전 세 개를 비교, 아침부터 밤까지 사물에 비치는 빛, 핵심에 도달할 때까지 외피를 층층이 분해.
- 도입: 내부 부품 하나를 먼저 보여준 뒤 외피를 주변에 형성, 바닥의 집광을 먼저 보여주고 빛을 따라 사물을 찾음.
- 끝맺음: 사물은 사라지고 집광만 계속 움직임, 빛이 천천히 꺼지고 윤곽만 남음.

## 함정
- 어두운 바탕의 무광 유리가 검은 플라스틱처럼 보임: 내부나 뒤에 밝은 물체를 둔다.
- AgX 톤 매핑이 강조색을 흰색처럼 바꿈: Neutral 톤 매핑을 사용한다.
- 분해도 축이 시선과 수직이라 선 하나처럼 보임: 축과 시선을 약 40°로 둔다.
- 소프트웨어 렌더링이 매우 느림: `check-env`에서 소프트웨어 렌더링이 표시되면 해상도를 낮춰 시간을 먼저 측정한다.
