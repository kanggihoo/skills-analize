# 채색 필사본 (illuminated-manuscript)

> 양피지 위에 잉크 글자, 광물 안료, 금분 또는 금박을 올린다. 장식 첫 글자와 여백 삽화가 이야기를 품고 천천히 살아난다.
> 참고 (문법만 참고): 유럽의 채식 필사본, 고딕 장식 첫 글자, 세밀한 여백화.

## 본질 / 본질이 아닌 것
- 본질: 페이지를 구도 단위로 삼고 텍스트, 삽화, 귀한 금 장식을 하나의 수공예품처럼 구성한다. 금색 재질의 변화와 종이의 고요함이 함께 질감을 만든다.
- 금분 채색과 금박 표면은 다르므로 선택한 공예 방식에 맞게 처리한다. 모든 금색을 거울처럼 반사하지 않는다. 스테인드글라스는 빛 투과에 의존하지만 이 스타일은 종이 위 안료와 금속의 반사에 의존한다.

## 식별 신호: 영상마다 2–3개 선택

| 신호 | 어떤 모습인가 | 적합한 주제 |
|---|---|---|
| 장식 첫 글자 | 큰 글자에 식물이나 세밀화가 얽혀 있음 | 문학, 시작, 브랜드 첫 글자 |
| 울퉁불퉁한 금박 바탕 | 금 장식에 잔결, 이음매, 압인이 있음 | 공예, 수집품 |
| 국소 반사 | 빛이 지나갈 때 금속 부분만 뚜렷하게 밝아짐 | 발견, 깨움 |
| 양피지 페이지 | 따뜻한 섬유결, 가장자리 색 차이, 얕은 주름 | 책, 기억 |
| 붉은색·파란색 광물 안료 | 두꺼운 평면 채색과 섬세한 먹선 | 역사, 우화 |
| 여백 덩굴무늬 | 본문을 덮지 않고 판면 주변을 감싼 줄기와 잎 | 성장, 시간 |
| 주홍색 도입 표기 | 짧은 제목이나 첫 문장을 빨간색으로 구분 | 장, 명명 |
| 여백의 작은 생물 | 새나 짐승이 페이지 경계 안에서 제한된 동작을 함 | 짧은 우화, 문화 |
| 이단 조판 또는 정돈된 필사 행 | 일정한 행간의 글을 삽화가 일부 깨뜨림 | 독서, 기록 |
| 수작업 압인 | 빛에 따라 금박의 점무늬와 새김선이 드러남 | 디테일, 재질 |

규칙: 영상마다 2–3개를 고르고 적어도 하나는 진부한 표현에서 벗어난 신호를 선택한다. 구체적인 지역, 시대, 서체에는 근거가 있어야 한다. 판타지 창작은 현대적 재해석이라고 명시한다.

## 이 스타일의 가장 진부한 버전

- 화면: 누런 종이, 검은 고딕 글자, 화면 가득한 금색 그라데이션, 대칭 덩굴무늬, 떠다니는 별빛.
- 사운드: 장엄한 합창과 종소리, 금색이 밝아질 때마다 마법 종소리.
- brief에 어떤 고전 신호를 유지하고 페이지를 주제에 맞춰 어떻게 재구성할지 쓴다. 작고 유머러스하거나 진지하게 만들 수 있으며 종교 이야기를 기본으로 가정하지 않는다.

## 적합성

- 용도: 문화·예술 오프닝, 책 홍보, 문학 주제, 귀한 공예, 짧은 우화.
- 콘텐츠: 천천히 읽을 가치가 있는 글, 책 페이지 안의 동작, 장식과 의미가 연결되는 주제.
- 정확한 재현은 시대와 출처를 밝혀야 한다. 사료 근거가 없는 요소는 허구 디자인으로 표시하고 문화재 복제라고 주장하지 않는다.

## 기술 구현

- Canvas나 SVG로 종이, 안료, 먹선, 금 장식, 움직이는 삽화를 분리한다. 정적인 복잡한 장식은 캐시할 수 있으며 빛과 동작만 시간에 따라 갱신한다.
- 금 장식은 기하 마스크와 재질 레이어로 따로 만든다. 화면의 노란색을 임계값으로 골라 종이나 피부까지 금으로 처리하지 않는다. WebGL은 미세 법선, 거칠기, 방향성 반사를 처리할 수 있다. Canvas는 고정 텍스처와 제어된 빛 띠로 근사할 수 있다.
- 페이지 넘김이나 분명한 측면 시점이 필요하면 Three.js의 얇은 페이지 메시, 양면 재질, 국소 휨을 고려한다. 정면 페이지에 기술 복잡성을 위해 3D를 억지로 추가하지 않는다.
- SVG 경로는 덩굴이 자라거나 제한된 관절 애니메이션을 만드는 데 적합하다. 곡선 정리는 Paper.js로 보조할 수 있다. 삽화의 구조와 가림은 사람이 확인해야 한다.
- 느린 동작은 `--subframes 1–2`가 적합하고 섬세한 장식은 `--dpr`을 높일 수 있다. 텍스처는 페이지 좌표에 고정하며 화면 전체에 프레임마다 노이즈를 뿌리지 않는다.

## 재질과 렌더링

- 제작 근거: 먼저 페이지 본문과 삽화 위치를 정하고 먹선, 안료, 국소 금박을 올린 뒤 문지르거나 압인한다. 각 재료의 반사 범위를 구분한다.
- 양피지는 대비가 낮은 섬유결, 부분적인 색 차이, 가장자리 어두워짐으로 표현한다. 얼룩이 글자를 가리지 않게 하고 축소 후에도 종이로 읽히게 한다.
- 광물 안료는 풍부한 평면 채색을 사용하고 두께 차이로 약간의 불균일함을 준다. 주체, 잎, 첫 글자도 같은 방식으로 처리해 매끈한 캐릭터가 낡은 종이 위에 붙은 느낌을 피한다.
- 금박은 잔주름, 작은 이음매, 밝기 변화가 있을 수 있다. 금분 붓칠은 더 가늘고 무광이며 고르다. 압인의 어두운 가장자리와 밝은 가장자리는 같은 입사 방향을 따른다.
- 금속 하이라이트는 광원이나 관찰 방향에 따라 바뀌며 금 장식 마스크 안에만 나타난다. 넓은 빛 띠로 재질을 표현하고 작은 반짝임은 장식으로만 쓴다. 금속 느낌을 별 모양으로 대신하지 않는다.

## 색상

예시는 방향만 참고하고 그대로 베끼지 않는다.

- 주홍·파랑·금: 종이 `#EDE0BF` / 파랑 `#294A79` / 주홍 `#A93F35` / 금 `#B58A39`.
- 식물 필사본: 종이 `#EAE3CA` / 초록 `#415F46` / 먹 `#45372D` / 금 `#C3A458`.
- 황혼의 페이지: 종이 `#DCCCAE` / 보라 `#63516D` / 빨강 `#9A414C` / 금 `#AA7D34`.

먼저 종이, 먹, 주 안료, 금속색을 정한다. 금속의 밝은 곳은 연한 크림색에 가까울 수 있지만 어두운 곳은 갈색을 띤 노랑으로 남겨 보통의 노란색 채움처럼 보이지 않게 한다. 본문은 진한 먹으로 대비를 확보한다.

## 글꼴

짧은 라틴어 제목에는 자체 호스팅하는 OFL 글꼴 UnifrakturMaguntia, Cormorant Garamond를 쓸 수 있고, 중국어에는 Source Han Serif를 사용할 수 있다. 검은 고딕체는 읽을 수 있는 짧은 내용에만 쓰며 긴 본문을 장식 글꼴로 억지로 처리하지 않는다. 역사적 원문은 사실을 확인하고 현대 창작에는 읽기 쉬운 문자를 쓴다. 가짜 라틴어를 만들지 않는다.

## 움직임

- 페이지를 안정된 무대로 삼고 덩굴, 새, 글자 등 내용에 맞는 일부만 움직인다. 동작 범위는 삽화 비율과 페이지 여백 안에서 정한다.
- 잎은 줄기의 순서에 따라 펼쳐지고 약간의 지연을 줄 수 있지만 장식을 전부 동시에 호흡시키지 않는다.
- 빛은 방향을 유지하며 연속적으로 이동한다. 카메라가 멈춘 뒤에는 반사가 한 번 천천히 지나가고 조용한 엔드카드로 이어진다.
- 페이지를 넘길 때 앞뒷면, 그림자, 가림 관계를 처리한다. 넘김이 필요하지 않으면 페이지를 고정하고 만능 책 넘김 전환을 쓰지 않는다.

## 화면에 생동감 더하기

- 동작이 발생하는 위치에서 잎 한 장이 살짝 휘고 먼 쪽의 잎은 가만히 둔다.
- 움직이는 빛이 금박의 명암을 바꾸되 종이와 안료는 무광을 유지한다.
- 여백의 작은 생물이 잠시 뒤돌거나 몸을 내밀거나 먹선을 따라 움직인 뒤 읽을 수 있는 자세로 돌아온다.

## 카메라 문법

| 카메라 움직임 | 표현하는 것 | 적합한 콘텐츠 |
|---|---|---|
| 금 장식 접사에서 후퇴 | 공예 디테일에서 페이지 전체로 | 수집품, 오프닝 |
| 판면을 따라 천천히 이동 | 글자나 장식의 흐름 | 독서, 여정 |
| 고정된 페이지 일부에서 작은 동작 | 장식 안에서 벌어지는 이야기 | 우화, 캐릭터 |
| 살짝 비스듬한 시점이나 스치는 빛 | 압인과 금속을 드러냄 | 재질, 공예 |
| 근거 있는 페이지 넘김 | 시간이나 장의 전환 | 문학, 역사 |

## 사운드 팔레트

1단계에서 성긴 플럭, 부드러운 오르간, 약한 마찰음, 종이 넘기는 합성음을 쓸 수 있다. 구체적인 고악기 소리가 필요하면 2단계에서 라이선스가 확인된 샘플을 쓰고 음원 출처를 정확히 표시한다. 합성 플럭을 실제 류트 녹음이라고 부르지 않는다.

리듬은 박자 없는 열린 5도, 가벼운 3박자, 촘촘한 플럭의 문답이 가능하다. 작은 광택 변화에는 소리를 붙일 필요가 없다. 긴 리버브를 쓰더라도 종이 효과음은 가까운 거리감을 유지한다.

## 이 매체만의 표현

- 첫 글자에서 가지와 잎이 페이지 여백으로 뻗음: 글자에서 이야기가 펼쳐지는 장면에 적합 (고전 기법).
- 빛이 한 번 지나가며 보이지 않던 압인이 드러남: 발견과 수집품에 적합.
- 여백의 생물이 삽화 안으로 걸어갔다가 글자 옆으로 돌아옴: 책 속 세계와 읽기의 관계에 적합.
- 먹선이 형태를 먼저 만들고 안료와 금 장식이 층별로 드러남: 공예 과정을 보여줄 때 적합.
- 종이가 살짝 휘고 금 장식만 빛나며 안료는 변하지 않음: 재료 비교에 적합.

## 변주 여지

- 구조: 금 장식 접사에서 페이지 전체로, 페이지 안의 짧은 이야기, 글쓰기와 금박 과정을 따라 층별로 완성.
- 도입: 무엇인지 알아보기 어려운 압인, 이미 펼쳐진 책, 판면 옆에서 일어나는 작은 움직임.
- 끝맺음: 읽을 수 있는 페이지 전체로 돌아감, 여백 속에 동작 하나를 감춤, 다음 페이지가 시작될 위치를 명확히 남김.

## 함정

- 황갈색 종이와 금색을 함께 밝게 훑음: 금 장식 전용 마스크를 쓰고 종이, 안료, 금속의 밝기 변화를 따로 확인한다.
- 그라데이션만 있고 미세 구조가 없음: 고정된 주름, 이음매, 압인을 더한다. 금분과 금박을 같은 표면처럼 섞지 않는다.
- 별빛이 너무 많고 페이지 전체가 빛남: 반짝임을 줄이고 반사 방향과 거칠기로 재질을 표현한다.
- 덩굴이 글자를 너무 빽빽하게 둘러쌈: 판면을 먼저 확보한 뒤 장식을 놓는다. 카메라가 멀어진 상태에서 한글과 짧은 제목을 확인한다.
- 배경은 낡았는데 주체가 벡터 스티커처럼 보임: 먹선과 안료 질감을 공유하고 가장자리 처리를 통일한다.
- 페이지 장식 전체가 계속 흔들림: 이야기 동작이 일어나는 곳만 움직이고 나머지는 읽을 여백으로 둔다.
- 카메라가 다가왔다 멀어질 때 본문이 화면 가장자리에 잘림: 온전히 읽을 수 있는 구도에서만 본문을 보여주거나 판면과 카메라를 먼저 조정한다.
- 캐릭터의 시작과 끝은 글자를 피하지만 이동 중에는 제목을 가로지름: 전체 이동 경로에 금지 영역을 두고 날개와 꼬리 깃털 등 중심보다 튀어나오는 부분까지 확인한다.
