# 시대별 매체 혼합 (mixed-media-era)

> 시대나 단계마다 픽셀, 벡터, 셰이더, 3D, 손그림 등 다른 매체로 표현하고 한 줄기로 이어 하나의 영상을 만든다.
> 참고 (문법만 참고): 공개된 코드 구현형 “비디오게임 발전사” 단편 (Canvas 픽셀 + CRT 셰이더 + Three.js 3D + 합성 음악), 매체사를 다루는 다큐멘터리 오프닝. 구체적인 작품은 복제하지 않는다.

## 본질 / 본질이 아닌 것
- 본질: **매체 자체가 콘텐츠다.** 어느 시대를 말하는지에 따라 해당 시대의 시각 기술을 사용하고, 구간 전환은 “매체 업그레이드”가 된다. **영상 전체를 관통하는 한 줄기가 필요하다** (같은 주인공, 같은 전환 문법, 단계적으로 발전하는 같은 음악).
- 본질이 아닌 것: 여러 스타일을 무작위로 이어 붙인 템플릿 모음. 연결하는 줄기가 없으면 산만하게 흩어진다.

## 식별 신호: 영상마다 2–3개 선택
| 신호 | 어떤 모습인가 | 적합한 주제 |
|---|---|---|
| 암각화, 벽화 | 황토색 손바닥 자국, 새김선, 벗겨진 벽면 | 기원, 선사 시대 |
| 인쇄물 | 활자, 신문 하프톤, 리소그래프 별색 인쇄 | 출판, 정보, 19–20세기 |
| 필름 | 입자, 긁힘, 깜박임, 흑백 또는 빛바랜 색 | 영화, 기억 |
| 손그림 셀 애니메이션 | 12fps 선화와 평면 채색 | 애니메이션, 어린 시절 |
| CRT와 비디오테이프 | 스캔라인, 트래킹 노이즈, OSD 문자 | 80–90년대, 텔레비전 |
| 픽셀 | 작은 캔버스, 고정 팔레트, 프레임 스텝 | 게임, 초기 컴퓨터 |
| 터미널 문자 | 모노스페이스 문자, 초록색 / 호박색 화면 | 컴퓨터, 초기 인터넷 |
| 플랫 벡터 | 깔끔한 기하 형태와 평면 채색 | 모바일 인터넷, 현대 |
| 3D 렌더 | 빛과 그림자, 재질, 공간 카메라 | 최근, 미래 |
| 셰이더 / 생성형 | 노이즈 장, 입자, 유체 | 알고리즘, AI, 미래 |
| 종이 공예와 실물 | 종이 자르기, 점토, 수작업 질감 | 수공예, 개인사 |

규칙:
- 영상마다 2–3개를 고르고, 그중 하나 이상은 아래의 “가장 진부한 버전”에 없는 신호로 선택한다.
- 신호는 주제에 맞춰 선택하고 나열된 순서대로 전부 사용하지 않는다.
- 매체는 주제의 실제 역사에서 선택한다. 출판 역사는 활자 인쇄에서 화면으로, 음악은 음반 커버에서 스트리밍 인터페이스로, 한 인물의 이야기는 어린 시절 낙서에서 직장 화면으로 전환할 수 있다.
- 영상 전체를 관통하는 줄기를 하나 이상 선택한다: 주인공 하나, 같은 구도 뼈대, 같은 전환 문법, 단계별 편곡이 발전하는 음악 한 곡.

## 이 스타일의 가장 진부한 버전
- 화면: 게임 역사 연대기처럼 픽셀 → 16비트 → 로우폴리 3D → 현대 렌더 순으로 보여주고, 끝에서 모든 시대 화면을 벽처럼 이어 붙여 로고로 모음.
- 사운드: 칩튠 음악 → 신시사이저 → 오케스트라로 단계별 발전.
- brief의 style 항목에 이번 영상에서 뒤집은 규칙이나 고전적 표현을 유지한 이유를 쓴다. 유지한다면 구도, 카메라, 리듬 또는 예상 밖의 기억점에 힘을 줍니다.

## 적합성
- 용도: 역사 회고, 포트폴리오, 제품 진화사, 브랜드 기념일. 보통 길이가 깁니다 (60초–2분). 60초를 넘으면 구간별로 제작하고 확인합니다.
- 콘텐츠: 게임 역사, 인터넷 역사, 기술 발전, 브랜드 역사, 개인 성장.

## 기술 구현
페이지 하나에 구간별 렌더러 함수 여러 개를 두고 (각자 Canvas / WebGL / Three.js 사용) timeline.js의 구간 시간으로 스케줄링합니다. 카메라 추상화와 전환 함수는 공유합니다. 렌더링이 느린 구간 (3D, 셰이더)은 --start와 --duration을 써서 따로 측정하고 다시 렌더링합니다. 기술 세부는 해당 스타일 파일 (pixel-game.md, crt-vhs.md, glass-material.md 등)을 참고하되 색상과 글꼴은 영상 전체의 중심 줄기를 따릅니다.

## 재질과 렌더링
- 각 구간은 시대 매체의 실제 제약을 지킵니다 (픽셀 구간은 실제 16색만, CRT 구간은 실제 스캔라인). 이 제약이 신뢰감을 만듭니다.
- 주인공 기호, 빛 점, 제목 글자 등 관통 요소는 매체마다 해당 매체 방식으로 다시 그립니다: 픽셀 버전, 벡터 버전, 3D 버전 등. 관객이 “같은 것”임을 바로 알아봐야 합니다. **관통 요소에도 해당 매체의 재질 처리** (픽셀화, 스캔라인, 종이결, 붓 터치)를 적용해야 합니다. 배경만 새 매체로 바꾸고 주인공을 원래 벡터 그대로 두면 위에 붙인 스티커처럼 보입니다.
- **구도 뼈대는 고정합니다.** 주인공, 수평선, 제목, 카운터의 위치를 매 구간에서 같은 좌표계에 맞춥니다 (코드 상수 하나에 정의해 각 구간에서 가져다 씀). 뼈대를 고정하면 관객이 달라진 매체를 알아보기 쉽고 전환도 같은 물체에서 시작할 수 있습니다. 구도를 바꾸는 구간은 의도한 예외로 스토리보드에 기록합니다.
- 연도 / 라벨 카드의 타이포그래피는 영상 전체에서 통일합니다. 이것도 관통 요소입니다.

## 색상
아래 값은 예시입니다. 방향만 참고하고 그대로 복사하지 않습니다.
- 각 구간은 매체의 대표 팔레트를 쓰되 영상 전체에 강조색 하나를 고정 (예: 관통 요소는 늘 같은 색).
- 타이틀 카드의 색상은 영상 내내 통일.
- 색상 도출: 각 구간은 매체의 대표 팔레트를 쓰고 영상 전체에 고정 강조색 하나를 반복합니다 (관통 요소의 색을 브랜드에서 가져옴). 타이틀 카드 색상도 전체에서 통일합니다.

## 글꼴
- 타이틀 카드는 영상 전체에서 글꼴 하나를 통일합니다 (예: 연도에 모노스페이스 사용).
- 각 구간 내부 글꼴은 해당 시대의 글꼴을 쓸 수 있습니다 (픽셀 글꼴, 80년대 굵은 이탤릭, 현대 산세리프).

## 움직임
- 각 구간은 해당 매체의 움직임 규칙을 따릅니다 (픽셀은 스텝, 3D는 부드러운 움직임, 손그림은 12fps). 이것이 매체의 “목소리”입니다.
- **관통 요소의 움직임은 전체 타임라인을 따릅니다.** 주인공 동작과 카운터 (연도)는 전체 t만으로 결정하며 구간이 바뀌어도 처음부터 반복하지 않습니다. 그래야 전환 양쪽에서 자세가 이어져 관객이 같은 순간의 매체만 바뀐 것으로 봅니다. 구간별 시간으로 동작을 매번 처음부터 재생하면 같은 장면을 다섯 번 반복하는 것처럼 보입니다. 한 구간에만 해당하는 연기는 구간 시간을 사용합니다. 전환 중 카운터는 이전과 새 매체가 같은 숫자를 각자의 글꼴로 표시하되 중간 프레임에서 글꼴을 바꾸고 서로 겹치지 않습니다.
- 전환은 “업그레이드”입니다: 해상도가 갑자기 높아짐, 2D 평면이 뒤로 넘어가 3D 바닥이 됨, 픽셀 블록이 벡터로 세분됨. 전환 모양은 **다음** 매체가 어떻게 나타나는지에 따라 설계합니다 (craft.md 5절). 공개 프레임을 마디 첫 박자에 맞추고 전환 문법은 전체에서 통일합니다.
- 리듬을 점차 가속할 수 있습니다: BPM은 유지하고 구간마다 박자 수를 줄이다 마지막 구간을 길게 둡니다 (craft.md 2절 “가속”).

## 화면에 생동감 더하기
- 각 구간 유지 중에는 관통 요소의 연속 동작 하나와 해당 시대 매체의 작은 반복 동작 2–3개를 둡니다: 픽셀 구간의 HUD 깜박임과 물음표 블록 반동, CRT 구간의 트래킹 라인, 필름 구간의 긁힘과 깜박임, 3D 구간의 천천히 도는 환경광 등.
- 첫 구간 앞에 이어질 전환이 없으면 화면이 “스스로 그려지게” 만듭니다: 픽셀이 행별로 켜지고, 벡터 선이 한 획씩 그려지며, 별색 인쇄가 판별로 겹칩니다.

## 카메라 문법
| 카메라 움직임 | 표현하는 것 | 적합한 콘텐츠 |
|---|---|---|
| 화면으로 전진해 다음 시대에 진입 | 시간 여행 | 구간 전환 |
| 2D에서 3D로 카메라가 올라감 | 차원 업그레이드 | 중요한 기술 도약 |
| 후퇴해 모든 시대를 나란히 보여줌 | 회고 | 엔딩 |

## 사운드 팔레트
**음악도 시대에 맞춰 발전합니다.** 도입은 칩튠 (구형파, 노이즈), 중간은 신시사이저 패드와 드럼 머신, 후반은 샘플 악기와 큰 리버브 (2단계: 피아노, 넓은 공간감)를 추가하고 클라이맥스에서 모든 소리를 합칩니다. 한 곡이 영상 전체를 관통하고 편곡이 단계별로 발전하는 것이 가장 강한 연결고리입니다. BPM은 영상 전체에서 고정하거나 천천히 높입니다.

리듬과 화성 (예시이며 한 가지로 한정하지 않음): BPM은 고정하고 리듬은 시대에 맞춰 변화 (칩튠의 곧은 박자 → 80년대 gated snare → breakbeat → 현대 half-time). 매체 느낌은 버스의 crush (칩튠)와 wow (테이프)를 단계적으로 줄여 마지막 구간은 깨끗하고 넓게 만듭니다. 서너 음의 짧은 모티프를 영상 전체에 반복하되 구간마다 시대 대표 악기와 화음으로 변형하면 새 곡을 매번 쓰는 것보다 “한 편의 영화”처럼 들립니다. 화면을 먼저 정했고 구간 길이가 불규칙하면 sound.md 8절에 따라 속도를 각 구간별로 살짝 조정해 경계를 마디 첫 박자에 맞춥니다.

## 이 매체만의 표현
- 해상도 도약: 같은 구도가 픽셀 화면에서 갑자기 고화질로 변함. 기술 발전에 적합.
- 같은 주인공이 매체마다 새 모습으로 탄생. 진화와 성장에 적합.
- 마지막에 모든 시대의 화면을 벽처럼 이어 붙인 뒤 로고로 수렴. 회고와 엔딩에 적합.

## 변주 여지
- 구조: 연대기 순서, 역순 (현재에서 시작으로), 같은 동작을 시대 여섯 곳에서 반복, 같은 방 / 거리 모양은 고정하고 매체만 변화, 주인공이 왼쪽에서 오른쪽으로 이동하며 경계를 넘을 때마다 시대 전환 (긴 파노라마).
- 시대 수에는 하한이 없습니다. 세 시대도 가능하며 유지할 것은 구도 뼈대이고 바꿀 것은 매체입니다.
- 도입: 픽셀 하나, 오래된 기계가 켜지는 소리, 첫 그림이 스스로 그려짐.
- 끝맺음: 관통 요소에 작은 농담이나 연기를 남김. 앞부분이 “감상”이었다면 마지막 몇 초는 웃음이나 놀라움을 주고 엔드카드로 연결.
- 끝맺음: 처음의 픽셀 하나로 돌아와 처음과 끝을 연결, 또는 오늘날 장면을 멀리서 보면 미래의 화면에 표시된 한 프레임임을 드러냄.

## 함정
- 관통 요소가 없어 스타일 콜라주처럼 흩어짐.
- 매 구간의 내부 시간으로 같은 동작을 다시 실행해 전환 양쪽 자세가 맞지 않고 주인공이 같은 일을 여러 번 반복하는 듯 보임.
- 배경만 바뀌고 관통 요소에 새 매체 재질을 적용하지 않아 스티커처럼 보임.
- 시그니처 전환이 너무 짧음: 복잡한 형태는 0.3초에 읽히지 않으므로 최소 0.45초를 주고 strip --at으로 확인.
- 각 구간을 너무 빽빽하게 채워 전체 길이와 렌더 시간이 폭증: 구간당 8–20초로 제한하고 저해상도 초안을 먼저 만들어 전체 리듬을 확인.
- 역사적 오류: 연도, 이름, 최초 발명자를 확인하고 불확실한 항목은 쓰지 말고 사용자에게 확인 목록으로 전달.
