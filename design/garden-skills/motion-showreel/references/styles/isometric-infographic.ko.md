# 아이소메트릭 인포그래픽 (isometric-infographic)

> 아이소메트릭 시점의 작은 세계를 만든다. 블록, 파이프, 캐릭터, 데이터 타워를 층층이 쌓아 복잡한 주제를 이해하기 쉽게 설명한다.
> 참고 (문법만 참고): 아이소메트릭 일러스트, 기술 기업 아키텍처 삽화, 도시 시뮬레이션 게임의 시점. 특정 일러스트레이터의 작품을 복제하지 않는다.

## 본질 / 본질이 아닌 것
- 본질: **고정된 아이소메트릭 투영** (축 각도 30°), 원근 왜곡이 없다. 요소는 깔끔한 기하 입체이며 세 면을 세 단계의 명도로 표현한다. 정보는 “쌓기”, “흐르기”, “켜기”로 설명한다.
- 본질이 아닌 것: 임의의 3D 원근, 요소를 과하게 채운 복잡한 삽화.

## 식별 신호: 영상마다 2–3개 선택
| 신호 | 어떤 모습인가 | 적합한 주제 |
|---|---|---|
| 조립 | 블록이 위에서 떨어져 시스템을 층층이 구성 | 시작부터 완성, 아키텍처 |
| 파이프와 데이터 흐름 | 데이터 점이 파이프를 따라 일정한 속도로 이동 | 흐름, 인과, 전송 |
| 점등 | 모듈이 순서대로 강조색으로 켜짐 | 활성화, 출시 |
| 분해된 블록 | 블록 하나를 나눠 내부 구조를 드러냄 | 원리, 내부 메커니즘 |
| 작은 사람과 자동차 | 작은 세계의 거주자가 경로를 따라 움직임 | 사용자, 장면 |
| 데이터 타워 | 수량을 나타내는 기둥이 바닥에서 솟아남 | 규모, 성장 |
| 구획과 도로 | 아이소메트릭 지면에 구역과 도로를 나눠 그림 | 도시, 생태계 |
| 떠 있는 아이콘 | 모듈 위에 아이콘과 라벨이 떠 있음 | 기능 설명 |
| 연결망 | 모듈 사이의 연결선이 빛남 | 통합, 네트워크 |
| 낮과 밤의 변화 | 같은 작은 세계의 조명이 낮에서 밤으로 바뀜 | 시간, 운영 |

규칙:
- 영상마다 2–3개를 고르고 적어도 하나는 가장 진부한 버전에서 벗어난 신호로 선택한다. 주제에 맞춰 선택하며 나열된 순서대로 전부 쓰지 않는다.
- 아이소메트릭 투영 자체가 스타일의 제약이다. 영상 내내 투영을 하나만 사용한다. 신호는 무엇을 어떻게 설명할지를 정한다.

## 이 스타일의 가장 진부한 버전
- 화면: 밝은 회색 바탕의 지면, 파란 블록과 주황색 데이터 흐름, 서버·클라우드·휴대폰 아이콘을 선 하나로 연결한 뒤 마지막에 후퇴해 전체 공개.
- 사운드: 경쾌한 마림바와 부드러운 전자 비트.
- brief의 style 항목에 이번 영상에서 뒤집은 규칙이나 고전적 표현을 유지한 이유를 쓴다. 유지한다면 구도, 카메라, 리듬 또는 예상 밖의 기억에 남는 순간에 공을 들인다.

## 적합성
- 용도: 아키텍처·흐름·생태계를 설명하는 제품 홍보, 설명 영상, 데이터 시각화.
- 콘텐츠: SaaS 아키텍처, 물류, 에너지, 도시, 공급망, 개발 프로세스.

## 기술 구현
Canvas 2D나 SVG에서 아이소메트릭 투영 함수 `iso(x, y, z) → [sx, sy]`를 직접 구현한다 (`sx = (x − y)·cos30°`, `sy = (x + y)·sin30° − z`). Three.js 정사영 카메라를 쓸 수도 있지만 2D가 더 제어하기 쉽고 렌더링이 빠르다. 그리는 순서는 깊이 기준으로 정렬한다 (x + y + z 작은 값부터 큰 값).

## 재질과 렌더링
- 블록은 면을 세 개로 나눈다: 윗면이 가장 밝고 왼쪽 면은 중간, 오른쪽 면은 가장 어둡다 (같은 색조의 명도 세 단계).
- 가는 윤곽선은 선택 사항 (같은 색보다 한 단계 어둡게). 지면 격자는 매우 연하게.
- 캐릭터와 아이콘은 원기둥 + 구 같은 단순한 기하 형태로 만들고 얼굴은 그리지 않는다.
- 데이터 흐름은 파이프를 따라 움직이는 점이나 짧은 선으로 표현하고 시간에 따라 오프셋 (`(t * speed + i * gap) % length`).

## 색상
아래 색상은 예시다. 방향만 참고하고 그대로 베끼지 않는다.
- 바탕 `#F3F1EC` / 블록 `#FFFFFF`·`#E4E1DA`·`#CFCAC0` / 강조 `#2F6BFF` / 데이터 흐름 `#FF7A1A`
- 바탕 `#0F1626` / 블록 `#26324D`·`#1C2640`·`#141C30` / 강조 `#3EE6B0`
- 규칙: 구조는 중립색으로 만들고 “현재 벌어지는 일” (흐름, 점등, 추가)에만 강조색을 사용한다.
- 색상 도출: 구조에는 세 단계 명도의 중립색 (밝은 바탕과 어두운 바탕 모두 가능)을 쓰고 강조색은 진행 중인 사건에만 사용한다. 데이터 흐름에 두 번째 색을 쓸 수 있다. 강조색은 브랜드에서 가져오며 파랑과 주황이 가장 흔한 조합이다.

## 글꼴
라벨에는 깔끔한 산세리프 (Manrope, DM Sans)를 쓴다. 글자를 아이소메트릭 면 위에 배치할 수도 있다 (아이소메트릭 변환 행렬 `ctx.setTransform`으로 기울임).

## 움직임
- 조립: 블록이 위에서 떨어져 스프링 `{2.4, 0.7}`로 안착하며 살짝 눌린다. 의존 관계에 따라 시차를 둔다.
- 점등: 면 색상이 강조색으로 바뀌고 펄스 한 번 발생.
- 흐름: 데이터 점이 일정한 속도로 계속 이동 (지속적인 운영을 나타내므로 여기서 일정한 속도가 맞음).

## 화면에 생동감 더하기
- 파이프와 연결선 안의 데이터 점이 일정한 속도로 흐른다. 작은 기계와 집의 표시등은 박자에 맞춰 깜박이고 캐릭터나 자동차는 작은 세계의 주민처럼 경로를 오간다.
- 움직이는 요소는 모두 정보와 연결되어야 한다. 데이터가 이동하는 방향이 곧 정보 흐름의 방향이다.

## 카메라 문법
| 카메라 움직임 | 표현하는 것 | 적합한 콘텐츠 |
|---|---|---|
| 정사영 카메라로 평행 이동 | 흐름을 따라감 | 단계, 데이터 흐름 |
| 모듈 하나로 천천히 확대 | 한 부분에 초점 | 기능 디테일 |
| 후퇴해 전체를 보여줌 | 생태계 전체 | 요약, 엔딩 |
| z축 기준 90° 회전 (깊이 순서 재정렬) | 다른 시점 | 비교, 전환 |

## 사운드 팔레트
선명한 플럭, 나무 느낌의 click (`rim`, `mallet({ material: 'wood' })`, 또는 짧은 `tom` + 하이패스), 블록이 바닥에 닿는 가벼운 `boom`, 흐름을 위한 부드러운 패드. 1단계 합성으로 충분하다.

리듬과 화성 (예시이며 한 가지로 한정하지 않음): 곧은 박자나 가벼운 swing, 16분음표의 기계적 느낌. 장조, Lydian. `mallet({ material: 'wood' | 'marimba' })`는 나무 블록 소리에 해당한다. 도시가 블록별로 자라며 성부가 차례로 추가되는 누적 곡선이 잘 어울린다.

## 이 매체만의 표현
- 한 지면 위에 도시 (또는 시스템 전체)가 점차 자라남: 시작부터 완성되는 과정을 보여줄 때 적합.
- 데이터 점이 파이프를 흐르며 다음 모듈을 켬: 과정과 인과를 설명할 때 적합.
- 블록 하나를 분리해 내부 구조를 드러냄: 원리 설명에 적합.

## 변주 여지
- 구조: 요청 하나의 여정, 하루 동안 변하는 작은 도시, 모듈 세 개를 차례로 켜고 연결.
- 도입: 블록 하나가 하늘에서 떨어짐, 데이터 흐름이 화면 밖에서 들어옴.
- 끝맺음: 후퇴해 전체를 보여주며 시스템 전체가 한 번 맥동, 모든 모듈이 로고 블록 하나로 합쳐짐.

## 함정
- 깊이 정렬이 틀려 앞뒤 가림이 어색함: x + y + z 기준으로 엄격히 정렬하고 격자 여러 칸을 차지하는 큰 물체는 나눠 그린다.
- 아이소메트릭과 원근을 섞음: 영상 전체에서 투영 하나만 사용한다.
- 요소가 많고 작아짐: 휴대폰에서 읽히지 않으므로 더 적고 크게 만든다.
