# 18개 이상 모듈로 구성된 마스코트 전체 과정 브랜드 디자인 문서 템플릿

이 문서는 "하나의 거대한 캔버스에 마스코트의 DNA 분석부터 실제 적용까지 전체 디자인 문서를 한 이미지로 압축해 담는" 시각물을 만들 때 사용합니다.

대표적인 용도:

- 디자인 회사가 고객에게 제안하는 브랜드 북 / IP 가이드라인 보드
- 디자이너 포트폴리오 표지(전체 디자인 과정을 한 이미지로 보여 주기)
- IP 출시 전 "디자인 근거" 보드
- 교육 예시: "마스코트의 콘셉트부터 실제 적용까지" 전 과정
- 입찰 / 제안 경쟁용 역량 소개 이미지

기존 `mascot-brand-kit.md`와 다른 점:

| 항목 | `mascot-brand-kit.md`(기존) | 이 템플릿(신규) |
|---|---|---|
| 모듈 수 | 4~6개 구역 | **18~24개 모듈** |
| 관점 | 대표 이미지 + 삼면도 + 표정 + 적용 사례 | **DNA 분석 → 무드보드 → 탐색 스케치 → 선화 → 3D → 색상 → 재질 → 디자인 시스템 → 디지털 적용 → 실물 적용 → 최종본** |
| 용도 | IP 소개 페이지 / 굿즈 카탈로그 | **전체 브랜드 북 / 디자인 제안서 / 입찰 자료** |
| 렌더링 밀도 | 중간 | 매우 높음(브랜드 북 PDF 한 페이지를 한 화면에 조합한 수준) |

## 적용 범위

- 18개 이상 모듈로 구성된 마스코트 전체 과정 디자인 문서
- 전체 브랜드 북 / IP 가이드라인 한눈에 보기
- 디자인 회사의 입찰 / 제안용 히어로 이미지
- "디자인 과정 시각화" 교육 보드

## 사용 시점

- 사용자가 "전체 브랜드 디자인 과정 / brand guideline / IP design book"을 언급할 때
- 결과물뿐 아니라 "디자인 도출 과정이 포함된" 이미지를 원할 때
- 고객이 "DNA → 스케치 → 선화 → 3D → 적용" 전 과정을 이미지 하나에 담고 싶어 할 때

다음에는 사용하지 마세요.

- IP 캐릭터 모음만 필요할 때 → `branding-and-packaging/mascot-brand-kit.md` 사용
- 일반적인 브랜드 아이덴티티(로고 / 색상 / 서체 / 활용 사례)만 필요할 때 → `branding-and-packaging/brand-identity-board.md` 사용
- 캐릭터 하나의 삼면도 / 표정만 필요할 때 → `portraits-and-characters/character-sheet.md` 사용
- IP 굿즈 상품 이미지만 필요할 때 → `branding-and-packaging/character-merch-board.md` 사용

## 누락 정보 확인 우선순위

1. 브랜드 / IP 이름과 업종(차 음료 / 교육 / 디지털 기기 / 문화 상품 등)
2. 마스코트의 기본 형태(동물 / 사람형 / 사물형 / 음식 / 추상형)
3. 주색 + 보조색(지정하지 않으면 업종의 기본값 적용)
4. 렌더링 스타일(**픽사풍 3D 실사 카툰 / 평면 2D / 귀여운 치비 / 의인화**)
5. 모듈 밀도(18 / 24 / 사용자 지정 목록)
6. 반드시 포함할 활용 장면(봉제 인형 / 포장 / 앱 아이콘 / 매장 등)

### 매개변수 전략

- **반드시 질문**: 브랜드 이름 + 업종, 캐릭터 설명, 렌더링 스타일, 주색 / 보조색
- **기본값 지정 가능**: 태그라인, 페이지 배경, 화면 비율
- **무작위 지정 가능**: 표정 모음 / 포즈 모음의 구체적인 항목 11개 / 9개(IP 성격에 따라 자동 선택)

### 자동 완성 전략

- 사용자가 "마스코트"와 업종만 말하면 업종의 의미에 맞춰 형태를 자동으로 생성합니다(차 음료 → 시바견 / 토끼; 기술 → 로봇 / 픽셀 괴물; 유아·출산 → 귀여운 동물 / 구름 사람).
- 표정 11개 / 포즈 9개의 구체적인 내용을 지정하지 않으면 템플릿의 기본 목록을 사용합니다.
- 재질 / 적용 장면을 지정하지 않으면 업종의 기본값을 적용합니다(식음료는 포장 / 인형 강조, 기술은 앱 아이콘 / UI 강조).

## 피해야 할 사항

- ❌ 모듈 번호를 빼먹거나 순서를 바꾸지 않습니다(18개 모듈의 번호가 템플릿의 핵심입니다).
- ❌ 모듈마다 마스코트 형태를 다르게 만들지 않습니다(같은 형태를 엄격하게 유지해야 합니다).
- ❌ 표정 / 포즈 / 회전도 수를 바꾸지 않습니다(11 / 9 / 5는 검증된 시각적 밀도입니다).
- ❌ 목업 영역을 실제 재질 렌더링이 아니라 이미지 조각의 콜라주로 만들지 않습니다.
- ❌ 이미지 전체에서 18개 모듈이 모두 같은 글자 크기를 쓰지 않게 합니다 → 위계가 무너집니다. 구역 제목은 본문보다 최소 1.6배 커야 합니다.
- ❌ 전체가 18장의 개별 포스터를 붙여 놓은 것처럼 보이지 않게 합니다 → 공통 배경, 일관된 여백, 통일된 제목 스타일을 사용합니다.
- ❌ 화질이 제한된 상황에서 24개 모듈을 무리하게 넣지 않습니다 → 각 칸의 세부 묘사가 무너지므로 18개를 상한으로 권장합니다.
