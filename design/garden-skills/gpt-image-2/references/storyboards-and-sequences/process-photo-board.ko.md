# 실제 인물 촬영형 절차 / 장비 착용 보드 템플릿

이 문서는 "실제 인물 / 캐릭터가 시네마틱 실사 질감으로 여러 단계의 조작 과정을 수행하는 절차 보드"를 만들 때 사용합니다. 대표적인 장면:

- 장비 착용 / 갑옷 조립 / 제복 갈아입기 절차
- 공예 작업 / 메이크업 / 실험 / 작업장 단계
- 훈련 / 무술 / 피트니스 동작 분해
- 기계 수리 / 조립 / 장비 작동 절차
- 캐릭터 코스프레 / 소품 착용 절차
- "1단계 → N단계, 각 단계마다 실사 시네마틱 이미지 + 번호 + 설명"으로 구성된 시각 안내서

기존 / 신규 템플릿과 다른 점:

| 템플릿 | 특징 |
|---|---|
| `recipe-process-flowchart.md`(기존) | 레시피 절차(손그림 / 일러스트 스타일) |
| `pose-reference-sheet.md`(신규) | 포즈 사전(같은 캐릭터의 독립 동작 N개, 순서형 서사 없음) |
| `cinematic-storyboard-grid.md`(신규) | 영화 콘티(연속 내러티브, 사건 / 감정 중심) |
| `product-tvc-storyboard.md`(신규) | 상업 TVC 콘티(제품 중심) |
| **이 템플릿**(신규) | **실제 인물 / 캐릭터 촬영 스타일 시네마틱 절차 보드**(단계 중심 + 순서 + 장비 상태 변화) |

**핵심 차이**: 각 이미지는 "같은 캐릭터가 단계마다 달라지는 실제 촬영 / 시네마틱 스틸"입니다. **장비 상태 / 동작 자세가 1단계에서 N단계까지 어떻게 변화하는지** 강조하고 단계 번호 + 제목 + 설명을 함께 넣습니다.

## 적용 범위

- 장비 착용 절차(갑옷 / 전술 장비 / 코스프레)
- 공예 작업 절차(커피 추출 / 메이크업 / 실험)
- 훈련 분해(무술 / 피트니스 / 춤 기술)
- 장비 작동 / 수리 / 조립 절차
- 의식 / 복식 예절 절차

## 사용 시점

- 사용자가 "장비 / 착용 / 절차도 / 단계 보드 / 동작 분해 / process board"를 언급할 때
- **같은 실제 인물 캐릭터** 또는 **같은 물체**가 **순서에 따라 상태를 바꾸는 과정**을 보여 줄 때
- **실사 / 시네마틱 사실주의 질감**을 원할 때(손그림 / 선화 아님)
- 각 단계에 이미지 + 단계 번호 + 설명 문장이 필요할 때

다음에는 사용하지 마세요.

- 레시피 / 튜토리얼 선화 절차 → `recipe-process-flowchart.md` 사용
- 순서가 없는 포즈 / 동작 사전 → `pose-reference-sheet.md` 사용
- 단계보다 서사가 중요한 영화 콘티 → `cinematic-storyboard-grid.md` 사용
- 제품 중심 상업 광고 TVC → `product-tvc-storyboard.md` 사용

## 누락 정보 확인 우선순위

1. 절차 주제(어떤 절차인가? 장비 / 메이크업 / 조작 / 훈련)
2. 캐릭터 설명(성별 / 나이 / 헤어스타일 / 의상 / 주요 식별 특징)
3. 단계 수(4 / 6 / 8 / 9 권장) + 그리드(2×3 / 3×2 / 3×3 / 2×4)
4. 단계별 제목 + 짧은 설명(장비 상태 / 동작 설명)
5. 스타일(**시네마틱 실사 / 특촬물 / 패션 화보 / 작업장 기록 / 튜토리얼 스크린샷**)
6. 언어(제목 / 설명 문구: 일본어 / 중국어 / 영어)
7. 환경(작업장 / 메이크업 룸 / 체육관 / 실험실 / 야외)
8. 비율(가로 16:9 보드 / 세로 4:5 매뉴얼 / 정사각 1:1 소셜 미디어)

### 매개변수 전략

- **반드시 질문**: theme(절차 주제), character(캐릭터 설명), 순서에 따라 진행되는 6개 step title + caption + image, language
- **기본값 지정 가능**: 스타일, 환경, 구도, 조명, 그리드
- **무작위 지정 가능**: 바닥글 슬로건, 배경 세부 사항(사용자가 지정하지 않은 경우)

### 자동 완성 전략

- 사용자가 "장비 착용 6단계"를 원한다고 하면 "내피 → 상체 → 하체 → 머리 장비 준비 → 머리 장비 착용 → 전체 장비 완료"로 자동 구성합니다.
- 사용자가 "커피 내리기 6단계"라고 하면 "분쇄 → 계량 → 물 끓이기 → 뜸 들이기 → 물 붓기 → 추출 완료"로 자동 구성합니다.
- 사용자가 "메이크업 6단계"라고 하면 "베이스 → 컨실러 → 아이 메이크업 → 블러셔 → 립 → 고정"으로 자동 구성합니다.
- 언어를 지정하지 않으면 사용자 대화 언어를 기본으로 사용합니다.

## 변형 1: 3×3 = 세로형 매뉴얼 9단계(4:5 / 9:16)

📝 프롬프트

```json
{
  "type": "9단계 절차 매뉴얼 보드, 세로 포스터",
  "layout": { "rows": 3, "columns": 3, "panel_count": 9, "aspect_ratio": "세로 4:5 또는 9:16" },
  "use_case": "더 세밀한 단계 매뉴얼 / 샤오홍슈 / 공식 계정 세로 이미지 / 튜토리얼 표지"
}
```

### 이 변형을 선택할 때

- 6단계보다 많을 때(예: 상세 튜토리얼 9단계)
- 세로형이 필요할 때(소셜 미디어 / 모바일 읽기)
- 튜토리얼 콘텐츠

## 피해야 할 사항

- ❌ 패널마다 캐릭터 외모가 달라짐(**캐릭터 일관성 필수**) 
- ❌ 장비 상태가 순서대로 진행되지 않음(단계에 따라 명시적으로 추가해야 함)

- ❌ 절차 보드가 순서 없는 포즈 사전처럼 보임(`pose-reference-sheet.md` 사용)
- ❌ 절차 보드를 만화로 만들거나 말풍선 추가
- ❌ 패널마다 환경 / 조명 / 필터가 서로 다름
- ❌ 모델이 단계를 자유롭게 만들게 둠(단계별 제목 + 설명 + 샷 묘사를 명시해야 함)
- ❌ 얼굴을 가리거나 흐리지 않은 상태에서 실제 인물과 닮은 사진 생성(**인물 신원 및 개인정보 보호 조건 준수**)
