# 영화적 내러티브 콘티 콘택트 시트 템플릿

이 문서는 "연속된 이야기 / 감정 / 사건의 흐름을 중심으로 9~15개의 시네마틱 스틸을 N×M 그리드에 배치"한 영화 콘티 보드를 만들 때 사용합니다.

대표적인 용도:

- 단편 영화 / 콘셉트 필름 / 피치 트레일러 비주얼 제안
- AI 동영상 생성(Sora / Runway / Pika)에 사용할 샷 목록 참고
- 만화 / 애니메이션 / 게임 시네마틱 컷신 제안
- 영화 투자 제안 덱의 콘셉트 비주얼
- "이 이야기를 촬영하면 어떻게 보일까"를 이미지 한 장으로 제시
- 공상과학 / 전투 / 재난 / 로맨스 / 미스터리 등 모든 장르

기존 스토리보드 템플릿과 다른 점:

| 템플릿 | 특징 |
|---|---|
| `four-panel-comic.md`(기존) | 만화 4칸 / 개그 / 반전 |
| `manga-spread-page.md`(기존) | 만화 펼침 페이지(불규칙한 칸 구성) |
| `recipe-process-flowchart.md`(기존) | 절차 설명(레시피 / 튜토리얼) |
| `product-tvc-storyboard.md`(신규) | **상업 광고 TVC 콘티(제품 중심)** |
| **이 템플릿**(신규) | **영화 / 단편 / 콘셉트 필름 내러티브 콘티**(사건 / 감정 / 이야기 중심) |

**핵심 차이**: 각 패널은 모두 "영화 수준의 시네마틱 스틸"입니다. 제품 / 상업 광고가 아니라 "이 순간 무슨 일이 일어나는가 + 카메라가 어떻게 촬영하는가 + 감정은 무엇인가"에 중점을 둡니다.

## 적용 범위

- 영화 / 단편 / 애니메이션 시네마틱 콘티 보드
- AI 동영상 샷 목록
- 피치 트레일러 비주얼 제안
- 콘셉트 필름 스토리보드(공상과학 / 전투 / 재난 / 로맨스 / 미스터리)

## 사용 시점

- 사용자가 "영화 콘티 / cinematic storyboard / 단편 샷 리스트 / 콘셉트 필름 샷 목록"을 언급할 때
- 주제가 제품 / 상업 광고가 아니라 사건 / 감정 / 이야기일 때
- 만화풍 / 광고풍보다 영화적 느낌을 원할 때

다음에는 사용하지 마세요.

- 제품이 포함된 상업 광고 TVC 콘티 → `product-tvc-storyboard.md` 사용
- 대사 말풍선 / 속마음이 있는 만화 콘티 → `four-panel-comic.md` / `manga-spread-page.md` 사용
- 레시피 / 튜토리얼 절차 → `recipe-process-flowchart.md` 사용
- 실제 인물 사진 절차 / 장비 착용 → `process-photo-board.md` 사용

## 누락 정보 확인 우선순위

1. 이야기 / 줄거리(누가 + 어디서 + 무슨 일 + 결말을 한 문단으로 설명)
2. 장르(**공상과학 / 재난 / 전투 / 로맨스 / 미스터리 / 서부극 / 필름 누아르**)
3. 샷 수(9 / 12 / 15) + 그리드(3×3 / 3×4 / 3×5 / 4×4)
4. 감정 곡선(**시작 → 상승 → 절정 → 하강 / 계속 긴장 / 계속 차분하다가 폭발**)
5. 스타일(**실사 / 유화 질감 / 애니메이션 영화풍 / 흑백 영화 / 70년대 레트로**)
6. 색상 방향(전체 샷의 색보정 결정)
7. 비율(패널별 16:9 / 21:9 영화 와이드; 전체 시트 1:1 콘택트 시트 또는 4:5 / 16:9)

## 기본 템플릿: 3×4 = 12컷 영화풍 콘티 콘택트 시트(공상과학 사례)

### 매개변수 전략

- **반드시 질문**: primary subject, mood, cinematic style, 12개 샷의 간단한 설명
- **기본값 지정 가능**: 조명, 환경, 비율
- **무작위 지정 가능**: 이야기 흐름에 맞춰 각 샷의 구체적인 각도(wide / POV / CU 혼합)

### 자동 완성 전략

- 사용자가 이야기 개요 한 문장을 주면 "진입 → 중간 → 고조 → 절정 → 공개" 구조로 12개 샷을 자동 구성합니다.
- mood를 지정하지 않으면 장르에 따라 자동 설정합니다(공상과학 = 압박감; 로맨스 = 따뜻함; 전투 = 긴장감; 미스터리 = 차가움).
- 각 샷 유형을 지정하지 않으면 와이드 4개 / 미디엄 4개 / 클로즈업 2개 / POV 2개를 섞습니다.

  "use_case": "1~2분 단편 / 콘셉트 필름 / TikTok 장편 영상"

### 이 변형을 선택할 때

- 이야기가 더 짧거나 리듬이 촘촘할 때
- 12컷까지 필요하지 않을 때
- 단편 / 짧은 동영상 제안에 적합

## 피해야 할 사항

- ❌ 12개 패널의 이야기가 끊어짐(연속된 서사여야 함)
- ❌ 주인공 외형이 달라짐
- ❌ 색보정이 일관되지 않음(한 칸은 따뜻하고 한 칸은 차가움)
- ❌ 같은 유형의 샷만 반복(와이드 / 미디엄 / 클로즈업 / POV / 하이·로우앵글 혼합)
