# 생체모방 / 산업 디자인 콘셉트 포스터 템플릿

이 문서는 "자연의 원형 → 추상화 → 산업 제품"으로 이어지는 콘셉트 디자인 포스터를 만들 때 사용합니다. 생물 형태, 진화 과정, 최종 제품 히어로 렌더링, 다각도 기술 도면, 브랜드 문구를 콘셉트 보드 한 장에 조합합니다.

대표적인 용도:

- 생체모방 산업 디자인 콘셉트(항공기 / 자동차 / 로봇 / 가전 / 신발)
- 디자이너 / 학생 포트폴리오 표지
- 스타트업 데모데이의 "아이디어에서 제품까지" 소개
- 산업 디자인 수업 프로젝트 결과물
- 속도감 / 효율을 강조하는 브랜드 비주얼 선언
- 스케치 → 청사진 → 렌더링의 전체 과정 시연

기존 포스터 템플릿과 다른 점:

| 템플릿 | 용도 |
|---|---|
| `brand-poster.md`(기존) | 브랜드 메인 포스터(제품 / 인물 / 핵심 문구) |
| `campaign-kv.md`(기존) | 캠페인 KV + 파생 레이아웃 시스템 |
| `banner-hero.md`(기존) | 웹 히어로 / 랜딩 페이지 가로 구도 + CTA |
| `editorial-cover.md`(기존) | 잡지 / 정기 간행물 표지 |
| **이 템플릿**(신규) | **산업 디자인 콘셉트 포스터: 원형 → 진화 → 히어로 → 다각도 기술 도면** |

## 적용 범위

- 생체모방 산업 디자인(가오리 / 상어 / 매 / 잎 / 벌집에서 영감)
- 제품 콘셉트 소개 포스터
- 학생 / 디자이너 포트폴리오 표지
- "영감 → 제품"의 시각적 내러티브
- 고급 제조 / 항공 / 자동차 / 아웃도어 제품군

## 사용 시점

- 사용자가 "생체모방 / 콘셉트 디자인 / 산업 디자인 / 진화 과정 / 영감의 원천"을 언급할 때
- "생물 원형에서 최종 제품까지" 시각적인 이야기를 만들고 싶을 때
- 히어로 렌더링 + 다각도 기술 도면 + 디자인 도출 과정을 한 장에 모두 담고 싶을 때

다음에는 사용하지 마세요.

- 일반 제품 광고 포스터 → `brand-poster.md` 또는 `product-visuals/premium-studio-product.md` 사용
- 학술 논문의 그림 → `academic-figures/method-pipeline-overview.md` 사용
- 사용자 조사 / 요구 사항 분석 포스터 → `slides-and-visual-docs/visual-report-page.md` 사용

## 누락 정보 확인 우선순위

1. 제품 종류 + 이름(항공기 SKYRAY / 신발 SHARK SOLE / 의자 LEAF CHAIR)
2. 생체모방 원형(가오리 / 상어 / 나뭇잎 / 벌집 / 바닷가재 등)
3. 스타일 방향(**검정 + 시안 하이테크 / 미색 + 검은 잉크 선화 / 따뜻한 나무색 + 자연 / 레트로 청사진**)
4. 5단계 영감 → 제품 진화 띠가 필요한지 여부
5. 기술 다각도 도면(top / side / front / rear / underside / detail)이 필요한지 여부
6. 태그라인 / 하단 본문
7. 비율(기본값 세로 3:4)

### 매개변수 전략

- **반드시 질문**: 제품 종류 + 이름, 동물 / 생물학적 영감, 업종
- **기본값 지정 가능**: 태그라인, 배경, 색상 팔레트
- **무작위 지정 가능**: 진화 5단계의 구체적인 설명, 기술 뷰의 세부 확대 영역

### 자동 완성 전략

- 사용자가 "제품 + 영감"을 제시하면 "생물 → 해부 → 추상 → 산업 → 완제품"의 5단계 과정으로 자동 전개합니다.
- 업종을 지정하지 않으면 제품 유형으로 분류합니다(항공기 = 항공우주; 신발 = 신발; 의자 = 가구).
- 색상을 지정하지 않으면 업종에 맞게 추천합니다(항공우주 = 검정 + 시안; 신발 = 흰색 + 주황색; 가구 = 따뜻한 나무색 + 크림색).

## 피해야 할 사항

- ❌ 진화 5단계가 모두 "완성 제품의 서로 다른 각도" → 반드시 "생물 → 추상 → 제품"으로 발전해야 함
- ❌ 히어로 이미지와 기술 뷰의 제품 윤곽 / 비율이 다름
- ❌ 기술 뷰 6개가 모두 렌더링 이미지 → 최소 4개는 정투영 선화, 1개는 재질 세부 확대여야 함
- ❌ 하단 문구가 마케팅 문구가 됨 → 디자인 철학 / 공학적 설명이어야 함
