# 캠페인 키 비주얼 템플릿

이 문서는 "확장하고 재사용할 수 있는 시리즈형 캠페인 대표 비주얼"을 만들 때 사용합니다.

- 분기별 캠페인 대표 이미지
- 명절 캠페인 메인 이미지
- 플랫폼 간 광고 소재에 공통으로 쓰는 비주얼
- 공동 브랜드 캠페인 대표 이미지

특징:

- 대표 비주얼을 배너 / 스토리 / 짧은 동영상 표지로 확장할 수 있어야 합니다.
- 앵커 비주얼 하나와 레이아웃 시스템 하나로 구성합니다.
- 캠페인의 핵심 주장을 강조합니다.
- 색상 팔레트를 엄격하게 통일합니다.

## 적용 범위

- 신규 캠페인 대표 비주얼 시스템
- 명절 / 11월 11일 쇼핑 행사 / 대형 프로모션 캠페인
- 공동 브랜드 캠페인

## 사용 시점

- 사용자가 "캠페인 / 대형 프로모션 / 분기 행사 / KV / 시리즈 대표 비주얼"을 언급할 때
- 배너 / 스토리 / 포스터로 확장 가능한 시각물을 원할 때

다음에는 사용하지 마세요.

- 단일 브랜드 포스터(`brand-poster.md` 사용)
- 웹 히어로(`banner-hero.md` 사용)

## 누락 정보 확인 우선순위

1. 캠페인 주제
2. 캠페인 기간
3. 캠페인 핵심 주장(claim / 슬로건)
4. 브랜드 색상 + 캠페인 전용 색상
5. 대표 비주얼의 중심 대상(인물 / 제품 / 개념 그래픽)
6. 파생 레이아웃을 보여 줘야 하는지 여부

## 기본 템플릿: 캠페인 키 비주얼 + 파생 레이아웃

📖 설명

메인 이미지는 앵커 비주얼이며 중앙에는 캠페인 핵심 문구를 둡니다. 아래에는 파생 레이아웃(1:1, 9:16, 16:9)의 작은 미리보기를 보여 줍니다.

📝 프롬프트

```json
{
  "type": "캠페인 키 비주얼 시스템",
  "goal": "캠페인 메인 이미지로 사용할 수 있고 파생 버전도 보여 주는 비주얼 시스템 이미지 생성",
  "campaign": {
    "name": "{argument name=\"campaign name\" default=\"AURORA Spring Drop 2026\"}",
    "claim": "{argument name=\"campaign claim\" default=\"봄의 새 소리, 설레는 순간을 들어 보세요\"}",
    "duration": "{argument name=\"duration\" default=\"2026.4.20 - 2026.5.15\"}"
  },
  "visual_system": {
    "color_palette": "{argument name=\"color palette\" default=\"벚꽃 분홍 + 안개 파랑 + 미색\"}",
    "anchor_visual": {
      "description": "{argument name=\"anchor visual\" default=\"새 무선 이어폰을 착용한 소녀, 배경에는 흩날리는 벚꽃잎\"}",
      "composition": "인물을 화면 왼쪽 1/3 지점에 배치하고 핵심 문구를 위한 여백 확보"
    },
    "graphic_motif": "{argument name=\"motif\" default=\"반복되는 작은 벚꽃 로고 + 리듬을 만드는 점\"}"
  },
  "claim_typography": {
    "font_style": "{argument name=\"font style\" default=\"현대적인 세리프체 + 둥근 세부 형태\"}",
    "color": "짙은 회색 + 벚꽃 분홍 포인트"
  },
  "derivative_layouts": {
    "enabled": "{argument name=\"derivatives enabled\" default=\"true\"}",
    "items": [
      "1:1 소셜 미디어 대표 이미지",
      "9:16 짧은 동영상 표지",
      "16:9 배너"
    ],
    "rule": "파생 레이아웃 세 개를 메인 이미지 아래 한 줄로 배열"
  },
  "logo_placement": {
    "position": "오른쪽 아래 모서리"
  },
  "constraints": {
    "must_keep": [
      "앵커 비주얼과 파생 레이아웃의 시각 스타일을 일관되게 유지",
      "모든 비율에서 핵심 문구를 읽을 수 있어야 함",
      "색상 팔레트를 엄격하게 통일",
      "모든 버전에 브랜드 로고 포함"
    ],
    "avoid": [
      "파생 레이아웃의 스타일이 달라짐",
      "작은 크기에서 핵심 문구가 읽히지 않음",
      "팔레트에 색상이 추가됨",
      "앵커 비주얼의 주제가 화면 밖으로 벗어남"
    ]
  }
}
```

### 매개변수 전략

- 반드시 질문: 캠페인 이름, 핵심 문구, 색상 팔레트, 앵커 비주얼
- 기본값 지정 가능: 파생 레이아웃 목록, 로고 위치, 글꼴
- 무작위 지정 가능: 그래픽 모티프의 구체적인 형태

### 자동 완성 전략

- 사용자가 주제와 시점(봄 / 여름 / 11월 11일 / 크리스마스)을 알려 주면 색상 팔레트와 모티프를 자동 선택합니다.
- 핵심 문구 기본 길이는 12~18자입니다.
- 파생 레이아웃은 기본적으로 비율 3종류를 사용합니다.

## 변형 1: 공동 브랜드 캠페인

📝 프롬프트

```json
{
  "type": "공동 브랜드 캠페인 대표 비주얼",
  "campaign": {
    "name": "{argument name=\"co-brand campaign\" default=\"AURORA × MUJI Limited\"}",
    "claim": "{argument name=\"claim\" default=\"일상의 소리, 고요한 힘\"}"
  },
  "visual_system": {
    "color_palette": "회백색 + 따뜻한 베이지 + 브랜드 색상 한 방울",
    "anchor_visual": {
      "description": "두 브랜드의 제품을 나란히 배치한 일상 장면"
    }
  },
  "constraints": {
    "must_feel": "절제되고 공통된 맥락이 있으며 어느 브랜드도 다른 브랜드를 압도하지 않음"
  }
}
```

```json
{
  "type": "순수 그래픽 캠페인 대표 비주얼",
  "visual_system": {
    "anchor_visual": {
      "description": "{argument name=\"motif\" default=\"브랜드 워드마크에서 파생된 기하학적 형태\"}"
    },
    "graphic_motif": "{argument name=\"pattern\" default=\"반복 그리드 + 리듬을 만드는 점\"}"
  },
  "constraints": {
    "must_feel": "개념적이고 추상적이며 브랜드 자산에 속하는 느낌"
  }
}
```

## 변형 3: 자동 완성 모드

📝 프롬프트

```json
{
  "type": "캠페인 KV 자동 완성 템플릿",
  "mode": "auto-fill",
  "rule": "사용자가 캠페인 주제 + 기간을 제시하면 핵심 문구, 색상 팔레트, 앵커 비주얼, 파생 레이아웃을 자동 결정",
  "constraints": {
    "must_feel": "광고 시스템에 바로 등록할 수 있어야 함"
  }
}
```

## 피해야 할 사항

- 파생 레이아웃의 스타일이 메인 이미지와 분리되지 않게 합니다.
- 핵심 문구가 주제 위를 가로지르지 않게 합니다(여백 확보).
- KV 시스템 하나에서 글꼴을 두 종류 넘게 사용하지 않습니다.
- 모든 비율을 같은 구도로 만들지 않습니다(각 비율에 맞게 구도를 재구성해야 함).
- 모티프가 주제를 압도하지 않게 합니다.
