# 인물 사진 국소 수정 워크플로 템플릿

이 문서는 "인물 사진의 일부를 수정"하는 편집 작업에 사용합니다.

- 헤어스타일 / 머리색 변경
- 의상 색상 / 디자인 변경
- 안경 / 액세서리 변경
- 메이크업 수정
- 표정의 가벼운 수정

특징:

- 인물 정체성(얼굴형 / 이목구비 비율)을 반드시 유지합니다.
- 국소 영역만 수정합니다.
- 필요한 경우 마스크를 사용합니다.
- 장면은 변경하지 않습니다.

## 적용 범위

- 인물 사진의 부분 수정
- 의상 / 액세서리 수정
- 메이크업 수정
- 헤어스타일 / 머리색 수정

## 사용 시점

- 사용자가 인물 사진을 제공하고 일부를 바꾸고 싶어 할 때
- "같은 사람"이라는 느낌을 유지하길 원할 때

다음에는 사용하지 마세요.

- 배경 전체 교체(`background-replacement.md` 사용)
- 다른 객체 / 물건으로 교체(`local-object-replacement.md` 사용)
- 특정 객체 삭제(`object-removal.md` 사용)

## 누락 정보 확인 우선순위

1. 수정하고 싶은 부위(헤어스타일 / 의상 / 메이크업 / 액세서리)
2. 수정 후 모습 설명
3. 마스크를 제공했는지 여부
4. 표정 / 자세를 유지할지 여부
5. 조명을 조정할지 여부

## 기본 템플릿: 헤어스타일 / 머리색 변경

📖 설명

인물의 정체성과 구도를 유지하면서 헤어스타일 / 머리색만 수정합니다.

📝 프롬프트

```text
REFERENCE_0를 바탕으로 인물의 얼굴형, 이목구비 비율, 피부색, 표정, 자세, 의상과 배경을 유지하고 헤어스타일 / 머리색만 다음과 같이 바꿉니다.
{argument name="new hair description" default="어깨 길이의 단발 + 자연스러운 검은색 + 살짝 컬이 들어간 머리"}.
새 헤어스타일의 그림자, 반사, 헤어라인은 원본 조명 방향과 일치해야 합니다.
인물 정체성의 특징(눈 모양, 입 모양, 코, 귀)은 변경하지 않습니다.
배경을 수정하지 않습니다.
```

### 매개변수 전략

- 반드시 질문: 수정 부위, 원하는 새 모습
- 기본값 지정 가능: 정체성 유지, 배경 유지, 조명 유지
- 무작위 지정 가능: 머리카락 세부 묘사

### 자동 완성 전략

- 기본적으로 인물 정체성을 유지합니다.
- 기본적으로 구도와 조명을 유지합니다.
- 기본적으로 국소 수정만 수행하고 나머지는 바꾸지 않습니다.

## 변형 1: 의상 수정

📝 프롬프트

```text
REFERENCE_0를 바탕으로 인물의 얼굴, 헤어스타일, 자세, 표정, 배경은 유지하고 의상만 다음과 같이 바꿉니다.
{argument name="new outfit description" default="베이지색 긴팔 셔츠 + 카키색 재킷"}.
새 의상의 주름과 그림자는 원본 조명 방향과 일치해야 합니다.
인물 정체성의 특징은 변경하지 않습니다.
배경을 수정하지 않습니다.
```

## 변형 2: 메이크업 수정

📝 프롬프트

```text
REFERENCE_0를 바탕으로 인물 정체성과 구도를 유지하고 메이크업만 다음과 같이 바꿉니다.
{argument name="new makeup description" default="매트한 누드 립 + 브라운 계열 아이섀도 + 자연스러운 블러셔"}.
피부색, 피부 질감의 세부 묘사, 이목구비 형태를 유지합니다.
메이크업이 지나치게 짙거나 피부색과 어울리지 않게 하지 않습니다.
배경을 수정하지 않습니다.
```

## 변형 3: 액세서리 수정 / 추가

📝 프롬프트

```text
REFERENCE_0를 바탕으로 인물 정체성과 구도를 유지하고 액세서리를 다음과 같이 추가 / 수정합니다.
{argument name="accessory description" default="얇은 금속 테두리가 있는 둥근 안경"}.
액세서리의 각도와 그림자는 원본 조명 방향과 일치해야 합니다.
다른 신체 부위는 수정하지 않습니다.
배경을 수정하지 않습니다.
```

## 변형 4: 자동 완성 모드

📝 프롬프트

```text
REFERENCE_0를 바탕으로 인물의 스타일을 가볍게 개선합니다(헤어스타일 / 메이크업 / 의상 중 하나). 현재 가장 어색한 부분을 자동으로 판단해 보정합니다.
인물 정체성을 유지합니다.
배경을 유지합니다.
```

## 피해야 할 사항

- 얼굴 특징을 바꿔 다른 사람처럼 만들지 않습니다.
- 수정한 부분의 조명 방향이 원본과 달라지지 않게 합니다.
- 배경이나 피부색을 덩달아 바꾸지 않습니다.
- 메이크업이 "필터를 씌운 가짜 피부"처럼 짙어지지 않게 합니다.
- 마스크가 없으면 결과가 약간 달라질 수 있다고 사용자에게 알립니다.
- 사용자가 요청하지 않은 성별 / 인종 특성을 바꾸지 않습니다.
