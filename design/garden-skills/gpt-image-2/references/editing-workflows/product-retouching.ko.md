# 제품 정밀 보정 워크플로 템플릿

이 문서는 "원본 이미지를 바탕으로 제품을 정밀 보정"하는 편집 작업에 사용합니다.

- 제품 이미지의 질감 향상
- 결함 / 흠집 보정
- 광택 / 반사 조정
- 라벨 개선 / 글자 선명하게 만들기
- 그림자 / 반사상 재정리

특징:

- 주제(제품)는 유지합니다.
- 핵심은 "대체"가 아니라 "질감 개선"입니다.
- 배경을 무리하게 교체하지 않습니다.
- 제품의 형태와 글자를 변경하지 않습니다.

## 적용 범위

- 제품 이미지의 질감 향상
- 결함 보정
- 조명 재작업
- 라벨 / 글자를 선명하게 처리

## 사용 시점

- 사용자가 원본 이미지(REFERENCE_0)를 제공하고 제품을 더 고급스럽게 만들길 원할 때
- 장면은 유지하고 질감만 개선하길 원할 때

다음에는 사용하지 마세요.

- 배경 전체 교체(`background-replacement.md` 사용)
- 제품을 다른 제품으로 교체(`local-object-replacement.md` 사용)
- 흰 배경 대표 이미지를 새로 생성(`product-visuals/white-background-product.md` 사용)

## 누락 정보 확인 우선순위

1. 원본 제품 설명
2. 개선하고 싶은 부분(질감 / 광택 / 라벨 / 그림자)
3. 결함 제거가 필요한지 여부
4. 배경을 유지할지 여부
5. 전후 비교 이미지로 출력할지 여부

## 기본 템플릿: 제품 질감 향상

📖 설명

원본 이미지의 제품과 장면은 유지하고 제품 자체의 질감만 개선합니다(더 투명하게 / 광택을 살려 / 라벨을 선명하게 / 더 고급스럽게).

📝 프롬프트

```text
REFERENCE_0를 바탕으로 화면 속 {argument name="product" default="흰색 펌프 용기"}의 모양, 비율, 라벨 내용과 장면 배경을 유지하고 제품 자체의 질감을 개선합니다.
- {argument name="enhancement focus" default="용기 표면의 광택과 미세 반사"}를 개선합니다.
- {argument name="defect to fix" default="용기 표면의 가벼운 긁힘과 얼룩"}을 보정합니다.
- {argument name="label sharpening" default="앞면 라벨의 글자와 로고"}를 더 선명하게 만듭니다.
- 그림자와 반사는 원본 이미지의 방향을 유지하면서 더 섬세하게 표현합니다.
- 제품의 색상, 글자, 재질 종류를 바꾸지 않습니다.
- 배경을 교체하지 않습니다.
렌더링 스타일: {argument name="render style" default="고급 상업용 제품 사진 + 잡지 수준의 후반 보정"}.
```

### 매개변수 전략

- 반드시 질문: 개선하고 싶은 부분
- 기본값 지정 가능: 배경 유지, 글자 유지, 색상 유지
- 무작위 지정 가능: 그림자의 부드러운 정도

### 자동 완성 전략

- 기본적으로 광택 개선 + 결함 보정 + 라벨 선명화를 적용합니다.
- 개선 강도를 지정하지 않으면 "절제된 개선"을 적용합니다.
- 브랜드 색상을 변경하지 않습니다.

## 변형 1: 라벨 / 글자 선명화

📝 프롬프트

```text
REFERENCE_0를 바탕으로 화면 속 제품 라벨의 글자만 선명하고 또렷하게 처리합니다.
- 모든 문구, 자간, 서체를 유지합니다.
- 용기의 다른 부분은 수정하지 않습니다.
- 배경을 수정하지 않습니다.
```

## 변형 2: 그림자 / 반사상 재작업

📝 프롬프트

```text
REFERENCE_0를 바탕으로 제품 자체는 유지하고 더 섬세한 {argument name="shadow type" default="아래쪽의 부드러운 그림자 + 은은한 반사"}를 다시 생성합니다.
- 그림자 방향은 원본 이미지의 조명과 일치해야 합니다.
- 반사는 절제해 제품보다 눈에 띄지 않게 합니다.
- 제품 자체는 수정하지 않습니다.
- 배경을 수정하지 않습니다.
```

## 변형 3: 자동 완성 모드

📝 프롬프트

```text
REFERENCE_0를 바탕으로 제품 전체의 질감을 개선하고 광택 / 라벨 / 그림자 / 가장자리 중 개선할 부분을 자동으로 결정합니다.
제품의 원래 정체성을 유지하면서 전체 완성도를 한 단계 높입니다.
```

## 피해야 할 사항

- 제품의 글자(특히 브랜드 이름)를 변경하지 않습니다.
- 광택을 높여 "플라스틱 같은 느낌"이 들지 않게 합니다.
- 사용자가 허용하지 않는 한 배경을 다시 생성하지 않습니다.
- 그림자 방향이 달라지지 않게 합니다.
- 제품 색상을 과도하게 조정하지 않습니다.
