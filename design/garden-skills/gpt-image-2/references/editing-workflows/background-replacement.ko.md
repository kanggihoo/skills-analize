# 배경 교체 워크플로 템플릿

이 문서는 "이미지의 배경을 새 배경으로 교체"하는 편집 작업에 사용합니다. 스크립트 `scripts/edit.js`에 대응합니다.

적합한 장면:

- 제품 이미지의 배경 교체(흰 배경 → 생활 공간 / 스튜디오 / 야외)
- 인물 사진의 배경 교체(복잡한 배경 → 깔끔한 스튜디오 배경)
- 오래된 사진의 배경 보정
- 여러 제품군 이미지의 배경 스타일 통일

## 적용 범위

- 단일 주제가 있는 이미지의 배경 교체
- 주제는 그대로 유지하고 배경만 변경
- 주제의 가장자리가 뚜렷하고 식별 가능함

## 사용 시점

- 사용자가 원본 이미지(REFERENCE_0)를 제공하고 "XX 배경으로 바꿔 주세요"라고 할 때
- 주제는 그대로 두고 배경만 교체하고 싶어 할 때
- 여러 이미지의 배경을 통일하고 싶어 할 때

다음에는 사용하지 마세요.

- 주제 자체를 수정해야 할 때(`local-object-replacement.md` 사용)
- 무언가를 제거하기만 할 때(`object-removal.md` 사용)
- 제품 자체를 정밀 보정해야 할 때(`product-retouching.md` 사용)

## 누락 정보 확인 우선순위

1. 원본 이미지 설명 / 주제가 무엇인지
2. 새 배경: 장면 / 색조 / 조명
3. 원본의 조명 방향을 유지할지 여부
4. 그림자 / 반사를 다시 만들지 여부
5. 출력 비율(원본 유지 / 조정)

## 기본 템플릿: 제품 이미지 배경 교체

📖 설명

주제가 담긴 이미지를 입력하고, 주제는 유지한 채 지정한 장면으로 배경을 교체한 이미지를 출력합니다.

📝 프롬프트

```text
REFERENCE_0를 바탕으로 {argument name="subject" default="화면 중앙의 흰색 펌프 용기"}의 형태, 비율, 라벨, 재질은 유지하고 배경만 {argument name="new background" default="아침 햇살이 비치는 나무 화장대. 왼쪽 창문에서 부드러운 빛이 들어오고, 먼 배경은 살짝 흐리게 처리. 배경에 물 한 잔, 흰 꽃잎 몇 장, 접힌 베이지색 수건 포함"}로 교체합니다.
새 배경에 어울리는 그림자와 반사를 다시 만들어 주제가 새 장면 안에 실제로 존재하는 것처럼 표현합니다.
주제 자체의 색상, 글자, 형태 또는 재질은 변경하지 않습니다.
렌더링 스타일: {argument name="render style" default="고해상도 상업 사진, 자연스러운 입자감, 얕은 피사계 심도, 주제는 선명하게, 배경은 자연스럽게 흐림"}.
출력 비율: {argument name="aspect ratio" default="원본 비율 유지"}.
```

### 매개변수 전략

- 반드시 질문: 원본 이미지의 주제, 새 배경 설명
- 기본값 지정 가능: 렌더링 스타일, 비율
- 무작위 지정 가능: 배경의 작은 소품 세부 사항

### 자동 완성 전략

- 업종에 따라 배경을 자동 선택합니다: 화장품 → 화장대, 식품 → 식탁, 전자제품 → 미니멀한 책상
- 기본적으로 원본 비율을 유지합니다.
- 기본적으로 그림자를 다시 생성합니다.

## 변형 1: 인물 사진의 스튜디오 배경 교체

📝 프롬프트

```text
REFERENCE_0를 바탕으로 {argument name="subject" default="화면 속 인물"}의 자세, 표정, 옷차림과 얼굴 특징을 유지하고 배경만 {argument name="studio backdrop" default="중성 회색 배경지"}로 교체합니다.
새 배경에 맞는 부드러운 빛과 그림자를 다시 생성합니다. 인물의 외모, 피부색, 의상 색상은 바꾸지 않습니다.
렌더링 스타일: {argument name="render style" default="부드러운 조명을 사용한 자연스러운 피부 질감의 스튜디오 인물 사진"}.
```

## 변형 2: 제품 이미지의 야외 장면 배경 교체

📝 프롬프트

```text
REFERENCE_0를 바탕으로 {argument name="subject" default="화면 중앙의 제품"}을 유지하고 배경을 {argument name="outdoor scene" default="해변의 나무 데크, 따뜻한 황혼빛, 멀리 흐릿하게 보이는 파도"}로 교체합니다.
제품의 모든 라벨과 재질 세부 사항을 유지하고 야외 조명의 방향에 맞춰 제품의 그림자를 다시 생성합니다.
빛 때문에 제품 색상이 지나치게 변하지 않게 합니다(브랜드 색상 유지).
```

## 변형 3: 자동 완성 모드

📝 프롬프트

```text
REFERENCE_0를 바탕으로 주제를 유지합니다. 주제에 가장 잘 어울리는 "깔끔한 스튜디오 / 자연 장면 / 미니멀 실내" 중 하나를 자동으로 선택해 배경을 교체합니다.
원본 비율을 유지하고 주제를 위한 자연스러운 그림자를 다시 생성합니다.
```

## 피해야 할 사항

- 사용자가 허용하지 않는 한 주제 자체를 수정하지 않습니다.
- 조명 방향이 주제의 원래 조명과 일치하지 않게 하지 않습니다.
- 배경 요소를 너무 많이 넣어 주의를 분산시키지 않습니다.
- 주제 가장자리에 눈에 띄는 누끼 흔적이 남지 않게 합니다.
- 주제의 글자 / 라벨을 변경하지 않습니다.
