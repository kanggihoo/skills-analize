# 불필요한 객체 제거 워크플로 템플릿

이 문서는 "이미지에서 특정 대상을 제거하고 나머지 장면을 보존"하는 편집 작업에 사용합니다.

- 행인 / 구경꾼 제거
- 워터마크 / 로고 제거(저작권 문제가 없는 경우에 한함)
- 불필요한 소품 제거
- 어지러운 선 / 전선 제거
- 이미지 속 결함 제거

특징:

- 새 객체로 교체하지 않습니다.
- 제거된 영역은 자연스럽게 채워야 합니다.
- 필요한 경우 마스크를 사용합니다.
- 주요 주제에 영향을 주지 않습니다.

## 적용 범위

- 방해 요소 하나 제거
- 방해 요소 여러 개 제거
- 넓은 영역 제거(전선 / 케이블)
- 국소적인 결함 제거

## 사용 시점

- 사용자가 원본 이미지(REFERENCE_0)를 제공하고 특정 대상을 지우고 싶어 할 때
- 화면을 더 깔끔하게 만들고 싶어 할 때

다음에는 사용하지 마세요.

- 새 객체로 교체(`local-object-replacement.md` 사용)
- 배경 전체 교체(`background-replacement.md` 사용)

## 누락 정보 확인 우선순위

1. 제거할 객체
2. 마스크를 제공했는지 여부
3. 제거 후 해당 영역에 무엇을 채울지(배경 이어짐 / 단색 바탕)
4. 그림자 / 반사에 영향을 줄지 여부

## 기본 템플릿: 방해 객체 하나 제거

📖 설명

객체 하나를 정밀하게 지우고 주변 환경을 자연스럽게 이어 해당 영역을 채웁니다.

📝 프롬프트

```text
REFERENCE_0를 바탕으로 이미지 속 {argument name="object to remove" default="배경의 행인"}을 제거합니다.
제거한 영역은 주변 환경({argument name="fill description" default="거리 바닥, 벽, 먼 배경의 건물"})을 자연스럽게 이어 채워 대상이 원래부터 없었던 것처럼 보이게 합니다.
주제, 조명 방향, 그림자, 구도를 유지합니다.
다른 인물, 객체, 글자는 수정하지 않습니다.
```

### 매개변수 전략

- 반드시 질문: 제거할 객체, 채울 내용
- 기본값 지정 가능: 주제 유지
- 무작위 지정 가능: 보완할 세부 요소

### 자동 완성 전략

- 기본적으로 주변 환경을 바탕으로 채울 내용을 추론합니다.
- 기본적으로 모든 그림자의 방향을 유지합니다.

## 변형 1: 마스크를 사용한 제거

📝 프롬프트

```text
REFERENCE_0를 바탕으로 REFERENCE_1(마스크)에 표시된 영역을 제거 대상으로 사용하고, 해당 영역을 주변 환경이 자연스럽게 이어지도록 채웁니다.
마스크 영역만 수정하고 바깥은 픽셀 단위로 보존합니다.
채운 영역에 알아볼 수 있는 이음매나 질감의 급격한 변화가 생기지 않게 합니다.
```

## 변형 2: 여러 요소 일괄 제거(예: 전선 / 구경꾼)

📝 프롬프트

```text
REFERENCE_0를 바탕으로 이미지 속 모든 {argument name="objects to remove" default="하늘의 전선 / 거리의 행인"}을 제거합니다.
제거된 부분은 해당 배경(하늘 / 지면 / 건물)이 자연스럽게 이어지도록 채웁니다.
주제, 조명, 그림자, 구도를 유지합니다.
```

## 변형 3: 자동 완성 모드

📝 프롬프트

```text
REFERENCE_0를 바탕으로 주제를 보는 데 방해가 되는 요소를 자동으로 찾아 제거합니다(예: 행인, 전선, 병, 물 얼룩).
주제와 구도를 유지하고 배경은 자연스럽게 채웁니다.
```

## 피해야 할 사항

- 주제까지 함께 제거하지 않습니다.
- 조명 방향을 바꾸지 않습니다(제거 후에도 그림자 방향을 유지).
- 채운 영역이 "뭉개지거나 / 질감이 반복되는" 것처럼 보이지 않게 합니다.
- 마스크가 없으면 최선을 다해 처리할 뿐이며 결과에 약간 차이가 날 수 있다고 사용자에게 알립니다.
- 사용자가 합법적인 소유자가 아닌 한 저작권이 있는 로고 / 워터마크를 제거하지 않습니다.
