# 국소 객체 교체 워크플로 템플릿

이 문서는 "원본 이미지의 특정 객체를 다른 객체로 교체"하는 편집 작업에 사용합니다.

- 이미지 속 커피잔을 보온병으로 교체
- 이미지 속 인물의 티셔츠를 후드티로 교체
- 자동차 로고를 다른 브랜드 로고로 교체
- 반려동물을 고양이에서 강아지로 교체
- 배경 속 물건을 다른 물건으로 교체

특징:

- 주제 대부분을 보존합니다.
- 국소 영역만 정밀하게 교체합니다.
- 주변 조명 / 그림자를 새 객체에 맞춥니다.
- 필요한 경우 마스크를 함께 사용합니다.

## 적용 범위

- 객체 하나 교체
- 객체 여러 개 교체
- 마스크를 활용한 정밀 교체

## 사용 시점

- 사용자가 원본 이미지(REFERENCE_0)를 제공하고 특정 객체를 바꾸고 싶어 할 때
- 교체 대상 외에는 다른 요소를 그대로 두길 원할 때

다음에는 사용하지 마세요.

- 배경 전체 교체(`background-replacement.md` 사용)
- 객체 제거만 수행(`object-removal.md` 사용)
- 제품 / 인물 사진 정밀 보정(`product-retouching.md` / `portrait-local-edit.md` 사용)

## 누락 정보 확인 우선순위

1. 원본에서 교체할 객체
2. 무엇으로 교체할지
3. 마스크를 제공했는지 여부
4. 교체 후 그림자 / 반사를 다시 만들지 여부
5. 교체 객체의 크기 / 위치를 유지할지 여부

## 기본 템플릿: 객체 하나 교체

📖 설명

객체 하나를 정밀하게 교체하고 나머지 장면은 최대한 보존합니다.

📝 프롬프트

```text
REFERENCE_0를 바탕으로 {argument name="original object" default="책상 위의 흰색 세라믹 커피잔"}을 {argument name="replacement object" default="같은 크기의 스테인리스 보온병. 무광 은색이며 몸체에 간결한 브랜드 글자 'AURORA'가 있음"}으로 교체합니다.
원본의 다른 모든 요소는 위치, 조명, 그림자, 구도를 그대로 유지하고 교체 대상 객체만 수정합니다.
새 객체에 원본 조명 방향과 일치하는 그림자, 반사, 재질을 다시 생성합니다.
다른 인물, 책상, 배경은 변경하지 않습니다.
```

### 매개변수 전략

- 반드시 질문: 원래 객체, 교체할 객체
- 기본값 지정 가능: 그림자를 다시 생성할지 여부
- 무작위 지정 가능: 교체 객체의 부수적인 세부 사항

### 자동 완성 전략

- 기본적으로 원래 객체의 크기와 위치를 유지합니다.
- 기본적으로 그림자를 다시 생성합니다.
- 사용자가 재질을 지정하지 않으면 합리적으로 유사한 재질을 선택합니다.

## 변형 1: 마스크를 사용한 정밀 교체

📝 프롬프트

```text
REFERENCE_0를 바탕으로 REFERENCE_1(마스크)에 표시된 영역을 사용해 {argument name="object to replace" default="인물의 흰색 티셔츠"}를 {argument name="new object" default="가슴에 'AURORA' 글자가 인쇄된 짙은 남색 긴팔 후드티"}로 정밀하게 교체합니다.
마스크 영역만 수정하고 나머지 영역은 픽셀 단위로 보존합니다.
새 옷에 원본 조명과 일치하는 주름과 그림자를 만듭니다.
인물의 체형과 자세는 완전히 그대로 유지합니다.
```

## 변형 2: 여러 객체 일괄 교체

📝 프롬프트

```text
REFERENCE_0를 바탕으로 장면 속 모든 {argument name="original objects" default="나무 의자"}를 {argument name="replacement objects" default="베이지색 플라스틱 의자"}로 교체합니다.
각 의자의 위치, 각도, 놓인 방향을 그대로 유지합니다.
새 의자에 원본 조명 방향과 일치하는 그림자를 생성합니다.
탁자, 벽, 조명 기구, 인물은 수정하지 않습니다.
```

## 변형 3: 자동 완성 모드

📝 프롬프트

```text
REFERENCE_0를 바탕으로 원본 이미지의 {argument name="object" default="주요 전경 객체"}를 같은 기능을 하는 더 현대적인 시각 스타일의 객체로 교체합니다. 재질과 색상은 자동으로 정하되 위치와 크기는 그대로 유지합니다.
```

## 피해야 할 사항

- 사용자가 허용하지 않는 한 교체 후 원래 객체의 위치 / 비율을 바꾸지 않습니다.
- 교체 객체의 조명 방향이 원본과 일치하지 않게 하지 않습니다.
- 관련 없는 다른 요소를 함께 수정하지 않습니다.
- 교체 객체의 재질이 "붙여 넣은 듯" 보이지 않게 합니다.
- 마스크가 없을 때 정밀 교체인 것처럼 가장하지 않습니다(가장자리가 약간 달라질 수 있다고 설명).
