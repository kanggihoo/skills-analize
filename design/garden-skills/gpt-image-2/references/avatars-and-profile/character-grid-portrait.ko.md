# 캐릭터 n×n 그리드 초상화 템플릿

이 문서는 "한 이미지 안에 같은 캐릭터의 여러 버전(표정 / 직업 / 왕조 / 스타일이 다른 모습)을 담는" 경우에 사용합니다.

- 2×2 / 3×3 / 4×4로 한 인물의 여러 직업이나 장면 표현
- 표정 9분할(기쁨, 분노, 슬픔, 즐거움 등)
- 왕조 / 신화 속 캐릭터 시리즈 초상화
- 여러 스타일을 통일된 방식으로 보여 주기
- 여러 캐릭터의 그룹 초상화 그리드

특징:

- 한 이미지가 여러 칸으로 나뉩니다.
- 각 칸은 동일한 정체성을 서로 다르게 표현합니다.
- 그리드 선 또는 투명한 구분선을 사용합니다.
- "같은 사람 / 같은 캐릭터"라는 일관성을 강조합니다.

## 적용 범위

- 한 사람의 여러 직업을 담은 그리드
- 표정 9분할
- 한 캐릭터의 여러 왕조 / 문화별 모습
- 한 캐릭터의 여러 의상과 스타일 모음

## 사용 시점

- 사용자가 한 이미지에서 한 인물의 여러 모습을 보여 주고 싶어 할 때
- 사용자가 단일 이미지가 아니라 "그리드 이미지"를 원할 때
- 동일한 인물의 여러 버전을 직접 비교하고 싶어 할 때

다음에는 사용하지 마세요.

- 표정 / 의상 설정 시트( `portraits-and-characters/character-sheet.md` 사용)
- 단일 이미지 스타일 변환( `style-transfer-selfie.md` 사용)
- 서로 다른 여러 캐릭터의 콜라주( `grids-and-collages/mixed-style-multi-panel.md` 사용)

## 누락 정보 확인 우선순위

1. 주인공의 정체성(참고 이미지 / 텍스트 설명)
2. 그리드 크기(2×2 / 3×3 / 4×4)
3. 각 칸의 차이를 만드는 기준(직업 / 표정 / 왕조 / 스타일)
4. 각 칸에 넣을 구체적인 내용(사용자가 지정하거나 제가 제안)
5. 기본 스타일(실사 / 3D 카툰 / 애니메이션)
6. 화면 비율

## 기본 템플릿: 한 인물의 여러 직업을 담은 2×2 그리드

📖 설명

2×2 네 칸으로 구성합니다. 모든 칸에 동일 인물을 배치하고, 각기 다른 직업과 장면을 보여 줍니다.

📝 프롬프트

```json
{

  "goal": "동일 인물이 각 칸에서 서로 다른 직업과 장면으로 등장하는 2×2 그리드 이미지를 생성합니다. LinkedIn 프로필, 자기소개 또는 창의적인 아바타로 사용할 수 있습니다.",
  "subject": {
    "description": "{argument name=\"subject description\" default=\"동아시아 젊은 남성, 짧은 검은 머리, 자연스러운 미소\"}",
    "consistency": "네 칸 모두 얼굴형, 피부색, 이목구비 비율을 엄격히 동일하게 유지해야 합니다."
  },
  "style": "{argument name=\"art style\" default=\"고해상도 실사 인물 사진 + 자연광\"}",
  "layout": {
    "format": "2x2 grid",
    "panel_count": 4,
    "gap": "얇은 흰색 구분선",
    "panels": [
      {
        "position": "top-left",
        "scenario": "{argument name=\"panel 1\" default=\"비즈니스 업무: 짙은 남색 정장 + 흰 셔츠 + 파란 넥타이, 회색 질감 배경\"}"
      },
      {
        "position": "top-right",
        "scenario": "{argument name=\"panel 2\" default=\"야외 캐주얼: 짙은 남색 티셔츠, 흐릿한 공원 배경\"}"
      },
      {
        "position": "bottom-left",
        "scenario": "{argument name=\"panel 3\" default=\"건설 노동자: 노란 안전모 + 주황색 반사 조끼, 흐릿한 작업장 배경\"}"
      },
      {
        "position": "bottom-right",
        "scenario": "{argument name=\"panel 4\" default=\"의료 종사자: 흰 실험복 + 연한 파란 셔츠, 흐릿한 실험실 배경\"}"
      }
    ]
  },
  "constraints": {
    "must_keep": [
      "네 칸 모두 동일 인물로 표현",
      "각 칸의 조명은 자연스럽고 전체 스타일은 통일",
      "의상과 장면이 잘 어울림",
      "얇은 구분선을 선명하게 표현"
    ],
    "avoid": [
      "네 칸의 인물이 서로 다른 사람처럼 보임",
      "의상과 장면이 명백히 어울리지 않음",
      "그리드 선이 지나치게 굵어 시각적 흐름을 해침",
      "칸마다 스타일이 달라짐"
    ]
  }
}
```

### 매개변수 전략

- 반드시 질문: 인물 설명, 네 칸의 차이를 만드는 기준
- 기본값 지정 가능: 기본 스타일, 그리드 구분선
- 무작위 지정 가능: 각 칸의 배경 세부 요소

### 자동 완성 전략

- 사용자가 인물만 제시하면 대비가 뚜렷한 직업 / 장면 네 가지를 자동으로 선택합니다(비즈니스 + 야외 + 현장 노동 + 의료가 대표 조합입니다).
- 기본값은 2×2 그리드입니다.
- 기본값은 실사 사진입니다.

## 피해야 할 사항

- 서로 다른 칸의 인물이 다른 사람처럼 보이지 않게 합니다(일관성이 핵심입니다).
- 그리드 구분선을 지나치게 굵게 만들지 않습니다.
- 각 칸의 스타일이 달라지지 않게 합니다(전체 스타일을 통일해야 합니다).
- 4×4보다 큰 그리드는 사용하지 않습니다(칸이 너무 작아집니다).
- 그리드의 주제를 서로 무관한 소재로 흩뜨리지 않습니다(일관성을 유지하는 기준이 필요합니다).
