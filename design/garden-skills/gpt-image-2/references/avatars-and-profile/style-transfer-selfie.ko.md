# 스타일 변환 셀피 / 퍼스널 캐릭터 템플릿

이 문서는 "참고 이미지(사용자의 셀피 / 공개 사진)를 바탕으로 인물을 특정 스타일로 변환"하는 퍼스널 이미지에 사용합니다.

- 코스프레 셀피 스타일
- 고딕 / 레트로 필름 / 스트리트 / 그래피티 스타일의 인물 이미지
- 아이돌 화보 / 폴라로이드 스타일
- 야외 활동 장면 사진(코믹월드, 농구장, 카페)
- 유명인 / 캐릭터 스타일 변환

특징:

- 참고 이미지(REFERENCE_0)를 바탕으로 얼굴 특징과 인물 정체성을 유지해야 합니다.
- 스타일 / 메이크업 / 의상 / 장면의 분위기만 바꿉니다.
- 단일 이미지로 출력합니다(그리드 / 시트가 아닙니다).
- "나의 또 다른 버전"처럼 보여야 합니다.

## 적용 범위

- 셀피를 특정 캐릭터 / 스타일로 변환
- 원하는 캐릭터로 코스프레한 모습 생성
- 메이크업 + 의상 + 장면 분위기를 함께 변경

## 사용 시점

- 사용자가 셀피를 제공하고 스타일 변환을 요청할 때
- 사용자가 자기 모습을 설명하고 원하는 스타일을 알려 줄 때
- 사용자가 "내 모습은 유지하면서 X 스타일로" 만들고 싶어 할 때

다음에는 사용하지 마세요.

- 여러 버전의 그리드( `character-grid-portrait.md` 사용)
- 일반적인 직업용 프로필 사진( `portraits-and-characters/professional-portrait.md` 사용)
- 창업자 화보( `portraits-and-characters/founder-portrait.md` 사용)
- VTuber / 2차원 캐릭터( `portraits-and-characters/virtual-host.md` 사용)

## 누락 정보 확인 우선순위

1. 참고 이미지(REFERENCE_0)를 제공했는지 여부. 이미지가 없다면 본인의 외모를 텍스트로 설명해야 합니다.
2. 원하는 스타일 주제(코스프레 / 고딕 / 필름 / 스트리트 / 아이돌 / 유명인풍)
3. 의상 / 메이크업 / 헤어스타일을 얼마나 바꿀지
4. 배경 장면(원본 유지 / 새로운 장면)
5. 화면 비율

## 기본 템플릿: 스타일 변환 셀피(REFERENCE_0 기반)

📖 설명

참고 이미지 속 인물의 정체성과 기본 자세를 유지하면서 전체 스타일을 지정한 주제로 바꿉니다.

📝 프롬프트

```text
REFERENCE_0의 인물을 바탕으로 얼굴형, 이목구비 비율, 피부색과 기본 자세를 유지하고 전체 스타일을 {argument name="target style" default="trad goth 고딕 스타일"}로 변환합니다.
- 머리: {argument name="hair description" default="검은색 짧은 머리 + 무겁게 내려오는 일자 앞머리"}
- 메이크업: {argument name="makeup description" default="짙은 스모키 아이 메이크업 + 검은색 매트 립"}
- 의상: {argument name="outfit description" default="검은색 가죽 상의 + 은색 십자가 목걸이 + 여러 겹으로 착용한 액세서리"}
- 액세서리: {argument name="accessories" default="코 피어싱, 귀걸이 2개, 은반지"}
- 장면: {argument name="scene description" default="원본 이미지의 배경 유지"}
- 조명: {argument name="lighting" default="극적인 측면광, 높은 대비"}

출력 스타일: {argument name="rendering" default="고해상도 실사 사진"}, 단일 인물 사진.

제약 조건:
- 인물의 정체성을 바꾸지 않습니다(얼굴형과 이목구비 비율을 알아볼 수 있어야 합니다).
- 성별, 연령대, 인종을 바꾸지 않습니다.
- 메이크업은 짙게 하되 부자연스럽지 않게 하고 피부 질감을 유지합니다.
- 의상 스타일을 통일하고 서로 어울리지 않는 요소를 섞지 않습니다.
```

### 매개변수 전략

- 반드시 질문: 참고 이미지, 목표 스타일
- 기본값 지정 가능: 헤어스타일, 메이크업, 의상, 액세서리
- 무작위 지정 가능: 배경의 세부 요소, 액세서리의 구체적인 디자인

### 자동 완성 전략

- 사용자가 스타일 키워드 하나만 제시하면 헤어스타일 + 메이크업 + 의상 + 액세서리 네 가지를 자동으로 구체화합니다.
- 참고 이미지가 없으면 먼저 이미지를 요청하거나 일반 텍스트 설명을 기반으로 생성합니다.
- 스타일상 장면 변경이 꼭 필요한 경우가 아니라면 기본적으로 원본 배경을 유지합니다.

## 변형 1: 코스프레 셀피(코믹월드 / 캐릭터 분장)

📝 프롬프트

```text
REFERENCE_0의 인물을 바탕으로 합니다(참고 이미지가 없다면 {argument name="subject self description" default="동아시아 젊은 여성, 자연스러운 미소"}라는 설명을 사용). 인물을 {argument name="character" default="원신의 라이덴 쇼군"} 코스프레 셀피로 변환합니다.
촬영 장면: {argument name="event location" default="상하이 코믹월드 현장"};
인물 본인의 얼굴 특징을 유지해 "이 사람이 이 캐릭터로 코스프레했다"고 알아볼 수 있게 합니다.
스마트폰 셀피 스타일 + 행사 현장 분위기 + 자연광으로 렌더링합니다.
```

## 변형 2: 레트로 필름 / 빈티지 35mm 플래시 인물 사진

📝 프롬프트

```text
REFERENCE_0의 인물을 빈티지 35mm 플래시 필름 인물 사진으로 다시 촬영합니다.
- 플래시를 정면으로 비춰 생기는 단단한 그림자
- 입자감 있는 필름 질감
- 1990년대 분위기의 따뜻한 노란색 색조
- 장면: {argument name="vintage scene" default="길가의 당구장"}
- 인물은 자연스러운 표정을 짓고 일부러 포즈를 취하지 않음
원본 이미지 속 인물의 정체성을 유지합니다.
```

## 변형 3: 아이돌 화보 / 폴라로이드 모음(한 장의 폴라로이드 형태)

📝 프롬프트

```text
REFERENCE_0의 인물을 바탕으로 폴라로이드 사진 한 장을 생성합니다.
- 폴라로이드 테두리(두꺼운 흰색 테두리, 아래쪽에 손글씨 라벨을 넣을 여백)
- 인물을 화면 중앙에 배치
- 스타일: {argument name="polaroid mood" default="일본 아이돌의 청순한 분위기"}
- 폴라로이드 아래쪽에 손글씨로 문구 한 줄: '{argument name="caption" default="2026.4.24 weekend"}'
- 전체적으로 입자감이 있고 살짝 과다 노출된 느낌
```

## 변형 4: 자동 완성 모드

📝 프롬프트

```text
REFERENCE_0의 인물을 바탕으로 가장 잘 어울리는 "고급스러운 스타일 캐릭터 이미지"로 변환하고 다음을 자동으로 결정합니다.
- 인물의 분위기에 어울리는 스타일 주제를 자동으로 판단
- 헤어스타일 / 메이크업 / 의상 / 장면 / 조명을 구체화
- 인물의 정체성은 바꾸지 않음
- 단일 이미지 출력
```

## 피해야 할 사항

- 이목구비 비율을 바꾸지 않습니다(가장 흔한 실패는 얼굴이 바뀌는 것입니다).
- 성별 / 인종 특성을 바꾸지 않습니다.
- 메이크업을 너무 짙게 해 "필터를 씌운 가짜 피부"처럼 보이게 하지 않습니다.
- 배경이 주제와 동떨어지게 바꾸지 않습니다.
- 참고 이미지가 없는데도 참고 이미지를 기반으로 한 것처럼 가장하지 않습니다(텍스트 설명 모드로 전환하면 됩니다).
- 실제 저작권이 있는 캐릭터 이름을 그대로 사용해 코스프레를 요청하지 않습니다(이름 대신 특징을 설명하는 방식을 권장합니다).
