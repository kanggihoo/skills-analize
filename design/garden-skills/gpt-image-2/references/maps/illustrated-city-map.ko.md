# 손그림 도시 풍경 지도 템플릿

이 문서는 "도시 전체의 풍경을 담은 지도"를 만들 때 사용합니다. 음식 / 경로 / 매장 중심이 아니라 도시 자체에 초점을 둡니다.

- 도시 관광 홍보 이미지
- 도시 문화 대표 시각물
- 도시 IP 캐릭터 이미지
- 축제 행사 대표 이미지
- 교육 / 공공 홍보 이미지

특징:

- 도시 전체 범위를 다룹니다.
- 여러 랜드마크를 배치합니다.
- 스타일화된 일러스트를 사용합니다.
- 중앙에 도시 상징 / 강 / 산을 둘 수 있습니다.

## 적용 범위

- 도시 전체 풍경 이미지
- 도시 문화 대표 시각물
- 도시 IP 이미지
- 구 / 거리 단위 풍경 이미지

## 사용 시점

- 사용자가 "도시 지도 / 도시 일러스트 지도 / 도시 풍경 이미지 / 도시 대표 지도"를 언급할 때
- 음식 / 경로보다 도시 문화와 랜드마크를 강조하고 싶어 할 때

다음에는 사용하지 마세요.

- 음식 주제(`food-map.md` 사용)
- 경로 주제(`travel-route-map.md` 사용)
- 매장 분포 주제(`store-distribution-map.md` 사용)

## 누락 정보 확인 우선순위

1. 도시 / 구역 이름
2. 스타일: 레트로 수채화 / 현대 평면 / 귀여운 스타일 / 아이소메트릭 3D / 중국풍 트렌드 일러스트
3. 강조할 랜드마크(5~12곳)
4. 강 / 하천 / 산 / 호수를 포함할지 여부
5. 중앙 마스코트가 필요한지 여부
6. 언어: 중국어 / 이중 언어

## 기본 템플릿: 레트로 수채화 도시 풍경 지도

📖 설명

도시 전체를 위에서 내려다보는 손그림 일러스트입니다. 랜드마크 건축물을 화면 곳곳에 배치하고 강, 산, 다리 같은 지형 요소를 시각적 뼈대로 사용합니다. 모서리에는 문화 요소를 장식합니다.

📝 프롬프트

```json
{
  "type": "도시 풍경 일러스트 지도",
  "goal": "도시 전체의 풍경을 대표하는 일러스트 지도를 생성합니다. 도시 문화 대표 시각물, 관광 대표 이미지, 도시 IP 이미지로 사용할 수 있습니다.",
  "style": "{argument name=\"art style\" default=\"레트로 수채화 + 베이지색 양피지\"}",
  "title_section": {
    "city": "{argument name=\"city\" default=\"항저우\"}",
    "title_text": "{argument name=\"title\" default=\"천년의 항저우 풍경 지도\"}",
    "subtitle": "{argument name=\"subtitle\" default=\"강남의 시정 · 산수 사이에서\"}"
  },
  "geography_skeleton": {
    "rivers_or_lakes": "{argument name=\"water elements\" default=\"시후, 첸탕강\"}",
    "mountains": "{argument name=\"mountains\" default=\"바오스산, 레이펑산\"}",
    "main_streets": "{argument name=\"streets\" default=\"난산루, 후빈루\"}"
  },
  "landmarks": {
    "count": "{argument name=\"landmark count\" default=\"10\"}",
    "items": "{argument name=\"landmarks\" default=\"레이펑탑, 단교, 쑤디, 링인사, 성황각, 칭허팡, 룽징촌, 허팡제, 징항 대운하, 시시 습지\"}"
  },
  "centerpiece": "{argument name=\"centerpiece\" default=\"시후와 레이펑탑을 이미지 중앙에 두어 시각적 중심을 형성\"}",
  "edge_decorations": [
    "{argument name=\"deco 1\" default=\"강남식 처마 실루엣\"}",
    "{argument name=\"deco 2\" default=\"흩날리는 계화 꽃잎\"}",
    "{argument name=\"deco 3\" default=\"시적인 문구가 적힌 작은 인장\"}"
  ],
  "extras": ["레트로 나침반", "가는 테두리", "도시 문화를 담은 짧은 문구"],
  "constraints": {
    "must_keep": [
      "대표 랜드마크를 알아볼 수 있어야 함",
      "강 / 호수 / 산의 상대적인 위치가 크게 어긋나지 않아야 함",
      "전체적으로 손그림 수채화 느낌 유지"
    ],
    "avoid": [
      "현대 자동차 / 고속도로 / 마천루가 주제를 압도함",
      "라벨마다 글꼴 스타일이 다름",
      "색상 채도가 지나치게 높음"
    ]
  }
}
```

### 매개변수 전략

- 반드시 질문: 도시 이름, 스타일, 랜드마크 목록(또는 제가 목록을 제안해도 되는지)
- 기본값 지정 가능: 모서리 장식, 나침반, 부제
- 무작위 지정 가능: 문구 인장, 장식 꽃

### 자동 완성 전략

- 사용자가 도시 이름만 주면 대표 랜드마크 8~12곳과 도시를 가장 잘 드러내는 지형을 자동으로 선택합니다.
- 기본 스타일은 수채화입니다.
- 문구는 도시 문화와 관련된 짧은 구절로 자동 설정합니다.

## 피해야 할 사항

- 도시 지도를 실제 축척에 맞춰 정확하게 압축하지 않습니다.
- 도시 전체의 고층 건물을 전부 그리지 않습니다(시각적으로 무너집니다).
- 강 / 하천의 방향이 명백히 틀리지 않게 합니다.
- 테두리 장식이 주요 이미지를 가리지 않게 합니다.
- 랜드마크를 15개 넘게 넣지 않습니다.
