# 당일 여행 / 하루 일정 지도 템플릿(왼쪽 경유지 + 오른쪽 그림 지도)

이 문서는 "세로 2:3 당일 여행 가이드 포스터"를 만들 때 사용합니다. 왼쪽 절반은 일정 카드(번호가 붙은 경유지 5곳 + 시간 + 설명), 오른쪽 절반은 환상적이고 사실적인 산수 지도이며, 같은 번호로 표시된 경유지 5곳이 대응합니다.

대표적인 용도:

- 관광지 / 국립공원 / 옛 마을 당일 여행 추천 포스터
- 관광청 / 문화관광 캠페인 대표 이미지
- 공식 계정 / 샤오홍슈 긴 콘텐츠 표지
- 여행 브랜드 / 민박 / OTA의 하루 여행 일정 홍보물
- 휴일 여행지 체크인 경로 공유 이미지
- 여행기 표지 / 일정 기념 포스터

기존 지도 템플릿과 다른 점:

| 템플릿 | 특징 |
|---|---|
| `travel-route-map.md`(기존) | **여러 날 일정**(D1-D7)으로 도시 간 경로를 표시, 순서 + 시간 강조 |
| `food-map.md`(기존) | **맛집 지도**(여러 가게를 높은 밀도로 표시) |
| `illustrated-city-map.md`(기존) | **도시 풍경 지도**(랜드마크 일러스트) |
| `store-distribution-map.md`(기존) | **매장 분포 지도** |
| **이 템플릿**(신규) | **당일 일정 분할 포스터**: 왼쪽 일정 카드 + 오른쪽 환상적 사실주의 지도, 경유지 5~7곳을 엄격하게 정렬 |

**핵심 차이**: 이 템플릿은 "하루 일정 + 레트로 여행 포스터 미학 + 양쪽 열의 엄격한 정렬"을 시각적 형식으로 삼습니다. 관광지 당일 여행, 국립공원 일정, 도시의 하루 시티워크 계획에 가장 적합합니다.

## 적용 범위

- 하루 일정(경유지 5~7곳)
- 관광지 / 국립공원 / 산악 지역 / 옛 마을 당일 여행
- 하루 동안 도시를 걷는 시티워크 계획
- 문화관광 기관 / 여행 브랜드 캠페인
- 레트로 일러스트 / 국립공원 포스터 미학

## 사용 시점

- 사용자가 명확하게 "당일 여행 / 하루 일정 / 하루 itinerary / 하루 체크인"을 말할 때
- 레트로 일러스트 + 양피지 + 좌우 분할 디자인을 원할 때
- 경유지 수가 적당할 때(5~7개 권장)
- 경유지마다 시간 + 설명 + 아이콘이 필요할 때

다음에는 사용하지 마세요.

- 여러 날 일정(D1-D7) → `travel-route-map.md` 사용
- 음식점 밀도가 높고 순서가 중요하지 않은 맛집 지도 → `food-map.md` 사용
- 경로가 강조되지 않는 도시 랜드마크 일러스트 → `illustrated-city-map.md` 사용
- 상업적 매장 분포 → `store-distribution-map.md` 사용

## 누락 정보 확인 우선순위

1. 목적지(관광지 / 도시 / 국립공원 이름)
2. 제목 문구(중국어 / 일본어 / 영어 등)
3. 경유지 수(5개 권장, 최대 7개)
4. 각 경유지의 "이름 + 시간 + 중국어 설명 한 문장 + 작은 일러스트 주제"
5. 전체 경로 주제(자연 / 역사 / 음식 / 순례 / 사진 촬영)
6. 스타일 분위기(레트로 일러스트 / 국립공원 포스터 / 수채화 / 아르누보 / 양피지)
7. 색상 방향(따뜻한 세피아 + 금색 / 에메랄드 + 금색 / 청백색 설산)
8. 하단 통계(총 거리 / 걸음 수 / 고도 / 예상 시간)
9. 나침반 장미 / 장식 테두리 / 레트로 인장이 필요한지 여부

## 기본 템플릿: 경유지 5곳 세로 분할 당일 여행 포스터

📖 설명

세로형 2:3 포스터입니다. 왼쪽에는 양피지 일정 카드(제목 + 번호가 붙은 경유지 5곳, 각 경유지에 원형 번호 배지 + 작은 일러스트 + 이름 + 괄호로 표시한 시간 + 중국어 설명)를 놓고 오른쪽에는 환상적 사실주의의 산수화를 둡니다. 오른쪽에는 금빛 구불구불한 경로로 번호가 붙은 표시 5개를 연결합니다. 각 표시의 번호와 이름은 왼쪽 일정과 정확히 일치해야 합니다. 오른쪽 아래에는 나침반 장미 + 통계 정보 상자를 배치합니다. 전체적으로 세피아 + 금색 + 비취색의 레트로 여행 포스터 미학을 사용합니다.

### 매개변수 전략

- **반드시 질문**: destination name, headline, 경유지 5곳(이름 + 시간 + 설명 + 왼쪽 삽화 + 오른쪽 장면)
- **기본값 지정 가능**: 전체 스타일, 좌우 스타일, 색상 팔레트, 통계, 태그라인, 언어
- **무작위 지정 가능**: 태그라인 문구, 통계 수치(사용자가 실제 데이터를 제공한 경우 제외)

### 자동 완성 전략

- 사용자가 "XX 당일 여행을 원해요"라고 하면 인기 명소에 맞춰 시간 순서(아침 → 저녁)로 경유지 다섯 곳을 추론합니다.
- 사용자가 시간을 지정하지 않으면 오전 8:00 / 9:30 / 11:30 / 오후 1:30 / 오후 4:00으로 자연스럽게 진행합니다.
- 언어를 지정하지 않으면 목적지의 공식 언어를 기본으로 사용합니다(대만 → 번체 중국어, 교토 → 일본어, 파리 → 프랑스어, 뉴욕 → 영어).
- 통계를 지정하지 않으면 합리적인 추정치를 사용합니다(5~15km / 8,000~15,000보).

## 피해야 할 사항

- ❌ 좌우 번호가 맞지 않거나 이름이 서로 다름
- ❌ 오른쪽 경로가 모든 표시를 연결하지 않음(번호 순서대로 금색 경로 하나로 연결해야 함)
- ❌ 2:3 분할 레이아웃을 깨뜨림(좌우 너비는 같아야 함)
- ❌ 여러 날 일정을 이미지 한 장에 욱여넣음(**`travel-route-map.md` 사용**)
- ❌ 맛집 지도를 함께 넣음(**`food-map.md` 사용**)
- ❌ 시간 / 설명 / 통계 누락
- ❌ 양피지 카드에 현대적 미니멀 스타일 사용
- ❌ 오른쪽을 단순한 선 지도처럼 그림(산수 장면 전체를 사실적으로 표현해야 함)
- ❌ 모델이 경유지를 임의로 정하게 함(각 지점의 이름 + 시간 + 설명 + 왼쪽 삽화 + 오른쪽 장면을 명시해야 함)
- ❌ 경유지를 7곳 초과로 설정(시각 밀도가 지나치게 높음)
