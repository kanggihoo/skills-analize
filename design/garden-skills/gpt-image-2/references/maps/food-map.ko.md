# 손그림 도시 맛집 지도 템플릿

이 문서는 "도시 / 특정 구역의 맛집 지도" 시각물을 만들 때 사용합니다. 대표 용도:

- 여행 / 맛집 가이드 대표 이미지
- 소셜 미디어 유입용 이미지
- 외식 브랜드 행사 대표 이미지
- 교육 / 문화 설명 이미지
- 도시 IP 굿즈 이미지

주요 특징:

- 손그림 수채화 / 레트로 일러스트 스타일
- 번호가 붙은 위치 표시 + 텍스트 라벨
- 범례와 방향 표시
- 중앙 IP(판다 / 도시 마스코트 / 음식 마스코트)
- 모서리 장식

## 적용 범위

- 도시 맛집 지도
- 동네 맛집 경로 지도
- 명절 / 테마 행사 맛집 지도
- 단일 요리 / 음식 종류별 지도(훠궈 / 차 음료 / 베이킹)

## 사용 시점

- 사용자가 "맛집 지도 / 먹거리 지도 / 도시 맛집 / 맛집 탐방 지도"를 언급할 때
- 소셜 미디어에 공유하기 좋은 강한 손그림 느낌을 원할 때
- "어디에서 무엇을 먹을지 이미지 한 장으로 설명"하고 싶을 때

다음에는 사용하지 마세요.

- 일반 도시 지도를 원하는 경우(`illustrated-city-map.md` 사용)
- 길 안내 지도를 원하는 경우(`travel-route-map.md` 사용)
- 매장 분포 지도를 원하는 경우(`store-distribution-map.md` 사용)

## 누락 정보 확인 우선순위

1. 도시 / 구역 이름
2. 주제: 맛집 / 인기 매장 / 간식 / 음료
3. 맛집 목록: 사용자가 지정하거나 제가 정리
4. 랜드마크 포함 여부(최대 10곳)
5. 스타일: 레트로 양피지 / 현대 수채화 / 귀여운 일러스트
6. 중앙 마스코트(판다, 고추, 도시 상징)가 필요한지 여부
7. 언어: 중국어 / 이중 언어

### 매개변수 전략

- 반드시 질문: 도시 이름, 주제, 맛집 목록(또는 제가 정리해도 되는지), 스타일
- 기본값 지정 가능: 배경 질감, 범례, 나침반
- 무작위 지정 가능: 해당 도시에서 타당한 랜드마크 이름

### 자동 완성 전략

- 사용자가 도시 이름만 주면 그 도시의 유명한 음식 8~12개와 대표 랜드마크 6곳을 선정합니다.
- 기본 스타일은 "레트로 수채화 + 베이지 양피지"입니다.
- 도시별 마스코트를 선택합니다: 청두는 판다, 충칭은 훠궈를 든 판다, 광저우는 거위구이, 베이징은 용, 창사는 취두부.
- 슬로건은 12자 이하로 제한합니다.

## 피해야 할 사항

- 맛집 지도를 실제 지리 축척 지도처럼 그리지 않습니다.
- 맛집 항목을 15개 넘게 넣지 않습니다. 라벨이 서로 밀립니다.
- 범례가 랜드마크와 겹치지 않게 합니다.
- 한 지도에 "맛집 + 경로 + 매장 분포" 기능을 함께 섞지 않습니다(각 기능을 별도 템플릿으로 분리).
- 마스코트를 제목보다 더 눈에 띄게 하지 않습니다(마스코트는 보조 요소입니다).
