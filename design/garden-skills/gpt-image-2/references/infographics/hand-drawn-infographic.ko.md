# 손그림 스타일 인포그래픽 템플릿

이 문서는 "손그림 / 노트 / 낙서 / 따뜻한 마카롱 색 / 모란디 안개색" 분위기의 인포그래픽을 만들 때 사용합니다.

- 학습 노트 / 지식 카드 / 개념 설명
- 공식 계정 / 샤오홍슈용 "손그림 추천" 콘텐츠
- 학습 자료 / 수업 중 낙서
- 여행 다이어리 / 맛집 다이어리 / 독서 노트
- 행사 안내 / 따뜻한 색감의 행사 포스터

특징:

- 모든 선이 약간 흔들리거나 불규칙합니다(손그림의 흔들림).
- 수채화나 색연필처럼 채도가 낮고 따뜻한 색을 사용합니다.
- 요소 사이에 "여백 + 낙서 장식"을 넉넉히 둡니다.
- 글씨는 손글씨 느낌이며 컴퓨터 글꼴이 아닙니다.
- 색을 칠할 때 가장자리까지 채우지 않고 손으로 칠한 것처럼 약간 비워 둡니다.

> 디자인 판단: 손그림 스타일은 하나의 "시각 언어"이며 자유도가 매우 높습니다. 학습 / 음식 / 여행 / 기분 등 주제마다 필요한 구체적인 요소가 크게 달라집니다. **JSON을 억지로 사용하면 오히려 화면의 자유도가 제한됩니다.** 따라서 이 템플릿에서는 순수 JSON 대신 **구조화된 자연어 프롬프트 + 매개변수 표 + 요소 목록**의 혼합 형식을 사용합니다.

## 적용 범위

- 학습 노트 / 개념 해설 / 지식 카드
- 단계별 튜토리얼 / 사용법 / 조작 과정을 손그림으로 표현
- 목록 / 체크리스트 / 순위표의 손그림 버전
- 따뜻한 분위기의 콘텐츠(감정 / 힐링 / 음식 / 여행)
- 공식 계정 / 샤오홍슈 / 소셜 플랫폼의 다이어리 스타일 이미지

## 사용 시점

- 사용자가 "손그림 / 다이어리 / 스케치 노트 / 낙서 / 노트 / 수업 노트 / 마카롱 / 모란디 / 따뜻한 색 / 힐링"을 언급할 때
- "친근하고 읽기 쉬우며 PPT 같지 않은" 시각물을 원할 때
- 독자가 "사람이 직접 그린 그림 같다"고 느끼길 원할 때

다음에는 사용하지 마세요.

- 고밀도 과학 인과 관계 / 해부도를 원하는 경우(`infographics/legend-heavy-infographic.md` 사용)
- 모듈형 벤토 그리드를 원하는 경우(`infographics/bento-grid-infographic.md` 사용)
- 공학적으로 정확한 순서도 / 아키텍처 다이어그램을 원하는 경우(`technical-diagrams/` 사용)
- 출판물 수준의 도표를 원하는 경우(`academic-figures/publication-chart.md` 사용)
- 실제로 힐링 장면 일러스트를 원하는 경우(`scenes-and-illustrations/healing-scene.md` 사용)

## 누락 정보 확인 우선순위

1. 주제(무엇을 설명할지? 예: "커피 내리는 방법 5가지", "포모도로 기법", "상하이 시티 워크 TOP 10")
2. 항목 수(3~7개 권장)
3. 색상 방향(따뜻한 크림색 마카롱 / 모란디 안개색 / 크라프트지 / 칠판 색상)
4. 인물 / 마스코트가 필요한지 여부(고양이 / 간단한 사람 그림 / 인물 없음)
5. 비율(샤오홍슈 세로 3:4 / 공식 계정 가로 16:9 / 정사각 1:1)
6. 색상 면으로 "항목을 구역별로 나눌지" 또는 자유롭게 배치할지

## 기본 템플릿: 손그림 스타일 인포그래픽

📖 설명

노트에 사람이 직접 그린 듯한 인포그래픽 한 장입니다. 따뜻한 배경 + 손글씨 대제목 + 손그림 카드 / 원 / 말풍선 3~7개 + 간단한 아이콘 + 낙서 장식 + 손그림 화살표로 구성합니다.

📝 프롬프트(구조화된 자연어 템플릿)

```
고품질 불렛 저널 페이지 스타일의 손그림 교육 인포그래픽.

주제: {argument name="topic" default="포모도로 기법의 핵심 단계 5가지"}.

화면 비율: {argument name="aspect_ratio" default="3:4 세로형"}.

배경:
- 은은한 입자감이 있는 따뜻한 {argument name="background_color" default="크림색 / 미색"} 종이 질감.
- 선택 사항: 모서리에 사선 줄무늬가 있는 차분한 색상의 와시 테이프 조각을 추가.
- 순백색이나 완전한 검정 배경은 사용하지 않음.

색상 팔레트:
- {argument name="palette" default="macaron"} — 다음 색상 설명을 참고:
  - macaron: 따뜻한 크림색 #F5F0E8 배경, 차분한 파랑 #A8D8EA, 라벤더 #D5C6E0, 민트 #B5E5CF, 복숭아색 #F8D5C4, 강조용 코랄 레드 #E8655A
  - morandi: 더스티 세이지, 테라코타, 머스터드, 토프, 부드러운 벽돌색
  - kraft: 크라프트지 배경, 짙은 갈색 잉크, 강조용 토마토 빨강, 차분한 남색
  - chalkboard: 짙은 슬레이트 배경, 흰색 분필, 노랑 / 코랄 / 민트색 분필 강조
- 전체 색상은 4~5가지로 제한. 강조색은 중요한 내용을 드러낼 때만 조금 사용.

제목:
- 위쪽에 큰 손글씨 캘리그래피로 "{argument name="title" default="포모도로 기법 5단계"}"를 표시.
- 제목은 불규칙한 타원, 물결 모양 사각형, 물결 배너 등 손으로 그린 프레임 안에 배치.
- 선택 사항: 제목 아래에 더 작은 손글씨 활자체로 부제 추가.

본문:
- 정보 항목 {argument name="item_count" default="5"}개.
- 각 항목은 손그림 카드 / 둥근 사각형 / 구름 모양 말풍선 / 원형으로 표현하고 다음을 포함:
  - 손으로 그린 원 안에 숫자 배지(1, 2, 3 ...)
  - 굵은 손글씨 항목 제목
  - 읽기 쉬운 손글씨로 본문 1~2줄
  - 항목을 나타내는 간단한 낙서 아이콘(획 1~2개, 사실적으로 그리지 않음)
- 항목 배치 방식: 세로 목록 / 2열 그리드 / 원형 바퀴 / 구불구불한 경로.

낙서 장식(대칭적이지 않게 자연스럽게 흩어 배치):
- 작은 별, 반짝임, 하트, 곡선 화살표, 점선, 느낌표.
- 중요한 단어를 강조하는 손그림 밑줄과 동그라미 표시.
- 필요한 경우 품질 표시로 웃는 얼굴 / 찡그린 얼굴(😊 ☹) 사용.
- 선택 사항: 이야기꾼 역할을 하는 마스코트 하나(고양이 / 막대 사람 / 얼굴이 있는 커피잔).

스타일 규칙:
- 모든 선에 손그림 특유의 흔들림이 드러나야 함 — 완벽하게 곧은 선은 금지.
- 모든 색상 채우기는 테두리 전에 작은 틈을 남겨 손으로 칠한 느낌을 표현.
- 모든 글씨는 손글씨로 표현 — 컴퓨터 글꼴, Helvetica, Arial 금지.
- 약간의 불완전함은 의도된 것. 디지털로 정밀하게 만든 느낌이 들면 안 됨.
- 이미지 전체가 누군가의 노트 한 페이지처럼 느껴져야 함.

구도:
- 여백을 넉넉하게 확보(캔버스의 약 30~40%).
- 정보 위계: 제목 > 항목 제목 > 본문 > 낙서 장식.
- 항목은 읽을 수 있을 만큼 크게 만들고 지나치게 욱여넣지 않음.

언어: {argument name="language" default="중국어(손글씨 느낌)"}. 기술 용어 / 고유 명사는 영어로 남겨도 됨.
```

### 매개변수 전략

- **반드시 질문**: `topic`, `item_count`, `aspect_ratio`
- **기본값 지정 가능**: `palette`(기본값 macaron), `background_color`(팔레트에 맞춤), `language`(기본값 중국어)
- **무작위 지정 가능**: 마스코트를 넣을지 / 어떤 마스코트를 쓸지, 낙서 장식의 구체적인 모양, 카드 형태(둥근 사각형 / 구름 / 원)

### 자동 완성 전략

- 사용자가 `topic`만 제시하면:
  - 핵심 항목 5개를 자동으로 결정합니다(주제가 "습관 7가지"처럼 명백한 목록이면 7개 사용).
  - macaron 팔레트를 기본으로 적용합니다.
  - 샤오홍슈에 적합한 3:4 세로 비율을 기본으로 사용합니다.
  - 마스코트는 넣지 않습니다(단, "고양이 돌보기 5단계"처럼 주제에 잘 맞으면 고양이를 넣을 수 있음).
- 사용자가 "샤오홍슈 스타일"을 원하면 macaron 또는 morandi 팔레트를 자동 선택하고 비율은 3:4로 설정합니다.
- 사용자가 "교육 / 수업"을 원하면 chalkboard 또는 macaron 팔레트를 자동 선택합니다.
- 사용자가 "따뜻한 분위기 / 음식 / 힐링"을 원하면 morandi 또는 kraft 팔레트를 자동 선택합니다.

## 변형 1: 칠판 분필 손그림 인포그래픽

위 프롬프트의 팔레트를 `chalkboard`로 바꿉니다.

```
배경: 희미한 분필 가루 질감이 있는 짙은 슬레이트 / 칠판 초록(#2F4F4F).
선과 글씨: 압력 변화가 눈에 띄는 흰색 분필.
강조: 중요한 키워드에는 노란 분필, 강조점에는 코랄 / 민트 분필.
장식: 배경에 지워진 분필 자국, 분필 화살표, 분필 밑줄.
```

적합: 수업 자료, 교실 게시판, "수업 중" 분위기의 지식 설명.

## 변형 2: 크라프트지 / 따뜻한 크라프트 손그림 인포그래픽

배경을 `kraft paper`로 바꿉니다.

```
배경: 종이 섬유가 보이는 따뜻한 크라프트지 #C9A876.
선과 글씨: 손그림의 흔들림이 있는 진한 에스프레소 갈색 #3E2723.
강조색: 토마토 빨강 #E63946, 차분한 청록 #457B9D.
장식: 도장 자국, 점선 테두리, 실 / 털실 낙서, 우편물 스타일 요소.
```

적합: 레트로 다이어리, 커피 / 베이킹 / 슬로 라이프, 문화 상품.

## 변형 3: 단색 연필 / 미니멀 손그림 인포그래픽

```
배경: 순수한 크림색 #FAF7F2.
선: 짙은 색 하나만 사용(차콜 #2B2B2B 또는 세피아 #6B4423).
여러 색으로 채우지 않음. 명암에는 다양한 선 굵기와 교차 음영을 사용.
장식: 최소한으로 사용 — 점선과 작은 기호만 추가.
```

적합: 절제되고 문학적이며 진지하지만 손그림 느낌이 필요한 콘텐츠(철학, 독서 노트).

## 피해야 할 사항

- 요소를 완벽한 기하학 형태 / 직선으로 그리면 손그림의 매력이 사라집니다.
- Helvetica / Arial / Source Han Sans 등 컴퓨터 글꼴을 사용하면 즉시 인공적인 느낌이 납니다.
- 색을 가장자리까지 빈틈없이 채우면 손그림이 아니라 디지털 스티커처럼 보입니다.
- 그라데이션 / 그림자 / 유리 질감 / 금속 질감은 스타일에서 완전히 벗어납니다.
- 이미지 한 장에 주색을 6가지 이상 사용하면 다이어리의 절제된 느낌이 사라집니다.
- 글줄 간격이 너무 좁거나 글자 크기가 모두 같으면 위계가 사라집니다.
- 장식이 지나치면 주의를 빼앗아 정보를 읽기 어렵습니다.
- 모든 정보 카드 모양이 완전히 같으면(똑같은 둥근 사각형 5개) 손그림 특유의 자연스러운 느낌이 사라집니다.
