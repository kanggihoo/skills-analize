# 범례가 많은 고밀도 인포그래픽 템플릿

이 문서는 "범례 / 주석이 많고 정보 밀도가 높은" 교육 / 설명형 인포그래픽을 만들 때 사용합니다.

- 의학적 인과 관계 인포그래픽
- 제조 공정 인포그래픽
- 역사 / 문화 해설 인포그래픽
- 장비 / 생물 해부도
- 복잡한 시스템 구조도

특징:

- 중앙에 주요 대상(인체 / 장비 / 개념 도식)이 있습니다.
- 주변에 번호가 매겨진 여러 정보 블록을 배치합니다.
- 각 블록은 "번호 + 제목 + 아이콘 + 하위 항목"으로 구성합니다.
- 중국어와 영어 또는 여러 언어를 함께 표시합니다.
- 정보량은 많지만 레이아웃은 엄격합니다.

## 적용 범위

- 의학 정보 이미지
- 패션 / 디자인 프로세스 다이어그램
- 진화 / 발전 / 역사 타임라인 이미지
- 장비 해부도
- 여러 학문을 잇는 시스템 다이어그램

## 사용 시점

- 사용자가 "인과 관계 / 진화도 / 시스템 도식 / 해부도 / 공정도 / 인포그래픽"을 언급할 때
- 체계 하나를 이미지 한 장에서 설명하고 싶을 때
- 중국어와 영어를 함께 표시하고 싶을 때

다음에는 사용하지 마세요.

- 설명용 슬라이드(`slides-and-visual-docs/dense-explainer-slides.md` 사용)
- 지도(지도 템플릿 사용)
- 발표용 페이지(`policy-style-slide.md` 사용)

## 누락 정보 확인 우선순위

1. 주제(질환 / 공정 / 개념)
2. 메인 제목 + 영어 부제
3. 장 수(8~14개 권장)
4. 중앙 대표 이미지
5. 색상 계열(의료용 빨강·파랑 / 자연 초록 / 기술 파랑 / 베이지색 책 종이)
6. 이중 언어가 필요한지 여부

### 매개변수 전략

- 반드시 질문: 주제, 메인 제목, 장 수, 중앙 대상
- 기본값 지정 가능: 색상 계열, 영어 제목, 하단 요약 문장
- 무작위 지정 가능: 장별 아이콘의 구체적인 형태

### 자동 완성 전략

- 사용자가 주제만 제시하면 장을 8~14개로 자동 구성하고 영어 제목을 함께 작성합니다.
- 중앙 대상은 주제에 따라 선택합니다(의학 → 인체; 제조 → 장비 단면도; 진화 → 타임라인; 역사 → 주인공 실루엣).
- 색상은 주제에 맞춰 기본값을 선택합니다.

## 피해야 할 사항

- 장이 6개 미만이면 내용이 빈약해 보이고 16개를 넘으면 지나치게 빽빽해집니다.
- 중국어 제목과 영어 제목의 글자 크기를 같게 하지 않습니다.
- 모든 장을 한쪽에 쌓지 말고 중앙을 둘러 배치합니다.
- 선이 교차해 읽기 어렵게 하지 않습니다.
- 인포그래픽을 순수 텍스트 포스터로 만들지 않습니다(아이콘 + 중심 대상 필요).
- 주색을 4가지 넘게 사용하지 않습니다.
