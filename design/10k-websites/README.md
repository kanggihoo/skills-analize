# 10K Websites

브리프만 가진 초보자를 데리고 **영화적인 스크롤 사이트**를 기획 → OpenArt로 원본 이미지/영상 생성 →
전용 스크롤 엔진으로 빌드 → Hostinger 배포까지 전 과정을 end-to-end로 수행하는 스킬.

실제 스킬 본체는 `10k-websites/`(원본 repo 구조를 그대로 유지한 중첩 폴더) 안에 있습니다:
`SKILL.md`, `references/*.md`(디자인 지침), `engine/`(스크롤 엔진), `tools/`(인코딩/검증 스크립트),
`backend/`(실제 문의폼 템플릿). 설치 메타데이터는 이 레포 루트의 `design/skills-lock.json`에
`10k-websites` 항목으로 병합되어 있습니다.

## 한 줄 요약

> "영상을 재생"하는 사이트가 아니라, **스크롤 위치를 영상의 재생 시점(프레임)에 직접 매핑해서
> 스크러빙하고, 그 영상 속 표면(벽·테이블·제품 면)에 타이포그래피를 물리적으로 고정시키는**
> 1페이지 마케팅 사이트를 자동으로 만들어주는 스킬.

## 무엇을 하는가 (11단계)

1. **셋업/브리프** — 툴·OpenArt·Hostinger 연결 확인, 비즈니스 정보 수집, 제작 등급 선택
2. **리서치/컨셉** — 실제 고객 언어 조사, 서로 다른 짧은 필름 컨셉 몇 개를 제안
3. **디자인 패키지/견적** — 카피·팔레트·타이포·모션을 하나로 묶은 명세서 작성, 가격 승인
4. **생성/검수** — OpenArt로 키프레임(OPEN-EVENT-REST) 이미지 → 영상 클립 생성, 연속성/정체성 검증
5. **빌드** — `encode.mjs`로 인코딩, `track.mjs`로 영상 속 표면 추적, `filmtype.js`로 타이포 고정
6. **점검/프리뷰/배포/반복** — 자동 검사(`check.mjs`, `typesync.mjs`) → 로컬 프리뷰 → 실 배포 → 추후 수정

- **제작 등급(Production Level)** 3단계(Focused budget / Studio / Full throttle)가 GPT 모델 선택과
  이미지·영상 생성 품질을 동시에 결정
- 결과물은 프레임워크·빌드 스텝 없는 순수 HTML/CSS/JS (`site/`), 스킬이 제공하는 엔진 파일은 그대로 복사해서 사용

## `design/` 안의 다른 스킬들과 다른 점

| 항목 | 10k-websites | 나머지 (web-design-engineer, impeccable, tasteskill 등) |
|---|---|---|
| **출발점** | 생성된 영상/이미지의 **카메라 모션**에서 디자인이 시작됨 | 레이아웃·컬러·타이포 토큰에서 디자인이 시작됨 |
| **핵심 메커니즘** | 스크롤 위치를 영상 재생 시점(frame)에 1:1 매핑하는 **스크러빙 엔진** + 영상 속 표면을 추적해 타이포를 고정하는 CV 기반 트래킹(`track.mjs`) | 없음 — 일반적인 스크롤 애니메이션/엔트런스 모션 수준 |
| **이미지/영상 소스** | **OpenArt API를 직접 호출**해 스킬 워크플로우 안에서 생성(대화 중 생성·대기·다운로드까지 처리) | 사용자가 가진 실제 사진/로고/스크린샷을 "구해오는" 쪽을 우선 (AI 생성 이미지를 대체재로 꺼림) |
| **근거 기반** | 저자의 실전 경험담(실패 사례 각주) 기반 휴리스틱 | tasteskill은 247개 Awwwards 사이트 실증 연구 + 수치 기반 |
| **스타일 선택지** | 없음 — "One world" 원칙만 있고 구체적 팔레트/타입 카탈로그 없음 | web-design-engineer/tasteskill은 Linear·Aesop 등 **named 스타일 레시피 라이브러리** 보유 |
| **자동 검증** | 자체 엔진 전용: 영상 "최악의 프레임" 기준 자막 대비, 스크롤-타이포 동기화(`typesync.mjs`) | 범용 페이지 품질 측정(헤드라인 줄수, 여백, 금지 패턴 등 — tasteskill `inspect.mjs`) |
| **적용 범위** | **영화적 히어로가 있는 1페이지 마케팅 사이트**에 한정된 좁고 깊은 특화 스킬 | 대시보드·앱 UI·슬라이드·프로토타입 등 범용 |
| **배포** | Hostinger 커넥터로 실제 라이브 배포까지 포함 | 배포 범위 밖 (아티팩트/코드 산출까지만) |

**요지**: 10k-websites는 "범용 웹 디자인 스킬"이 아니라, *생성 AI 영상 + 스크롤 스크러빙*이라는
하나의 니치 시나리오에 올인한 특화 스킬입니다. 반면 "기계적으로 보이는 패턴 금지"
(그라데이션, 아이콘 카드 반복, 가짜 후기, Inter/Roboto 디스플레이 폰트 등)에 대한 인식은
`design/` 안의 다른 스킬들과 거의 동일하게 수렴되어 있습니다 — AI 디자인 스킬들 사이의
공통된 업계 컨센서스로 보입니다.
