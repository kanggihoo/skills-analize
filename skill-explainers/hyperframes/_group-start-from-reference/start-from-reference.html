Answer

출발점이 영상 파일이면 reverse-any-video, 영상을 만든 코드(Remotion 등)면 remotion-to-hyperframes, 검증된 스타일 5종 중 하나면 style-sampling으로 간다. 세 스킬은 서로 대안이고 함께 실행하지 않는다. 길을 고르는 안내는 hyperframes의 요청 안내표가 한다.1

  1. 영상 하나를 프레임 단위로 다시 만들려면 reverse-any-video다. HyperFrames Pro 기능이고, 원본과 맞는지 diff로 확인한다.2
  2. 기존 영상 코드와 footage를 HyperFrames로 가져오려면 remotion-to-hyperframes다. Native, Hosted, Media 세 수준 중 가장 높은 수준으로 가져온다.3
  3. 스타일 템플릿 5종 중 하나로 새 에피소드를 만들려면 style-sampling이다. 5종 밖 스타일은 reverse-any-video나 hyperframes로 보낸다.4

어느 길로 가나?

Diagram structure
  • hyperframes hf
  • remotion-to-hyperframes rem
  • reverse-any-video rev
  • style-sampling sty
  • hf → rem · Remotion 코드 R07
  • hf → rev · 영상 파일 R04
  • hf → sty · 스타일 에피소드 R05
  • sty → rev · 5종 밖 제안 R21

화살표는 원장의 넘김이다. hyperframes의 안내표는 요청 종류를 알려 줄 뿐이며 스킬을 자동 호출하지 않는다. style-sampling이 5종 밖 스타일을 reverse-any-video로 보내는 것은 제안이고, 사용자가 길을 고른다.14

  1. hyperframes ↗

    요청 종류를 보고 갈 스킬을 알려 준다.

  2. reverse-any-video ↗

    영상 하나를 편집 가능한 프로젝트로 다시 만들고 원본과 대조한다.

  3. remotion-to-hyperframes ↗

    영상 코드를 Native·Hosted·Media 중 한 수준으로 가져와 대조한다.

  4. style-sampling ↗

    템플릿 5종 중 하나를 pull해 사용자 주제의 새 에피소드를 만든다.

각 스킬 내부 규칙과 수치는 개별 페이지에 있다. 색인 기준 hyperframes/reverse-any-video/reverse-any-video.html, hyperframes/remotion-to-hyperframes/remotion-to-hyperframes.html, hyperframes/style-sampling/style-sampling.html에서 본다.

어떤 관계로 무엇을 주고받나?

rel-id·종류조건과 전달물그림 반영
R04·R05·R07 · 넘김hyperframes 안내표가 복사·재현할 영상은 /reverse-any-video, 검증된 스타일 에피소드는 /style-sampling, Remotion source는 /remotion-to-hyperframes로 안내한다. 강제는 아니다. /remotion-to-hyperframes는 온디맨드 스킬이라 설치돼 있지 않을 수 있다.1표시
R21 · 넘김5종 밖 스타일(채널·영화를 이름으로 댄 경우)이면 style-sampling이 한 줄로 알리고 두 길을 제안한다. 영상 하나를 프레임 단위로 다시 만들고 내용을 바꾸는 /reverse-any-video가 그중 하나다. 사용자가 고른다.4표시
R22 · 넘김다른 길은 그 스타일의 문법을 가져와 새 영화를 만드는 /hyperframes("From a reference")다. 이름만 댄 스타일은 예시 영상을 요청한다.4생략(되돌아가는 선)
R14·R15 · 참고reverse-any-video는 결과물을 /hyperframes 계약에 맞춰 만들고, remotion-to-hyperframes는 Native 단계에서 /hyperframes 계약으로 번역한다.25생략(되돌아가는 선)
R28 · 같은 계열reverse-any-video(영상 파일)와 remotion-to-hyperframes(영상 코드)는 모두 기존 작업을 HyperFrames로 가져와 원본과 프레임 단위로 대조한다. 직접 연결은 없다. 판정이며 두 description이 근거다.23생략
R23·R24 · 참고·공유 상태style-sampling은 생성 media에 media-use의 Credits 규칙을 따르고, 사용자가 말한 한도를 .hyperframes/credit-limit.json에 쓴다.6생략

관계의 단일 원본은 relations.md다.

어떤 선택을 피해야 하나?

판정 · 새 영상을 기획하거나 스타일만 빌릴 때는 reverse-any-video가 맞지 않는다. 이 스킬의 원문에 직접 금지 문장은 없고, 영상 한 편을 그대로 복원하는 목적이라는 점과 style-sampling의 제안이 근거다.24 또 style-sampling은 5종 템플릿을 기억이나 웹에서 다시 만들지 않는다.7
