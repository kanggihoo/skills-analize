principle-build-the-lever 스킬은 에이전트를 어떻게 바꾸나

Long image

A

Answer

principle-build-the-lever를 읽은 에이전트는 사소하지 않은 일을 손으로 하지 않는다. 그 일을 하거나 증명하는 도구(지렛대)를 먼저 만든다. 코드모드, 스크립트, 생성기, 서브에이전트가 따르는 스킬이 여기에 든다.1

  1. 원문이 드는 이득은 둘이다. 도구는 매번 같은 방식으로 일하고 공짜로 다시 돈다. 리뷰어는 도구 하나를 읽고 다시 돌려서 확인한다.2
  2. 기준은 반복 여부가 아니라 사소함이다. 한눈에 보이는 뻔한 수정 두어 개만 예외다.34
  3. 이 원칙을 적용하면 파일이 남는다. 인용했는데 diff에 도구가 없으면 적용하지 않은 것이다.5
  4. 도구는 가장 작은 스크립트로 만든다. 프레임워크를 만들지 않는다.4
