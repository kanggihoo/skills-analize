principle-experience-first 스킬은 에이전트를 어떻게 바꾸나

Long image

A

Answer

principle-experience-first를 읽은 에이전트는 구현이 편한 쪽과 사용자가 만족하는 쪽이 부딪히면 사용자 만족을 고른다. 기능을 적게, 대신 다듬어서 내보낸다.1

  1. 모든 기능, 컨트롤, 옵션은 있어야 할 이유를 대야 한다.2
  2. 원문에서 사용자는 작업 결과를 쓰는 사람 모두다. UI에서는 최종 사용자이고, 라이브러리나 내부 인터페이스에서는 그것을 가져다 쓰는 동료다. 다음에 코드를 고칠 엔지니어도 사용자다.3
  3. 작업의 영향은 그 사용자의 관점에서 설명한다.3
  4. 이 원칙은 일의 목표를 정한다. 일의 순서는 기초 설계 원칙(principle-foundational-thinking)이 정한다.4
