  • landing-page-design 단일 오퍼·타깃·CTA 전략과 엄격한 시각 규칙으로 전환형 랜딩 페이지를 만든다
  • web-design-engineer 5개 다이얼과 3단계 체크포인트로 웹 페이지·대시보드·프로토타입을 구현·리디자인한다
  • impeccable 24+개 서브 커맨드와 전용 서브에이전트·훅으로 프론트엔드 품질을 전 주기 관리한다
  • design-taste-frontend 업종별 deal과 내장 에셋·린트·Chrome 게이트(Stop 훅)로 AI 티 없이 웹사이트를 제작한다

garden-visual

Garden 계열 시각 아티클·이미지·영상·지식검색을 수행한다
  • beautiful-article 원자료을 8단계 하네스와 reacticle 컴포넌트로 편집해 오프라인 HTML 아티클을 만든다
  • gpt-image-2 실행 환경을 판별해 API 호출·호스트 도구 위임·프롬프트 가이드로 GPT Image 2를 생성·편집한다
  • kb-retriever 계층적 data_structure.md 색인과 점진적 검색으로 로컬 지식베이스에서 근거를 찾는다
  • motion-showreel 결정론적 웹 페이지와 타임라인·오디오로 최대 20분 모션 그래픽 MP4를 렌더링한다
  • web-design-engineer 5개 다이얼과 3단계 체크포인트로 웹 페이지·대시보드·프로토타입을 구현·리디자인한다
  • web-video-presentation 원고를 구술 대본과 1920x1080 클릭 진행형 웹 무대로 구축해 녹화까지 지원한다

motion-craft

웹·모바일 애니메이션을 설계·진단·개선·리뷰한다
  • animate 필요 여부부터 중단·종료 처리까지 정해진 순서로 웹 애니메이션을 구현한다
  • animate-expo React Native와 Expo에서 UI 스레드 기반으로 제스처·시트·전환 애니메이션을 구현한다
  • animation-performance 웹 애니메이션의 프레임 드랍 원인을 진단하고 합성 전용 속성으로 성능을 고친다
  • animation-vocabulary 모호한 모션 묘사를 정확한 웹 애니메이션 용어와 정의로 역조회해 준다
  • apple-design Apple의 유체 인터페이스·스프링·제스처 원칙을 웹 구현 규칙으로 옮겨 적용한다
  • emil-design-eng UI 폴리시와 애니메이션 판단 등 Emil Kowalski의 디자인 엔지니어링 원칙을 적용한다
  • find-animation-opportunities 코드베이스에서 애니메이션이 필요한 지점만 골라 구현 없이 정확한 수치로 제안한다
  • improve-animations 코드베이스의 애니메이션을 감사해 우선순위별 개선 계획서를 작성하고 필요 시 위임한다
  • review-animations 애니메이션 코드를 기준표로 리뷰해 Before/After 표와 Approve/Block 판정을 내린다

ui-component

UI 라이브러리 선택·프로토타입 비교·극한 데이터 테스트를 수행한다
  • stageshow React/CSS 키트와 커서 리허설로 실제 제품처럼 보이는 가짜 제품 UI 데모를 만든다
  • animate 필요 여부부터 중단·종료 처리까지 정해진 순서로 웹 애니메이션을 구현한다
  • ask-sonner React 토스트 라이브러리 Sonner의 설치·호출 패턴·트러블슈팅을 안내한다
  • break-ui 최악의 데이터를 주입해 UI가 깨지는 지점과 수정안을 보고한다
  • mobile-native 모바일 웹 앱의 CSS·메타태그를 고쳐 네이티브 앱 같은 사용감을 만든다
  • pick-ui-library 프론트엔드 UI 작업에 맞는 라이브러리를 큐레이션 목록에서 골라 설치까지 돕는다
  • prototype 방향이 다른 3~5개 UI 프로토타입을 플로팅 피커로 비교한 뒤 고른 안을 코드에 통합한다

interface-audit

Jakubkrehel 도메인 규칙으로 인터페이스 전체와 변경분을 리뷰·개선한다
  • afk 부재 중 프로젝트 증거를 모아 개선점을 로컬 브랜치에 구현·검증하고 보고서를 남긴다
  • better-accessibility WCAG 2.2 기준으로 키보드·포커스·ARIA·폼·확대/리플로우를 리뷰하고 수정한다
  • better-colors OKLCH 팔레트 생성, 시맨틱 토큰 명명, 포맷 변환 및 렌더링 대비 측정을 수행한다
  • better-interface 7개 better-* 도메인 스킬을 순차 호출해 단일 우선순위 인터페이스 리뷰 보고서를 낸다
  • better-layout 그룹화·정렬·여백·읽기 순서·반응형·RTL 대응을 설계하고 검증한다
  • better-typography 타입 스케일·폰트·줄바꿈·문장부호·숫자 정렬 등 텍스트 렌더링을 설정·리뷰한다
  • better-ui 모서리 반경·광학적 정렬·그림자·아이콘 상태를 정밀 수치로 마감한다
  • better-writing 레이블·에러·빈 상태 등 인터페이스 카피를 제품 어조와 용어에 맞게 작성·리뷰한다
  • build-design Figma나 디자인 이미지를 프로젝트 기존 토큰·컴포넌트로 구현하고 비교 검증한다
  • interface-review 브랜치·PR·미커밋 변경분의 영향 범위와 제거 신호를 추출해 better-interface에 넘긴다

component-workbench

컴포넌트 스트레스 테스트·상태 확인·대안 비교·역설계·기술 일러스트를 수행한다
  • break 컴포넌트 하나를 임시 페이지에 최악 시나리오별로 한꺼번에 렌더링해 깨짐을 찾는다
  • explain-interface 라이브 URL이나 스크린샷을 분석해 프론트엔드 시스템과 시각 효과 구현을 설명한다
  • state-machine 컴포넌트의 모든 도달 가능 제품 상태를 모의 데이터·스위처가 있는 페이지에 렌더링한다
  • teardown 실물·개념의 조립/분해도 기하 모델을 구축해 독립 뷰어 페이지로 패키징한다
  • variant 실제 페이지 맥락에서 단일 디자인 축을 따라 3가지 컴포넌트 변형과 피커를 만들어 고른다
