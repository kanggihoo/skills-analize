묶음

motion-craft

웹 UI의 모션을 찾고, 계획하고, 만들고, 검토한다
  • animate 웹 애니메이션을 "움직일지부터 퇴장까지" 정해진 순서로 결정하며 직접 구현한다
  • animate-expo React Native·Expo 앱의 애니메이션과 제스처를 스레드·스프링 순서로 결정해 구현한다
  • animation-performance 끊기는 웹 애니메이션의 원인을 찾아 프레임 예산 안에 들게 고친다
  • find-animation-opportunities 아직 움직이지 않는 곳 중 애니메이션이 정말 필요한 곳만 골라 수치와 함께 제안한다(코드는 안 고침)
  • improve-animations 코드베이스의 모션 코드를 감사해 우선순위 목록과 다른 에이전트가 실행할 구현 계획을 쓴다
  • review-animations 애니메이션 코드를 높은 기준으로 리뷰한다. 기본은 지적이고 통과는 얻어 내야 한다(명시 호출만)

ui-component

UI 조각을 라이브러리로 고르거나 여러 버전으로 만들어 보고, 최악의 데이터로 깨 본다
  • animate 웹 애니메이션을 "움직일지부터 퇴장까지" 정해진 순서로 결정하며 직접 구현한다
  • ask-sonner React toast 라이브러리 Sonner의 설치·사용법과 흔한 고장을 답한다
  • break-ui 긴 이름·빈 값·이모지 같은 최악의 데이터를 넣어 UI가 깨지는 곳을 찾고 고칠 방법을 보고한다
  • pick-ui-library 프론트엔드 작업(toast, 차트, 드래그 등)에 맞는 라이브러리를 정해진 추천 목록에서 고른다(명시 호출만)
  • prototype 설명한 UI 조각을 서로 다른 버전 여러 개로 만들어 화면 선택기로 비교하게 한다(명시 호출만)

garden-visual

만들 결과물(웹 페이지, 장문 기사, 클릭형 발표, MP4 모션 영상, 이미지)에 맞는 garden 스킬을 고른다
  • beautiful-article URL·PDF·문서 같은 소재를 오프라인으로 열리는 단일 HTML 장문 웹 기사로 만든다
  • gpt-image-2 GPT Image 2용 템플릿으로 이미지를 생성·편집하거나, 도구가 없으면 프롬프트를 짜 준다
  • motion-showreel 코드로 그래픽·글자·UI 모션 영상을 만들어 MP4와 편집 가능한 소스로 낸다(최대 20분)
  • web-design-engineer HTML·CSS·JS·React로 페이지·대시보드·프로토타입·슬라이드 같은 시각 결과물을 만든다
  • web-video-presentation 글이나 원고를 클릭으로 넘기는 "영상 같은" 16:9 웹 발표로 만들고 음성을 붙인다

site-design-choice

랜딩 페이지·회사 웹사이트를 만들 스킬을 고른다(작성자가 다른 대안 비교)
  • 10k-websites 초보자를 브리프부터 스크롤 연출 웹사이트 제작, OpenArt 이미지·영상 생성, Hostinger 배포까지 데려간다
  • landing-page-design 질문·섹션 구성·카피·SEO와 엄격한 시각 규칙으로 전환율 높은 랜딩 페이지를 만든다
  • web-design-engineer HTML·CSS·JS·React로 페이지·대시보드·프로토타입·슬라이드 같은 시각 결과물을 만든다
  • impeccable 프론트엔드 UI를 설계·비평·감사·다듬는 명령 24개 모음. 디자인 문맥 파일·검사 엔진·편집별 hook을 함께 쓴다
  • design-taste-frontend 업종(6종)에 따라 허용 범위를 정하고, AI 티를 없앤 회사·제품 웹사이트를 만들어 headless Chrome 검사기로 수치 판정한다

interface-audit

화면·흐름·저장소나 branch·PR 변경을 여섯 도메인 스킬로 리뷰해 순위 매긴 보고서 하나로 합친다
  • better-accessibility 키보드·focus, ARIA, 접근 가능한 이름, 폼, 스크린 리더 안내, 모션·확대를 WCAG 2.2 기준으로 리뷰하고 고친다
  • better-colors 팔레트를 만들고 semantic token 이름을 정하고 색 형식을 바꾸며 대비를 수치로 잰다
  • better-interface 화면·흐름·저장소 전체를 접근성·레이아웃·카피·타이포·색·UI 완성도로 리뷰해 순위 매긴 보고서 하나로 합친다
  • better-layout 묶음·정렬·읽는 순서·반응형 구조·번역 글자 여유를 정해 크기·번역·좌우 반전에도 버티는 레이아웃을 만든다
  • better-typography type scale, 간격, 폰트 기능, 줄바꿈·말줄임, 문장부호까지 글자가 그려지는 방식을 정하고 리뷰한다
  • better-ui border radius, 광학 정렬, shadow, 아이콘 상태, 애니메이션의 정확한 값으로 표면·아이콘·모션을 다듬는다
  • better-writing 라벨·에러·빈 상태·확인 창 같은 인터페이스 카피를 제품 어조에 맞게 쓰고 리뷰해 다음 행동을 알려 준다
  • interface-review branch·PR·미커밋 변경이 새로 만들거나 퇴보시킨 인터페이스 문제를 diff 단위로 리뷰하고 better-interface에 넘긴다(명시 호출만)

component-workbench

한 컴포넌트를 상태별·대안별·최악의 데이터로 임시 페이지에서 작업한다
  • break 고른 컴포넌트를 닿을 수 있는 모든 시나리오로 임시 페이지에 그려 스트레스 테스트한다(명시 호출만)
  • state-machine 고른 컴포넌트가 가질 수 있는 모든 상태를 mock 데이터와 전환기를 단 임시 페이지에 그려 상태별로 작업하게 한다(명시 호출만)
  • variant 작업 중인 컴포넌트를 의도적으로 다른 3가지 버전으로 만들어 실제 페이지의 picker로 비교·선택하게 한다(순위는 매기지 않음, 명시 호출만)

  • build-design Figma 파일이나 디자인 이미지를 프로젝트의 기존 token·컴포넌트로 같은 모양의 UI로 만든다
  • explain-interface 실제 URL이나 스크린샷을 보고 웹사이트·시각 효과·애니메이션이 어떻게 만들어졌는지 설명한다(평가하지 않음, 명시 호출만)
  • teardown 물리 물체나 디스플레이 픽셀·인터페이스 레이어 같은 작동 원리를 분해도·가는 선·부품 색으로 그린 기술 일러스트를 만든다
