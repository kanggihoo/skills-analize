묶음

ship

변경을 검증하고 PR로 올려 병합한다
  • dsh-ci-test-reliability CI 동시 실행·시계·프로세스 전역 상태 때문에 흔들리는 테스트를 설계·리뷰·진단한다
  • dsh-merging-stacked-prs 서로 기대는 PR 묶음을 GitHub 공식 스택 기능과 gh stack으로만 병합한다
  • dsh-pr-description PR 설명의 각 절, 이슈 참조, 테스트 설계, AI 사용 등급표를 정하고 언제 갱신할지 정한다
  • dsh-pre-push-checks push·준비 완료 표시 전에 바뀐 범위를 덮는 가장 작은 테스트와 검사만 골라 돌린다
  • record-browser-gif 브라우저 조작 데모를 GIF로 녹화·인코딩해 PR에 첨부한다. GUI를 바꾸는 PR에는 필수다

review

deepseek-harness PR을 리뷰한다
  • cordis-styling-nitpicking Cordis 플러그인 코드에서 싱글턴 상태·되돌리지 않는 부작용·정리 순서 위반 세 가지 P0만 근거를 들어 찾는다
  • dsh-ci-test-reliability CI 동시 실행·시계·프로세스 전역 상태 때문에 흔들리는 테스트를 설계·리뷰·진단한다
  • dsh-client-ui-ux 클라이언트 GUI 변경에서 알림 위치·재사용·오버레이 안전·플랫폼 창 적응 같은 판단을 안내한다
  • dsh-code-review deepseek-harness PR을 리뷰할 때 읽을 규칙과 다른 스킬을 알려 주고, 코드만으로는 안 보이는 점검 항목을 시킨다
  • dsh-error-handling 실패 분류·처리 책임·상태 보장·사용자에게 보이는 오류 보고의 원칙을 적용한다
  • dsh-prose-standard 저장소의 모든 글(문서·주석·프롬프트·UI 문자열)에서 계약을 지키며 필요한 만큼만 쓰게 한다
  • dsh-session-projection 세션에서 복구할 상태를 Projection으로 만들거나 늘리거나 옮길 때의 규칙을 적용한다

docs

문서와 글을 쓰고 다듬는다
  • dsh-create-upgrade-guide 외부에서 보이는 표면을 깨는 변경에 대해 버전별 업그레이드 가이드를 쓰거나 고친다
  • dsh-doc DSH 문서·패키지 README·문서 웹사이트를 독자 우선 계층과 이중 언어 정렬 규칙으로 쓰고 감사한다
  • dsh-pre-push-checks push·준비 완료 표시 전에 바뀐 범위를 덮는 가장 작은 테스트와 검사만 골라 돌린다
  • dsh-prose-standard 저장소의 모든 글(문서·주석·프롬프트·UI 문자열)에서 계약을 지키며 필요한 만큼만 쓰게 한다
  • dsh-translate-docs 사용자가 이름으로 부를 때만 확장 이중 언어 번역 워크플로를 돌린다
  • dsh-trim-cot-leakage 주석·문서에 남은 작업 세션의 추론 흔적(결정 번호, 변경 서술, 리뷰어에게 하는 말)을 찾아 지금 상태로 고쳐 쓴다

client-ui

클라이언트 GUI를 설계·리뷰하고 증거를 남긴다
  • dsh-client-ui-ux 클라이언트 GUI 변경에서 알림 위치·재사용·오버레이 안전·플랫폼 창 적응 같은 판단을 안내한다
  • dsh-error-handling 실패 분류·처리 책임·상태 보장·사용자에게 보이는 오류 보고의 원칙을 적용한다
  • dsh-official-plugin-artwork 공식 플러그인 아이콘과 기능 미리보기 그림을 그리고 리뷰한다(툴바·액션 아이콘 제외)
  • dsh-responsive-ui 반응형 레이아웃·터치 판별·말줄임·아이콘 전용 버튼·폭 변화 중 포커스를 설계하고 리뷰한다
  • record-browser-gif 브라우저 조작 데모를 GIF로 녹화·인코딩해 PR에 첨부한다. GUI를 바꾸는 PR에는 필수다

cleanup

코드와 기록을 줄이고 Agent Note를 정리한다
  • dsh-archive-agent-notes Agent Note를 추가·정리할 때 대체된 기록을 찾고, 남길지·지울지·보관할지 정해 보관 규칙대로 옮긴다
  • dsh-find-simplifications 코드·API·설정·테스트·글에서 근거 있는 단순화 후보를 찾아 제안서로 쓰거나 작은 정리 거리를 짚는다
  • dsh-pre-push-checks push·준비 완료 표시 전에 바뀐 범위를 덮는 가장 작은 테스트와 검사만 골라 돌린다

독립 스킬

  • dsh-cua-macos-signing 소스로 Computer Use를 쓰는 macOS 개발자에게 고정 서명 키를 권하고 만들기·설정·제거를 돕는다
  • dsh-speed-up-perf 성능 문제를 실제와 닮은 벤치마크로 재고 동작을 바꾸지 않는 수정으로 개선한다
