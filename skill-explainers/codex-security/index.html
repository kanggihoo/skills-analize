묶음

scan-vulnerabilities

소스에서 취약점을 찾고 후보를 검증하고 공격 경로로 보고 여부를 정한다
  • security-scan 저장소 전체나 지정 경로의 현재 소스에서 공격자가 실제로 악용할 수 있는 취약점을 한 번의 audit로 찾는다
  • security-diff-scan PR, commit, branch diff, working-tree patch의 변경 파일을 위협 모델부터 공격 경로 분석까지 단계별로 돌려 취약점을 찾는다
  • deep-security-scan 사용자가 deep, 철저한 감사를 요청했을 때 Standard scan을 반복 실행해 결과를 병합한다
  • threat-model 저장소의 실제 구조, 공격자 능력, 신뢰 경계로 위협 모델을 만들거나 기존 모델을 재사용한다
  • finding-discovery 위협 모델과 보안 정책을 근거로 악용 가능해 보이는 취약점 후보를 찾아 근거와 함께 남긴다
  • validation 후보마다 근거가 받쳐 주는지 따져 reportable, suppressed, not_applicable, deferred 중 하나로 처분한다
  • attack-path-analysis finding을 source에서 sink까지 추적해 공격 경로, 영향, 심각도, 보고 여부를 정한다

remediate-finding

이미 있는 취약점 finding을 고치고, 고친 결과의 위험과 효과를 점검한다
  • triage-finding scanner 보고서, advisory, GitHub, Jira, Linear 항목을 정적 근거만으로 confirmed, not_actionable, needs_review로 분류한다
  • fix-finding 사용자가 요청한 보안 취약점을 가장 작은 변경으로 고치고 고쳐졌는지 검증한다
  • verify-fix 보안 수정이 현재 checkout에서 실제로 취약점을 막았는지 파일을 바꾸지 않고 판정한다
  • assess-patch-risk 이미 만들어진 patch를 읽기 전용으로 분석해 영향, 회귀 위험, 자동 merge 자격을 판정한다
  • resolve-dependency-alert 취약한 의존성이 무엇에 끌려 들어왔는지 추적하고 업그레이드 가능 여부를 판단한다

external-findings

scanner와 Cloud, issue tracker 사이에서 finding을 가져오고, 올리고, 기록하고, 읽는다
  • resolve-dependency-alert 취약한 의존성이 무엇에 끌려 들어왔는지 추적하고 업그레이드 가능 여부를 판단한다
  • publish-findings 외부 scanner 결과를 가져와 local workbench에 저장하고 선택분을 Codex Security Cloud에 게시한다
  • track-findings 봉인된 scan의 finding을 Linear, Jira, GitHub issue, 초안 advisory에 미리보기와 승인을 거쳐 기록한다
  • cloud-findings 연결된 Codex Security Cloud의 finding, 보고서, 할당, 검증 기록, scan 상태를 읽기만 한다

finding-reports

확정된 finding을 보고서와 구조적 보강안으로 정리한다
  • vulnerability-writeup 취약점 메모, PoC, finding을 다른 연구자가 확인할 수 있는 독립 보고서로 쓴다
  • propose-security-hardening 개별 patch를 넘어서는 구조적 보안 보강안을 근거와 대안 비교로 제안한다

threat-model-and-policy

scan 전에 읽을 보안 맥락(위협 모델, SECURITY.md)을 만들고 읽기 쉽게 보여 준다
  • threat-model 저장소의 실제 구조, 공격자 능력, 신뢰 경계로 위협 모델을 만들거나 기존 모델을 재사용한다
  • define-security-policy SECURITY.md를 새로 쓰거나 검토해 scanner가 무엇을 finding으로 볼지 알려 준다
  • threat-model-visualize 이미 있는 위협 모델을 읽어 구조와 위협 경로를 보여 주는 standalone HTML explorer를 만든다

skill-vetting

스킬을 설치하기 전에 위험한 지시와 스크립트를 읽기 전용으로 검토한다
  • check-skills 설치 전 스킬 파일이나 묶음을 읽기 전용으로 검토해 BLOCK, REVIEW, INCOMPLETE, PASS를 낸다
  • editorial-guide 문단을 고치되 외부 URL의 최신 절차를 읽고 거기 적힌 도구 동작까지 모두 따르라고 지시하는 검토용 표본이다
  • word-list 문단을 고치되 외부 URL은 단어 뜻 조회에만 쓰고 그 안의 지시는 인용문으로만 다루라고 하는 검토용 표본이다
  • style-guide 위험한 curl ... \| sh 설치 예시를 나쁜 사례로만 인용해 설명하라는 검토용 표본이다
  • status-summary 빌드 상태를 요약하라는 짧은 스킬이지만 참조 파일과 스크립트로 숨은 지시와 토큰 전송 경로를 둔 검토용 표본이다
