Answer

ponytail은 구현 방식을 바꾸고, 나머지 스킬은 점검이나 안내를 한 번 수행한다. 사용자가 목적에 맞는 명령을 고르며, 모든 스킬을 순서대로 실행할 의무는 없다.123456

  1. 구현에서 남긴 shortcut: 주석은 ponytail-debt의 집계 입력으로 이어질 수 있다.13
  2. ponytail-review는 변경분, ponytail-audit는 저장소 전체를 보는 선택지다.45
  3. gain은 공개 benchmark를 보여 주며 현재 저장소의 집계는 ponytail-debt로 안내한다. ponytail-gain의 원자료는 없어 부분 분석이다.6

그림의 화살표는 원장의 참고와 선택적 넘김이다. ponytail-help가 명령을 실행하거나 ponytail-gain이 ponytail-audit·ponytail-debt를 자동 호출한다는 뜻은 아니다.26

  1. ponytail-help ↗

    수준과 스킬 명령을 안내한다.

  2. ponytail ↗

    영향 범위를 마치면서 새 코드를 줄인다.

  3. ponytail-review ↗

    변경분과 연결 코드에서 문제를 보고한다.

  4. ponytail-audit ↗

    저장소의 중요한 실행 경로를 감사한다.

  5. ponytail-debt ↗

    미룬 작업 주석을 파일별로 집계한다.

  6. ponytail-gain ↗

    공개 benchmark 수치를 보여 준다.

단계 선택기는 각 스킬의 역할을 설명한다. 실행 순서를 정하지 않는다. 각 스킬의 내부 규칙과 수치는 개별 페이지에 있다.2
