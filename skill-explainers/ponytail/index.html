묶음

minimal-code

불필요한 코드를 줄이고 남긴 한계와 위험을 점검한다
  • ponytail 영향 범위를 끝까지 고치면서 새 코드를 최소화한다
  • ponytail-review diff와 연결 코드를 읽어 고칠 문제를 보고한다
  • ponytail-audit 저장소의 위험한 실행 경로를 감사해 문제를 우선순위로 보고한다
  • ponytail-debt 미룬 작업을 표시한 주석을 모아 한계와 재검토 조건을 보고한다
  • ponytail-gain 공개 benchmark 수치를 보여 주고 현재 저장소의 절감량을 꾸며내지 못하게 한다
  • ponytail-help 수준과 명령을 안내하고 모드나 파일은 바꾸지 않는다
