ponytail-debt는 미뤄 둔 작업을 어떻게 드러내나?

Long image

A

Answer

ponytail-debt는 주석에 적힌 한계와 재검토 조건을 모아 보고한다. 주석을 읽어서 집계하므로, 표시하지 않은 작업이나 실제 절감량까지 알아내지는 못한다.12

  1. shortcut:과 구형 ponytail:을 찾고 파일별로 한 줄씩 묶는다.12
  2. 재검토 조건이 없는 항목에는 no-trigger를 붙인다.2
  3. 기본은 읽기와 보고만 한다. 파일 저장은 별도로 물어본 뒤 한다.3

언제 쓰고 무엇을 입력받나?

description은 모델이 호출 여부를 판단할 때 참고하는 설명이다. 특정 단어와 정확히 일치해야 켜진다는 뜻은 아니다. disable-model-invocation 필드는 이 원문에 명시되어 있지 않다.4

원문은 미룬 작업 확인, 지름길 목록과 /ponytail-debt를 호출 맥락으로 든다. /ponytail-debt TODO처럼 사용자가 표식을 지정하면 기본 표식 대신 그 단어를 검색한다.41

  1. 주석 검색 ↗

    .git과 .gitignore가 무시하는 파일을 제외한다. 언어에 필요한 주석 접두어를 더한다.1

  2. 미룬 작업? ↗

    표식 규칙을 설명하는 문장과 단축키 같은 동음이의 항목을 뺀다.1

  3. 파일별 집계 ↗

    적합한 주석 하나당 원장 한 줄을 만든다.2

원문의 검색 명령은 분석 자료로만 읽었다. 여기서는 실행하지 않았다.1

실행으로 확인하지 않은 부분

검색 명령의 실제 호환성과 표식 누락률은 실행으로 확인하지 않았다. 사용자 정의 표식에서도 적용할 정확한 검색식은 원문에 명시 없음.

분석 중 원본은 수정하지 않았다. 분석 전 사용자 승인으로 컬렉션 7개 파일을 commit했다. 새 분석 초안과 HTML, 관계 원장, 색인, 검증 보고서를 작성했다. 원문의 명령과 설치·설정 변경은 실행하지 않았다.
