# 에이전틱 엔지니어링

AI 에이전트가 대부분의 구현 작업을 수행하고, 사람이 품질과 위험 통제를 맡는 엔지니어링 워크플로에 이 스킬을 사용하세요.

## 운영 원칙

1. 실행 전에 완료 기준을 정의하세요.
2. 작업을 에이전트가 다룰 수 있는 단위로 분해하세요.
3. 작업 복잡도에 따라 모델 등급을 라우팅하세요.
4. 평가와 회귀 검사로 측정하세요.

## 평가 우선 루프

1. 능력 평가와 회귀 평가를 정의합니다.
2. 기준선을 실행하고 실패 시그니처를 기록합니다.
3. 구현을 실행합니다.
4. 평가를 다시 실행하고 변화량을 비교합니다.

## 작업 분해

15분 단위 규칙을 적용하세요:
- 각 단위는 독립적으로 검증 가능해야 합니다
- 각 단위는 지배적인 위험 하나만 가져야 합니다
- 각 단위는 명확한 완료 조건을 드러내야 합니다

## 모델 라우팅

- Haiku: 분류, 상투적 변환, 좁은 범위의 편집
- Sonnet: 구현과 리팩터링
- Opus: 아키텍처, 근본 원인 분석, 여러 파일에 걸친 불변식

## 세션 전략

- 밀접하게 연결된 단위에는 세션을 이어서 사용하세요.
- 주요 단계가 바뀌면 새 세션을 시작하세요.
- 마일스톤이 끝난 뒤에 압축하고, 활발한 디버깅 중에는 압축하지 마세요.

## AI 생성 코드의 리뷰 초점

다음을 우선하세요:
- 불변식과 엣지 케이스
- 오류 경계
- 보안 및 인증 가정
- 숨겨진 결합과 롤아웃 위험

자동 포맷/린트가 이미 스타일을 강제하고 있다면, 스타일에 관한 의견 차이로 리뷰 주기를 낭비하지 마세요.

## 비용 관리

작업마다 다음을 기록하세요:
- 모델
- 토큰 추정치
- 재시도 횟수
- 실제 소요 시간(wall-clock)
- 성공/실패

낮은 등급의 모델이 명확한 추론 격차로 실패할 때에만 모델 등급을 올리세요.
