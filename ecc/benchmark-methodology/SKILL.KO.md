# 벤치마크 방법론

범위가 정해진 경쟁사 집합을 **비교 가능하고 근거가 탄탄한 점수**로 바꾸는 데 이 스킬을 사용합니다. 각 경쟁사는 같은 9개 차원에서 명시적인 1-5 루브릭으로 평가되며, 이후 통일된 프로필 카드로 정리됩니다. 일관성이 핵심입니다. 같은 근거라면 어떤 경쟁사든 같은 점수를 받아야 점수가 쓸모가 있습니다.

## 사용 시점

- competitive-platform-analysis에서 범위가 정해지고 계층화된 경쟁사 집합이 채점 준비가 되었을 때
- 감이 아니라 근거에 고정된, 경쟁사 간 비교 가능한 점수가 필요할 때
- 클라이언트의 전략적 긴장(목표 빈 공간을 정의하는 짝지어진 축)이 확립되었을 때
- competitive-report-structure에서 조립할 프로필 카드를 만들 준비가 되었을 때

## 클라이언트 포지셔닝 브리프 (먼저 확립)

채점 전에 클라이언트의 포지셔닝 브리프를 확립하세요. 다음을 제공합니다.

- **전략적 긴장** — 두 축(예: 기억 가능성 × 채용 가능성)이며, 교차점이 클라이언트의 목표 빈 공간을 나타냅니다. 차원 9는 항상 클라이언트가 지정한 긴장이며, 두 극을 평균내지 않고 따로 보고합니다.
- **차별화 요소** — 클라이언트의 해자(moat)가 무엇인지. 어떤 차원이 클라이언트의 포지셔닝 주장에 가장 중요한지를 알려 줍니다.
- **브랜드 균형** — 서로 다른 전략적 강조점의 의도된 조합. 전략적 권고는 그 균형을 깨면서도 이를 표시하지 않으면 안 됩니다.

## 왜 이 차원들인가

클라이언트는 서비스의 폭이 아니라, **두 극에 걸쳐 있는 특정한 긴장**으로 경쟁합니다. 차원들은 그 해자를 반영하도록 가중치가 매겨집니다. 두 개의 차원, 즉 긴장의 두 극은 **따로 채점하며 절대 평균내지 않습니다**. 클라이언트의 전략적 질문은 바로 경쟁사가 두 가지를 동시에 달성하는지이기 때문입니다.

## 9개 차원 (가중치 포함)

가중치는 합성의 강조점을 안내할 뿐, 단일 혼합 점수를 만들지 않습니다(거짓 합성 점수를 피하라는 편향 통제 항목 참조). 합계 = 100%.

1. **포지셔닝 명확성과 차별성** (18%) — 스튜디오의 포지션이 날카롭고, 소유 가능하며, 즉시 읽히는가? 아니면 일반적인가?
2. **브랜드 보이스 / 언어적 차별성** (15%) — 카피에 소유 가능한 어조가 있는가, 아니면 서로 바꿔 쓸 수 있는 에이전시 말투인가?
3. **비주얼 아이덴티티와 사이트 크래프트** (15%) — 비주얼 시스템의 품질과 소유권. 장인정신의 증거로서의 사이트.
4. **서비스 오퍼와 패키징** (12%) — 상품화되어 있고 읽기 쉬운가(이름 붙은 스프린트/감사), 아니면 모호한가. 패키징의 성숙도.
5. **근거와 신뢰성** (12%) — 이름이 밝혀진 고객, 수치화된 성과, 사례 연구의 깊이. 주장을 넘어선 증명.
6. **엔터프라이즈 준비도 / 상업적 성숙도** (10%) — SaaS/핀테크/B2B/엔터프라이즈 작업을 따내고 유지할 수 있다는 신호(프로세스, 로고, 규모, 계약).
7. **사고 리더십 / 콘텐츠 존재감** (8%) — 소유된 관점: 글, 강연, 뉴스레터, 프레임워크. 양보다 깊이.
8. **가격 투명성과 참여 모델** (5%) — 가격이나 참여 방식이 읽히는가? 상품화되어 있는가, 맞춤형인가, 불투명한가.
9. **[클라이언트의 전략적 긴장]** (플래그로 5%; **두 극을 모두 채점하고 따로 보고**) — 클라이언트의 포지셔닝 브리프에서 긴장의 이름과 축 설명을 읽으세요. 두 극을 모두 플롯하세요. 그 간극이 통찰입니다. 클라이언트의 목표 사분면이 가장 중요한 단일 발견입니다. 이미 거기에 누가 있는가?

## 채점 루브릭 (1-5, 차원 1-8에 적용)

모든 점수를 관찰 가능한 근거에 고정하세요. 아래는 일반적인 설명입니다. 차원마다 세부 사항을 맞추되, 각 수준의 의미는 일정하게 유지하세요.

- **1 — 부재 / 일반적.** 식별 가능한 포지션이나 장인정신이 없으며, 템플릿과 구별되지 않음. 적극적인 부담.
- **2 — 기준 이하.** 의도는 있으나 일관성이 없고, 파생적이거나 설득력이 부족함. 나란히 놓으면 버티지 못함.
- **3 — 적당함 / 기본 요건.** 탄탄하고 전문적이지만 특별하지 않음. 기대치는 충족하지만 누구도 소유하지 못함.
- **4 — 강함 / 차별적.** 동종 업계보다 확실히 앞서 있음. 구매자가 알아차리고 언급할 만한 실제 강점.
- **5 — 카테고리를 정의함.** 최고 수준이며, 소유 가능하고 모방하기 어려움. 다른 이들이 반응하는 기준을 세움.

### 긴장 축 (차원 9) — 각각 1-5로 채점

긴장 축의 라벨과 1/3/5 앵커는 클라이언트의 포지셔닝 브리프에서 읽으세요. 기억 가능성 × 신뢰성 긴장에 대한 예시 앵커는 다음과 같습니다.

- **기억 가능성** — 1: 즉시 잊힘 · 3: 맥락 속에서 알아볼 수 있음 · 5: 잊을 수 없고, 입에 오르내리며, 뚜렷하게 소유됨.
- **신뢰성** — 1: 위험해 보이거나 아마추어 같음 · 3: 안전하고 유능하지만 흥미롭지 않음 · 5: 엔터프라이즈가 신뢰하고, 명백한 안전한 선택.

경쟁사를 긴장 2×2에 배치하세요. 클라이언트의 목표 사분면은 포지셔닝 브리프에 명시되어 있습니다. 그 사분면에 이미 누가 있는지가 이 벤치마크의 가장 중요한 발견입니다.

## 데이터 수집 방법

각 경쟁사에 대해 차원을 다음 순서로 살펴보세요(가장 저렴한 신호부터).

1. **경쟁사 자체 사이트** — 포지셔닝, 보이스, 오퍼 패키징, 가격 태도, 이름이 밝혀진 고객, 선언문/관점. 홈페이지와 사례 연구 하나의 스크린샷을 찍으세요.
2. **사례 연구 / 작업물** — 근거의 깊이, 수치화된 성과, 고객 이름. *주장된*("우리는 X를 전달했다") 것과 *입증된*(지표, 이름, 검증 가능) 것을 구별하세요.
3. **리뷰 디렉터리** — 고객, 프로젝트 규모, 참여 모델을 확인 → 신뢰성과 엔터프라이즈 준비도 (예: Clutch.co 또는 틈새 시장의 동등한 것).
4. **LinkedIn** — 팀 규모/모델, 창업자 서사, 콘텐츠 주기 → 사고 리더십, 모델.
5. **포트폴리오 / 크래프트 플랫폼** — 크래프트 레지스터(해당 틈새 시장 고유의 쇼케이스 사용: 디자인 보드, 쇼릴, 공개된 샘플 등).
6. **콘텐츠 채널** — 뉴스레터/강연/글 → 사고 리더십의 깊이.

**차원별로 기록할 내용:** 점수, 한 줄 정당화, 그 점수를 얻게 한 출처 링크/스크린샷. 근거 없는 점수는 없습니다.

## 편향 통제

- **단일 합성 점수 금지.** 차원 점수와 긴장 플롯을 따로 보고하세요. 가중 평균은 중요한 비대칭을 가립니다.
- **주장된 것 vs 입증된 것.** 확인되지 않은 자기 보고 주장은 신뢰성/근거 점수를 낮추세요. 사이트 카피는 마케팅이지 사실이 아닙니다.
- **미적 친화 편향.** 평가자는 자신과 미적 취향이 같은 스튜디오를 과대평가하고, 경쟁사의 상업적 역량을 과소평가할 수 있습니다. 크래프트와 신뢰성을 독립적으로 채점하세요. "지루한" 사이트가 더 큰 고객을 따내고 있을 수도 있습니다.
- **최신성 / 화려함 편향.** 수상작과 쇼케이스 작업은 눈길을 끌지만 상업적 깊이가 부족할 수 있습니다. 신뢰성을 채점하기 전에 디렉터리와 고객으로 검증하세요.
- **생존자 편향.** 눈에 띄고 마케팅을 잘하는 스튜디오가 시장의 전부는 아닙니다. 디렉터리와 리뷰에서 찾은, 강하지만 조용한 운영자를 기록하세요.
- **고립이 아니라 집합 전체에서 보정하세요.** 확정하기 전에 점수를 나란히 다시 읽으세요. "4"는 모든 경쟁사에게 같은 의미여야 합니다. 이상치는 조정하세요.

## 경쟁사 프로필 카드 (출력 형식)

프로파일링한 경쟁사마다 카드 하나를 만드세요. 이것이 보고서가 조립되는 원자 단위입니다.

```
## <경쟁사 이름>
- **Profile / Tier:** <포지셔닝 입장 · 전문 분야 · 규모 구간> / <Direct | Adjacent | Aspirational>
- **One-liner:** <그들이 자신을 어떻게 포지셔닝하는지, 그들의 말로>
- **Model / size / geography:** <solo|micro|boutique> · <지역> · <가격/참여 모델>
- **Notable clients / evidence:** <이름 밝힘, proven/asserted 태그 포함>

### Dimension scores
| Dimension | Score (1–5) | Justification (1 line) | Source |
|---|---|---|---|
| 포지셔닝 명확성과 차별성 | | | |
| 브랜드 보이스 / 언어적 차별성 | | | |
| 비주얼 아이덴티티와 사이트 크래프트 | | | |
| 서비스 오퍼와 패키징 | | | |
| 근거와 신뢰성 | | | |
| 엔터프라이즈 준비도 / 상업적 성숙도 | | | |
| 사고 리더십 / 콘텐츠 존재감 | | | |
| 가격 투명성과 참여 모델 | | | |

### Tension plot
- **[포지셔닝 브리프의 축 1]:** <1–5> — <이유>
- **[포지셔닝 브리프의 축 2]:** <1–5> — <이유>
- **Quadrant:** <high/high | high-1/low-2 | low-1/high-2 | low/low>

### [클라이언트]를 위한 해석
- **배울 만한 강점:** <…>
- **공략할 약점 / 그것이 드러내는 빈 공간:** <…>
- **[클라이언트]에 대한 위협:** <…>
```

완성된 카드와 긴장 플롯을 `competitive-report-structure`에 넘기세요.

## 안티 패턴

- **긴장 축 평균 내기.** 클라이언트 긴장의 두 극은 따로 채점하고 따로 보고해야 합니다. 평균은 통찰을 파괴합니다. 두 극 사이의 간극이 바로 발견입니다.
- **근거 없이 채점하기.** 모든 점수에는 한 줄 정당화와 출처 링크가 필요합니다. 근거 없는 점수는 벤치마크가 아니라 의견입니다.
- **단일 합성 점수 만들기.** 차원 점수는 개별적으로 보고하세요. 가중 평균은 포지셔닝에 중요한 비대칭적 강점을 가립니다.
- **앵커를 맞추지 않고 일반 루브릭 적용하기.** 1-5 앵커는 특정 차원과 경쟁사 집합에 맞게 보정되어야 합니다. 일반적인 설명은 출발점이지 고정된 기준이 아닙니다.
- **집합 범위를 정하기 전에 실행하기.** 먼저 competitive-platform-analysis를 사용해 계층화되고 가지치기된 집합을 만드세요. 범위가 정해지지 않은 목록을 채점하면 관련 없는 경쟁사에 노력을 낭비하게 됩니다.

## 관련 스킬

- `competitive-platform-analysis` — 선행 단계이며, 이 스킬이 채점할 계층화된 경쟁사 집합을 만듭니다.
- `competitive-report-structure` — 다음 단계이며, 채점된 프로필 카드를 클라이언트 전달용 보고서로 조립합니다.
