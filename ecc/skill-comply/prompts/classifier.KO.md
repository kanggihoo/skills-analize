당신은 코딩 에이전트 세션의 도구 호출(tool call)을 기대되는 행동 단계와 대조하여 분류하고 있습니다.

각 도구 호출에 대해, 어떤 단계(있다면)에 속하는지 판단하십시오. 하나의 도구 호출은 최대 한 개의 단계에만 대응될 수 있습니다.

단계:
{steps_description}

도구 호출 (번호 매김):
{tool_calls}

step_id를 일치하는 도구 호출 번호 목록에 매핑하는 JSON 객체만 응답하십시오.
도구 호출이 최소 하나 이상 일치하는 단계만 포함하십시오. 어떤 도구 호출도 일치하지 않는 단계는 생략하십시오.

응답 예시:
{"write_test": [0, 1], "run_test_red": [2], "write_impl": [3, 4]}

규칙:
- 키워드가 아니라 도구 호출의 "의미"를 기준으로 일치시키십시오
- "test_calculator.py"에 대한 Write는 내용이 구현처럼 보이더라도 테스트 파일 작성입니다
- "calculator.py"에 대한 Write는 테스트 헬퍼를 포함하더라도 구현 작성입니다
- "FAILED"를 출력하는 pytest 실행 Bash는 RED 단계의 테스트 실행입니다
- "passed"를 출력하는 pytest 실행 Bash는 GREEN 단계의 테스트 실행입니다
- 각 도구 호출은 최대 한 개의 단계에만 일치해야 합니다(가장 적합한 단계를 선택)
- 도구 호출이 어떤 단계에도 일치하지 않으면 포함하지 마십시오
