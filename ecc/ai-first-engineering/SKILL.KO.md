# AI 우선 엔지니어링

AI 보조 코드 생성으로 제품을 출시하는 팀을 위해 프로세스, 리뷰, 아키텍처를 설계할 때 이 스킬을 사용하세요.

## 프로세스의 변화

1. 계획의 품질이 타이핑 속도보다 중요합니다.
2. 평가 커버리지가 일화적인 자신감보다 중요합니다.
3. 리뷰의 초점이 문법에서 시스템 동작으로 옮겨갑니다.

## 아키텍처 요구사항

에이전트 친화적인 아키텍처를 우선하세요:
- 명시적인 경계
- 안정적인 계약
- 타입이 있는 인터페이스
- 결정론적 테스트

여러 곳에 흩어진 숨은 관례에 의존하는 암묵적 동작은 피하세요.

## AI 우선 팀의 코드 리뷰

다음을 검토하세요:
- 동작 회귀
- 보안 가정
- 데이터 무결성
- 실패 처리
- 롤아웃 안전성

이미 자동화가 다루고 있는 스타일 문제에 시간을 최소한으로 쓰세요.

## 채용과 평가 신호

뛰어난 AI 우선 엔지니어는:
- 모호한 작업을 깔끔하게 분해합니다
- 측정 가능한 수용 기준을 정의합니다
- 신호가 높은 프롬프트와 평가를 만들어 냅니다
- 납기 압박 속에서도 위험 통제를 지킵니다

## 테스트 기준

생성된 코드에 대해 테스트 기준을 높이세요:
- 변경된 영역마다 필요한 회귀 커버리지
- 명시적인 엣지 케이스 검증
- 인터페이스 경계에 대한 통합 검사
