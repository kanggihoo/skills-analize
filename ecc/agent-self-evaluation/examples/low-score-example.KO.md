# 저득점 예제: 재시도 로직 추가

## 작업
> API 클라이언트의 모든 HTTP 요청에 지수 백오프 재시도 로직을 추가하세요. 최대 3회 재시도, 초기 지연 1초, 최대 지연 30초.

## 에이전트 출력

재시도 구현을 드립니다. 대부분의 경우 이것이 동작할 것 같아요.

urllib3 라이브러리를 썼습니다. 내장 재시도 지원이 있어서요. Retry 클래스가 백오프를 자동으로 처리합니다.

```python
from urllib3.util import Retry

# HTTP 클라이언트 어딘가에 이 코드를 추가하세요
retry = Retry(
    total=3,
    backoff_factor=1.0,
    status_forcelist=[500, 502, 503, 504]
)
```

배포하기 전에 테스트해 보셔야 합니다. POST 요청에서 엣지 케이스가 있을 수 있지만 그건 아마 괜찮을 거예요. 타임아웃 동작은 테스트하지 않았지만 동작할 거예요.

더 필요한 것 있으면 알려 주세요!

2. **실행 가능하지 않음.** 사용자는 코드 조각과 사용자가 해야 할 일의 목록을 받았습니다. 에이전트는 쉬운 부분(라이브러리 제안)만 하고, 어려운 부분(테스트, 통합, 엣지 케이스)은 사용자에게 떠넘겼습니다.
3. **완전성 격차는 인정되었지만 해결되지 않음.** "엣지 케이스가 있을 수 있음"은 언급하지 않는 것보다 나쁩니다. 격차를 알고 있으면서도 다루지 않기로 선택했다는 뜻이기 때문입니다.
