# 연결 최적화기

아웃바운드를 일방향 영업 목록으로 다루지 않고, 사용자의 네트워크 자체를 재정비합니다.

이 스킬이 다루는 범위:

- X 팔로잉 정리 및 확장
- LinkedIn 팔로우 및 연결 분석
- 검토 우선 가지치기 큐
- 추가/팔로우 추천
- 따뜻한 경로(warm path) 식별
- Apple Mail, X DM, LinkedIn 초안 생성(사용자의 실제 말투 기준)

## 활성화 시점

- 사용자가 X 팔로잉을 가지치기하려 할 때
- 사용자가 누구를 팔로우하거나 연결 상태로 둘지 재균형하려 할 때
- 사용자가 "네트워크 정리해줘", "누구를 언팔로우할까", "누구를 팔로우할까", "누구와 다시 연결될까"라고 말할 때
- 아웃리치 품질이 차가운 목록 생성보다 네트워크 구조에 달려 있을 때

## 필수 입력

다음을 수집하거나 추론하십시오.

- 현재 우선순위와 진행 중인 작업
- 목표 역할, 산업, 지역, 또는 생태계
- 플랫폼 선택: X, LinkedIn, 또는 둘 다
- 건드리면 안 되는 목록(do-not-touch)
- 모드: `light-pass`, `default`, `aggressive`

사용자가 모드를 지정하지 않으면 `default`를 사용하십시오.

## 도구 요구 사항

### 우선 사용

- X 그래프 조회와 최근 활동을 위한 `x-api`
- 대상 발굴과 따뜻한 경로 순위를 위한 `lead-intelligence`
- 더 넓은 리드 워크플로와 별개로 다리 가치(bridge value)를 점수화하고 싶을 때 `social-graph-ranker`
- 사람 및 회사 정보 보강을 위한 Exa / 심층 리서치
- 아웃바운드 작성 전 `brand-voice`

### 대체 수단

- LinkedIn 분석과 초안 작성을 위한 브라우저 제어
- API 적용 범위가 제한될 때 X를 위한 브라우저 제어
- 이메일이 적절한 채널일 때 데스크톱 자동화를 통한 Apple Mail 또는 Mail.app 초안 작성

## 안전 기본값

- 기본값은 검토 우선이며, 맹목적인 자동 가지치기는 하지 않습니다.
- X: 사용자가 팔로우한 계정만 가지치기하며, 팔로워는 절대 대상으로 삼지 않습니다.
- LinkedIn: 1촌 연결 제거는 수동 검토 우선으로 취급합니다.
- DM, 초대, 이메일을 자동으로 보내지 않습니다.
- 어떤 적용 단계 이전에도 순위가 매겨진 실행 계획과 초안을 출력합니다.

## 플랫폼 규칙

### X

- 맞팔은 일방향 팔로우보다 더 오래 유지되는 관계입니다.
- 맞팔이 아닌 계정은 더 공격적으로 가지치기할 수 있습니다.
- 활동이 매우 적거나 사라진 계정은 빠르게 드러내야 합니다.
- 팔로워 수보다 참여도, 신호 품질, 다리 가치가 더 중요합니다.

### LinkedIn

- 사용자가 실제로 LinkedIn API 접근 권한을 가지고 있다면 API를 우선합니다.
- API 접근 권한이 없으면 브라우저 워크플로가 동작해야 합니다.
- 아웃바운드 팔로우와 수락된 1촌 연결을 구분하십시오.
- 아웃바운드 팔로우는 더 자유롭게 가지치기할 수 있습니다.
- 수락된 1촌 연결은 자동 제거가 아니라 기본적으로 검토 대상으로 둡니다.

## 모드

### `light-pass`

- 확실히 가치가 낮은 일방향 팔로우만 가지치기합니다.
- 나머지는 검토용으로 제시합니다.
- 작은 추가/팔로우 목록을 생성합니다.

### `default`

- 균형 잡힌 가지치기 큐
- 균형 잡힌 유지 목록
- 순위가 매겨진 추가/팔로우 큐
- 유용한 곳에는 따뜻한 소개 또는 직접 아웃리치 초안을 작성합니다.

### `aggressive`

- 더 큰 가지치기 큐
- 맞팔이 아닌 오래된 계정에 대한 낮은 허용 기준
- 여전히 적용 전에 검토 게이트를 거칩니다.

## 점수 모델

다음 긍정 신호를 사용하십시오.

- 상호성
- 최근 활동
- 현재 우선순위와의 정합성
- 네트워크 다리 가치
- 역할 관련성
- 실제 참여 이력
- 최근의 존재감과 응답성

다음 부정 신호를 사용하십시오.

- 사라졌거나 방치된 계정
- 오래된 일방향 팔로우
- 우선순위와 무관한 주제 군집
- 가치가 낮은 노이즈
- 반복된 무응답
- 더 나은 대체 후보가 많은데도 맞팔이 되지 않는 경우

맞팔과 실제 따뜻한 경로의 다리 역할은 일방향 팔로우보다 덜 공격적으로 감점해야 합니다.

## 워크플로

1. 우선순위, 건드리면 안 되는 제약, 선택한 플랫폼을 파악합니다.
2. 현재 팔로잉/연결 목록을 가져옵니다.
3. 가지치기 후보를 명시적 이유와 함께 점수화합니다.
4. 유지 후보를 명시적 이유와 함께 점수화합니다.
5. `lead-intelligence`와 리서치 도구를 사용해 확장 후보의 순위를 매깁니다.
6. 적절한 채널을 맞춥니다.
   - 따뜻하고 빠른 소셜 접점에는 X DM
   - 전문적인 그래프 인접성에는 LinkedIn 메시지
   - 맥락이 깊은 소개나 아웃리치에는 Apple Mail 초안
7. 메시지를 작성하기 전에 `brand-voice`를 실행합니다.
8. 적용 단계 이전에 검토 묶음을 반환합니다.

## 검토 묶음 형식

```text
CONNECTIONS OPTIMIZER REPORT
============================

Mode:
Platforms:
Priority Set:

Prune Queue
- handle / profile
  reason:
  confidence:
  action:

Review Queue
- handle / profile
  reason:
  risk:

Keep / Protect
- handle / profile
  bridge value:

Add / Follow Targets
- person
  why now:
  warm path:
  preferred channel:

Drafts
- X DM:
- LinkedIn:
- Apple Mail:
```

## 아웃바운드 규칙

- 기본 이메일 경로는 Apple Mail / Mail.app 초안 작성입니다.
- 자동으로 보내지 않습니다.
- 따뜻함, 관련성, 맥락의 깊이에 따라 채널을 고릅니다.
- 이메일이나 아무 아웃리치도 하지 않는 편이 맞을 때는 DM을 억지로 보내지 않습니다.
- 초안은 자동화된 영업 문구가 아니라 사용자의 말투처럼 들려야 합니다.

## 관련 스킬

- `brand-voice`: 재사용 가능한 말투 프로필
- `social-graph-ranker`: 독립형 다리 점수화와 따뜻한 경로 계산
- `lead-intelligence`: 가중치 기반 대상 및 따뜻한 경로 발굴
- `x-api`: X 그래프 접근, 초안 작성, 선택적 적용 흐름
- `content-engine`: 네트워크 변화를 중심으로 공개 런칭 콘텐츠도 원할 때
