# 12 · 물속에 퍼지는 잉크 — GPU 유체 시뮬레이션 (Stable Fluids)

> **가장 중요한 규칙: 기술만 가져간다.** 아래 "화면"은 이 데모가 그린 것이다. 기법을 보여 준 예일 뿐이니 소재·장면·이야기·구도·문구·색은 영상에 옮기지 않는다.
> 노트와 코드를 충분히 읽어 "기법과 원리"의 기술만 가져가고, 장면은 작업 중인 영상의 대본으로 새로 짓는다.

## 화면

수면에서 비스듬히 내려오는 빛줄기가 깊은 남청색 물속을 비추고, 맨 위에는 커스틱이 일렁이며 부유 입자가 떠다닌다.
0.5초에 왼쪽 위와 오른쪽 아래 노즐이 동시에 잉크를 짧게 쏜다. 청록 잉크와 장밋빛 잉크가 각각 버섯 모양의
**와류 쌍극자**(mushroom head)로 말리면서 한 직선 위를 마주 보고 다가온다.
2.6–4초가 절정이다. 두 머리가 정면으로 부딪혀 납작해지며 서로 맞물린 태극 모양이 되고, 뒤따르는 줄기는 카르만 와열처럼
작은 소용돌이를 줄줄이 말아 올린다. 부딪힌 덩어리는 옆으로 퍼져 위는 청록, 아래는 장밋빛인 물결 띠가 된다.
가장자리는 계속 말려 들어가고, 잉크는 위에서 오는 빛을 받아 윗면은 밝고 아랫면은 스스로 그림자를 진다.
4.1초에 수면 쪽에서 금빛 한 방울이 떨어져 작은 버섯이 되어 내려오고(6–9초 여운), 띠에 박히면서 세 가지 잉크가
대리석 무늬로 섞인다. 화면은 천천히 다가가고 마지막에 조금 어두워진다.

## 기법과 원리

- **격자**: 속도·압력 270×480(RG32F / R32F), 잉크 540×960(RGBA16F, 3채널 = 세 잉크).
  비디오 1프레임 = 서브스텝 2회(dt = 1/60 s).
- **서브스텝 순서**(`main.js:414` 이하, Jos Stam / GPU Gems 38 구성):
  1. 컬(curl)(`main.js:55`)
  2. 힘(`main.js:65`): **와도 감금**(vorticity confinement, ε=7, `main.js:76`) + 잉크 농도에 비례하는 약한 음의 부력
     (`main.js:81`) + 노즐(가우시안 영역에서 속도를 목표 제트 속도로 섞기, `main.js:85`). 벽에서 법선 속도는 0.
  3. 발산(`main.js:93`, 벽에서 반사)
  4. **야코비 압력 30회**(`main.js:106`). 이전 압력에 0.8을 곱해 웜스타트한다(`main.js:431`). 압력도 상태의 일부다.
  5. 압력 기울기 빼기(`main.js:115`)
  6. 속도의 자기 이류: semi-Lagrangian, RK2 역추적(`main.js:125`)
  7. **잉크 이류: MacCormack**(`main.js:137`, `main.js:147`). 앞으로 한 번, 결과를 거꾸로 한 번 이류해서 왕복 오차의 절반을
     보정하고, 원래 주변 4텍셀의 min/max로 클램프해(`main.js:163`) 새 극값이 생기지 않게 막는다.
     번짐이 크게 줄어 가는 필라멘트와 소용돌이가 살아난다.
- **노즐 스크립트**(`main.js:23`): 위치·각도·세기가 t의 순수 함수다. 짧고 강한 퍼프(쌍극자)를 쏜 뒤 약한 줄기가 이어진다.
  잉크는 제트 축이 아니라 **전단층(노즐 둘레의 고리)**에 주로, 맥동(7 Hz, `main.js:442`)과 함께 주입한다(`main.js:170`).
  유동 가시화 실험처럼, 와류가 이 띠를 감아서 소용돌이 구조가 눈에 보인다.
- **빛**(`main.js:177`): 270×480에서 수면 방향으로 22스텝 레이마칭을 해 잉크별 흡수(보색, `main.js:313`)를 누적하고,
  **색이 있는 투과율**을 얻는다(`main.js:192`). 이 하나로 잉크의 자기 그림자, 겹친 잉크 아래의 색 그림자, 물속 빛줄기에
  드리운 그림자(`main.js:263`)를 모두 처리한다.
- **최종 셰이더**(`main.js:215`): 잉크는 4탭 B-스플라인으로 업샘플한다. 잉크별 커버리지를 더하는 산란 모델이라서
  겹친 곳이 탁해지지 않고 밝아진다(`main.js:270–272`). 블러된 밀도의 기울기로 부드러운 램버트 음영을 넣고(`main.js:278`),
  두께가 두꺼울수록 산란이 늘며, 가장자리는 반투명하게 빛나고, 블룸(4× 다운샘플 + 가우시안)을 더한다.
  물은 깊이 그라디언트, 빛줄기(`main.js:260`), 유계 커스틱(도메인 워핑 노이즈의 능선, `main.js:233`)이고,
  잉크 위에도 커스틱 쿠키를 얹는다. 부유 입자, 톤매핑·비네트·그레인으로 마무리한다.

## 결정성 전략

- `replay({ dt: 1/30, every: 30 })`(`main.js:414`): 스텝 n은 서브스텝 2회이고, 서브스텝 시각 (2n+s)/60에서 노즐을 계산한다.
- **상태 = 속도 + 압력 + 잉크** 세 텍스처. `save()`는 새 텍스처 세 장에 `blitFramebuffer`로 GPU 안에서 복사하고,
  `load()`는 거꾸로 복사한다(`main.js:454–459`). curl, 발산, MacCormack 중간 결과, 빛·블룸은 매번 다시 계산하는 임시값이라
  상태에 넣지 않는다. 웜스타트 때문에 압력은 반드시 상태에 넣어야 한다. 빠뜨리면 점프백 검사에서 어긋난다.
- 루프 끝 → 0이면 체크포인트 0(모두 0인 물)을 복원한다. 실시간 재생에서 프레임이 건너뛰면 그만큼 스텝을 더 돈다.
- 헤드리스(`?render`)에서만 스텝마다 1픽셀 `readPixels`로 GPU 완료를 기다린다(`main.js:449`). 스크린샷 30초 타임아웃을 피하기 위한
  하네스 우회다. 라이브 재생에서는 실행하지 않는다.
- 결과: `deterministic: true`(앞→뒤, 새 페이지 뒤→앞, 점프백).

- `frameMsAvg`는 1초 간격 seek의 비용이라 **샘플 하나 = 30스텝 + 캡처**다. 비디오 1프레임에 해당하는 헤드리스(SwiftShader)
  비용은 약 **106 ms**다. 이전 렌더러로 270프레임을 순차 렌더했을 때(머신에 부하가 걸린 상태) 0.46 s/프레임(캡처 포함)이었다.
- 실제 GPU에서 한 스텝은 270×480 패스 약 70개 + 540×960 패스 4개이므로 수 ms 수준으로 예상한다(직접 측정하지는 않았다).

## 한계와 다음 단계

- 2D 유체라서 3D 잉크의 볼륨감(소용돌이 고리가 뒤집히며 생기는 깊이)은 셰이딩으로 흉내만 낸다. 빛 레이마칭도 2D 평면 안의 근사다.
- 야코비 30회는 완전 수렴이 아니라서 작은 압축성 잔차가 남는다. 멀티그리드나 레드-블랙 가우스-자이델을 쓰면 같은 비용에 더 정확하다.
- 270×480 속도 격자의 해상도 한계 때문에 와도 감금으로 잔소용돌이를 보충한다. 너무 세면 콜리플라워 질감이 되어서 ε=7로 낮췄다.
- 속도장도 MacCormack으로 이류하고 격자를 키우면 실제 GPU에서 더 가는 난류를 얻을 수 있다. 노즐을 글자 모양 경로로 움직이는 연출도 다음 후보다.
