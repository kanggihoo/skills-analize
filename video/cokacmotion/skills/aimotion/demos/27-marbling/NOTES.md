# 27 · 물 위의 마블링 — 수학적 마블링 · 잉크 방울과 빗질의 닫힌식 변형 (Jaffer·Lu)

> **가장 중요한 규칙: 기술만 가져간다.** 아래 "화면"은 이 데모가 그린 것이다. 기법을 보여 준 예일 뿐이니 소재·장면·이야기·구도·문구·색은 영상에 옮기지 않는다.
> 노트와 코드를 충분히 읽어 "기법과 원리"의 기술만 가져가고, 장면은 작업 중인 영상의 대본으로 새로 짓는다.

## 화면

10초. 우윳빛 사이즈(수조 물) 위로 창빛이 비친다. 맨 아래에는 수조의 호두나무 테두리(자막 자리).

1. **바탕 (0.3–0.85초).** 쪽빛(인디고) 한 번 크게 부어 수조 전체를 덮는다.
2. **방울 (0.9–3.4초).** 황토·꼭두서니 빨강·호분 흰색·쪽빛 방울 23개가 하나씩, 9개 자리에 번갈아 떨어진다. 떨어지는 방울과
   그림자가 한 점으로 모이고, 닿는 순간 원이 퍼지며 **먼저 떨어진 모든 고리를 바깥으로 민다**. 같은 자리의 다음 방울은 조금
   비껴 떨어져 고리가 한쪽으로 쏠린다. 방울마다 점성 있는 수면에 빨리 잦아드는 물결이 하나씩. 자리끼리 밀어 원이 다각형
   '돌'이 되고, 바탕의 쪽빛은 돌 사이의 가는 맥으로 눌린다(터키 에브루의 바탈 무늬).
3. **송곳 (3.5–5.2초).** 송곳이 돌 세 개 사이에서 원을 한 번 그려 소용돌이를 만들고, 가로로 세 번 왕복한다(겔-git).
4. **빗 (5.22–6.2초).** 40px 간격의 핀 빗이 위에서 아래로 훑어 내려가며 모든 고리를 V자 깃털로 당긴다(절정).
5. **종이 (6.25–7.9초).** 종이가 위에서 들어와 내려앉고, 젖은 경계가 위에서 아래로 번지며 뒷면에 색이 비친다. 종이가 가로축으로
   뒤집혀 들리면 찍힌 면이 나온다 — 수조 무늬의 **상하 거울상**. 종이를 들어낸 자리의 수조에는 잉크가 거의 남지 않는다.
6. **여운 (7.9–10초).** 레이드지(발 자국·체인 선·섬유) 위의 판화에 사광이 천천히 지나간다. 공기 방울 자국 몇 개와
   첫 접촉선의 옅은 얼룩까지.

## 기법과 원리

엔진은 `ops.js`(116줄), 이야기·그리기는 `main.js`. 렌더러는 Canvas 2D.

1. **잉크 막 = 다각형, 동작 = 평면의 닫힌식 사상** (`ops.js:21` `makeMap`). 모든 막의 모든 꼭짓점에 같은 사상을 적용한다.
   - 방울(`ops.js:22`): p → c + (p − c)·√(1 + r²/|p − c|²). 바깥 고리의 넓이가 정확히 πr²씩 늘어나는 면적 보존 사상이라
     막끼리 겹치지도 비지도 않는다. 진행 중에는 r²에 진행률 k를 곱한다(퍼지는 원의 반지름 r√k, `ops.js:114`).
   - 송곳·빗(`ops.js:31`): p → p + z·u·λ^d (λ^d = e^(−d/L), d = 송곳 선까지 거리, 빗이면 가장 가까운 핀 선까지 거리 —
     `d − S·round(d/S)`). u 방향 전단이라 면적 보존.
   - 원 송곳 = 소용돌이(`ops.js:51`): 반지름마다 각도 θ = z·e^(−||p−c|−R|/L)/|p−c|만큼 회전. 원마다 강체 회전이라 면적 보존.
2. **적응 세분** (`ops.js:70`, `ops.js:82`). 사상 뒤 상(像)의 변이 2.4px보다 길면 그 변의 **원상(原像) 중점을 사상한 점**을
   넣고 재귀로 나눈다(사상된 두 점의 중점이 아니라 — 그래서 빗 핀 옆으로 수십 배 늘어난 곡선도 매끄럽다). 0.7px보다 붙은 점은
   솎는다(`ops.js:92`). 꼭짓점은 바탕 3천 개에서 시작해 방울 뒤 ~1.8만, 빗 뒤 ~10만 개.
3. **움직이는 송곳** (`ops.js:31`의 주석). 변위 크기에 진행률을 곱하는 대신, 송곳 끝 sTip이 실제로 지나간다: 끝 뒤쪽은 다
   밀리고 앞쪽은 아직 그대로이며, 그 사이 경사 구간을 2z 이상으로 둬 ds′/ds ≥ 0.25 — 사상이 계속 일대일이라 막이 뒤집히지
   않는다. 시작·끝 위치는 화면 모서리에서 계산해(`main.js:58`) 화면 밖 꼭짓점이 튀어 들어오지 않게 했고, k = 1이면 정확한
   닫힌식이라 체크포인트와 이어진다. 핀은 경사 구간 가운데에 그린다(`main.js:300`의 tools).
4. **체크포인트** (`main.js:154`). setup에서 29개 동작을 전부 적용하며 동작이 끝날 때마다 막 목록을 저장(Float32Array). setup의
   엔진 계산은 약 40ms.
5. **그리기.** 막을 떨어진 순서대로 칠한다(`main.js:120`) — 사상이 위상을 보존하므로 화가 알고리즘이 정확하다(새 방울은 늘
   예전 막의 '구멍' 속에 있다). 경로마다 closePath 없이 fill(), 화면 밖 막은 경계 상자로 건너뛴다. 안료는 미세한 입자감의
   타일 패턴(`main.js:103`). 수조는 종이와 같은 값 노이즈 텍스처 + 창빛(screen) + 비네트(multiply).
6. **종이** (`main.js:226`–`262`). 마지막 막들로 setup에서 굽는다: 앞면 = 레이드지 텍스처(`main.js:75`) × 상하 반전한 잉크
   (multiply), 공기 방울 자국(holidays), 접촉선 얼룩. 뒷면 = 흐리게(blur 3px) 비친 색 + 젖은 회색. 수조 쪽은 종이 아래 잉크만
   거의 걷힌 '유령 수조'. 뒤집기는 가로축 회전의 원근 없는 근사(scaleY = |cos θ|, 들릴수록 커지고 어두워지며 그림자가 멀어짐,
   `main.js:371`).

## 결정성 전략

- `frame(t)`(`main.js:275`)는 "t 이전의 마지막 체크포인트 + 진행 중인 동작 하나를 진행률 k(t)로"만 계산한다(`main.js:266`).
  이전 프레임 상태를 전혀 쓰지 않으므로 어느 순서로 seek해도 같은 그림. 한 프레임 엔진 비용은 빗질 중 최대 ~4ms(Node 측정).
- 방울 자리 순서·비껴 떨어짐은 `rand(27)`, 공기 방울 자국은 `rand(2727)`, 텍스처는 정수 해시 — 모두 setup에서.
- 물결·떨어지는 방울·핀·종이·사광은 모두 t의 닫힌식(`track`).
- 빗질이 끝난 뒤(6.2초~)는 정적인 무늬를 구운 캔버스를 그린다.

## 한계와 다음 단계

- 물결은 장식이다(잉크를 움직이지 않음). 실제 방울은 떨어지는 충격으로 가장자리가 출렁인다.
- 안료 막의 두께(가장자리에 안료가 몰리는 테두리, 담즙을 섞은 잉크의 번짐)는 없다. 막마다 두께 필드를 실어 나르면 가능.
- 물결 빗(wavy comb)은 쓰지 않았다 — 같은 틀에서 d를 sin으로 흔든 핀 선까지의 거리로 바꾸면 된다.
- 종이 뒤집기는 2D 근사이고, 종이가 수조에서 잉크를 들어 올릴 때의 미세한 끌림(드래그 자국)은 없다.
- 빗질 중 프레임에는 꼭짓점 ~10만 개 경로를 Canvas 2D가 채운다. 약한 GPU에서 느리면 MAXLEN(`ops.js:15`)을 3으로.
