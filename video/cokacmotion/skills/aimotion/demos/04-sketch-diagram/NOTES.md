# 04 · 손으로 그린 설명 — rough.js + perfect-freehand · 손그림 렌더링

> **가장 중요한 규칙: 기술만 가져간다.** 아래 "화면"은 이 데모가 그린 것이다. 기법을 보여 준 예일 뿐이니 소재·장면·이야기·구도·문구·색은 영상에 옮기지 않는다.
> 노트와 코드를 충분히 읽어 "기법과 원리"의 기술만 가져가고, 장면은 작업 중인 영상의 대본으로 새로 짓는다.

## 화면

스탠드 빛이 비치는 스케치북 한 장(종이 결, 옅은 점 격자, 아래는 책상). 연필 한 자루가 물의 순환을 한 획씩 그린다:
제목 「물의 순환」과 붉은 밑줄, 부제 → 바다의 물결선과 파란 물감 번짐, 「바다」 → 해(둥근 윤곽, 빛살, 노란 물감) →
바다에서 올라가는 수증기 세 줄기와 「① 증발」 → 구름 윤곽과 회청색 물감, 「② 응결」 → 산(윤곽 + 초록 연필 빗금 + 물감),
눈 덮인 봉우리, 비 줄기, 「③ 강수」 → 산에서 바다로 흐르는 강, 「④ 흐름」 → 마지막으로 전체를 한 바퀴 도는 붉은 화살표
네 개(절정). 연필은 획 사이에서 들려 이동하고(그림자가 커지고 흐려진다), 다 그리면 화면 밖으로 빠진다. 여운에서는
물방울 일곱 개가 순환 고리를 따라 돈다. 마지막 0.4 s에 페이지가 빈 종이로 돌아가 처음과 이어진다.

## 기법과 원리

- **획(stroke)이 단위다** (main.js:115–148). 세 종류:
  - `line`: rough.js 도형(고정 `seed`)의 op-set(`move`/`bcurveTo`/`lineTo`)을 3차 베지어 샘플링으로 폴리라인으로 바꾸고
    (`opsToPolylines`, main.js:47) 누적 길이표를 만든다(`measure`, main.js:32). rough.js의 이중 획(multi-stroke)과
    빗금 채우기(`fillSketch`)도 각각 하나의 획 → 펜이 윤곽을 두 번 돌고, 빗금을 한 줄씩 긋는다(main.js:124–131).
  - `free`: perfect-freehand. 점 목록의 앞부분(현재 펜 위치까지)을 매 프레임 `getStroke`에 넣어 필압 있는 외곽선을
    얻고 채운다(main.js:282). 그리는 중에는 끝 테이퍼 0, 끝나면 테이퍼를 준다.
  - `text`: 한글 손글씨 폰트(Nanum Pen Script)로 한 번 그려 둔 라벨을 펜이 기준선을 따라 지나가며 왼쪽부터 열어 보인다.
- **하나의 펜 시간표** (`schedule`, main.js:245): 모든 획을 순서대로 늘어놓고 길이/속도(빗금은 빠르게, 손글씨는 천천히)와
  펜을 들어 옮기는 시간(거리에 비례)을 더한 뒤, 전체를 0.25–8.3 s에 맞게 한 비율로 늘이거나 줄인다 — 리듬은 유지된다.
  물감 번짐은 해당 윤곽 획이 끝나는 순간 시작한다. 펜 위치(`penAt`, main.js:290)도 같은 시간표에서 나온다.
- **수채 번짐** (`watercolor`, main.js:93): 다각형을 재귀적 중점 변위로 일그러뜨린 층 36장을 4.5% 투명도로 겹치고
  가장자리에 안료가 고인 선을 더해 setup에서 한 번 굽는다. 매 프레임 기원점에서 원형 클립이 커지며 피어나고,
  `multiply`로 종이에 스민다(main.js:375–381).
- **프레임 렌더** (main.js:368): 종이 → 물감 → 끝난 그룹은 setup에서 구운 캐시(경계 상자 크기)를 한 번 그리기(main.js:391) →
  그리는 중인 그룹만 획 단위로(main.js:394) → 물방울(main.js:399) → 연필(main.js:426, 육각 몸통·나무 깎은 면·흑연·지우개, 들림에 따른 그림자).

## 결정성 전략

- rough.js는 모든 도형에 고정 `seed`(seed 0이면 Math.random을 쓰므로 금지), 수채·종이 결·별 등은 `rand(seed)`.
- 시간표·펜 위치·캐시 모두 setup에서 결정되고 frame(t)은 t만 본다(캐시는 "t가 그룹 끝 이후인가"로만 고른다 — 이전 프레임의
  잉크를 누적하지 않는다).
- 글리프는 setup 첫머리에 `document.fonts.load(…, 쓸 글자 전부)`로 필요한 유니코드 서브셋을 모두 받은 뒤 그린다(main.js:322).
- 매 프레임 그리는 캔버스는 `?render`일 때만 `willReadFrequently`(헤드리스 SwiftShader에서 CPU 래스터가 빠르고 결정적),
  실제 GPU 브라우저에서는 옵션 없이(main.js:329). setup에서 한 번 굽는 캔버스는 항상 CPU.

## 한계와 다음 단계

- 손글씨는 글꼴을 왼쪽부터 드러내는 방식이라 실제 필순이 아니다. 한글 필순 획 데이터(또는 글리프 외곽선의 골격화)가
  있으면 글자도 perfect-freehand 획으로 쓸 수 있다.
- 물감 번짐은 원형 클립으로 피어난다. 젖은 물감이 퍼지는 방향을 노이즈 필드로 흔들면(01번 데모의 도착 시간장처럼) 더 자연스럽다.
- 연필이 획의 진행 방향과 상관없이 같은 각도로 쥐어져 있다. 손목 각도를 획의 접선에 약하게 따르게 하면 더 사람 같다.
- 레이아웃은 손으로 잡은 좌표다. 라벨이 많아지면 rough.js 도형 경계 상자에서 라벨 자리를 자동으로 찾는 편이 낫다.
