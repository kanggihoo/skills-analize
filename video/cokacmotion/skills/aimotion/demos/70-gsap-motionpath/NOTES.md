# 70 · 종이비행기 편지 — GSAP MotionPath(캔버스 객체) · CustomWiggle · Physics2D

> **가장 중요한 규칙: 기술만 가져간다.** 아래 "화면"은 이 데모가 그린 것이다. 기법을 보여 준 예일 뿐이니 소재·장면·이야기·구도·문구·색은 영상에 옮기지 않는다.
> 노트와 코드를 충분히 읽어 "기법과 원리"의 기술만 가져가고, 장면은 작업 중인 영상의 대본으로 새로 짓는다.

## 화면

맑은 봄날 오후다. 하늘은 위에서 아래로 파스텔 하늘색 → 복숭앗빛 → 크림색으로 내려온다. 왼쪽 위에 연노랑 해와 무리가 있고, 납작한 구름 다섯 개가 천천히 흐른다.
그 아래로 먼 연보라 스카이라인이 있고, 그 앞에는 파스텔 건물들이 서 있다(창문, 측면 그늘, 물탱크, 안테나, 옥상 나무). 앞쪽 옥상 난간에는 화분이 놓여 있고, 깃대에서 시작한 파스텔 가랜드가 펄럭이며 도시를 가로지른다.
난간 아래는 짙은 자두색 벽돌 벽이라 하네스 자막이 그 위에서 읽힌다.

하늘에는 종이비행기 26대가 깊이별로 날아간다. 먼 것은 작고 하늘색에 묻히며 느리고, 가까운 것은 크고 빠르다. 두 대는 공중제비를 돈다.
비행기마다 접힌 종이 입체다. 용골 면과 날개 면이 한 빛을 받아 양쪽에 두 가지 톤을 낸다. 난기류에 위아래로 까딱이고, 경로가 휘는 만큼 기울어진다(뱅크).

이야기는 이렇다.

- **0–4.5 s 비행**: 왼쪽 먼 하늘에서 작게 나타난 주인공 비행기가 카메라 쪽으로 다가온다. 화면 가운데에서 크게 한 바퀴 루프를 돌고(꼭대기에서 뒤집힘), 급강하했다가 기수를 들어 난간에 내려앉는다.
- **4.5–4.9 s 착지**: 미끄러지며 멈추고, 코가 한 번 튕겼다가 가라앉는다. 하얀 속도선이 피어나고, 내려앉는 동안 난간에 그림자가 진다.
- **4.9–5.3 s 펼치기 시작**: 살짝 주저앉았다가(예비 동작) 떠오른다. 3D로 접힌 용골과 날개를 펴며 기수를 위로 돌리고 정면을 본다.
- **5.3–6.1 s 패널 전개**: 2D 패널 변형으로 펼쳐진다. 먼저 양쪽 날개 판이 접힌 선을 축으로 뒤집혀 열리고(뒷면이 보였다가 앞면으로), 이어서 코 쪽 삼각 덮개 두 장이 위로 젖혀진다. 덮개가 열리면 우표와 소인이 나타난다.
- **5.3–6.8 s 떠오르기**: 그사이 편지지는 커지며 화면 가운데로 떠오른다. 살짝 지나쳤다가 제자리를 잡고(CustomEase), 그림자가 깊어진다.
- **6.0 s~ 꽃잎**: 편지 뒤에서 벚꽃잎과 색종이가 분수처럼 터져 오른다. 위에서는 꽃잎이 천천히 내려온다.
- **6.3–9.4 s 손글씨**: 괘선 편지지 위에 나눔손글씨 펜으로 "잘 지내지? / 여기도 봄이 왔어 / 바람 편에 보낼게"가 한 글자씩 써진다. 하트 낙서가 그려지고, 마지막으로 서명 "— 봄날의 옥상에서"가 붙는다.
- **끝**: 편지는 숨 쉬듯 떠 있고, 배경 비행기들은 계속 지나간다.

## 기법과 원리

- **업계 패턴: 일반 객체를 트윈하고 캔버스는 직접 그린다.** GSAP은 캔버스를 모른다. 비행기 26대와 주인공(`Hs`), 편지(`LF`), 글자(`chars`), 꽃잎(`p`)은 모두 평범한 객체다.
  `frame(t)`은 `tl.time(t)` 뒤에 그 속성들로 장면 전체를 다시 그린다(`main.js:547`).
- **MotionPathPlugin**
  - **경로 만들기**: 경유점 → `MotionPathPlugin.arrayToRawPath`(curviness 1) → `rawPathToString`(`main.js:181` `route`). 같은 rawPath는 `cacheRawPathMeasurements`로 측정해 곡률 계산에 다시 쓴다.
  - **트윈**: `motionPath: { path, autoRotate: true }`가 x, y, rotation을 쓴다. 같은 트윈에 `u: 1`(또는 `hu`)를 함께 넣어, 경로 위 길이 진행률을 같은 ease로 얻는다(`main.js:441–443`, 주인공 `:475`).
  - **곡률 뱅크**: frame에서 `getPositionOnPath(raw, u ± ε, true)`의 각도 차이를 호 길이로 나눠 곡률을 구하고, 그만큼 롤을 준다(`main.js:189` `bankAt`, 최대 ±24°).
    `getRelativePosition`은 DOM 요소 사이의 좌표 변환이라 캔버스 객체에는 쓸 수 없어서, 같은 정보를 경로 데이터에서 직접 얻었다.
  - **이음매 없는 반복**: 배경 비행기는 주기 D 또는 D/2(가까운 것)로 경로를 정확히 한 바퀴 돈다. 위상 φ에서 출발해 `start: φ → end: 1`, 이어서 `start: 0 → end: φ`인 두 구간을 반복 중첩 타임라인에 담았다(`main.js:440–443`). 10 s → 0 s로 넘어갈 때 튀지 않는다.
  - **주인공의 크기(깊이)**: 경유점마다 정한 스케일(`main.js:198`)을 `hu`(호 길이 진행률)로 다시 읽는다. setup에서 경유점의 진행률을 경로를 따라가며 찾아 두었다(`main.js:451–471`). 루프가 경로를 교차해도 앞으로만 찾으므로 헷갈리지 않는다.
- **CustomWiggle**
  - 난기류: 비행기마다 bob(px)과 wobble(°)을 10초짜리 uniform 위글(정수 회)로 준다. 그래서 루프 경계에서도 0으로 돌아온다(`main.js:445–446`).
  - 주인공의 순항 흔들림은 easeInOut 위글이라 착지 직전에 잦아든다(`main.js:476–477`).
  - 착지 때 코 튕김은 easeOut 위글이다(`:480`). 편지가 떠 있는 숨결은 `:502–503`이다.
  - `type: 'random'`(내부 `Math.random`)은 쓰지 않는다.
- **접힌 종이비행기 입체**(`main.js:109–176`). 비행기는 실제 편지지를 접은 다트다.
  - 2차 접기까지 한 S2 윤곽의 한쪽 절반을 용골 띠(중심 주름 ~ 용골선)와 날개로 나눈다.
  - 용골은 중심 주름을 축으로 ψ만큼, 날개는 용골선을 축으로 ω만큼 먼저 돈다. 비행 상태는 ψ = −90°, ω = −90° + 상반각 9°이다.
  - 방향 θ(autoRotate)와 롤 ρ(내려다보는 각 58° + 뱅크)로 만든 기저 (f, l, u)에 놓고 정사영한다. 면 깊이로 뒤에서 앞으로 칠한다(`main.js:149` `drawDart`).
  - 면마다 법선과 광원의 내적으로 종이색과 라벤더 그늘색을 섞는다. 뒷면이 보이면 조금 어두운 뒷면 종이색을 쓴다(`main.js:141` `tone`). 그래서 용골과 날개가 한쪽에 두 톤을 낸다.
  - 왼쪽으로 나는 비행기는 '위' 방향 부호를 반대로 둔다(sdir). 루프 꼭대기에서는 θ가 이어지므로 자연스럽게 뒤집힌다.
- **3D → 2D 전개의 이음매**. 착지 뒤 `flat`이 ψ, ω를 0으로, `top`이 ρ를 90°(정면)로 돌린다. 이와 함께 θ를 −90°(기수 위)로, 크기를 230px/단위로 바꾼다(`main.js:483–489`).
  이 순간 3D 모델의 투영은 정확히 '화면 = 중심 + 단위·(x, y − 0.65)'다. 2D 편지 프레임 `LF`는 같은 중심과 단위에서 시작하므로(`main.js:492`), 손바뀜(`TS`)에서 윤곽이 그대로 이어진다.
- **2D 패널 전개**(`main.js:64–107`, 그리기 `:591`).
  - 주름 네 개(F1: 위 모서리 → 중심선, F2: 새 빗변 → 중심선)는 모두 코(원점)를 지난다. 패널 7장은 각자 자기를 나르는 접기 목록을 가진다.
  - 접기 각 α = π·k로 패널을 주름 축 둘레로 돌린다(`hinge`). 투영은 주름에 수직인 방향으로 cos α만큼 줄어드는 선형 사상이 된다.
  - 이 사상을 기저 벡터 두 개의 상(像)으로 얻어 `ctx.setTransform`에 그대로 넣는다(`main.js:633`). 그래서 미리 그려 둔 편지지(괘선, 여백선, 옛 주름, 우표, 소인; `main.js:335`)가 패널과 함께 일그러지며 접힌다.
  - 앞면이 보이는 패널에만 편지지를 클립해 그린다. 뒤집히는 패널은 아래에 그림자를 드리운다(`:620`).
  - F2 묶음은 모서리가 보이는 순간(k = 0.5)에 층 순서가 뒤집힌다(`main.js:614`).
- **손글씨 쓰기**(`main.js:377` `bakeLine`, `:507–513`, `:691`).
  - 줄마다 나눔손글씨 펜으로 한 번 래스터해 두고, 글자별 끝 x 위치를 잰다.
  - GSAP `stagger`가 글자 객체들의 r(0→1)을 차례로 올린다. 가장 최근에 시작한 글자의 진행 위치가 '펜 끝'이다. 그 왼쪽은 그대로, 펜 끝 16px는 4단 페더로 그린다. 하트는 dash 길이로 그린다.
- **Physics2DPlugin**(`main.js:518–537`).
  - 분수: 꽃잎과 색종이 96장은 원하는 최고 높이 h와 도달 시간 tp에서 v_y = 2h/tp, g = 2h/tp²를 거꾸로 구해 `physics2D: { velocity, angle, gravity }`로 넘긴다.
  - 비: 위에서 내리는 꽃잎 44장은 느린 속도에 약한 중력이다.
  - friction 0이라 위치는 p₀ + v·t + ½·g·t²의 닫힌 식이다(t = 트윈 시간).
  - 회전은 같은 트윈의 `rot`(ease none)이다. 좌우 흔들림과 뒤집힘(세로 축소)은 frame에서 (t − t₀)의 sin·cos로 정한다. 홀짝으로 편지 앞뒤 층을 나눠 깊이를 준다.

## 결정성 전략

- 타임라인은 `paused: true`, `defaults: { lazy: false }`로 만든다(`main.js:417`). setup 끝에서 `tl.time(D); tl.time(0)`으로 한 번 훑어, 모든 트윈이 시간 순서대로 시작값을 기록하게 한다(`main.js:541`).
- 같은 속성의 트윈은 시간이 겹치지 않게 했다. 나중에 나타나는 것(주인공 숨김·편지 표시·꽃잎 `on`)은 `tl.set`으로 바꾸므로, 되감으면 원래 값으로 돌아간다.
- Physics2D는 friction 0의 닫힌 식이고, 경로 위치·뱅크·크기는 모두 트윈 값의 함수다. 꽃잎 흔들림, 가랜드 펄럭임, 구름 흐름은 t의 사인·일차식이다.
- 난수는 모두 setup의 `rand(seed)`다(비행기 경로·깊이·종이색, 도시, 꽃잎). GSAP의 `random()`과 CustomWiggle `random` 타입은 쓰지 않는다.

## 한계와 조정 손잡이

- 화면 검증은 사용자가 브라우저에서 한다. 이 작업에서는 `node _tools/smoke.mjs 70-gsap-motionpath`만 돌렸다(오류 없음).
- 비행기 면 정렬은 면 평균 깊이로 하는 화가 알고리즘이다. 아주 비스듬한 순간에는 용골과 날개의 앞뒤가 한 프레임 바뀌어 보일 수 있다.
- 3D(4면) → 2D(7패널) 손바뀜에서 실루엣은 같지만, 2D 쪽에만 덮개 가장자리 선이 있어 미세한 선이 나타난다.
- 펼친 편지에 남는 옛 주름은 S0 기준 직선으로 근사한 것이라 실제 접기와 완전히 같지는 않다.
- 루프 직후 급강하 구간은 경로가 길어 화면 속도가 빠르다. `HERO` 경유점이나 `FLY1`로 조절한다.
