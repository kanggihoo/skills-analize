# 02 · 펼쳐지는 종이 마을 — CSS 3D 변형 · perspective + preserve-3d

> **가장 중요한 규칙: 기술만 가져간다.** 아래 "화면"은 이 데모가 그린 것이다. 기법을 보여 준 예일 뿐이니 소재·장면·이야기·구도·문구·색은 영상에 옮기지 않는다.
> 노트와 코드를 충분히 읽어 "기법과 원리"의 기술만 가져가고, 장면은 작업 중인 영상의 대본으로 새로 짓는다.

## 화면

어두운 호두나무 책상 위에서 금박 테두리와 「종이 마을 · 펼쳐 보세요」 글씨가 찍힌 천 장정 팝업북이 어둠 속에서 떠오른다(0–0.45 s).
표지가 접힌 선(gutter)을 축으로 일어서며(0.45–2.7 s) 안쪽에 인쇄된 노을 하늘이 드러나고, 하늘과 나란히 종이 산맥 두 겹이 선다.
앞 페이지(풀밭, 강, 오솔길이 인쇄된 종이)에서는 집 다섯 채가 차례로 일어선다: 오각형 앞벽이 서고, V자로 접혀 있던 옆벽이
벌어지고, 기와 줄무늬 지붕 두 장이 뚜껑처럼 닫힌다(빵집·책방·꽃집 간판). 나무(둥근 나무와 층층 침엽수, 두 장이 십자로 엇갈림),
아치 돌다리와 난간, 가로등이 선다. 카메라는 높고 먼 시점에서 낮고 가까운 시점으로 천천히 들어간다.
4 s부터 종이 해가 홈을 따라 산 뒤로 내려가고 빛이 푸르스름하게 식으며, 6 s부터 책상 오른쪽 스탠드의 따뜻한 빛, 창문 불빛과
그 앞 바닥의 빛 번짐, 가로등 세 개, 달과 별이 하나씩 켜진다. 마지막 0.4 s에 다시 어둠으로 가라앉아 처음과 이어진다.

## 기법과 원리

- **카메라 = perspective + 회전된 world** (main.js:334–339): `.cam`의 `perspective: 1700px`/`perspective-origin`이 렌즈,
  `.world`의 `translate3d(0, lift, dolly) rotateX(tilt)`가 책상 기울기와 달리(dolly)다.
- **접힘선에 놓인 transform-origin = 경첩** (`hinge`, main.js:71, `Node`, main.js:47). 노드는 모두 preserve-3d로 중첩된다.
  - 뒷장: origin = 아래 변(gutter), `rotateX(−φ)` 180° → 98°(main.js:327, 341). 안쪽 하늘과 바깥 표지는 서로 등을 댄
    두 장이고 `backface-visibility: hidden`(style.css:10)이라 접혀 있을 땐 표지만, 펼치면 하늘만 보인다.
    닫힌 책에서는 뒷장 전체가 뒤집혀 있으므로 표지 글씨는 180° 돌려 인쇄했다(main.js:166).
  - 평행 접기 산맥: 밑변 축 `rotateX(−180° + a)`, a는 책이 펼쳐진 정도에서 나온다 — 덮으면 앞으로 납작하게, 펼치면 뒷장과
    나란히 선다(main.js:353 부근).
  - 집: `rotateZ(yaw) rotateX(−180° + 90°·rise)`(main.js:362) 안에 옆벽 경첩 `rotateY(176° → 90°)`(main.js:364),
    지붕 두 장은 박공의 두 빗변에 `rotateZ(경사각) rotateX(−175° → −90°)`로 달린 뚜껑(main.js:365).
  - 나무: 선 카드 안에 같은 모양의 카드를 `rotateY(8° → 90°)`로 돌려 십자 입체를 만든다(main.js:380).
- **카드 = 인쇄된 종이** (`card`, main.js:96): 종이 결 텍스처(setup에서 그린 256 px 노이즈, main.js:81)를 그림 위에 `multiply`로
  겹친다. 그림은 CSS 그라디언트이거나 setup에서 캔버스로 한 번 그린 PNG(앞 페이지의 풀밭·강·길·풀 터치 main.js:235,
  하늘과 먼 산 main.js:257, 별). 모양은 `clip-path`: 오각형 앞벽(polygon), 아치 다리와 구름·나무(path), 해·달(circle),
  산맥 실루엣(노이즈 섞은 polygon). 문·창·둥근 다락창·간판 글씨(Gaegu)는 카드 안의 DOM으로 인쇄된다.
  **카드의 인쇄는 setup 이후 절대 바뀌지 않는다** — 프레임마다 바뀌는 것은 transform, filter, opacity뿐이다.
- **면마다의 조명** (main.js:401–411): 매 프레임 각 노드의 회전을 3×3 행렬로 합성해 `R`을 얻고(`update`, main.js:62)
  카드의 법선 n = R·(0,0,1). 밝기 = 주변광 + 해·max(0, n·Ls) + 0.9·램프·max(0, n·Ll), 따뜻함 = 램프·max(0, n·Ll) (+ 해 질 녘의 해)를
  카드의 `filter: brightness() saturate() sepia()`로 쓴다. 필터는 이미 래스터된 카드에 컴포지터가 적용하므로 조명이 바뀌어도
  3D 레이어를 다시 그리지 않는다. 종이는 양면이므로 앞면·뒷면의 빛을 둘 다 계산해 카드가 모서리로 설 때(n·view ≈ 0) 부드럽게 섞는다.
- **빛나는 것들**: 창문 불빛(main.js:294), 가로등 전구, 바닥의 빛 번짐·그림자, 달·별은 조명을 받지 않는 카드이고 opacity만 바뀐다.
- **책상**(2D): 나뭇결·책 그림자·스탠드 빛 웅덩이·어둠을 배경 그라디언트로 매 프레임 다시 칠한다(main.js:416).

## 깜빡임을 없앤 방법

GPU 브라우저에서 보인 약간의 깜빡임은 다음 원인들이었고 각각 고쳤다.
- **조명이 3D 카드를 매 프레임 다시 그렸다**: 이전에는 빛을 `--lit` 사용자 속성 → `::after` 곱하기 덮개로 넣어, 인쇄 카드 54장(940×700
  두 장 포함)이 매 프레임 다시 래스터됐다. Chromium은 3D 레이어의 새 타일이 준비되기 전에도 화면을 내보낼 수 있어 카드가 순간적으로
  비거나 낡은 타일로 보였다. → 조명을 컴포지터 속성인 `filter`로 옮겼다(style.css:9의 설명).
- **정확히 같은 평면에 겹친 카드**: 나무의 엇갈리는 카드가 0°에서 쌍둥이 카드와 완전히 겹쳐 있었고, 옆벽이 180°로 앞벽 뒷면에
  딱 붙어 있었고, 가로등 갓이 기둥과 같은 평면이었다 — 깊이 정렬이 프레임마다 뒤바뀐다. → 엇갈림은 8°에서, 옆벽은 176°에서
  시작하고(main.js:364, 380), 갓은 3 px 앞(main.js:216). 앞에 덧댄 발광 카드도 3 px 이상 띄웠다.
- **납작하게 접힌 조각들이 페이지와 서로의 위에 겹쳐 누운 채 보였다**: → 조각마다 페이지에서 12° 일어서는 동안 나타난다
  (`reveal`, main.js:113; 조각별 카드 목록 main.js:226).
- **양면 조명이 한 방향(화면 중앙 시선)으로만 판정돼 돌아가는 카드가 모서리에 닿기 전에 밝기가 튀었다**: → 앞뒤 빛을 섞는다(main.js:409).
- 바닥에 눕는 그림자·창문 빛·가로등 빛 웅덩이는 서로 2 px 이상 떨어진 평면(main.js:30).

## 결정성 전략

- 모든 값은 t의 순수 함수(`track`/`ramp`/`ease`), 배치와 질감은 `rand(seed)`. frame(t)는 이전 상태를 읽지 않는다
  (`put`은 같은 값이면 다시 쓰지 않을 뿐, main.js:118).
- 첫 프레임 전에 준비를 끝낸다: 인쇄에 쓰는 Gaegu 두 굵기(index.html에서 @font-face를 링크하고 쓸 글자로 `document.fonts.load`,
  main.js:133)와 모든 PNG 그림의 디코드(main.js:231).

## 지표

이번 수정 후에는 리드의 지시대로 렌더러를 돌리지 않았다(사용자가 GPU 브라우저에서 확인). out/의 metrics.json·sheet.jpg는 이전 실행의 것이다.
frame(t)의 일: 노드 ~110개의 3×3 행렬 곱과 transform 문자열, 인쇄 카드 54장의 filter 문자열, 발광 카드 opacity, 책상 배경 한 번 —
카드 85장, 래스터는 책상(2D)뿐.

## 한계와 다음 단계

- 그림자는 진짜 그림자가 아니라 바닥에 깐 흐린 카드다. 빛 방향에 따라 그림자 카드를 기울여(투영 행렬) 늘이면 더 정확해진다.
- 팝업 메커니즘은 연출이다(집은 시간으로 일어선다). 실제 V-접기처럼 페이지 각도에서 각 판의 각도를 구속식으로 풀면
  책을 앞뒤로 흔들 때도 종이처럼 따라 움직인다.
- CSS 필터로는 임의의 색을 곱할 수 없어 빛의 색은 밝기·채도·세피아(따뜻함)로 근사한다. 푸른 저녁빛을 정확히 넣으려면
  장면 위에 multiply 그레이딩 레이어(2D)를 하나 두는 방법이 있다(창문 불빛도 함께 물드는 것이 단점).
