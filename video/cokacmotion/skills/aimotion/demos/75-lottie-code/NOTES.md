# 75 · 코드로 쓴 로티 — lottie-web · 트림 패스 · 리피터 · 매트 · 셰이프 모프 (JSON을 코드로 작성)

> **가장 중요한 규칙: 기술만 가져간다.** 아래 "화면"은 이 데모가 그린 것이다. 기법을 보여 준 예일 뿐이니 소재·장면·이야기·구도·문구·색은 영상에 옮기지 않는다.
> 노트와 코드를 충분히 읽어 "기법과 원리"의 기술만 가져가고, 장면은 작업 중인 영상의 대본으로 새로 짓는다.

## 화면

크림색 바탕(#FFF4DE), 아래에는 남색 언덕 두 겹, 위에는 「오늘의 날씨 / 서울 · 하루의 하늘」과 기온이 있다. 기온은 오도미터처럼 굴러간다.
가운데 배지에서 날씨 아이콘 다섯 장면이 이어진다. 평면적이고 굵고 친근한 하늘색·크림 팔레트다.

- **0–1.5 s**: 남색 테두리가 스스로 그려진다(트림 패스). 그 안에 하늘이 물처럼 출렁이며 차오른다(마스크 모프).
- **0.9–2.4 s, 맑음**: 해가 배지 안에서 떠오른다(배지 모양 트랙 매트로 잘림). 쌓여 있던 빛살 12개가 30° 간격으로 부채처럼 펴지며 길어지고,
  배지 둘레에 별 반짝이가 튄다. 아래 알약에는 「맑음」이 뜬다.
- **2.3–3.6 s, 구름 조금**: 구름이 오른쪽에서 들어와 오버슈트로 멈춘다. 해는 작아지며 왼쪽 위로 비켜난다.
- **3.6–5.3 s, 비**: 구름이 넓은 비구름으로 모프하며 잿빛으로 바뀐다. 하늘 그라디언트도 어두워지고 해는 아래로 진다.
  빗줄기는 배지 안에서만 떨어진다.
- **5.4–6.4 s, 천둥번개**: 작은 불씨 모양이 번개 모양으로 뻗는다(패스 모프, 큰 오버슈트). 화면이 두 번 번쩍이고 배지 전체가 흔들린다.
  구름은 더 어두워지고 번개는 깜빡인다.
- **6.5–7.9 s, 무지개**: 하늘이 개고 구름은 다시 뭉게구름이 되어 오른발로 간다. 왼발에는 작은 구름이 튀어나온다.
  다섯 띠의 무지개가 바깥 띠부터 그려지고 해가 다시 올라온다.
- **7.95–10 s, 마무리**: 배지가 원에서 둥근 사각형 타일로 모프하며 위로 올라가 작아진다. 아래에 맑음·구름·비·번개 타일 네 장이
  차례로 튀어 오른다. 타일 속 빛살은 돌고, 구름은 까딱이고, 비는 내리고, 번개는 깜빡인다.
  그 아래에 「비 온 뒤 무지개」가 한 글자씩 튀어 오르고 부제 「오늘의 날씨 아이콘 다섯 가지」가 이어진다.

하네스 자막(흰 글씨)은 남색 언덕 위(y 1650–1850)에 놓인다.

## 기법과 원리

애프터 이펙트 없이 **bodymovin 5.x JSON을 코드로 쓴다**. `lottie-kit.js`가 레이어·셰이프 그룹·키프레임·베지어 이징을 만드는 작은 빌더이고,
`weather.js`가 그 빌더로 장면을 짓는다. 쓰는 필드는 모두 `node_modules/lottie-web/player/js`에서 SVG 렌더러가 실제로 읽는지 확인했다.

- **키프레임과 이징**(lottie-kit.js:34–55): `{ t, s, o:{x,y}, i:{x,y} }`. 구간 k→k+1의 이징은 키 k에 저장된 cubic-bezier(o.x, o.y, i.x, i.y)이다
  (PropertyFactory.js `interpolateValue`). y가 1을 넘으면 오버슈트가 된다(`E.back`, `E.backBig`, lottie-kit.js:21).
  위치 키에는 공간 탄젠트(to/ti)를 일부러 넣지 않았다. lottie-web은 to/ti가 있으면 베지어 경로 길이를 따라가며 perc > 1을 끝점에 묶어 버려 오버슈트가 사라진다.
- **트림 패스**(`tm`): 테두리(weather.js:173–174), 무지개 다섯 띠(시작을 0.07 s씩 어긋냄, weather.js:167), 빛살 길이(weather.js:195),
  빗줄기(머리 e와 꼬리 s가 따로 가속, weather.js:68–73).
- **리피터**(`rp`, weather.js:197): 그룹 안에서 자기 위에 있는 [선, 트림, 스트로크]를 12번 복제한다. 복제마다의 회전 `tr.r`을 0° → 30°로
  키프레임해서 겹쳐 있던 빛살이 부채처럼 펴진다. 그룹 회전(150°/10 s)과 스케일 펄스가 2차 동작이다.
  리피터는 복제본을 그룹으로 만들어 셰이프 배열에 끼워 넣는다(RepeaterModifier.js `processShapes`).
- **셰이프 모프**(패스 키프레임, ShapeProperty.js `interpolateShape`):
  - 구름: `cloudPath`(lottie-kit.js:162)가 겹친 원 4개의 윗선을 원호(호마다 베지어 2개)로 따고 바닥을 평평하게 닫는다.
    꼭짓점이 늘 9개라서 뭉게구름과 비구름이 꼭짓점끼리 맞물려 모프한다(weather.js:45–46, 153).
  - 번개: 꼭짓점 7개 다각형이 불씨(같은 다각형을 14 %로 줄인 것)에서 25 % 오버슈트로 뻗는다. `rd` 둥근 모서리가 붙는다(weather.js:160).
  - 배지: 원을 둥근 사각형의 8개 꼭짓점과 **같은 극각**에 찍는다(`circleAt` + `roundSquareAngles`, lottie-kit.js:124, 148).
    그래서 원 → 둥근 사각형이 꼭짓점끼리 대응한다. 배경·하늘·매트·테두리·그림자가 같은 키프레임을 쓴다(weather.js:43).
- **트랙 매트**: 레이어 8이 `td: 1`인 배지 모양이고, 해(10)와 비 프리컴프(9)가 `tt: 1, tp: 8`로 그것을 알파 매트로 쓴다.
  lottie-web 5.13의 `tp`(매트 부모 ind)를 쓰면 한 매트를 두 레이어가 함께 쓸 수 있다(SVGRendererBase.js `buildItem`).
  비 타일 안에서도 둥근 사각형 매트가 한 번 더 쓰인다(weather.js:110–111).
- **마스크**: 하늘 레이어의 가산 마스크(weather.js:205–214)는 윗변이 물결인 사각형이다. 물결 꼭짓점의 기울기 부호를 키마다 뒤집으며
  올라와 출렁이며 차오른다. 불투명도 100, 확장 0이라 lottie는 이것을 clipPath로 그린다(mask.js).
- **그라디언트**: 하늘은 선형 `gf`이고 색 정지점 자체를 키프레임한다. 맑음 → 비 → 폭풍 → 맑음(weather.js:204, GradientProperty.js).
  해 몸통은 방사형 `gf`이다.
- **프리컴프**:
  - `drop`(빗줄기 하나, 0.53 s)을 `rainfall` 안에서 `st`를 달리한 인스턴스 36개로 깐다(AE의 "복제 후 시간 어긋내기", weather.js:75–84).
  - `rainfall`은 배지(st 3.95 s)와 비 타일(st 7.6 s, 28 % 크기)에서 재사용되고, 비 타일 안에서는 프리컴프 속 프리컴프가 된다.
  - `puff`는 무지개 왼발, 배경의 흘러가는 구름 둘, 구름 타일에서 재사용된다.
- **페어런팅**: 배지 레이어 전부가 SHAKE null(101) → BADGE null(100) 사슬에 달려 있다. BADGE는 팝인과 마지막의 상승·축소를,
  SHAKE는 천둥의 흔들림(위치·회전 키 7개, weather.js:256)을 맡는다.
- **2차 동작**: 구름 까딱임(사인 키, `bobK`), 반짝이 팝, 언덕 두 겹의 느린 숨쉬기(패스 모프), 장식 `+`의 회전.
- **글자**는 로티 텍스트 레이어가 아니라 DOM 오버레이다(Pretendard, Black Han Sans — OFL, main.js:56–80).
  상태 알약은 단어 띠를 세로로 굴린다. 기온은 자릿수 띠의 연속 이동으로 오도미터를 만든다(main.js:100–102).

## 결정성 전략

- `lottie.loadAnimation({ autoplay: false })`, `frame(t)`에서 `anim.goToAndStop(t * 1000, false)`(main.js:91).
  - lottie-web은 프레임 번호로 모든 속성을 다시 계산하고 동기적으로 그린다(AnimationItem.js `gotoFrame` → `renderFrame`).
  - 속성 캐시는 직전 프레임 기준이고, 뒤로 가면 `lastIndex`를 0으로 되돌린다(PropertyFactory.js `getValueAtCurrentTime`).
  - 서브프레임이 기본으로 켜져 있어 임의의 t에서 보간한다.
- rAF 루프(AnimationManager)는 재생 중인 애니메이션이 있을 때만 돈다. 여기서는 `play()`를 부르지 않는다.
- 웹 워커를 쓰지 않는 기본 설정이라 데이터 완성(DataManager)도 동기다. `isLoaded`가 거짓일 때만 `DOMLoaded`를 기다린다.
- lottie-web은 로딩 중 탄젠트를 상대 → 절대로 **제자리 변환**하므로, 같은 패스 객체를 여러 곳에서 공유하는 생성 JSON을
  `JSON.parse(JSON.stringify())`로 깊은 복사해서 넘긴다(main.js:41).
- lottie는 렌더 오류를 삼키고 `'error'` 이벤트만 낸다. 그 오류를 잡아 `frame()`에서 던져 점검 도구에 드러나게 했다(main.js:46, 92).
- 빗방울 배치는 `rand(7501)`이고 표현식·난수가 없다. DOM 오버레이는 t만의 함수다(`set`은 같은 값 다시 쓰기만 건너뜀).

## 한계와 조정 손잡이

- 장면 시각표: `T`(weather.js:32). 실제 키는 각 레이어에 직접 적혀 있다.
  - 구름 weather.js:150–158
  - 번개 weather.js:160
  - 무지개 시작 `T.rainbow`와 띠 간격 0.07 s(weather.js:168)
  - 마무리 null weather.js:253–255
- 오버슈트 크기: `E.back` / `E.backBig`(lottie-kit.js:27–28).
- 배지 크기·모프 목표: `R, SQ, RC`(weather.js:41). 마지막 위치·축소: `BADGE`(weather.js:31).
- 빗줄기 수·간격: `N = 36, span = 2.2`(weather.js:76). 기울기 `r: 14`(weather.js:82).
- 빛살 수·간격: `repeater({ c: 12 })`와 30°(weather.js:197). c를 바꾸면 360/c로 맞출 것.
- 하늘 색: `CLEAR/RAIN/STORM`(weather.js:204). 물결 높이·출렁임: `wave`/`liquid`(weather.js:205–212).
- 흔들림 세기: `jolt`(weather.js:256).
- 오버레이 타이밍:
  - 상태 단어 `STATES`(weather.js:266), 기온 `TEMP`(weather.js:268)
  - 알약 등장·퇴장 main.js:108
  - 제목 글자 간격 main.js:115
- 한계:
  - 로티 텍스트 레이어를 쓰지 않아 글자는 JSON 밖(DOM)에 있다. 로티 파일만 떼어 가면 글자가 따라가지 않는다.
  - SVG 렌더러는 매트·마스크 영역을 매 프레임 다시 래스터한다. 비 내리는 구간(매트 + 프리컴프 clip 36개)이 가장 무겁다.
  - 번개 그림자는 같은 패스를 오프셋한 평면 그림자다. 진짜 안쪽 음영이 필요하면 오른쪽 절반만 다른 패스로 그려야 한다.
