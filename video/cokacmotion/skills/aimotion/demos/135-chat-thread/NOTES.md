# 135 · 오늘 저녁 뭐 먹지 — 메신저 대화 장면 · 말풍선 레이아웃 + 스프링 스크롤 + 입력 중 표시

> **가장 중요한 규칙: 기술만 가져간다.** 아래 "화면"은 이 데모가 그린 것이다. 기법을 보여 준 예일 뿐이니 소재·장면·이야기·구도·문구·색은 영상에 옮기지 않는다.
> 노트와 코드를 충분히 읽어 "기법과 원리"의 기술만 가져가고, 장면은 작업 중인 영상의 대본으로 새로 짓는다.

가족 단톡방 「우리집」(엄마, 아빠, 동생, 나)이 10초 동안 저녁 메뉴를 정한다.
대화 표(`THREAD`) 하나와 읽음 표(`OPENS`) 하나가 화면의 모든 것을 움직인다. 말풍선 크기, 묶음과 꼬리, 목록 위치, 스크롤, 입력 중 표시, 안 읽은 수, 반응, 투표 막대가 모두 이 두 표와 t에서 나온다.
메신저 화면, 가족 넷의 얼굴, 떡볶이 사진, 반응 아이콘은 모두 이 데모에서 그렸다. 실제 앱의 색·모양·아이콘을 따르지 않고, 이모지 글꼴도 쓰지 않는다.
10초, 1080×1920, Canvas 2D 하나다.

## 화면

차가운 연회색 바탕에 떠 있는 대화창에서 가족 넷이 저녁 메뉴로 투닥이다가, 투표가 2 : 2로 갈리자 엄마가 "둘 다 시키자"를 보내고 반응이 터져 나온다.

색은 토큰 몇 개와 강조색 하나다. 바탕은 차가운 연회색(`#e2e7ef`→`#c5cedb`), 대화창 안은 `#eef1f6`, 남의 말풍선과 머리·입력 막대는 흰색, 글자는 잉크(`#1c2233`)다.
강조색은 산호색(`#f0583e`) 하나이고 "나"에게만 쓴다. 나의 말풍선, 보내기 버튼, 나의 표, 안 읽은 수, 하트, "입력 중" 글자, 절정의 도장과 링이 이 색이다.
깊이는 세 겹이다. 원경은 흐린 빛 덩어리들이 스크롤과 반대로 천천히 흐르고(시차 0.06), 중경은 그림자를 깐 대화창이며, 근경은 절정에 터져 나오는 반응 아이콘과 가장자리의 흐린 보케다.
글꼴은 Pretendard Variable 하나다(본문 500 44px, 이름 600 28px, 제목 800 44px, 시각 500 23px).
이야기 내내 돌아오는 장치는 "점 세 개"다. 동생, 아빠, 엄마, 다시 아빠가 입력할 때마다 말풍선 자리와 머리의 부제에 같은 점 세 개가 뛴다.

## 기법과 원리

- **어절을 지키는 줄바꿈(measureText)**(`main.js:101-121`). 공백으로 나눈 어절을 하나씩 붙여 보며 `measureText(줄 + ' ' + 어절).width ≤ 최대폭`이면 붙이고, 넘치면 줄을 끊고 어절을 다음 줄로 넘긴다(탐욕법).
  - 어절 하나가 최대폭보다 넓을 때만 음절(코드 포인트) 단위로 쪼갠다.
  - 쪼갤 때 닫는 문장부호(`! ? . , … ~ )`)가 줄 첫머리에 오게 되면 앞 음절을 함께 내려 보낸다(금칙).
  - 측정은 글꼴을 받은 뒤(`fontReady`) setup에서 한 번만 한다.
  - 결과는 "얘들아 오늘 저녁 뭐 먹을래? / 일곱 시 전에 정하자"(어절 단위)와 "치킨치킨치킨치킨치킨치킨치킨 / 치킨!!"(음절 단위)다.
- **말풍선 크기는 줄에서 나온다**(`main.js:146-149`).
  - 너비 = 가장 긴 줄의 측정 폭 + 2 × 좌우 여백(32)이다. 최대 너비 620은 줄바꿈 폭(620 − 64)으로만 쓰고, 말풍선은 가장 긴 줄에 맞춰 줄어든다.
  - 높이 = 줄 수 × 줄 높이(60) + 2 × 위아래 여백(22)이다.
  - 글자 기준선은 줄 중심 + (ascent − descent)/2다. ascent와 descent는 '가'의 `actualBoundingBox`로 한 번 잰다(`main.js:124`).
- **묶음: 아바타·이름은 첫째에, 꼬리는 마지막에, 모서리는 자리에 따라**(`main.js:143`, `main.js:168`, `main.js:230-246`).
  - 같은 사람이 같은 분(分)에 보낸 연속 메시지가 한 묶음이다. 구분선이 끼면 끊긴다.
  - 첫째 여부는 보낼 때 정해지고 바뀌지 않는다. 마지막 여부는 다음 묶음 메시지가 보내지는 시각 `lastUntil`부터 0.22초 동안 꺼진다.
  - 왼쪽 말풍선의 모서리: 위왼쪽 = 첫째 ? 30 : 8, 아래왼쪽 = 8(+ 꼬리), 오른쪽 둘 = 30이다. 나의 말풍선은 좌우를 뒤집는다.
  - 묶음 안 간격은 8, 묶음 사이는 30이다. 사진과 투표 카드도 같은 규칙을 따른다.
- **모서리 하나 = 3차 베지에 둘, 꼬리는 그 제어점의 보간**(`main.js:249-270`). 아래 모서리를 모서리 기준 지역 좌표(u: 아랫변 안쪽, v: 옆변 위쪽)의 점 7개로 쓴다.
  - k = 0이면 반지름 r의 90° 호다. 45° 조각 둘로 나누고 손잡이 길이는 (4/3)·tan(11.25°)·r = 0.2652r이다.
  - k = 1이면 바깥 아래로 튀어나온 꼬리다(`TAIL`).
  - 점마다 lerp(호, 꼬리, k)를 쓴다. 그래서 꼬리가 다음 말풍선으로 옮겨 갈 때 모서리가 끊김 없이 둥글어진다.
  - 오른쪽 아래 모서리는 같은 점을 x로 뒤집고 역순으로 잇는다.
- **콘텐츠 공간 목록**(`main.js:189-226`).
  - 항목 i의 콘텐츠 y = 위 여백 + Σ_{j<i}(간격_j + 높이_j(t))이다.
  - 높이 = 이름(44, 왼쪽 묶음의 첫째만) + (입력 중이면 88, 아니면 말풍선 높이) + 반응 줄 36·s(t − t_반응)이다.
  - 화면 y = 목록 위 + 콘텐츠 y − scroll(t)이다. 화면 밖 항목은 그리지 않고, 목록 위아래 끝은 배경색으로 흐리게 덮는다.
- **스크롤 = 감쇠 스프링 계단 응답의 합**(`main.js:50-57`, `main.js:201-213`).
  - s(τ) = 1 − e^(−ζωτ)·(cos ω_d τ + (ζω/ω_d)·sin ω_d τ)이다. ω = 2πf, ω_d = ω√(1 − ζ²)이고, τ ≤ 0이면 0이다. s(0) = 0, s′(0) = 0, s(∞) = 1이다.
  - 레이아웃 사건(메시지 들어옴, 입력 중 → 메시지, 반응 줄 생김)마다 정착한 높이로 목표 T_e = max(0, 콘텐츠 높이 − 화면 높이)를 구하고 계단 ΔT_e = T_e − T_{e−1}을 하나 만든다.
  - scroll(t) = T_0 + Σ ΔT_e · s(t − t_e)다. f = 1.75 Hz, ζ = 0.74로 약 0.5초에 정착하고 3 % 넘친다.
  - 이전 프레임을 기억하지 않는다. 계단이 겹쳐도 선형 합이라 그대로 맞는다.
  - 새 칸은 즉시 생기고 스크롤이 스프링으로 따라간다. 그래서 새 말풍선은 입력창 뒤에서 솟아오른다.
  - 반응 줄은 칸 높이를 같은 s로 키운다. 높이 증가와 스크롤 계단이 정확히 상쇄되어 그 아래 내용은 제자리에 있고, 위쪽만 밀려 올라간다.
- **꼬리 모서리에서 커지는 등장**(`main.js:775-779`). 배율 0.2 + 0.8·s(τ; f = 2.3, ζ = 0.55)를 꼬리 모서리(남은 왼쪽 아래, 나는 오른쪽 아래)를 원점으로 건다. ζ = 0.55라 약 13 % 넘쳤다가 자리 잡는다. 아바타는 같은 스프링으로 자기 중심에서 튀어나온다.
- **입력 중 표시와 말풍선 모프**(`main.js:664-672`, `main.js:233-235`, `main.js:796-799`).
  - 점 세 개는 같은 사인파를 0.95 rad씩 늦게 탄다. up = max(0, sin(2π·1.5t − 0.95i))만큼 9 px 뛰고 진해진다.
  - 메시지가 오면 말풍선 너비·높이·모서리가 (132 × 88, 알약 모양)에서 (실제 크기, 묶음 모서리)로 스크롤과 같은 스프링을 타고 보간된다.
  - 점은 0.08초에 사라진다. 글자는 0.04초 뒤부터 0.14초 동안 나타나며, 자라는 말풍선 모양으로 잘린다.
  - 칸 높이 계단과 크기 보간이 같은 스프링이라 말풍선 아래 가장자리가 화면에서 제자리에 있다.
  - 머리의 부제는 "엄마 · 아빠 · 동생 · 나"와 "○○ 입력 중 •••"를 위아래로 굴려 바꾼다(`main.js:843`).
- **안 읽은 수**(`main.js:170-184`, `main.js:612-626`).
  - 읽기 = 대화방을 연 시각(`OPENS`) + 입력·보내기·투표·반응 시각이다. 나는 받는 즉시 읽는다.
  - 메시지마다 보낸 사람과 나를 뺀 사람들의 "보낸 뒤 처음 읽은 시각"을 정렬해 둔다. count(t) = 인원 − (readAt ≤ t인 수)다.
  - 수가 바뀌면 0.28초 동안 옛 숫자는 위로 빠지고 새 숫자는 아래에서 알약 안으로 굴러 들어온다(`main.js:595`). 0이 되면 알약이 줄어 사라진다.
- **반응 칩**(`main.js:628-662`). 아이콘마다 칩 하나다. 첫 반응에서 s(τ; f = 3, ζ = 0.42)로 약 23 % 넘치며 튀어나온다. 반응이 더해질 때마다 숫자가 굴러 오르고 칩이 0.2만큼 부풀며 점 일곱 개가 퍼진다. 하트·웃음·냠 아이콘은 경로로 그린다(`main.js:280-321`).
- **시각 묶음**(`main.js:753-762`, `main.js:803-813`).
  - "오후 6:13" 같은 시각은 묶음의 마지막 말풍선 옆에만 붙는다. 묶음에 새 메시지가 들어오면 0.2초에 사라지고 새 말풍선 옆에 나타난다.
  - 안 읽은 수 알약은 시각이 있으면 그 위(바닥에서 52 px), 없으면 바닥 쪽(20 px)에 둔다.
  - 시간이 떨어진 대화 사이에는 가운데 구분선("오후 5:58")이 있다.
- **투표 막대**(`main.js:675-748`).
  - 막대 비율 = Σ 0.25·s(t − t_표) + (1 − 0.25·표 수)·s(t − T_둘다)다. "둘 다"에서 두 막대가 같은 스프링으로 끝까지 차고 체크가 튀어나온다.
  - 숫자와 투표한 사람의 얼굴은 표마다 굴러 오르고 튀어나온다. 나의 표는 산호색 외곽선이다.
  - 도장은 배율 1 + 0.9·(1 − outExpo(τ/0.26))로 내리꽂힌다. 큰 박자에만 쓰는 임팩트다.
- **반응 폭발: 선형 항력 + 부력의 닫힌 해**(`main.js:580-590`, `main.js:925-955`).
  - dv/dt = −kv + b를 풀면 x = x0 + vx(1 − e^(−kτ))/k, y = y0 + (b/k)τ + (vy − b/k)(1 − e^(−kτ))/k다(k = 4.2, b = −300 px/s²). 위로 떠오르는 힘이 있어 아이콘이 날아갔다가 천천히 솟는다.
  - 투표 카드가 바로 위에 있으므로 부채꼴을 −26°…+21°로 잡아 오른쪽 빈 쪽으로 보낸다.
  - 깊이 값 하나가 크기(40–104 px)와 속도를 함께 정하고, 먼 것부터 그린다.
  - 흰 스티커 테두리와 옅은 그림자(`main.js:957`)를 깔아 산호색 위에서도 읽힌다.
- **입력창과 보내기**(`main.js:868-914`). 사진 첨부 칩, 한 글자씩 쳐지는 "떡볶이 어때?", 보내기 버튼 눌림(사인 반파, 배율 −12 %)과 퍼지는 링을 그린다. 나의 말풍선이 오른쪽 아래에서 올라오는 이유가 화면에 보인다.

## 결정성 전략

- `frame(t)`는 t의 닫힌 식이다. 스크롤, 모프, 반응 줄, 투표 막대, 폭발이 모두 τ = t − t_사건을 넣은 스프링·항력의 해석해다. 이전 프레임의 상태를 쓰지 않는다.
- 줄바꿈, 말풍선 크기, 묶음, 읽은 시각, 스크롤 계단, 폭발 원점은 setup에서 한 번 계산한다(`main.js:972-994`).
- 매 프레임 `g.reset()`으로 2D 상태를 모두 되돌리고 `imageSmoothingQuality`만 다시 정한다.
- 배경, 대화창 그림자(흐림), 아바타 넷, 떡볶이 사진, 투표 아이콘은 setup에서 굽는다. 헤드리스에서는 CPU 래스터(`willReadFrequently`)로 굽고 본 캔버스에 한 번씩 합성해 둔다.
- 난수는 `rand(seed)`(사진 재료 배치, 배경 덩어리, 보케, 폭발)뿐이다.
- 렌더러 검사(정순 / 새 페이지 역순 / 되돌아가기): **byte-identical pass**.
