# 122 · 목마르기 전에 — 앱 소개 모션 · 폰 목업 + 화면 전환 + 탭 + 기능 콜아웃

> **가장 중요한 규칙: 기술만 가져간다.** 아래 "화면"은 이 데모가 그린 것이다. 기법을 보여 준 예일 뿐이니 소재·장면·이야기·구도·문구·색은 영상에 옮기지 않는다.
> 노트와 코드를 충분히 읽어 "기법과 원리"의 기술만 가져가고, 장면은 작업 중인 영상의 대본으로 새로 짓는다.

지어낸 식물 물주기 알림 앱 「촉촉」의 10초짜리 소개 영상이다. 직접 그린 일반 휴대폰(상표·노치·실제 기종 모양 없음)이 3D로 떠서 돌고, 터치 표시가 화면을 누를 때마다 UI가 그 UI의 논리대로 바뀐다.
그 옆에서는 기능 콜아웃(번호 라벨 + 큰 헤드라인 + 지시선)이 지금 시연하는 기능을 짚는다. 마지막은 앱 아이콘, 앱 이름, 가치 문장 한 줄, 직접 디자인한 스토어 스타일 배지로 끝나는 엔드 카드다.
1080×1920. 글자와 UI는 DOM, 기기는 CSS 3D 리그, 지시선·물방울은 SVG, 배경은 Canvas 2D로 그린다. 움직임은 GSAP 타임라인 하나와 닫힌 식 몇 개로 만든다.

## 화면

미감은 밝은 플랫 일러스트 앱 광고다. 바탕은 세이지 종이색이고, 가장자리에 흐린 몬스테라 잎 두 겹과 떠다니는 물방울 보케, 필름 그레인을 깔았다. 아래에는 자막용 짙은 초록 바닥 띠가 있다.
색은 먹초록(#17352a)과 물빛 파랑(#2c7bf2) 하나만 쓴다. 글꼴은 Pretendard 하나다. 글자는 두 층으로 나뉜다.
- **UI 글자**(화면 안): 13–32px. 날짜·제목·카드 이름·메타·알약·탭 이름처럼 실제 앱의 위계를 따른다. 숫자는 고정폭이다.
- **홍보 글자**(화면 밖): 헤드라인은 88px 800, 자간 −0.035em. 번호 알약(`01`)과 라벨 29px이 붙고, 핵심어 하나만 파랑이다.

## 기법과 원리

- **이야기 시계 한 곳**: 장면 시각은 `T`(`main.js:41`), 터치의 방문 지점과 누름 시각은 `TAPS`(`main.js:44`), 콜아웃 문구·초점 틀은 `CO`(`main.js:53`)에 있다. 타임라인과 닫힌 식이 모두 이 표를 읽는다.
- **기기 = CSS 3D 리그**(`main.js:412`, `style.css`의 `.cam`·`.rig`)
  - `.cam`에 `perspective: 2400px`을 주고, `.rig`(`transform-style: preserve-3d`) 안에 판 12장을 3.4px 간격 `translateZ`로 쌓았다. 그래서 3/4로 돌면 41px 두께의 옆면이 보인다. 판 색은 가운데 깊이가 밝아 금속 띠처럼 보이고, 가운데 판들에만 옆 버튼 하나를 달았다.
  - 그 위에 본체(베젤)와 화면이 있다. 그림자 판은 −110px 뒤에 흐리게 둬서 기기와 함께 기운다.
  - 자세는 GSAP이 프록시 `P = {x, y, rx, ry, rz, s}`를 트윈하고, frame이 느린 떠다님(y ±9px, rx ±1.1°, ry ±1.6°)과 물 박자의 감쇠 펀치를 더해 `translate3d · rotateX · rotateY · rotateZ · scale3d` 한 줄로 쓴다(`main.js:587-597`).
  - 화면 유리 반사(`.glare`)는 ry·rx에 따라 배경 위치가 옮겨 간다.
- **3D 투영으로 지시선 찾기**(`main.js:252`, `project`): CSS가 쓰는 것과 같은 변환(크기 → rotateZ → rotateY → rotateX → 이동 → 원근 w = 1 − z/P)을 JS로 다시 계산해, 화면 좌표의 UI 점이 무대 어디에 보이는지 구한다.
  - 지시선(`leaderD`, `main.js:300`)은 헤드라인 아래 점에서 수직으로 내려와 반지름 30px로 꺾인 뒤 초점 틀의 가장자리까지 간다. 진행률 p로 잘라 그린다.
  - 초점 틀(`frameD`, `main.js:323`)은 화면 평면 위 둥근 사각형을 한 점씩 투영한 경로다. 그래서 기기가 기울면 틀도 원근대로 기운다. 원형(썸네일)부터 긴 줄(알림 줄)까지 같은 함수로 그린다.
  - 맥박 틀은 0.95초마다 20px 부풀며 사라진다. 기기가 떠다니고 돌아도 지시선 끝은 매 프레임 UI 위에 붙어 있다(`main.js:637-659`).
- **화면 전환은 UI의 논리를 따른다**
  - *공유 요소(컨테이너 트랜스폼)*(`main.js:504`): 상세 화면 전체에 `clip-path: inset(카드 사각형 round 22px)`을 씌우고, 0.6초 동안 `inset(0 round 54px)`까지 연다. 처음 0.14초에는 카드의 메타·알약 복사본을 지운다. 히어로(290px 원)는 썸네일 자리에서 `scale 64/290`으로 출발하고, 제목은 카드 이름 자리에서 `scale 18/32`로 출발한다. 둘은 같은 곡선으로 날아간다. 목록은 0.93으로 물러나며 어두워진다. GSAP Flip(69번)은 쓰지 않았다. 좌표를 직접 설계한 레이아웃에서 시작·끝 변환을 손으로 정했다.
  - *시트*(`main.js:542`): 배경 막이 어두워지고 시트가 `back.out(1.05)`로 조금 넘치며 올라온다. 내용은 0.045초 간격으로 겹쳐 들어온다. 퇴장(`power2.in` 0.32초)은 등장보다 빠르다.
  - *탭 전환*(`main.js:555`): 세그먼트 표시가 141px 옆으로 가고, 두 창이 같은 곡선으로 476px씩 밀린다(나가는 창과 들어오는 창이 붙어 있음). 막대는 `scaleY` 0.05초 간격으로 솟는다.
- **터치 표시**(`touch`, `main.js:273`; `press`, `main.js:267`): 반투명 회색 원과 흰 테두리라서 흰 카드 위에서도 파란 버튼 위에서도 보인다.
  - 나타남(1.45→1배), 누름(0.82배까지 `outCubic`), 놓음(`outBack`으로 살짝 넘침), 사라짐이 모두 방문 표에서 나오는 닫힌 식이다.
  - 놓는 순간 손끝 고리(`ringAt`)와 눌린 요소 안의 잉크 물결(`rippleAt`, 요소의 `overflow: hidden`이 자른다)이 퍼진다. 눌린 요소는 CSS 독립 속성 `scale`로 3% 들어간다. GSAP이 쓰는 `transform`과 부딪히지 않는다.
  - 세 번째 방문은 사라지지 않고 다음 지점으로 미끄러진다(`g`). 손가락을 떼지 않고 옮겨 가는 흔한 시연 문법이다.
- **세는 숫자**: GSAP이 프록시 `N`을 트윈하고 frame이 반올림해 고정폭 숫자로 쓴다(`main.js:599-608`). 바뀐 글자만 DOM에 쓴다. 게이지 너비와 5/7 막대도 같은 값을 읽는다.
- **콜아웃 등장·퇴장**(`main.js:493`)
  - 등장: 라벨이 옆에서 들어온다(`expo.out`). 헤드라인 두 줄은 줄 마스크 안에서 0.1초 간격으로 올라온다. 0.3초 뒤 지시선이 0.42초 동안 그려지고, 틀이 `back.out(2.2)`로 열린다.
  - 퇴장은 0.3초 `power2.in`이다. 줄이 위로 빠지면서 투명해져 마스크 끝에 글자 조각이 남지 않는다.
  - 헤드라인은 1.0–1.3초 동안 멈춰 있어서 한 줄에 0.5초 이상 읽을 시간이 있다. 왼쪽·오른쪽 콜아웃을 번갈아 쓰고, 기기는 늘 콜아웃 쪽을 보도록 반대편으로 비켜 선다.
- **물방울**(`main.js:438`, `main.js:661`): 눈물방울 모양 18개다. 위치는 공기 저항이 있는 탄도의 닫힌 식 `x = v/k·(1 − e^(−k s))`에 중력을 더해 구한다. 뾰족한 끝은 속도 반대쪽을 향하고, 크기는 시간에 따라 1.8배까지 커진다. 버튼에서 물빛 고리 하나가 퍼진다.
- **엔드 카드**(`main.js:568`, `main.js:680-704`)
  - 물빛 원 와이프(dyn 캔버스)로 색온도를 바꾼다. 아이콘은 회전하며 튀어나오고 고리 둘이 퍼진다. 앱 이름은 음절마다 마스크에서 올라온다(자간 0, 마스크 여백을 겹쳐 획이 잘리지 않음).
  - 배지는 직접 디자인했다. 짙은 초록 알약에 기기+화살표 글리프, 두 줄 글, 파란 화살표 단추가 있다. 실제 스토어 배지 모양은 따르지 않았다.
- **배경**(`main.js:338`, `paintLeaf`)
  - 몬스테라 잎은 하트 모양 경로에 갈라진 틈 셋을 `destination-out`으로 낸 것이다. setup에서 원경(blur 10)과 중경(blur 1.5) 캔버스에 한 번 그리고, frame에서는 기기 위치의 반대로 미는 시차만 준다.
  - 보케 30개는 닫힌 식으로 떠오른다. 그레인은 540×960 노이즈를 두 배로 키워 5% 불투명도로 덮는다.
  - 화면 속 식물 그림(몬스테라·바질·스투키·고무나무, `main.js:105`)은 SVG 평면 일러스트다. 몬스테라의 틈은 잎 좌표계 마스크로 뚫는다.

## 결정성 전략

- 움직임은 `gsap.timeline({ paused: true, defaults: { lazy: false } })` 하나에 있다(`main.js:478`). frame은 `tl.time(t)`을 먼저 부른다.
  - 속성마다 첫 트윈은 `fromTo`이고 그다음은 `to`다. 같은 속성의 트윈이 시간상 겹치지 않게 짰다. setup 끝에서 `tl.time(D); tl.time(0)`으로 모든 트윈을 순서대로 한 번 초기화한다(`main.js:577`).
  - 보였다 안 보였다 하는 전환은 길이 0인 `set` 대신 1ms `autoAlpha` 트윈이다.
- 터치·고리·물결·누름·떠다님·펀치·물방울·보케·지시선·초점 틀·엔드 고리는 모두 t의 닫힌 식이다. 다른 효과가 끝나기를 기다리는 것은 없다.
- 지시선 끝점은 frame이 정한 자세에서 다시 계산한다. 레이아웃을 읽지 않는다(`getBoundingClientRect` 없음).
- 난수는 `rand(12201)`(보케), `rand(12202)`(물방울), `rand(12203)`(그레인)뿐이고 모두 setup에서 뽑는다.
- 배경 캔버스(바탕·잎 두 겹·그레인)는 setup에서 한 번 그린 정지 그림이다. 매 프레임 그리는 dyn 캔버스는 헤드리스에서 CPU 래스터(`willReadFrequently`)로 만든다. 그리기 전에 변환·알파·합성·필터를 기본값으로 되돌린다.
- 렌더러 검사(정순, 새 페이지 역순, 되돌아가기): 최대 1/255 차이로 통과(허용 4). 3D 합성 경계의 반올림으로 보인다.
