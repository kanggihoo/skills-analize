# 69 · 다시 놓이는 것들

> **가장 중요한 규칙: 기술만 가져간다.** 아래 "화면"은 이 데모가 그린 것이다. 기법을 보여 준 예일 뿐이니 소재·장면·이야기·구도·문구·색은 영상에 옮기지 않는다.
> 노트와 코드를 충분히 읽어 "기법과 원리"의 기술만 가져가고, 장면은 작업 중인 영상의 대본으로 새로 짓는다.

GSAP Flip · FLIP 레이아웃 전환 · CSS 그리드/플렉스. 24절기 카드 스물네 장이 다섯 가지 배치로 다시 놓인다. 10초, 1080×1920.

## 화면

미술관 도록처럼 차분한 화면이다.
- 바탕은 옅은 회백(#efece6)이다.
- 카드(3:4)는 위쪽 62%가 그 절기의 색면이고, 색면 안에 작은 SVG 모티프와 번호가 있다.
- 카드 아래쪽에는 한글 이름(Noto Serif KR 700), 한자(Noto Serif KR 400), 양력 날짜(Pretendard)가 있다.
- 위에는 `二十四節氣`와 부제, 오른쪽에 도판 번호(PL. 01 · GRID → … → PL. 05 · DETAIL)가 있고, 배치가 바뀔 때마다 마스크 안에서 갈아 끼워진다.
- 아래에는 각주와 자막용 먹색 띠(y ≥ 1672)가 있다.

## 기법과 원리

- **진짜 CSS 레이아웃 다섯 개**(`main.js:106-116`): 같은 덱(`.deck`)에 붙는 클래스만 바뀐다.
  - `L-grid`: `display: grid`, 6열.
  - `L-wheel`: 카드마다 `position: absolute` 후 `rotate(var(--a)) translateY(-360px)`.
  - `L-row`: `display: flex`. 카드마다 `top: var(--alt)`로 상대 위치를 주며, `--alt = −110·sin(황경)`이다(`main.js:166`).
  - `L-stack`: 2×2 grid에서 같은 칸(`grid-row/column: var(--gr/--gc)`)에 여섯 장을 겹치고, `--k`로 이동·회전해 부채꼴로 편다.
  - `L-strip`: flex 띠.
  - 장식 SVG와 레이어는 `position: absolute`라 흐름에 끼지 않는다.
- **Flip.getState로 상태를 기록한다**(`main.js:174-181`): setup에서 덱에 레이아웃 클래스를 차례로 붙이고, 그때마다 `Flip.getState(cards)`로 카드 24장의 경계·행렬을 기록한다. 장식 배치를 위해 무대 좌표도 함께 잰다. 그다음 덱을 기준 레이아웃(격자)으로 되돌린다.
- **Flip.fit(getVars)로 변환을 계산한다**(`main.js:204-217`):
  - `Flip.fit(card, state, { getVars: true, scale: true })`는 카드를 그 상태의 자리에 맞추는 `x, y, rotation, skewX, scaleX, scaleY`를 돌려준다. 값은 기준에 대한 상대값이고, DOM은 원래대로 되돌린다.
  - 무대 자체의 CSS 배율(창 맞춤)은 Flip이 부모 행렬의 역행렬로 지워 준다.
  - 회전은 (−180°, 180°]로 나오므로 바퀴로 갈 때 카드가 가까운 쪽으로 돈다.
  - 들어 올릴 자리는 보이지 않는 고스트 요소에 맞춘다(`main.js:184`, `main.js:212`).
- **중첩 공유 요소 모핑**(`main.js:213-216`, `main.js:360-365`):
  - 입춘을 들린 자세로 잠시 놓고(`gsap.set`), 페이지의 각 부분을 작은 카드의 해당 부분에 `Flip.fit`해 시작 변환을 얻는다. 페이지 판(색면 포함)은 카드 전체에, 모티프·이름·한자는 각각 작은 카드의 것에 맞춘다.
  - 펼칠 때 작은 카드와 페이지가 0.1초 교차한다. 판은 `power3.inOut`, 안의 부분들은 0.04/0.07/0.1초 늦게 `power4.inOut`으로 따로 날아가므로, 부모와 자식이 다른 곡선으로 움직이는 중첩 Flip이 된다.
- **스태거 전환**(`main.js:298-301`): `move()`가 카드마다 `fromTo(이전 변환 → 다음 변환)`을 각자의 지연으로 넣는다.
  - 격자 입장은 (행+열)×0.045초의 대각선이다(`main.js:316-319`).
  - 바퀴·줄은 번호 순이다(`main.js:325`, `main.js:335`).
  - 계절 더미는 `(k·0.03 + 계절·0.04)`로 네 더미가 함께 쌓인다(`main.js:350`).
  - 띠는 0.008초 간격이다(`main.js:358`).
- **덱 자체의 움직임**:
  - 바퀴가 머무는 동안 덱이 (540, 900)을 축으로 −12° 돌고, 다음 전환에서 0으로 돌아온다(`main.js:329`, `main.js:334`).
  - 해의 길 팬은 덱의 `x`를 움직인다(`main.js:340`). 카드가 아직 날아드는 중에도 팬이 겹칠 수 있다.
  - 팬이 끝나는 순간 덱 `x`를 0으로 되돌리고, 그만큼 카드 `x`로 옮겨 준다. 보이는 위치는 변하지 않는다(`main.js:343-345`). 그래서 다음 전환이 스태거로 늦게 출발하는 카드도 제자리에 있다.
- **장식**(`main.js:220-291`): 모두 setup에서 잰 기하로 놓는다.
  - 계절 라벨은 격자 줄 첫 카드 위, 더미 라벨은 더미의 합집합 상자 위에 놓는다.
  - 바퀴 원은 `stroke-dashoffset`으로 그려진다.
  - 해의 길은 카드 중심을 Catmull-Rom 곡선(3차 베지에)으로 잇는다(`main.js:258`). 처음 보이는 화면만큼 먼저 그리고, 나머지는 팬과 같은 곡선으로 그려서 펜이 화면 오른쪽 끝을 따라간다(`main.js:336-337`).
  - 띠의 빈 칸은 `L-strip`에서 잰 입춘의 자리에 놓는다(`main.js:291`).

## 결정성 전략

- **Flip은 setup에서만 쓴다.**
  - Flip은 DOM을 재야 하므로 `Flip.getState`와 `Flip.fit`은 setup에서만 부른다. `Flip.from`은 쓰지 않는다.
  - `Flip.from`은 만들어지는 순간의 DOM을 끝 상태로 삼고 절대 위치 전환·`clearProps`를 콜백으로 처리하므로, 임의 seek에 기록 순서 의존성이 생긴다.
- **타임라인에는 숫자 트윈만 있다.**
  - 기록된 상태에서 뽑은 변환값(숫자)만 `paused: true` 마스터 타임라인의 `fromTo`로 넣는다(`main.js:294`).
  - `frame(t)`는 `tl.time(t)`만 한다(`main.js:378-380`). frame에서는 레이아웃을 읽지도 바꾸지도 않는다. 덱의 클래스는 늘 `L-grid`다.
- **from 값을 명시한다.**
  - 각 요소·속성의 첫 트윈은 `fromTo`(immediateRender)다. 이후 전환은 이전 변환을 from으로 명시한 `fromTo(immediateRender: false)`다.
  - setup 끝에서 `tl.time(D); tl.time(0)`으로 모든 트윈을 재생 순서대로 초기화한다(`main.js:374-375`).
- **한 시각에 같은 속성을 두 트윈이 다투지 않게 한다.**
  - 팬 넘기기는 1 ms 트윈(길이 0인 `set`은 방향에 따라 달라짐)으로 한다.
  - 다음 전환은 그보다 2 ms 뒤에 시작한다(`main.js:350`). 그래서 5.8초(30 fps 프레임 위)를 앞에서 오든 뒤에서 오든 같은 그림이다.
- **난수를 쓰지 않는다.** 배치는 모두 CSS와 데이터에서 나온다.

## 한계와 조정 손잡이

- **박자**: `main.js:24`(`T`)에서 입장·바퀴·줄·팬·계절·들기·펼치기·정보·낙관 시각을 정한다.
- **배치 기하**:
  - 바퀴 반지름·카드 폭: `main.js:90`(`WHEEL`).
  - 줄 카드 폭·간격·태양 고도 진폭: `main.js:91`(`ROW`).
  - 레이아웃 CSS: `main.js:106-116`. 격자 위치는 `padding`, 더미 부채꼴은 `9px / −10px / 2.4deg`로 정한다.
- **데이터**: 절기 이름·한자·날짜·황경·색·모티프는 `main.js:33-46`, 모티프 SVG는 `main.js:50-82`에 있다. 날짜는 해마다 하루쯤 달라지는 대표값이다.
- **전환 곡선과 스태거**: 각 `move(…, { dur, ease, delay })` 호출에서 바꾼다(`main.js:325`, `335`, `350`, `358`). 중첩 모핑의 늦음과 곡선은 `main.js:362-365`에 있다.
- **팬 속도**: 2692 px를 1.9초에(`T.scroll`–`T.scrollEnd`) 움직이며, 정점 속도는 약 2800 px/s다. 더 느리게 하려면 `ROW.w`를 줄이거나 팬 시간을 늘린다.
- **한계**:
  - 카드 전환은 Flip처럼 직선 경로를 지난다(호를 따르지 않는다).
  - 덱 회전·팬과 겹치는 구간은 두 변환이 합성되므로 곡선 경로가 된다.
  - 들기 고스트는 페이지 중심에 맞췄다. 페이지 판과 작은 카드가 같은 3:4라 판은 균일 배율이다. 반면 이름·한자 상자는 글꼴 크기 비율이 미세하게 달라 `scaleX ≠ scaleY`가 아주 조금 섞일 수 있다.
