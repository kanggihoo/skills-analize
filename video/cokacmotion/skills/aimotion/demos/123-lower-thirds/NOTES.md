# 123 · 모퉁이 라이브 — 방송 그래픽 패키지 · 로어서드 · 티커 · 버그 · 스팅어

> **가장 중요한 규칙: 기술만 가져간다.** 아래 "화면"은 이 데모가 그린 것이다. 기법을 보여 준 예일 뿐이니 소재·장면·이야기·구도·문구·색은 영상에 옮기지 않는다.
> 노트와 코드를 충분히 읽어 "기법과 원리"의 기술만 가져가고, 장면은 작업 중인 영상의 대본으로 새로 짓는다.

지어낸 세로 영상 채널 "모퉁이"의 방송 그래픽 패키지다. 디자인 시스템 하나(그리드, 색 토큰, 글꼴 한 쌍, 모서리 16px, 시그니처 동작 하나)를
여섯 요소에 똑같이 적용하고, 평면 일러스트로 그린 "카메라 샷" 두 개 위에서 차례로 들이고 내보낸다.
요소는 채널 버그, 주제 바와 라이브 티커, 이름 자막(로어서드), 전환 스팅어, 데이터 칩, 인용 카드다.
모든 바의 폭은 setup에서 잰 글자 폭으로 정한다. 9:16 안전 영역은 처음과 끝에 그려 보인다.
10초, 1080×1920. 장면은 Canvas 2D이고, 그래픽은 DOM(Pretendard + Roboto Flex)을 GSAP 타임라인 하나로 움직인다.

## 기법과 원리

**디자인 시스템**
- 토큰(`main.js:30-55`):
  - 색: 먹 #0d1730, 종이 #f7f3ea, 라임 하나. `style.css:2-6`에서 CSS 변수로도 둔다.
  - 단위·그리드: 8px 단위. 박스 치수는 모두 `snap`(`main.js:33`)으로 8의 배수로 올린다. 6단 그리드(124 + 거터 24)가 x 72–936에 놓인다.
  - 안전 영역(`SAFE`)과 앱 UI 영역(`APP`): `main.js:35-36`.
- 글자 크기 단계(`main.js:32`): 30px에서 ×1.25씩 24·30·38·47·59·73·92px. 쓰임은 다음과 같다.
  - 24: 라틴 대문자 라벨(LIVE)
  - 30: 티커, 출처, 칩 라벨
  - 38: 직함, 주제, 버그
  - 59: 인용
  - 73: 이름
  - 92: 칩 숫자
- 글꼴 한 쌍:
  - Pretendard: 한글과 숫자. 숫자에는 `font-variant-numeric: tabular-nums`를 준다.
  - Roboto Flex: 라틴 대문자 라벨. `wdth 84`, 자간 +0.12–0.14em.
- 굵기 위계: 이름 800 / 직함 400. 직함은 가벼운 굵기로 이름 아래에 둔다.
- 자간: 큰 글자일수록 좁힌다. 이름 −0.02em, 인용 −0.025em, 락업 −0.035em.

**시그니처 동작 "앞서는 라임, 따라오는 바"**(`main.js:110-124`, `style.css:12-17`)
- 바마다 두 겹이다. 라임 판(`acc`, 왼쪽으로 10px 더 김)과 먹/종이 판(`base`)이 같은 `clip-path: inset(0 calc((1 - var(--r)) * 100%) 0 calc(var(--l) * 100%) round 16px)`를 쓴다.
- 들어올 때: GSAP이 `--r`을 0 → 1로 움직인다. 라임이 먼저 가고 바가 75ms 뒤에 따라온다(CustomEase `sig`, `main.js:57`). 다 열리면 라임은 왼쪽 10px 탭으로 남는다. 움직이는 끝도 둥글다(`round 16px`).
- 나갈 때: 같은 길을 거꾸로, 더 빠르게 간다(0.26초 `power2.in`). 글자가 먼저 빠지고 바가 0.04–0.09초 뒤에 되감긴다.
- 스팅어(`main.js:360-383`): 같은 `bar`/`sigIn`을 1160×322 띠 여섯 장에 그대로 쓴다. 나갈 때만 `--l`(왼쪽 끝)을 열어 오른쪽으로 빠져나간다.
- 브랜드 마크는 한 모서리만 둥근 정사각형이다(`main.js:125`, "모퉁이"). 이 모양을 버그, 티커 구분자, 인용 따옴표(두 개를 180° 돌려 붙임, `main.js:324-326`), 락업, 명세 카드에 같이 쓴다.

**글자를 재서 바를 만든다**
- `textW`(`main.js:72`): 실제 글꼴·자간·숫자 설정으로 숨긴 DOM 요소에 조판하고 폭을 잰다. 무대 배율로 나눈다.
- 바 크기:
  - 이름 바 = 이름 폭 + 36×2
  - 직함 바 = 직함 폭 + 28×2
  - 버그 = 마크 + 낱말
  - 주제 바 = LIVE 칩 + 주제
  - 칩 = max(라벨, 숫자 + 단위)
  - 인용 카드 = max(줄 폭, 출처)
  - 모두 8px로 올린다(`main.js:185, 207, 259-261, 292, 319`).
- 넘칠 때: `fitStep`(`main.js:92`)이 글자를 크기 단계에서 한 칸씩 내린다. 주제와 직함에 건다. 지금 문구는 넘치지 않는다.
- 잉크 중심 맞추기(`opticTop`, `main.js:79`):
  - 줄 상자가 아니라 한글 음절의 잉크(`actualBoundingBox`)가 바 높이의 가운데에 오도록 위치를 계산한다. CSS 반행간 모형으로 기준선 위치를 구한 뒤 잉크 중심을 맞춘다.
  - LIVE는 대문자 잉크, 시계는 숫자 잉크 기준이다.
  - 칩의 "마리"는 `baseOf`(`main.js:86`)로 숫자와 기준선을 맞춘다.
- 줄바꿈(`balance`, `main.js:98`):
  - 어절(공백)에서만 끊는다. 두 줄 중 긴 줄이 가장 짧은 자리를 고른다.
  - "한 마리 더"와 "23년 차"는 NBSP로 묶어 끊기지 않게 한다. 그래서 인용은 "추운 날엔 / 한 마리 더 드려요"가 된다.
  - 핵심어 위치는 조판 뒤 잰 사각형으로 구한다. 밑줄 폭이 곧 그 어절들의 폭이다(`main.js:335-344`).
- 한국어 표기:
  - 성명은 붙여 쓴다(최말순).
  - "년 차"는 의존명사라 띄어 쓴다(23년 차).
  - 가운뎃점(·)은 앞뒤를 한 칸씩 띄운다.

**티커와 숫자**
- 크롤(`main.js:218-235`, `main.js:493-494`):
  - 항목 다섯 개와 구분자(브랜드 마크 14px, 양옆 26px)를 세 벌 이어 붙인다. 한 벌의 폭 `loopW`를 재고, `x = −((t − 0.84)·112 mod loopW)`로 끊김 없이 돈다.
  - 창 양끝은 `mask-image`로 34px 동안 흐려진다.
- 시계(`main.js:495-496`): 21:47:05에서 매초 오른다. 숫자 폭이 같아서 상자가 흔들리지 않는다.
- 칩(`main.js:497-504`):
  - 앞자리 문자열과 일의 자리 칸(숫자 폭 하나, `overflow: hidden`)으로 나뉜다.
  - 올라가는 동안은 글자만 바꾼다. 절정에서는 칸 안의 두 줄(d, d+1)을 `outBack`으로 한 칸 올린다(오도미터).

**층과 슬롯**(`main.js:173`)
- 층 순서: 장면 0 < 그레인·비네트 1 < 어둠막 2 < 슬롯 그래픽(이름 자막·칩·인용) 3 < 스팅어 4 < 상시 그래픽(버그·주제·티커) 5 < 가이드 6.
- 이름 자막과 인용 카드는 같은 슬롯(아래 1384에 바닥을 맞춤)을 시간으로 나눠 쓰므로 겹치지 않는다.
- 슬롯 지도는 setup에서 잰 `box`(`main.js:178`, `main.js:356`)로 그린다. 라벨의 W×H는 실제 바의 크기다.
- 가이드(`main.js:385-468`):
  - SVG로 그린다. 빗금 패턴, `pathLength=1`과 `stroke-dashoffset`으로 선이 그려지는 효과를 낸다.
  - 라벨만 DOM 글자(패키지 글꼴)로 쓴다.

**장면**(`scene.js`)
- 깊이별 카메라(`scene.js:69`): 골목 0.35, 차양 1.1, 인물 1.0, 계산대 1.15, 앞눈 1.4. 깊이마다 밀기·핸드헬드 양이 다르다.
- 골목은 setup에서 `filter: blur(16px)`로 한 번 굽는다(`scene.js:43`). 보케·눈·김은 매 프레임 닫힌 식으로 그린다.
- 인물(`scene.js:196`):
  - 숨쉬기, 고개 기울임, 깜빡임 시각표, 말하기 구간의 입 모양(초당 12음절 표).
  - 네온 쪽 가장자리 빛과 털모자의 골지.
- 붕어빵(`scene.js:333`):
  - 외곽 반죽 테두리, 구움 정도(tone), 비늘 양각(어두운 호 + 밝은 호), 아가미, 꼬리 결.
  - 갈라진 것은 지그재그 클립 두 개와 팥소로 그린다(`scene.js:372`).
  - 내려놓는 동작과 김은 `scene.js:513-550`.

## 결정성 전략

- **그래픽**: 타임라인은 `gsap.timeline({ paused: true })` 하나다.
  - 각 속성의 첫 트윈은 `fromTo`이고, setup 끝에서 `tl.time(D); tl.time(0)`으로 모든 트윈을 기록 순서대로 초기화한다(`main.js:470`).
  - `frame(t)`는 `tl.time(t)` 뒤에 닫힌 식 값만 쓴다(`main.js:474-505`): 크롤 `translate`, 시계·칩 글자, 버그 마크 회전, LIVE 점.
  - GSAP이 맡은 `transform`과 frame이 쓰는 `translate`는 서로 다른 속성이다.
  - 길이 0인 `set`은 쓰지 않는다.
- **장면**: 매 프레임 2D 컨텍스트 상태(변환, 알파, 합성, 필터, 선 끝, 점선)를 기본값으로 되돌린다(`main.js:478-480`). 그다음 t의 닫힌 식으로 그린다.
  - 흩어짐 표(눈, 보케, 김, 음절)는 `rand(12301)`로 setup에서 굽는다.
  - 블러는 setup에서 한 번만 쓴다(구운 골목). 헤드리스에서는 `willReadFrequently` 캔버스에 굽는다.
- **그레인**: setup에서 `rand(9123)`으로 한 번 만든다. 프레임마다 `floor(t·12)`로 정한 정수 오프셋만큼 옮긴다.
- 렌더 검사 결과: 앞→뒤와 뒤→앞(새 페이지), 되돌아오기 모두 바이트 단위로 같다(`maxPixelDiff 0`).

## 한계와 다음 단계

- 글자 폭은 setup에서 한 번 잰다. 문구를 런타임에 바꾸는 패키지라면 `bar`를 다시 만들어야 한다.
- `fitStep`은 크기만 내린다. 직함이 두 줄이 되어야 하는 길이는 처리하지 않는다(`balance`를 이름 자막에도 쓰면 된다).
- 인용 카드의 높이는 두 줄 기준이다. 세 줄 이상이면 슬롯 위쪽(칩 슬롯과의 간격)을 다시 확인해야 한다.
- 집게는 두 팔이 화면 밖 경첩에서 나온다. 화면 안에서는 젓가락처럼 보일 수 있다.
- 앱 UI 영역(위 160, 오른쪽 버튼 열 x > 936·y 880–1560, 아래 1560)은 특정 앱의 값이 아니라 흔한 세로 영상 앱 배치를 어림한 값이다.
- 소리는 없다. 스팅어에는 보통 효과음이 붙는다.
