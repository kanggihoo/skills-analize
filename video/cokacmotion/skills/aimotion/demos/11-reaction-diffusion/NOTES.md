# 11 · 스스로 그리는 무늬 — GPGPU 반응-확산 (Gray–Scott)

> **가장 중요한 규칙: 기술만 가져간다.** 아래 "화면"은 이 데모가 그린 것이다. 기법을 보여 준 예일 뿐이니 소재·장면·이야기·구도·문구·색은 영상에 옮기지 않는다.
> 노트와 코드를 충분히 읽어 "기법과 원리"의 기술만 가져가고, 장면은 작업 중인 영상의 대본으로 새로 짓는다.

## 화면

어두운 청록 바닥 위, 0초에 씨앗 하나가 희미하게 빛난다. 카메라는 2.3배로 다가가 있고, 씨앗이 호박색 구슬로 부풀었다가
**스스로 둘로 갈라지며**(유사분열) 고리 모양 군락을 이룬다. 1–3초 사이 다른 씨앗 다섯 개가 화면 밖에서 차례로 싹트고,
카메라가 물러나면 구슬 군락 여러 개가 서로를 향해 자라 화면을 채운다(~4초).
4–6.5초가 절정이다. 첫 씨앗을 중심으로 매개변수 파동이 퍼지면서 구슬이 길쭉해지고 서로 이어져 줄무늬가 되고,
산호 미로로 바뀐다. 색도 호박색에서 산호색으로 넘어가고, 새로 생긴 무늬의 앞쪽 가장자리가 금빛으로 잠깐 빛난다.
그사이 따뜻한 키 라이트가 쓸고 지나가며 젖은 표면에 반사광이 미끄러진다.
6.5–9초는 여운이다. 미로가 자리 잡고 가장자리는 다시 구슬(동물 가죽 무늬)로 돌아가며, 카메라가 천천히 다시 다가가
윤기 있는 관 모양 입체를 보여준다. 위·아래는 피사계 심도로 흐려지고 앞쪽에는 초점이 나간 부유 입자가 떠다닌다.

## 기법과 원리

- **상태 = RGBA32F 텍스처 하나**(360×640): r=u, g=v, a=처음 v>0.18이 된 시각(birth). 핑퐁 두 장(`main.js:326`).
- **Gray–Scott 한 스텝**(`main.js:80`): 9점 라플라시안(인접 0.2, 대각 0.05, 중심 −1, `main.js:90`), Du=1, Dv=0.5, dt=1의
  명시적 오일러. 경계는 좌표 clamp(노이만). `texelFetch`만 쓰고 필터링 샘플은 쓰지 않는다. SwiftShader에서
  `texture()`+LINEAR는 2–3배 느렸다. 비디오 1프레임에 **110회 반복**(`main.js:28`, 9초 동안 29,700회).
- **공간·시간에 따라 변하는 feed/kill**(`main.js:65`): 첫 씨앗에서 퍼지는 파동 `wave(n)`(`main.js:249`)와 fBm 노이즈로
  p∈[0,1]을 만든다. p=0은 유사분열 구슬(f=0.0367, k=0.0649), p=1은 산호(f=0.0545, k=0.062)이고, 그 사이에 벌레/줄무늬 영역이 있다.
  `outer(n)`(`main.js:250`)은 끝무렵 가장자리를 다시 구슬로 되돌린다. 매 스텝 파라미터 텍스처로 한 번 굽는다.
- **씨앗**(`main.js:18`, `main.js:51`, `main.js:339`): `rand(11)`로 위치를 흔든 6개의 원반. 정해진 스텝 번호에
  v를 주입하며, 가장자리는 각도 노이즈로 들쭉날쭉하게 만든다. 첫 씨앗은 `init()`에서 심는다.
- **표면 렌더**(매 프레임, 시뮬레이션 해상도에서):
  1. 마스크 패스(`main.js:100`): v를 smoothstep으로 날카로운 무늬 마스크로 바꾸고, birth로부터 "갓 자란" 글로우를 만든다.
  2. 마스크를 가우시안 블러(분리형 2패스)한 것을 **높이**로 쓴다. 고원(plateau)이 둥근 돔이 되어 관·구슬처럼 보인다.
     그 기울기로 노멀을 만든다(`main.js:110`).
  3. 4× 다운샘플 + 블러(`main.js:121`, `main.js:135`): AO, 블룸, "도달한 영역" 마스크, 재질 p.
- **최종 셰이더**(`main.js:148`): 4탭 **3차 B-스플라인 업샘플**(`main.js:154`)로 3–7배 확대에도 텍셀 각이 보이지 않게 하고,
  `fwidth` 기반 재임계(`main.js:185`)로 줌과 무관하게 경계를 선명하게(안티에일리어싱 포함)유지한다.
  쓸고 지나가는 키 라이트(wrap diffuse) + 차가운 필 + Blinn 스페큘러 두 겹 + AO(`main.js:200–211`),
  빛 웅덩이(`main.js:203`), 피사계 심도(초점 띠 밖은 블러된 높이로 섞기, `main.js:181`),
  성장 글로우와 블룸(`main.js:216`), 낮은 주파수의 색조 변화(`main.js:192`), 초점 나간 부유 입자(`main.js:165`),
  톤매핑·비네트·그레인.

## 결정성 전략

- `replay({ dt: 1/30, every: 30 })`(`main.js:345`): 비디오 프레임 하나 = 스텝 하나(110회 반복). 스텝 내용은 n만의 함수다
  (씨앗 스케줄, `wave(n)`, `outer(n)`, birth 시각 = n/30/9).
- `save()`는 새 RGBA32F 텍스처를 만들어 `blitFramebuffer`(NEAREST)로 GPU 안에서 복사하고, `load()`는 거꾸로 복사한다
  (`main.js:365–366`). 체크포인트 0은 씨앗을 심은 직후 상태라서, 루프가 끝나 0으로 돌아가면 이것이 복원된다.
- 렌더 전용 텍스처(마스크, 블러, 파라미터)는 **매 프레임 n으로부터 다시 만든다**. 파라미터 맵도 렌더에서 다시
  계산하므로(`main.js:371`) 체크포인트 로드 뒤에 낡은 값이 남지 않는다.
- 하네스 우회: 헤드리스에서만(`?render`) 스텝마다 1픽셀 `readPixels`로 GPU를 기다린다(`main.js:360`). 이게 없으면
  긴 seek의 GPU 작업이 전부 스크린샷 쪽으로 밀려 Playwright의 30초 스크린샷 타임아웃에 걸렸다. 라이브 재생에서는 실행하지 않는다.
- 결과: 앞→뒤 / 뒤→앞(새 페이지) / 점프백 모두 픽셀 일치(`deterministic: true`).

## 지표 (out/metrics.json)

| 항목 | 값 |
|---|---|
| deterministic | true |
| frameMsAvg / frameMsMax | 10,159 ms / 13,782 ms |
| setupMs | 377 |
| loc | 409 |
| errors | 없음 |

- `frameMsAvg`는 시트를 위해 1초 간격으로 seek한 비용이다. 상태형 시뮬레이션이라 **샘플 하나 = 30스텝 + 캡처**이므로,
  비디오 1프레임에 해당하는 헤드리스 비용은 약 **340 ms**(=10,159/30)다. CPU가 거의 놀 때 이전 렌더러로 270프레임을
  순차 렌더했을 때도 0.41 s/프레임이었다. 이번 측정은 머신에 부하가 걸린 상태에서 했다.
- 실제 GPU에서는 스텝 하나가 360×640에 110회 반복(텍셀 접근 약 2.5천만 회)이고 표면·최종 패스가 몇 ms라서,
  프레임당 수 ms~십수 ms로 예상한다(직접 측정하지는 않았다).

## 한계와 다음 단계

- 명시적 오일러라 Du·dt가 안정 한계에 가깝다. 무늬 크기는 격자 셀 수(약 10셀)로 정해지므로 화면에서의 크기는
  해상도로만 조절된다.
- 360×640을 3배 업샘플한다. 경계 재임계로 선명하지만 아주 가는 구조는 표현할 수 없다. 실제 GPU라면 720×1280으로 올릴 만하다.
- 높이를 블러한 마스크로 근사하므로, 엄밀한 의미의 3D 표면(자기 그림자, 시차)은 없다. 다음 단계로 높이 기반
  스크린 공간 그림자나 비스듬한 카메라(perspective tilt)와 레이마칭 릴리프를 해 볼 만하다.
- 매개변수 파동은 손으로 짠 스크립트다. 이미지(글자, 로고)를 feed/kill 맵으로 써서 "무늬가 글자를 그리는" 연출로 확장할 수 있다.
