# 89 · 세 번 찍는 도장 — 임팩트 키트 · 한 박자를 세게 만드는 겹침

> **가장 중요한 규칙: 기술만 가져간다.** 아래 "화면"은 이 데모가 그린 것이다. 기법을 보여 준 예일 뿐이니 소재·장면·이야기·구도·문구·색은 영상에 옮기지 않는다.
> 노트와 코드를 충분히 읽어 "기법과 원리"의 기술만 가져가고, 장면은 작업 중인 영상의 대본으로 새로 짓는다.

10초, 1080×1920. 같은 도장이 같은 높이에서 세 번 떨어진다. 바뀌는 것은 겹친 효과의 수뿐이다(톡 3겹 → 탁 6겹 → 쾅 10겹).
아래 패널이 효과마다 켜지는 순간을 보여 주어 "예산을 어디에 쓰는지"가 보이고, 종이에 남은 도장 자국 셋이 그 결과를 나란히 비교한다.

## 화면

어두운 남색 펠트 깔판 위에 한지 서식 「한 박자 연습장」이 놓여 있다. 서식에는 결재란처럼 생긴 세 칸(작게 · 중간 · 크게)과 칸마다 「(인)」 자리가 인쇄되어 있다.
왼쪽 위에는 붓, 오른쪽 위에는 청자 인주함이 있고, 위쪽에서 따뜻한 등불빛이 비친다. 도장은 회양목 원통이다. 금색 띠와 둥근 꼭지가 있고 바닥에는 인주가 묻어 있다. 모두 잉크 외곽선을 두른 평면 그림이다.

| 시간 | 무엇이 보이나 |
|---|---|
| 0–0.9 s | 빈 서식에서 시작한다. 「같은 도장, **세 번** 찍는다」가 떠오르고, 도장이 위에서 내려와 떠 있는 자리에 멈춘다. 아래에서 패널(레이어 10칸, `0 / 10겹`)이 올라온다. |
| 0.5–1.4 s | 카메라가 첫 칸으로 다가간다(배율 1.12 → 1.38). 도장은 위아래로 천천히 떠 있다. |
| 1.5–2.4 s | **① 작은 톡.** 도장이 조금만 들렸다가(예비) 가볍게 내려앉는다. 작은 먹색 「톡」이 뜨고 back.out으로 제자리에 돌아온다(안착). 남은 자국은 왼쪽 아래 가장자리만 닿은 얼룩덜룩한 초승달이다. 패널은 `3 / 10`. |
| 2.4–3.1 s | 도장이 호를 그리며 둘째 칸으로 옮겨 가고, 카메라도 따라간다. 패널이 비워지고 「② 중간 탁」으로 바뀐다. |
| 3.25–4.4 s | **② 중간 탁.** 더 높이 들고 뒤로 젖혀 잠깐 겨눈다. 빠르게 내리꽂히며 속도선이 생기고, 닿는 순간 한 프레임 멈춘다(멈춤). 이어 작은 흔들림, 먹색 링, 「탁!」이 나온다. 자국은 75% 정도 찍히고 가장자리가 끊겨 있다. `6 / 10`. |
| 4.4–5.1 s | 위의 제목이 빠져나가 하늘을 비운다. 도장이 셋째 칸으로 가고, 카메라는 1.45배로 조금 더 다가간다. |
| 5.07–5.79 s | **③ 큰 쾅의 예비.** 도장이 화면 위쪽까지 크게 들린다. 높이에 따른 원근으로 커 보이고, 10° 젖히고 늘어난다. 0.22초 동안 떨며 겨누는 사이 카메라가 기울어 다가가고 화면 가장자리가 어두워진다(긴장 비네트). |
| 5.79 s | **절정.** 0.09초 만에 내리꽂힌다. 닿은 뒤 두 프레임(0.067 s) 동안 세상이 멈춘다. 이때 도장은 찌그러져 있고 섬광은 0.32에 머문다. |
| 5.86–6.5 s | 멈춤이 풀리면 0.02초 간격으로 반응이 겹쳐 터진다: 펀치(1.035배), 감쇠 흔들림(24 px), 주홍 링과 먹색 링, 파편(인주 방울 34·종이 조각 14·불꽃 20), 금색 별폭발 위의 「쾅!」, 테두리 밖으로 밀려 나오는 먼지 구름. 인주 방울은 포물선을 그리고 종이에 떨어져 점으로 남는다. 패널은 한 칸씩 켜지며 `9 / 10`이 된다. **포스터 6.0 s.** |
| 6.3–7.5 s | 도장이 눌린 채 잠시 머문다. 이어 back.out(1.8)으로 튀어 올라 안착하고(`10 / 10`), 바닥 아래로 선명한 「됐다」 자국과 튄 인주가 드러난다. 「쾅!」은 한 번 부풀었다가 줄어들며 사라지고, 도장은 오른쪽으로 들려 나간다. |
| 6.9–8 s | 카메라가 물러나 세 칸이 나란히 보인다. 「겹칠수록 / **세게** 꽂힌다」와 「다 겹치는 건 큰 박자 한 번만」이 들어온다. 칸 아래에는 「톡 · 3겹」「탁 · 6겹」「쾅 · 10겹」 알약이 차례로 튀어나온다. |
| 8–10 s | 여운. 카메라가 천천히 밀고 들어가고, 젖은 셋째 자국 위로 빛줄기가 한 번 지나간다. 등불 먼지가 떠다닌다. |

글꼴(모두 `FONTS` 등록, OFL 1.1):
- Pretendard 900/800: 제목, 패널
- Hahmlet 900/800/700: 서식 인쇄, 도장 글자 「됐다」
- 검은고딕(Black Han Sans): 의성어

## 기법과 원리

**박자 하나 = (t − t_hit)의 닫힌 식 묶음** (`kit.js`)

| 레이어 | 식 | 위치 |
|---|---|---|
| 예비·슬램·안착 | 구간별 포즈. ① 들기(outCubic) ② 겨눔(sin 떨림) ③ 슬램(진행률^pow, 톡 2 · 탁 3 · 쾅 4) ④ 멈춤 ⑤ 누름 ⑥ back.out 안착. 닿은 뒤 찌그러짐은 `1 − sq·e^(−9s)·cos(26s)`로 감쇠 진동하고, 가로는 `sx = 1 + (1 − sy)·0.75`로 부피를 지킨다. | `main.js:63` `beatPose` |
| 멈춤(hit-stop) | 시간 비틀기 `tw = t − Σ min(max(t − hit, 0), stop)`. 카메라와 GSAP 타임라인, 떠 있는 먼지, 떠 있는 도장의 흔들림이 tw를 읽으므로 멈춤 동안 세상 전체가 정지한다. 반응 레이어는 해제 시각 `rel0 = hit + stop`부터 시작한다. | `kit.js:25`, `main.js:231` |
| 섬광 | 닿는 순간 peak(0.32)로 뛰고, 멈춤 동안 유지하다가 power2.out으로 0.42 s 동안 꺼진다. | `kit.js:32`, `main.js:335` |
| 펀치 | 0.07 s 동안 outQuad로 +0.035, 0.5 s 동안 outCubic으로 0. CSS `scale` 속성에 쓴다. | `kit.js:41` |
| 흔들림 | `(1 − p)²` 포락선을 건 어긋난 sin 두 개(1 : 1.13). CSS `translate` 속성에 쓴다. | `kit.js:48` |
| 링 | 반지름은 expo.out, 선 굵기는 가늘어지고, 알파는 `(1 − k)^1.3`. 종이 평면에 있으므로 세로로 0.9배 눌렀다. | `kit.js:56`, `main.js:269` |
| 파편 | 평면에서는 항력 `p = p0 + v·(1 − e^(−ks))/k`, 높이는 중력 `z = vz·s − ½gs²`이다. 착지 시각 `s_L = 2vz/g`가 지나면 그 자리에 점으로 남는다. 불꽃은 항력만 받는 금색 쐐기다. | `kit.js:101` `fly`, `main.js:366` |
| 의성어 | 0.3 → peak(0.12 s, outQuad) → back.out(3)으로 1 → 유지 → 퇴장. 퇴장은 back.in으로 한 번 부풀었다가 줄어든다(반투명 겹침이 생기지 않게). 외곽선은 둥근 이음의 strokeText 세 겹(그림자·먹·크림)이다. | `kit.js:64`, `art.js:383`, `main.js:429` |
| 먼지 | 항력만 받는 퍼프가 커졌다가 줄어든다. 모든 원의 외곽선을 먼저 긋고 그 위에 채우기를 하면 합집합의 바깥선만 남아 한 덩어리 구름이 된다. | `main.js:406` |

**겹침의 순서와 예산**(`main.js:35–53`)
- 박자마다 `use` 목록이 있다(톡 3 · 탁 6 · 쾅 10).
- 레이어의 발사 시각은 한 규칙으로 정해진다. 예비는 들기 시작, 멈춤·섬광은 접촉, 반응 여섯은 해제 후 0.02 s 간격, 안착은 누름이 끝날 때다.
- 같은 시각표가 그림과 패널을 함께 움직인다. 그래서 칩이 켜지는 순간이 곧 그 효과가 시작되는 순간이다(`main.js:460` `updatePanel`).

**채널 분리: 한 요소에 세 움직임이 섞이지 않고 더해진다**(`main.js:325`)
- 카메라(이동·배율)는 GSAP이 트윈하는 `cam` 객체를 캔버스 변환으로 그린다. 확대해도 벡터가 선명하다.
- 펀치는 world 요소의 CSS `scale`, 흔들림과 핸드헬드는 CSS `translate`에 쓴다. 셋은 서로 다른 속성이라 서로 덮어쓰지 않는다. fxkit의 `addOffset`과 같은 원리다.
- 패널은 흔들림을 30%만 받는다.

**자국 굽기**(`art.js:244` `bakePrint`, 압력 함수 `main.js:156`)
- 도장 면을 백문으로 만든다. 불규칙한 원판을 칠하고, 고리와 「됐다」를 `destination-out`으로 파낸다.
- 픽셀마다 덮임을 `smoothstep(P + (fbm − 0.5)·A + 잔결)`로 곱한다. P는 그 점의 압력이다.
  - 톡: 왼쪽 아래 입술만 닿는 기울기라, 얼룩진 초승달이 남는다.
  - 탁: 약 0.7로 고른 압력이다.
  - 쾅: 0.97이다. 테두리로 갈수록 진해지고(밀려난 인주), 테두리 밖에 위성 점 26개가 생긴다.

**도장 그리기**(`art.js:300` `drawSeal`): 평면 일러스트에서 흔히 쓰는 눈속임이다.
- 종이는 위에서 본 모습, 도장은 3/4 입면으로 그린다.
- 바닥 타원의 가장 낮은 점이 찍히는 원의 아래 끝과 맞는다. 그래서 몸통이 자국을 완전히 가리고, 들어 올리면 자국이 아래부터 드러난다.
- 높이 h는 화면 위쪽 이동과 원근 배율 `1 + h/1400`으로 바꾼다. 그림자는 종이에 남아 h만큼 밀리고 흐려진다.
- 방울·조각·불꽃·먼지는 뒤로 날아가는 것(`dy < −0.25`)만 도장보다 먼저 그려 몸통에 가려지게 했다(`main.js:281`, `main.js:301`).

**배경 굽기**(`art.js:78` `bakeDesk`): 펠트·한지·서식·소품을 setup에서 1.4배 해상도의 비트맵 하나로 굽는다.
- 펠트: 털, 등불빛.
- 한지: 들쭉날쭉한 가장자리, 구름 같은 지합 얼룩, 섬유 1100가닥, 껍질 티, 그레인.
- 인쇄된 서식, 붓, 인주함.

frame에서는 `drawImage` 한 번으로 그린다. 「(인)」은 매 프레임 그린다. 둘째·셋째 칸은 자국이 찍힌 순간(몸통이 가리고 있을 때) 지운다(`main.js:241`).

**GSAP의 몫**(`main.js:203–225`)
- paused 타임라인 하나가 카메라 경로, 제목 입·퇴장, 패널 입장, 박자 이름 교체, 마무리 알약, 빛줄기를 맡는다.
- frame은 `tl.time(tw)`만 부른다.
- 효과 자체는 GSAP에 맡기지 않고 닫힌 식으로 쓴다.

## 결정성 전략

- 그림은 t의 순수 함수다.
  - 효과는 모두 `rel = t − 발사시각`의 닫힌 식이다.
  - 파편 표(방향·속도·크기·지연)는 setup에서 `rand(seed)`로 만든다.
  - 착지 여부도 `s ≥ 2vz/g`로 매번 다시 계산한다. 앞 프레임의 상태를 남기지 않는다.
- 히트스톱은 상태가 아니라 시간 비틀기다. `warp(t)`는 t만으로 정해지므로 어느 방향으로 seek해도 같은 프레임이 나온다.
- GSAP: 각 대상의 첫 트윈은 `fromTo`다. setup 끝에서 `tl.time(D); tl.time(0)`으로 모든 트윈을 재생 순서대로 초기화한다(`main.js:225`).
- DOM 쓰기(translate, scale, 칩 상태)는 값 문자열이 바뀔 때만 한다. 비교 기준도 t에서 계산한 값이다.
- 한지 그레인은 고정 시드 LCG, 섬유와 자국 잡음은 `rand(seed)` 기반 value noise다. 모두 setup에서 한 번 굽고 `createImageBitmap`으로 고정한다.
- 렌더러 검사(정순 · 새 페이지 역순 · 되돌아가기): **pass**, 채널당 최대 1/255 차이(허용 4).

## 한계와 다음 단계

- **원근 눈속임**: 종이는 위에서, 도장은 3/4로 그린다. 높이 h를 화면 위쪽 이동으로만 바꾸므로, 아주 높이 든 순간에는 도장이 종이에서 떠 있는 거리가 실제 원근보다 짧아 보인다. 그림자 오프셋이 그 차이를 일부 메운다.
- **효과 순서**: 반응 여섯을 0.02 s 간격으로 고정했다. 박자의 성격에 따라 간격을 바꾸는 손잡이(`main.js:51`)는 있지만, 지금은 모든 박자가 같다.
- **떨어진 인주의 가림**: 점은 도장 몸통 아래(종이 층)에 그린다. 몸통 뒤쪽에 떨어진 점은 도장이 들릴 때 드러나는데, 이것은 의도한 것이다. 날아가는 동안의 앞뒤 판정은 방향(dy)만 본다.
- **소리**: 화면 속 「톡/탁/쾅」만 있고 실제 소리는 없다. Tone.js로 세 박자의 타격음(톡 짧은 클릭, 쾅 저음 + 잔향)을 구워 `onTransport`로 재생하면, 겹침의 차이를 귀로도 비교할 수 있다.
- **성능**: 헤드리스 CPU에서 프레임당 약 0.26–0.38 s, 대부분 1160×2000 캔버스 래스터와 캡처다. GPU 브라우저에서는 배경 비트맵 한 장, 벡터 도장, 입자 70여 개라 실시간 예산 안에 든다.
