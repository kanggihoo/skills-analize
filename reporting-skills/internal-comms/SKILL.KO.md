## 이 스킬을 사용할 때
사내 커뮤니케이션을 작성할 때 다음 경우에 이 스킬을 사용합니다.
- 3P 업데이트 (Progress, Plans, Problems)
- 사내 뉴스레터
- FAQ 답변
- 상태 보고
- 리더십 업데이트
- 프로젝트 업데이트
- 장애 보고서

## 이 스킬을 사용하는 방법

사내 커뮤니케이션을 작성할 때는 다음 순서를 따릅니다.

1. 요청에서 **커뮤니케이션 유형을 식별**합니다.
2. `examples/` 디렉토리에서 알맞은 가이드라인 파일을 **불러옵니다**.
    - `examples/3p-updates.md` - Progress/Plans/Problems 팀 업데이트용
    - `examples/company-newsletter.md` - 전사 뉴스레터용
    - `examples/faq-answers.md` - 자주 묻는 질문에 답할 때 사용
    - `examples/general-comms.md` - 위에 명확히 해당하지 않는 나머지 모든 경우에 사용
3. 해당 파일에 적힌 **세부 지침**(형식, 어조, 내용 수집 방법)을 따릅니다.

커뮤니케이션 유형이 기존 가이드라인 중 어디에도 맞지 않으면 원하는 형식에 대해 추가 설명이나 맥락을 요청합니다.
