# 워크플로 선택지 보여주기

사용자에게 어떤 흐름을 쓸지 물을 때는 상자와 연결선으로 된 다음 일반 텍스트 차트를 보여줍니다.

```text
┌────────────────────┐      ┌──────────┐
│ Research questions │─────▶│ Research │
└────────────────────┘      └────┬─────┘
                                 │
       ┌─────────────────────────┘
       │
       │    ┌──────────────────────┐
       ├───▶│ 1. Design discussion │───┐
       │    └──────────────────────┘   │
       │    ┌────────┐    ┌─────┐      │
       ├───▶│ 2. PRD │───▶│ TDD │──────┤
       │    └────┬───┘    └─────┘      │
       │         └─────────────────────┤
       │    ┌────────┐                 │
       ├───▶│ 3. TDD │─────────────────┤
       │    └────────┘                 │    ┌────────────┐
       │                               ├───▶│  Outline   │
       │                               │    │ (optional) │
       │                               │    └─────┬──────┘
       │                               └──────────┤
       │                                          ▼
       │      4. Research only             ┌─────────────┐
       └──────────────────────────────────▶│  Implement  │
                                           └─────────────┘
```

설계 논의, PRD, TDD는 각각 개요로 가거나 바로 구현으로 넘어갈 수 있습니다. PRD는 TDD로도 갈 수 있습니다. 사용자는 어느 단계에서든 시작할 수 있습니다.

요청을 바탕으로 흐름을 간단히 추천한 다음, 사용자가 어떤 흐름을 선호하는지 물어봅니다. 상자 그리기 문자를 사용하고, Mermaid는 사용하지 않습니다.

차트와 추천 옆에 다음 메모를 함께 넣습니다.

> 구현은 워크플로의 어느 단계에서든 시작할 수 있습니다. 그 단계의 문서가 작업을 충분히 명시하고 있다고 판단되면 알려주세요. 나머지 워크플로는 건너뛰고 바로 구현 단계로 넘어가겠습니다.
