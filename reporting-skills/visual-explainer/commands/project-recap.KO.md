---
name: project-recap
description: Generate a visual project recap for context switching
---

visual-explainer 스킬을 로드하고, 프로젝트에 다시 돌아오는 사람을 위한 시각적 프로젝트 요약을 만드세요.

`$@`에 `--quick`이 있으면 플래그를 제거하고 스킬의 Quick 모드를 따르세요. 그렇지 않으면 `$@`로 시간 범위를 지정할 수 있습니다(예: `2w`).

README, 변경 로그, 패키지/빌드 파일, 최상위 디렉터리 트리, `git status`, 최근 커밋, 열린 브랜치, 최근 변경된 파일의 TODO, 진행 상황이나 할 일 메모, 주요 진입점을 읽으세요. 명령 출력 또는 `file:line`을 인용하세요. 추진력을 지어내지 마세요.

일반적인 섹션입니다. 내용에 따라 병합, 재정렬, 삭제 또는 추가하세요:

| 섹션 | 피규어 |
|---|---|
| 이것은 무엇인가 | 한 문장 + 스택 칩 + 진입점 |
| 아키텍처 | 주요 모듈과 모듈 간 데이터 흐름의 SVG |
| 최근 활동 | 원시 로그가 아니라 주제별로 묶은 타임라인 |
| 현재 상태 | 커밋되지 않은 작업, 브랜치, 차단 요소를 상태 칩으로 |
| 핫스폿 | 변경 빈도와 위험도로 순위를 매긴 모듈(막대) |
| 명령과 파일 | 간결한 참조 표 |
| 다음 단계 | 근거에 기반한 다음 단계 체크리스트 |

스킬의 규칙에 따라 전달하세요.
