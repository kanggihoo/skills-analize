# 말하는 사람 위의 카드

사람이 말하는 영상 위에 올리는 디자인된 카드, 로어서드, 분할 레이아웃이다. 배치 수치는 1920×1080과 1080×1920 기준이며, 다른 해상도는 비율에 맞춰 조정한다.

## 영상의 위치

| 레이아웃                     | 가로 (x, y, w×h)      | 세로 (x, y, w×h)     |
| ---------------------------- | --------------------- | -------------------- |
| Split, 카드 옆에 영상        | 960, 0, 960×1080      | 0, 960, 1080×960     |
| Stack, 영상이 위             | 14, 14, 1892×548      | 0, 0, 1080×844       |
| Overlay                      | 전체 프레임           | 전체 프레임          |

Picture-in-picture는 가장자리에서 28 px 떨어뜨린다(오른쪽 아래는 y = H − h − 28):

| 캔버스    | 소스 | 사각형            |
| --------- | ---- | ----------------- |
| 가로      | 16:9 | 1432, 28, 460×258 |
| 가로      | 9:16 | 1644, 28, 248×440 |
| 세로      | 16:9 | 690, 28, 360×203  |
| 세로      | 9:16 | 738, 28, 312×555  |

- 카드 영역: 로어서드는 아래 30%, 사이드 패널은 가로에서 오른쪽 42%, 세로에서 아래 40%다. 글래스 카드 슬롯은 가로 48, 460, 660×540, 세로 24, 1280, 1032×564다.
- 세로 화면의 글자는 가로 값의 1.3배로 쓴다(제목은 1.35배, 수치는 1.4배). 패딩은 40~64 px에서 24~36 px로 줄인다.
- 사각형은 소스 비율에 맞춘다. `object-fit: cover`는 가로 박스에 들어간 세로 소스를 잘라 낸다.

## 타이밍

- 카드는 0.4 s(`power2.out`)에 나타나고 0.35 s(`power2.in`)에 사라진다. 영상 리프레이밍(0.5~0.7 s)은 카드와 카드 사이의 빈 구간에서만 한다. `left`, `top`, `width`, `height` 대신 래퍼의 transform으로 움직인다.
- 정지된 카드는 약 8 s 뒤부터 죽은 화면처럼 보인다. 15 s를 넘기면 단계적으로 드러내야 한다. 시작 밀도의 기준은 이렇다. 1분 미만은 6~8 s마다 카드 하나, 3분까지는 8~12 s, 10분까지는 12~20 s다.
- 전사 결과의 마지막 단어가 미디어 길이를 넘어갈 수 있다. 카드의 끝과 루트 `data-duration`을 파일의 ffprobe 길이에 맞게 자른다. 그렇지 않으면 렌더 결과가 검은 화면으로 끝난다.

## 주의할 점

- 로어서드, 오버레이, picture-in-picture 장면은 루트가 투명해야 한다. 그렇지 않으면 화자를 가린다.
- 밝은 영상 위의 글래스는 흰 배경 위의 흰 글자가 된다. 어두운 스크림을 뒤에 깐다(위에서 아래로 `rgba(0,0,0,.55)`에서 점점 옅어지고, 아래는 `.72`), 그 위에 `backdrop-filter: blur(22px)`를 준 어두운 글래스 바탕(예: `rgba(15,16,22,.78)`)을 쓴다.
- 한 트랙에 시간이 있는 요소가 3개를 넘으면 `timeline_track_too_dense` 경고가 뜬다. 챕터마다 sub-composition을 따로 준다.
- 키프레임 간격이 약 1 s를 넘는 영상은 seek할 때 멈춘다. `-g <fps>`로 다시 인코딩한다.

영상과 인물 컷아웃 사이에 두는 텍스트(영상 위, 컷아웃 아래의 캡션)는 `captions.md`를 본다.
