# 첫 원리부터 다시 설계하기

변경 사항을 통합할 때 기존 설계에 덧붙이지 않는다. 요구사항이 처음부터 있었던 것처럼 다시 설계한다.

- 영향을 받는 모든 파일을 읽고 현재 설계를 이해한다
- 질문한다: "이 새 요구사항을 가지고 처음부터 작성한다면, 무엇을 만들 것인가?"
- 변경 사항을 모든 참조에 반영한다: 타입, 문서, 예제, 근거 섹션
- 전체 재설계를 생각한 뒤, 점진적으로 제공한다

이것은 변경 사항을 기존 설계에 통합할 때 선택지의 가치를 보존하는 방법이다.
